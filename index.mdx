<div className="ct-section">
  <div className="ct-kicker">Quick answers</div>
  <h2>Is it a fit?</h2>

| Question | Short answer | Details |
|---|---|---|
| What does it connect to? | Clouds (AWS, Google Cloud, Azure), Kubernetes, Git hosts (GitHub, GitLab, Bitbucket, Azure DevOps, CodeCommit), alert sources such as Datadog and PagerDuty, IaC such as Terraform, and ticketing such as Jira | [Connection catalog](/guide/connections/overview#connection-catalog) |
| What can agents touch? | Only what your connections allow. Agents can read anything a connection's credential can read, so scope the role or token to what you want them to see. Turn off **Allow writes** on a connection and every change to it is refused. | [How access works](/guide/connections/overview#how-access-works) |
| Where does it run? | CloudThinker Cloud, a managed service at `app.cloudthinker.io`. Workers, a dedicated cloud, and self-hosted deployments are available on request. A dedicated cloud runs in a region you choose. These docs don't publish the shared service's region, so ask for it when you contact CloudThinker. | [Deployment](/guide/deployment/overview) |
| Where do I use it? | The web app, the [CLI](/guide/cli/overview), [Slack](/guide/slack-integration), [Google Chat](/guide/google-chat-integration), and [Microsoft Teams](/guide/teams-integration) | |
| What does it cost? | Plans are priced per seat and include credits, the unit agent work uses. Team starts at $25 per seat a month with 200 premium credits per seat. Every chat message and product run spends credits. The Free plan gives 100 daily free credits for chat on the Light model. Product runs start on Team. | [Pricing](/guide/billing/pricing), [Usage](/guide/billing/usage) |
| How do I review it for my company? | Identity, data handling, access, and audit in one place | [Security overview](/guide/security/overview) |
