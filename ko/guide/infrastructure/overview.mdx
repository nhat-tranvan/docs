인프라 모듈은 연결된 모든 클라우드의 모든 리소스에 대한 단일 운영 뷰와, 이를 기반으로 행동할 수 있는 에이전트를 제공합니다. 콘솔 간 이동 없이 자산을 검색하고, 의존성을 추적하고, 아키텍처를 평가하고, 복구를 추적하세요.

클라우드 환경은 계정, 리전, 프로바이더 전반에 걸쳐 분산되어 있어 무엇이 실행 중인지, 어떻게 연결되어 있는지, 모범 사례를 따르고 있는지 한눈에 볼 수 있는 단일 콘솔이 없습니다. 인프라 관리는 [Alex](/ko/guide/agents/alex), [Oliver](/ko/guide/agents/oliver), [Kai](/ko/guide/agents/kai), [Tony](/ko/guide/agents/tony), [Anna](/ko/guide/agents/anna)가 모두 공통으로 사용하는 공유 인벤토리로 콘솔 간 전환을 대체합니다. 그 결과 비용 급등과 그 이면의 잘못된 구성이 동일한 조사에서 함께 드러납니다.

## 작동 방식

1. **검색** — [리소스](/ko/guide/infrastructure/resources)가 연결된 클라우드 계정을 스캔하고 컴퓨팅, 스토리지, 데이터베이스, 네트워크 자산의 실시간 인벤토리를 유지합니다.
2. **매핑** — [토폴로지](/ko/guide/infrastructure/topology)가 해당 인벤토리에서 의존성 그래프를 구축하여 어떤 서비스가 무엇에 의존하는지와 장애의 폭발 반경을 보여줍니다.
3. **평가** — [평가](/ko/guide/infrastructure/assessment)가 6가지 기둥 전반에 걸쳐 자동화된 Well-Architected 검토를 실행하고 구현 단계가 포함된 우선순위가 지정된 결과를 제공합니다.
4. **분석** — [분석](/ko/guide/infrastructure/analytics)이 클라우드 전반의 상태, 성능, 비용 신호를 상관 분석하여 리소스 경합과 과잉 지출을 구분할 수 있게 합니다.
5. **실행** — [계획](/ko/guide/infrastructure/plan)이 결과와 권장 사항을 추적 가능한 작업 항목으로 변환하고 식별에서 구현까지 추적합니다.

## 가능한 작업

| 기능 | 설명 | 자세히 보기 |
|---|---|---|
| 리소스 인벤토리 | AWS, GCP, Azure 전반의 모든 자산을 필터링, 태그 지정, 조치 | [리소스](/ko/guide/infrastructure/resources) |
| 의존성 매핑 | 서비스 관계와 더 빠른 근본 원인 분석을 위한 폭발 반경 추적 | [토폴로지](/ko/guide/infrastructure/topology) |
| Well-Architected 평가 | 우선순위가 지정된 결과를 포함한 6가지 기둥 전반의 자동화된 검토 실행 | [평가](/ko/guide/infrastructure/assessment) |
| 멀티 클라우드 분석 | 하나의 뷰에서 상태, 성능, 비용 신호 상관 분석 | [분석](/ko/guide/infrastructure/analytics) |
| 작업 계획 | 식별에서 구현까지 결과와 권장 사항 추적 | [계획](/ko/guide/infrastructure/plan) |

<Info>
절감액 분석이나 상시 모니터링을 원하시나요? 비용 권장 사항과 절감액 추적은 [CostOps](/ko/guide/cost-optimization/overview)에 있습니다. 지속적인 드리프트, 낭비, 잘못된 구성 검사는 [CloudKeepers](/ko/guide/infrastructure/cloudkeepers)로 실행됩니다.
</Info>
