artifact는 CloudThinker가 대화 중에 만드는, 저장되고 버전이 관리되는 결과물입니다: 리포트, 대시보드, 생성된 파일이 있습니다. 평이한 말로 요청하면 CloudThinker가 [연결](/ko/guide/connections/overview)을 조회하고, 결과는 **Library**에 들어갑니다. 워크스페이스는 Library에서 결과물을 열고, 다운로드하고, 공유할 수 있습니다. Library에는 Docs도 들어 있습니다.

## 사전 요구 사항

- artifact에 넣을 데이터가 있는 [연결](/ko/guide/connections/overview)이 하나 이상 필요합니다(예: 비용은 AWS, 쿼리 성능은 데이터베이스)
- 실시간 데이터(**Use live data**, **Refresh**)를 쓰려면 유료 [플랜](/ko/guide/billing/pricing)이 필요합니다. Free 플랜에서는 artifact가 게시된 스냅샷만 표시합니다.
- 하려는 작업을 허용하는 [워크스페이스 역할](/ko/guide/workspace-users):

| 작업 | Admin | Developer | Viewer |
|---|---|---|---|
| 대화에서 artifact 만들기 | 예 | 예 | 아니요 |
| artifact 열기 및 다운로드 | 예 | 예 | 예 |
| 실시간 데이터 실행(**Use live data**, **Refresh**) | 예 | 예 | 아니요 |
| 공개 링크 만들기 또는 끄기 | 예 | 예 | 아니요 |

기본적으로 워크스페이스의 모든 멤버가 모든 artifact를 열 수 있습니다. 소유자는 **Share**의 **General access**에서 이를 **Only people with access**로 좁힐 수 있습니다. 공유 필터의 **Private**는 artifact에 공개 링크가 없다는 뜻입니다.

## Artifact 유형

| 유형 | 설명 | 표시 위치 |
|---|---|---|
| **Report** | 테이블, 차트, 발견 사항, 권장 사항이 포함된 서술형 분석 | **Visuals** 탭 |
| **Dashboard** | 관련 지표와 차트를 한 페이지에 모은 뷰 | **Visuals** 탭 |
| **File** | CloudThinker가 대화에서 생성한 파일(예: CSV 또는 스크립트) 중 보관하기로 선택한 파일 | **Files** 탭 |

모든 리포트와 대시보드는 버전으로 저장됩니다. CloudThinker가 업데이트하면 새 버전을 게시하며, 이전 버전은 그대로 유지됩니다.

## Artifact 만들기

<Steps>
  <Step title="원하는 결과물의 형태를 말로 요청하기">
    대화를 시작하고 무엇을 어떤 형태로 원하는지 말하세요. 특별한 구문은 필요하지 않습니다.

    ```text
    Build a dashboard of AWS spend by service for the last 30 days, with the top 10 cost drivers and month-over-month change.
    ```

    ```text
    Write a report on Aurora cluster prod-aurora: p50, p95 and p99 query latency over the past 7 days, split by reads and writes, with queries over 200 ms called out.
    ```

    요청을 하나의 계정으로 고정하려면 `#`를 입력하고 연결을 선택하세요:

    ```text
    #aws-production Build a dashboard of EC2 and RDS spend for the last 30 days.
    ```

    **성공 상태:** CloudThinker가 대화에 artifact 카드로 답합니다. 카드를 클릭하면 대화 안에 artifact 패널이 열립니다(**View fullscreen**으로 크게 볼 수 있습니다). CloudThinker가 아직 작성 중이면 카드의 작업에 **Available after this artifact finishes**가 표시됩니다.
  </Step>
  <Step title="같은 대화에서 다듬기">
    "add a breakdown by the `team` tag" 또는 "compare against the previous 30 days"처럼 후속 메시지로 변경을 요청하세요.

    **성공 상태:** CloudThinker가 새 버전을 게시합니다. artifact를 이미 열어 두었다면 **Show vN** 버튼과 함께 **Version N is available** 알림이 나타납니다. 뷰가 스스로 버전을 바꾸는 일은 없습니다.
  </Step>
  <Step title="생성된 파일 보관하기(선택 사항)">
    CloudThinker가 대화에서 파일을 만들면 해당 파일 카드에서 **Save to artifacts**를 클릭하세요. 다시 클릭하면(**Remove from artifacts**) 빼낼 수 있습니다.

    **성공 상태:** 파일이 Library의 **Files** 탭에 나타납니다.
  </Step>
</Steps>

<Tip>
시간 범위, 그룹 기준(서비스, 계정, 태그), 비교 기간을 지정하세요. 빠뜨린 항목은 CloudThinker가 대신 고르므로, 원하는 정확한 결과를 얻으려면 후속 요청이 필요할 수 있습니다.
</Tip>

## 버전

버전 선택기(**v1**, **v2** 등)는 artifact 페이지의 오른쪽 위에 있습니다. 아무 버전이나 골라 읽을 수 있습니다. 이전 버전은 게시된 스냅샷만 표시하며, 실시간 데이터는 현재 버전에서만 실행됩니다.

복원 버튼은 없습니다. 이전 결과를 되살리려면 같은 대화에서 CloudThinker에게 요청하세요. CloudThinker가 그것을 새 버전으로 게시합니다.

## Library에서 artifact 찾기

사이드바에서 **More → Library**를 클릭하거나 [app.cloudthinker.io/library](https://app.cloudthinker.io/library)로 이동하세요.

| 컨트롤 | 옵션 |
|---|---|
| 탭 | **All**, **Docs**, **Visuals**(리포트와 대시보드), **Files** |
| 표시 | **Recent**, **All**, **Shared with me**, **Private**, **Trash** |
| 검색 | **Search library**는 입력하는 대로 목록을 필터링합니다 |
| 필터 | 공유(**Shared** 또는 **Private**)와 **Category** |
| 정렬 | **By source**, **Newest**, **Recently updated**, **Title** |
| 보기 | **Grid** 또는 **List** |

CloudThinker는 artifact를 만들 때 짧은 카테고리 라벨을 고릅니다. 고정된 목록이 없으므로 **Category** 필터에는 워크스페이스에서 사용 중인 라벨만 표시됩니다. artifact를 원하는 방식으로 묶으려면 요청에 카테고리 이름을 적으세요. 카드의 카테고리 태그를 클릭하면 그 카테고리로 필터링됩니다.

카드를 열면 artifact가 자체 페이지에 표시됩니다. 리포트와 대시보드 모두 페이지 상단에 **Download**가 있고, **More actions**(⋯) 메뉴에 **Download PDF**가 있습니다. 같은 메뉴의 **Open publishing conversation**은 그 artifact를 만든 채팅으로 돌아갑니다. 저장된 파일은 **Files** 탭의 카드에서 **Download**를 사용하세요.

## Artifact 관리

artifact를 삭제하려면 **More actions**(⋯)를 열고 **Move to trash…**를 클릭하세요. **Trash**에 30일 동안 보관된 뒤 영구 삭제되며, 복원하기 전까지 다른 사람은 접근할 수 없습니다. **Trash**에서 **Restore**를 클릭하면 되돌리고, **Delete forever**를 클릭하면 모든 버전, 파일, 공개 링크가 즉시 삭제됩니다. 이전 버전은 버전 선택기에서 계속 읽을 수 있습니다. artifact에 외부로 나가면 안 되는 데이터가 있다면 먼저 [공개 링크](/guide/sharing#revoke-a-link)를 끄세요. 저장된 파일을 Library에서 빼려면 **Files** 탭의 카드에서 **Remove from artifacts**를 클릭하세요. 이 작업은 파일의 공개 링크를 끄지 않으므로, 파일을 빼기 전에 링크를 먼저 끄세요. CloudThinker가 민감한 데이터를 처리하는 방식은 [데이터 보호](/guide/security/data-protection)를 참고하세요.

## 스냅샷과 실시간 데이터

리포트나 대시보드는 스냅샷과 함께 게시됩니다. 스냅샷은 해당 버전이 게시된 시점의 데이터입니다. artifact 페이지 상단의 표시(pill)는 지금 어떤 데이터를 보고 있는지 알려줍니다.

| 표시 | 의미 | 할 수 있는 작업 |
|---|---|---|
| **Snapshot** | "Data from" 시간과 함께 게시된 데이터를 보고 있습니다 | **Use live data**를 클릭하거나 필터를 바꾸면 artifact의 쿼리가 현재 데이터로 실행됩니다 |
| **Live** | 쿼리가 방금 연결에 대해 실행되었습니다 | **Refresh**를 클릭하면 다시 실행됩니다 |
| **Paused** | 페이지에서 일정 시간(15분) 활동이 없어 실시간 데이터 폴링이 멈췄습니다 | **Resume**을 클릭하세요 |
| **Refresh failed** | 마지막 실행이 실패해 마지막으로 성공한 데이터를 보고 있습니다 | **Retry**를 클릭하세요 |

실시간 데이터는 artifact의 읽기 전용 쿼리를 게시 당시의 연결에 대해, 해당 연결에 대한 사용자 본인의 접근 권한으로 실행합니다. 시작하기 전에 페이지에 연결 이름이 표시됩니다. 유료 [플랜](/ko/guide/billing/pricing)과 실시간 데이터를 실행할 수 있는 역할이 필요합니다. 각 실행은 [Audit Logs](/guide/security/audit-logs)에 기록됩니다.

이전 버전을 보고 있거나, 버전에 저장된 쿼리가 없으면(예: 업로드한 파일이나 붙여 넣은 데이터로만 만든 경우) artifact는 스냅샷 전용입니다. 이때 표시 아래 메시지는 **This artifact shows its published snapshot only.**입니다.

## Artifact 공유

artifact 페이지에서 **Share**를 클릭하세요. **General access**에서 워크스페이스의 누가 열 수 있는지 선택하거나, 이름이나 이메일로 사람을 추가하세요. **Public link**에서 **Anyone with the link can view**를 켜면 로그인 없이 누구나 열 수 있는 링크가 생깁니다. 리포트나 대시보드의 경우 카드 **⋯** 메뉴의 **Share**는 공개 링크를 만들거나 취소하기만 하는 간단한 대화 상자를 엽니다. 보는 사람에게 무엇이 보이는지와 링크를 취소하는 방법은 [공유](/guide/sharing)를 참고하세요.

<Warning>
링크는 공개되며, CloudThinker가 이후에 게시하는 모든 버전이 같은 URL에 표시됩니다. 보내기 전에 [공유 페이지의 경고](/guide/sharing#what-viewers-see)를 읽으세요.
</Warning>

## 일정에 따라 다시 실행

[automation](/guide/automation/automations)은 같은 요청을 일정에 따라 실행할 수 있습니다. 각 실행은 새 대화이므로 기본적으로 매번 새 artifact를 만들며, 이미 공유한 링크는 업데이트되지 않습니다. CloudThinker는 워크스페이스의 모든 artifact를 찾을 수 있으므로, 이해관계자를 위해 하나의 URL을 최신 상태로 유지하려면 automation 요청에 기존 artifact 이름을 적으세요(예: "update the AWS spend by service dashboard"). 그러면 각 실행이 그 artifact의 새 버전을 게시합니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="artifact에 데이터가 빠져 있거나 차트가 비어 있습니다">
    **원인:** CloudThinker가 해당 소스를 읽을 수 없었습니다. **확인:** [Connections](/ko/guide/connections/overview)에 연결이 있고 **Connected** 상태인지, 시간 범위에 데이터가 있는지 확인하세요. **해결:** 다시 연결하거나 범위를 넓힌 다음 CloudThinker에게 artifact 업데이트를 요청하세요.
  </Accordion>
  <Accordion title="Use live data가 보이지 않거나 표시가 Snapshot에 머물러 있습니다">
    **원인:** 워크스페이스가 Free 플랜이거나, 역할이 **Viewer**이거나, 이전 버전을 보고 있거나, 해당 버전에 저장된 연결이 없습니다. **확인:** 표시 아래 메시지에 이유가 나옵니다. **해결:** [플랜](/ko/guide/billing/pricing)을 업그레이드하거나, Admin에게 역할을 문의하거나, 버전 선택기에서 최신 버전으로 전환하세요.
  </Accordion>
  <Accordion title="실시간 데이터에서 연결에 접근 권한이 없다고 나옵니다">
    **원인:** 메시지가 **You do not have access to** 뒤에 연결 이름을 표시합니다. 해당 연결이 삭제되었거나 계정에서 볼 수 없습니다. 실시간 데이터는 해당 버전에 저장된 연결만 사용합니다. **해결:** artifact의 대화에서 CloudThinker에게 현재 연결로 다시 만들어 달라고 요청하세요. 새 버전은 그 연결로 실시간 실행됩니다.
  </Accordion>
  <Accordion title="생성된 파일이 Library에 없습니다">
    **원인:** 생성된 파일은 보관하기 전까지 대화에만 남아 있습니다. **해결:** 대화를 열고 파일 카드에서 **Save to artifacts**를 클릭하세요.
  </Accordion>
  <Accordion title="Download PDF가 실패합니다">
    **원인:** 인쇄 오류이거나, 분당 한도(사용자당 10회)를 넘는 PDF 요청입니다. **해결:** 1분 기다린 다음 페이지 상단의 **Retry download** 또는 **More actions** 메뉴의 **Print failed. Retry**를 클릭하세요.
  </Accordion>
</AccordionGroup>
