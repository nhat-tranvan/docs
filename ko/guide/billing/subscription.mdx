## 구독 관리

### 현재 플랜 확인

1. **관리자 설정 > 청구**로 이동
2. 현재 플랜, 사용량, 청구 주기 확인
3. 예정된 청구 내역 및 인보이스 이력 확인

### 업그레이드 또는 다운그레이드

플랜을 변경하려면:

1. **관리자 설정 > 청구**로 이동
2. **플랜 변경** 클릭
3. 새 플랜 선택
4. 변경 내용 검토 후 확인

<Info>
플랜 변경은 즉시 적용됩니다. 업그레이드는 현재 청구 기간에 대해 일할 계산됩니다. 다운그레이드는 다음 청구 주기부터 적용됩니다.
</Info>

### 팀원 추가

시트 기반 플랜의 경우:

1. **관리자 설정 > 조직**으로 이동
2. **멤버 초대** 클릭
3. 이메일 주소 입력
4. 역할 및 워크스페이스 접근 권한 선택
5. 추가 시트는 자동으로 청구됩니다

### 시트 작동 방식

**시트**는 구독의 유료 슬롯입니다. 각 시트는 구매 즉시 전체 크레딧 할당량을 부여합니다.

- **활성 멤버만 시트를 사용합니다.** 대기 중인 초대는 시트 사용량에 포함되지 않습니다.
- **크레딧 풀 확장을 위해 시트를 미리 구매할 수 있습니다.** 팀원이 합류하기 전에도 추가 시트를 구매하여 조직의 크레딧 풀을 늘릴 수 있습니다.
- **주기 중간 추가.** 새 멤버가 현재 시트 수를 초과하면 자동으로 시트가 추가되고 일할 계산 청구됩니다.
- **멤버 탈퇴.** 현재 주기의 크레딧은 그대로 유지됩니다. 시트 수는 다음 갱신 시 조정됩니다.

## 인보이스 & 결제

### 결제 수단

지원되는 결제 수단:

- 신용/체크카드 (Visa, Mastercard, Amex)
- ACH 계좌 이체 (미국)
- 전신 송금 (Enterprise)
- 인보이스 청구 (Enterprise)

### 결제 수단 관리

1. **관리자 설정 > 청구**로 이동
2. 결제 수단 추가 또는 업데이트
3. 기본 결제 수단 설정
4. 결제 내역 확인

### 인보이스

인보이스 이력에 접근하려면:

1. **관리자 설정 > 청구**로 이동
2. 인보이스 조회 및 다운로드
3. 날짜 범위로 필터링
4. 회계 처리를 위해 내보내기

### 청구 주기

- 월간 플랜: 구독 시작일에 청구
- 연간 플랜: 할인 적용하여 연간 청구
- 초과 사용량: 청구 기간 말에 청구
