크레딧은 AI 에이전트 작업의 기본 통화입니다. 에이전트와의 각 상호작용은 복잡도에 따라 크레딧을 소비합니다.

## 크레딧 작동 방식

크레딧은 플랜에 포함되어 모든 에이전트 대화 및 API 사용에 적용됩니다.

- 모든 플랜에는 매일 갱신되는 **100 무료 일일 크레딧**이 포함되며, **Light 모델과 채팅에만** 사용 가능합니다.
- **프리미엄 크레딧**은 조직에 매월 할당되는 크레딧입니다. Light, Pro, Ultra 모델에서 구독 플랜에 포함된 기능을 사용할 때 소비됩니다.

## 소비 순서

크레딧은 다음 순서대로 소비됩니다.

<Steps>
  <Step title="일일 크레딧">
    매일 초기화되는 100 무료 크레딧으로, **Light 모델과 채팅에만** 사용
    가능합니다. 모든 플랜에서 사용할 수 있습니다.
  </Step>
  <Step title="보너스 크레딧">
    추천인 프로그램이나 특별 혜택에서 제공되는 프로모션 크레딧입니다. **모든
    모델**과 함께 사용 가능하며 **만료되지 않습니다**.
  </Step>
  <Step title="프리미엄 크레딧">
    조직의 월간 크레딧 할당량으로, 각 청구 주기마다 초기화됩니다. 일일
    크레딧과 달리 프리미엄 크레딧은 **모든 모델** (Light, Pro, Ultra)과
    구독 플랜에 포함된 기능에서 사용할 수 있습니다.
  </Step>
  <Step title="Pay-As-You-Go">
    다른 크레딧이 소진된 후 사용량에 따라 요금이 청구됩니다. [PAYG](#pay-as-you-go)를 활성화한 경우, Team과 Scale은 크레딧당 $0.10이며 Enterprise는 별도 견적이 적용됩니다.
  </Step>
</Steps>

**관리자 설정 > 사용량**에서 잔액, 현재 기간 사용량, 이력 추세, 거래 내역을 실시간으로 모니터링할 수 있습니다.

## Pay-As-You-Go

Pay-As-You-Go(PAYG)를 활성화하면 다른 크레딧이 소진된 후에도 설정한 지출 한도까지 사용량에 따라 요금을 지불하며 작업을 계속할 수 있습니다.

|                          | 세부 사항                                                                        |
| ------------------------ | ------------------------------------------------------------------------------ |
| **요율**                 | Team과 Scale: 크레딧당 $0.10. Enterprise: 별도 견적                                                               |
| **사용 가능 플랜**         | Team, Scale, Enterprise 플랜                                     |
| **지출 한도** | 월별 한도를 직접 설정 — 최소 \$100, 최대 금액은 플랜 티어에 따라 다름 |
| **청구**              | 사용량 기반 — 각 청구 주기 말에 실제 사용량만큼만 청구       |
| **제어**              | 구독 설정에서 언제든지 활성화 또는 비활성화 가능                      |

<Warning>
  PAYG는 Free 플랜에서 사용할 수 없으며, 체험 기간 동안에도 비활성화됩니다.
  PAYG를 활성화하려면 Team 이상 플랜으로 업그레이드하세요.
</Warning>

### PAYG 활성화 또는 비활성화

1. **Admin Settings → Usage**로 이동
2. **Pay-As-You-Go** 열기
3. PAYG 토글 켜기 (또는 끄기)
4. 확인 — 변경 사항이 즉시 적용됩니다

### 지출 한도 설정

월별 한도는 한 청구 주기에서 PAYG가 청구할 수 있는 최대 금액을 제한합니다. 한도에 도달하면 다음 주기까지 PAYG가 중단됩니다.

1. **관리자 설정 > 청구 > Pay-As-You-Go**에서 **월별 한도** 설정
2. 최소 한도는 **\$100/월**이며, 최대 금액은 플랜 티어에 따라 다르고 플랜의 기본 한도가 미리 입력됩니다
3. 저장 — 한도 초과 사용은 다음 청구 주기까지 차단됩니다

<Info>
  한도는 청구 주기 단위로 적용되며 각 주기마다 초기화됩니다. 주기 중간에 한도를
  낮춰도 이미 발생한 사용량은 환불되지 않습니다.
</Info>

Enterprise 사용량 요금은 별도 견적에 따릅니다.
