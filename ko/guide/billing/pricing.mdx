Team과 Scale은 조직 전체에 월 고정 요금을 적용하며 멤버 수는 무제한입니다. 조직 내 모든 워크스페이스가 크레딧을 공유합니다.

## 플랜 선택

| | **Team** | **Scale** | **Enterprise** |
|---|---|---|---|
| **팀 전체 월 요금** | $99 | $499 | 별도 견적 |
| **월간 크레딧** | 1,000 | 5,000 | Pay-As-You-Go |
| **멤버** | 무제한 | 무제한 | 무제한 |
| **워크스페이스** | 3 | 10 | 무제한 |
| **격리 샌드박스 크기** | 중형 | 대형 | 맞춤형 |
| **배포** | SaaS | SaaS | Self-host / BYOC |
| **BYOK** | — | ✓ | ✓ |
| **SSO / SCIM** | — | ✓ | ✓ |
| **감사 로그** | — | ✓ | ✓ |
| **사용량 기반 결제** | ✓ | ✓ | ✓ |
| **지원** | 이메일 | 우선 지원 | 전담 지원 |
| **SLA** | — | 99.9% | 99.95% |

멤버를 추가해도 월 요금이나 월간 크레딧 할당량은 달라지지 않습니다. Enterprise 요금은 [별도로 문의하세요](https://cloudthinker.io/contact).

## 무료 이용

Free는 Light 모델 채팅에 사용할 수 있는 무료 크레딧을 매일 100개 제공합니다. 이 크레딧은 조직 전체가 공유합니다.
