Convention Rules를 사용하면 AI 리뷰어가 저장소에 이미 있는 파일에서 팀의 코딩 컨벤션을 읽고 따를 수 있습니다. 이를 통해 리뷰가 확립된 표준 및 코딩 관행과 일치하게 됩니다.

---

## 동작 방식

코딩 어시스턴트 도구를 선택하면 AI 리뷰어가 각 리뷰 중에 저장소에서 해당 컨벤션 파일을 자동으로 찾아 읽습니다. 수동 파일 경로 설정이 필요 없습니다.

---

## 커스텀 컨벤션 경로

**Custom Convention Paths**를 추가하여 저장소의 추가 컨벤션 파일이나 디렉토리를 리뷰어가 가리킬 수 있습니다. 팀이 비표준 위치에 컨벤션 파일을 관리하거나 여러 도구를 사용하는 경우에 유용합니다.

Convention Rules 대화 상자에서 **+ Add path**를 클릭하여 추가 컨벤션 파일이나 디렉토리의 상대 경로를 지정하세요.
