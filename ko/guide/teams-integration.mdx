Microsoft Teams를 한 번 연결하면 매핑된 팀의 누구나 채널에서 `@CloudThinker`를 멘션해 클라우드에 대해 질문하고, 스레드에서 대화를 이어갈 수 있습니다. 같은 연결로 알림, 코드 리뷰 요약 같은 [알림](/ko/guide/notifications)이 선택한 채널에 Adaptive Card로 전달됩니다.

## 사전 요구 사항

- CloudThinker 조직 **Owner** 또는 **Admin**. 다른 역할은 Teams 페이지를 볼 수 있지만 연결하거나 변경할 수 없습니다.
- Team, Scale 또는 Enterprise 플랜. Free 플랜에서는 Microsoft Teams 행에 **Requires Team plan**이 표시되고 **Configure** 버튼이 없습니다. [요금](/ko/guide/billing/pricing)을 참조하세요.
- Microsoft Entra ID에서 관리자 동의를 부여할 수 있는 Microsoft 365 관리자. CloudThinker는 봇을 조직의 Teams 앱 카탈로그에 게시하며, 이에는 관리자 동의가 필요합니다. 한 사람이 두 역할을 모두 맡을 수 있습니다. Microsoft 365 관리자가 아니라면 CloudThinker Owner 또는 Admin으로 Teams 페이지를 열고 2단계에서 **Connect with Microsoft**를 클릭한 뒤, 함께 작업하며 Microsoft 관리자가 해당 Microsoft 화면에서 로그인하도록 하세요. 관리자가 동의하는 권한은 [보안 및 권한](#보안-및-권한)에 나열되어 있습니다.
- app.cloudthinker.io에서 호스팅되는 CloudThinker. 셀프 호스팅 설치에서는 행에 **Not available on self-host**가 표시됩니다.

각 Microsoft 테넌트는 하나의 CloudThinker 조직에만 연결할 수 있습니다.

## Microsoft Teams 연결

<Steps>
  <Step title="Teams 연동 열기">
    **Settings → Organization → Chat integrations**로 이동해 **Microsoft Teams** 행을 찾고 **Configure**를 클릭합니다. Settings를 열려면 사이드바 상단의 워크스페이스 메뉴를 클릭한 뒤 **Settings**를 클릭합니다.
  </Step>
  <Step title="Connect with Microsoft 클릭">
    Microsoft 관리자 계정으로 로그인합니다. 권한 화면에서 **Consent on behalf of your organization**을 체크한 뒤 **Accept**를 클릭합니다.

    **완료 상태:** **Teams connected successfully** 메시지와 함께 Teams 페이지로 돌아오며, **Authenticate with Microsoft**에 테넌트 이름과 ID가 표시됩니다.
  </Step>
  <Step title="팀 추가">
    **Install bot and configure workspaces** 아래에서 **Add team**을 클릭하고 팀을 검색해 선택합니다. 검색에는 소유한 팀뿐 아니라 입력한 내용으로 이름이 시작하는 테넌트의 모든 팀이 나열되므로, 먼저 팀 소유자와 협의하세요. 팀의 모든 멤버가 봇을 보고 멘션할 수 있습니다. CloudThinker는 해당 팀에 봇을 설치하며, 봇은 그곳에서 채널 메시지를 읽고(`ChannelMessage.Read.Group` 권한) 답글과 카드를 게시할 수 있습니다.

    **완료 상태:** **CloudThinker bot installed to team** 메시지가 표시되고 팀이 행으로 나타납니다. 더 많은 팀에 반복하려면 **Add another team**을 클릭하세요.
  </Step>
  <Step title="각 팀의 워크스페이스 선택">
    팀 행에서 **Select workspace**를 열고 해당 팀이 사용할 연결을 가진 CloudThinker 워크스페이스를 선택합니다. 팀의 모든 채널이 이 워크스페이스를 사용합니다.

    **완료 상태:** **Workspace mapping updated** 메시지가 표시됩니다.
  </Step>
  <Step title="테스트 메시지 보내기">
    해당 팀의 표준 채널에서 봇을 멘션합니다.

    ```text
    @CloudThinker What drove our cloud spend up last week?
    ```

    **완료 상태:** CloudThinker가 스레드에 답합니다. 후속 질문은 그 스레드에 답글로 남기세요. 봇을 다시 멘션할 필요가 없습니다.
  </Step>
</Steps>

<Warning>
매핑된 팀에 게시할 수 있는 사람은 누구나 CloudThinker에게 해당 워크스페이스의 연결로 작업하도록 요청할 수 있습니다. CloudThinker 계정을 연결한 사람은 해당 사용자로 요청을 실행합니다. 그 외의 모든 사람은 하나의 계정으로 실행합니다. 워크스페이스를 만든 사람, 또는 조직이 소유한 워크스페이스라면 조직 **Owner**입니다. 멤버가 그 액세스 권한을 가져야 하는 팀만 매핑하세요.
</Warning>

### CloudThinker 계정 연결

계정을 연결하면 요청이 그 하나의 계정 대신 사용자 본인과 본인의 워크스페이스 역할로 실행됩니다. 원할 때 연결을 시작할 수는 없습니다. CloudThinker는 워크스페이스를 소유한 계정을 찾지 못할 때만 **Link Your CloudThinker Account** 카드를 게시합니다. 카드에서 **Link Account**를 클릭하고 로그인합니다. 완료되면 페이지에 **Account linked successfully!**가 표시됩니다. 2단계에서 로그인한 Microsoft 계정은 **Connect with Microsoft**를 클릭한 CloudThinker 계정에 자동으로 연결되므로, 두 사람이 함께 설정했다면 해당 Microsoft 관리자의 요청은 CloudThinker 관리자로 실행됩니다. 사용자별 연결 해제는 없으며, **Disconnect from Teams**가 연결된 모든 계정을 제거합니다.

## Teams에서 CloudThinker에 질문하기

팀 채널에서 새 요청은 항상 `@CloudThinker`로 시작합니다. 그 뒤에는 웹 앱에서 입력하는 것과 같은 요청을 작성합니다.

<PromptSyntaxBasics />

```text
@CloudThinker Which EC2 instances ran under 10% CPU for the last 14 days?
@CloudThinker Summarize open critical security findings for production
@CloudThinker Why did checkout latency spike at 14:00 UTC today?
```

| 표시되는 것 | 의미 |
| --- | --- |
| 입력 중 표시 | CloudThinker가 요청을 처리하고 있습니다 |
| 스레드의 답글 | 답변입니다. 전체 대화는 CloudThinker 웹 앱에도 표시됩니다 |
| **View in CloudThinker**가 있는 **Permission Required** 카드 | 요청에 [Approvals](/guide/approvals/overview) 설정이 사람에게 맡기는 작업이 필요합니다. 링크를 열어 웹 앱에서 승인하거나 거절하세요. Resolve 인시던트 채널에서는 카드에 대신 **Approve**와 **Reject** 버튼이 있습니다 |
| **Link Your CloudThinker Account** 카드 | 계정을 연결하지 않았고 CloudThinker가 워크스페이스를 소유한 계정을 찾지 못해 요청이 실행되지 않았습니다. **Link Account**를 클릭하고 CloudThinker에 로그인하세요 |

CloudThinker는 팀 채널에서만 작동합니다. 개인 채팅이나 그룹 채팅에서는 요청을 실행하지 않으며, 팀을 찾을 수 없으면 **I can only respond in team channels**라고 답합니다. 메시지의 텍스트를 읽으므로, 파일을 첨부하는 대신 읽히고 싶은 내용을 붙여 넣으세요.

## Teams로 알림 보내기

<Steps>
  <Step title="알림 설정 열기">
    Teams 페이지의 **Configure notifications** 아래에서 **Go to notification settings**를 클릭합니다. **Settings → Workspace → Notifications**로 이동할 수도 있습니다.
  </Step>
  <Step title="워크스페이스 기본 채널 선택">
    **Delivery channels** 아래에서 Teams 카드를 찾습니다(설정 전에는 **Pick a channel**로 표시됨). 설정 아이콘(**Change Teams channel**)을 클릭한 뒤 **Teams channel** 아래에서 채널을 검색해 선택합니다. 표준 채널만 나열됩니다. 비공개 채널과 공유 채널은 봇 알림을 받을 수 없습니다.
  </Step>
  <Step title="알림 유형별 재정의(선택)">
    **What to send** 아래에서 이벤트의 Teams 셀을 켠 뒤, 옆의 **→** 채널 칩을 클릭해 해당 이벤트를 다른 채널로 보냅니다. **Alerts**와 **Keepers** 행에는 심각도 선택기도 있습니다. 전체 유형 목록은 [알림](/ko/guide/notifications)을 참조하세요.

    **완료 상태:** 다음에 일치하는 이벤트가 선택한 채널에 카드로 게시됩니다.
  </Step>
</Steps>

## 코드 리뷰 알림

[Review](/ko/guide/code-review/overview)가 연결된 리포지토리의 풀 리퀘스트나 머지 리퀘스트를 마치면, CloudThinker가 Teams에 Adaptive Card를 게시할 수 있습니다.

- 심각도별 발견 사항 표
- 제목, 심각도, 파일 경로, 줄 번호가 있는 미해결 발견 사항 최대 5개
- 이전 발견 사항 중 해결된 수
- CloudThinker에서 리뷰를 여는 **View Review** 버튼
- 리뷰에 문제가 없을 때 **No issues found**

리뷰의 채널과 심각도 기준은 [알림](/ko/guide/notifications)에서 선택하세요.

## 보안 및 권한

| 질문 | 답변 |
| --- | --- |
| Microsoft Graph 권한 | 로그인 시 부여되는 위임 권한입니다. 아래 표를 참조하세요 |
| CloudThinker가 보관하는 토큰의 주인 | Teams를 연결한 Microsoft 관리자입니다. CloudThinker는 해당 관리자의 액세스 토큰과 리프레시 토큰을 암호화해 저장하며, 이를 사용해 팀과 채널을 나열하고 봇을 설치합니다. 관리자가 퇴사하는 등으로 토큰이 작동하지 않으면 팀 추가가 **Teams connection token expired. An admin must reconnect Teams.**와 함께 실패합니다. CloudThinker의 액세스를 취소하려면 Microsoft Entra ID의 **Enterprise applications**에서 관리자 동의를 제거하세요 |
| 각 팀에서의 봇 권한(애플리케이션, 리소스별) | `ChannelMessage.Read.Group`. 봇이 해당 팀 채널의 메시지를 읽을 수 있습니다 |
| CloudThinker가 저장하는 것 | 매핑된 워크스페이스에 대화로 저장된 요청과 답글, 그리고 팀-워크스페이스 매핑과 연결된 계정 |

| Graph 권한 | 이유 |
| --- | --- |
| `User.Read`, `openid`, `profile` | Microsoft 관리자 로그인 |
| `Organization.Read.All` | Teams 페이지에 표시할 테넌트 이름 읽기 |
| `Team.ReadBasic.All` | **Add team** 검색에 팀 나열 |
| `Channel.ReadBasic.All` | 알림 선택기에 채널 나열 |
| `AppCatalog.ReadWrite.All` | 조직의 Teams 앱 카탈로그에 CloudThinker 봇 게시 |
| `TeamsAppInstallation.ReadWriteForTeam`, `TeamsAppInstallation.ReadWriteSelfForTeam` | 추가한 팀에 봇을 설치하고, 팀을 제거하면 봇 제거 |
| `TeamsAppInstallation.ReadWriteAndConsentForTeam` | 봇이 참여하는 각 팀에서 `ChannelMessage.Read.Group` 권한 부여 |
| `offline_access` | 리프레시 토큰을 받아 CloudThinker가 새 로그인 없이 Graph를 계속 호출 |

## 연결 관리

| 작업 | 방법 |
| --- | --- |
| 팀을 다른 워크스페이스로 이동 | 행의 **Select workspace**를 변경합니다 |
| 팀에서 CloudThinker 사용 중지 | Teams 페이지에서 팀 행을 제거합니다. CloudThinker가 해당 팀에서 봇을 제거하고 그 채널을 가리키던 알림 설정을 지웁니다 |
| 연결 해제 | Teams 페이지 하단의 **Disconnect from Teams**를 클릭합니다. CloudThinker가 매핑된 모든 팀에서 봇을 제거하고 팀 매핑, 연결된 계정, Teams 알림 설정을 삭제합니다 |

## 문제 해결

<AccordionGroup>
  <Accordion title="Teams authorization denied">
    Microsoft 로그인이 거부되었거나 취소되었습니다. **Connect with Microsoft**를 다시 클릭하고 권한을 수락하세요.
  </Accordion>
  <Accordion title="팀 추가 시 Missing required permissions">
    Microsoft 계정이 관리자 동의를 부여하지 않았습니다. Microsoft 365 관리자로 다시 로그인해 **Consent on behalf of your organization**을 체크하거나, Microsoft Entra ID에서 CloudThinker에 관리자 동의를 부여하세요.
  </Accordion>
  <Accordion title="봇이 팀에 설치되지 않음">
    Teams 관리자 설정이 사용자 지정 앱을 차단하고 있을 수 있습니다. Teams 관리 센터에서 **Teams apps → Manage apps**로 이동해, 개발자 CloudThinker가 조직에 게시한 사용자 지정 앱 **CloudThinker**를 검색하세요. 상태가 차단이면 허용으로 설정하고, 앱 권한 정책이 이를 차단하지 않는지 확인하세요. 그런 다음 **Add team**을 다시 클릭하세요.
  </Accordion>
  <Accordion title="This tenant is already connected">
    Microsoft 테넌트가 이미 다른 CloudThinker 조직에 연결되어 있습니다. 먼저 그곳에서 연결을 해제하세요.
  </Accordion>
  <Accordion title="This team isn't linked to any workspace">
    팀에 워크스페이스 매핑이 없습니다. Teams 페이지에서 팀 행의 **Select workspace**를 설정하거나, 팀이 목록에 없으면 **Add team**을 클릭하세요.
  </Accordion>
  <Accordion title="봇이 답하지 않음">
    추가한 팀의 표준 채널에 게시했는지, 새 메시지에서 `@CloudThinker`를 멘션했는지 확인하세요. 멘션이 없는 메시지는 CloudThinker가 이미 시작한 스레드 안에서만 답을 받습니다.
  </Accordion>
  <Accordion title="알림 선택기에 채널이 나타나지 않음">
    표준 채널만 나열됩니다. 같은 팀의 표준 채널을 선택하거나, 팀이 Teams 페이지에 나타나는지 확인하세요.
  </Accordion>
</AccordionGroup>
