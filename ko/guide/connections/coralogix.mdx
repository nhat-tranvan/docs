Coralogix 계정을 연결하면 CloudThinker 에이전트가 옵저버빌리티 스택 전반에서 로그를 검색하고, 메트릭과 트레이스를 쿼리하고, 인시던트를 분류하고, 데이터 파이프라인 상태를 검사할 수 있습니다.

Coralogix는 **리전**에 스코프가 지정된 **API 키**로 인증합니다. CloudThinker는 리전에서 올바른 Coralogix 엔드포인트를 확인하므로, 동일한 설정이 모든 US, EU, AP 데이터 센터에서 작동합니다.

---

## 지원 리전

Coralogix 팀 로그인 도메인과 일치하는 리전을 선택하세요.

| 데이터 센터 | 리전 |
|-------------|---------|
| US | `us1`, `us2`, `us3` |
| 유럽 | `eu1`, `eu2` |
| 아시아 태평양 | `ap1`, `ap2`, `ap3` |

---

## 사전 요구 사항

- 조사할 팀에 접근 권한이 있는 **Coralogix 계정**.
- CloudThinker가 접근할 옵저버빌리티 데이터에 대한 읽기 권한이 있는 **API 키**.
- Coralogix 팀의 **리전**.

<Info>
읽기 전용 조사에 필요한 최소 권한으로 API 키를 사용하세요. CloudThinker의 설정 검증은 데이터만 읽으며 Coralogix 리소스를 수정하지 않습니다.
</Info>

---

## 설정

<Steps>
  <Step title="Coralogix 열기">
    Coralogix 계정에 로그인합니다. 로그인 URL은 `https://<team>.app.<region>.coralogix.com` 형식으로, `<region>` 부분이 리전입니다.
  </Step>
  <Step title="API 키 생성">
    **Settings → Users and Teams → API Keys**로 이동하여 **Add key**를 클릭합니다.
    - **Name**: `cloudthinker`
    - **Type**: **Team Key**를 선택합니다. 팀 키는 공유 키로, 생성자의 접근 권한이 만료되더라도 유효하게 유지됩니다. 개인 키는 개인에 연결되어 테스트용으로만 사용됩니다.
    - **Permissions**: CloudThinker가 접근해야 할 데이터에 대한 읽기 권한 부여

    키를 즉시 복사하세요 — 이후에는 다시 표시되지 않을 수 있습니다.
  </Step>
  <Step title="CloudThinker에 연결 추가">
    **Connections → Coralogix**로 이동하여 다음을 입력합니다.
    - **API Key**: 방금 생성한 키
    - **Region**: 로그인 URL의 리전 (예: `eu2`)

    **Connect**를 클릭합니다. CloudThinker가 자격 증명을 검증하고 **Connected** 상태를 표시합니다.
  </Step>
</Steps>

<Warning>
생성 후 API 키를 즉시 복사하세요. 분실 시 새 키를 생성해야 합니다.
</Warning>

## 연결 세부 정보

| 필드 | 설명 | 예시 |
|-------|-------------|---------|
| **CORALOGIX_API_KEY** | Coralogix API 키 | — |
| **CORALOGIX_REGION** | 팀 로그인 도메인의 리전 | `us2` |

<Note>
CloudThinker는 리전에서 Coralogix API 엔드포인트를 유도하므로 수동 URL 구성이 필요하지 않습니다.
</Note>

---

## 필수 권한

CloudThinker가 조사하는 옵저버빌리티 데이터(로그, 메트릭, 트레이스, 인시던트, 알림, 커넥터, 파싱 규칙, 프리셋, 대시보드)에 대한 **읽기** 권한을 API 키에 부여합니다.

<Tip>
최소 권한 원칙을 따르세요. 조사에는 읽기 전용 키로 충분합니다. 특정 쓰기 워크플로가 필요한 경우가 아니라면 CloudThinker가 사용하는 키에 변경 권한을 부여하지 마세요.
</Tip>

---

## 에이전트 기능

연결 후 에이전트는 Coralogix 옵저버빌리티 데이터에 읽기 접근 권한을 갖습니다.

| 기능 | 설명 |
|------------|-------------|
| **탐색** | 계정 상태 요약 — 활성 인시던트, 커넥터 수, 비활성화된 파싱 규칙, 메트릭 미매칭 처리 |
| **인시던트 분류** | 활성 인시던트 목록 조회 및 컨텍스트 검사 |
| **로그** | 시간 범위에 걸쳐 로그 검색 및 분석 |
| **메트릭** | 메트릭 쿼리 및 메트릭 카탈로그 검사 |
| **트레이스** | 분산 트레이스 검사 |
| **파이프라인 상태** | 잘못 구성된 커넥터, 파싱 규칙, 프리셋 검토 |
| **알림 및 대시보드** | 알림 정의 및 대시보드 검사 |

### 연결 확인

```text
@alex run Coralogix discovery and summarize active incidents, connector count, disabled parsing rule count, and whether metric no-match handling is healthy
```

### 예시 프롬프트

```text
@alex triage active Coralogix incidents and #report anything affecting production
@alex search Coralogix logs for 5xx errors in the api-gateway over the last hour
@alex check Coralogix pipeline health and list any disabled parsing rules
```

<Note>
크거나 노이즈가 많은 카탈로그의 경우, 짧은 시간 범위와 알려진 메트릭 또는 로그 쿼리로 요청 범위를 좁혀 에이전트가 집중적인 결과를 반환하도록 하세요.
</Note>

## 문제 해결

<Accordion title="401 또는 403 Unauthorized">
API 키가 누락되었거나, 만료되었거나, 필요한 권한이 없습니다. 필요한 읽기 권한으로 새 Coralogix API 키를 생성하고 다시 연결하세요.
</Accordion>

<Accordion title="404 Not Found">
API 키가 다른 Coralogix 리전에 속합니다. 팀 로그인 도메인을 확인하고 **CORALOGIX_REGION**을 일치하도록 업데이트하세요.
</Accordion>

<Accordion title="메트릭을 찾을 수 없음">
메트릭 카탈로그에 일치하는 메트릭이 없거나 계정에 메트릭 데이터가 없습니다. 빈 결과로 처리한 후 알려진 메트릭 이름으로 시도하거나 인시던트와 로그로 계속 진행하세요.
</Accordion>

<Accordion title="탐색에서 저하 상태 표시">
하나 이상의 Coralogix 목록 호출이 오류를 반환했습니다. API 키 권한과 리전을 확인한 후 탐색을 다시 실행하세요.
</Accordion>

<Accordion title="크거나 노이즈가 많은 출력">
범위가 없는 카탈로그 또는 쿼리 사용은 너무 많은 데이터를 반환합니다. 짧은 시간 범위와 특정 쿼리로 요청 범위를 좁혀 결과가 집중적으로 유지되도록 하세요.
</Accordion>
