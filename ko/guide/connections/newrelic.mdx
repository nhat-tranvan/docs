New Relic 계정을 연결하여 CloudThinker 에이전트가 애플리케이션 성능을 모니터링하고, 인프라를 검사하며, NRQL 쿼리를 실행하고, 알림을 검토하며, 옵저버빌리티 스택 전반의 인시던트를 조사할 수 있도록 합니다.

New Relic은 **User API 키**(`NRAK-…`)로 인증하며 **New Relic AI MCP 서버**를 통해 연결됩니다. 연결 전에 MCP 서버를 활성화해야 합니다.

---

## 지원 리전

| 리전 | MCP 엔드포인트 |
|------|---------------|
| **US** | `mcp.newrelic.com` |
| **EU** | `mcp.eu.newrelic.com` |

<Warning>
계정과 일치하는 리전을 선택하세요. EU 계정을 US 리전(또는 그 반대)으로 연결하면 인증 실패 또는 빈 결과가 반환됩니다.
</Warning>

---

## 사전 요구 사항

**New Relic AI MCP 서버**가 활성화되어 있고 **User API 키**(`NRAK-…`)가 있어야 합니다.

**New Relic AI MCP 서버 활성화:**

CloudThinker는 New Relic AI MCP 서버를 통해 New Relic에 연결합니다. 이 서버는 공개 미리보기 상태로 연결 전에 활성화해야 합니다. FedRAMP 또는 HIPAA 관련 계정에서의 사용은 New Relic 약관에 따라 엄격히 금지됩니다.

1. New Relic에서 왼쪽 하단 모서리의 **사용자 이름**을 클릭합니다.
2. **Administration → Previews & Trials**로 이동합니다.
3. **New Relic AI MCP server** 미리보기 토글을 활성화합니다.

**User API 키 생성:**

1. **API keys**를 엽니다 (사용자 메뉴 → **API keys**, 또는 `one.newrelic.com/api-keys`로 이동; EU: `one.eu.newrelic.com/api-keys`).
2. **Create a key**를 클릭하고 **Key type**을 **User**로 설정합니다.
3. 이름(예: `CloudThinker`)을 지정하고 저장합니다.
4. 키 값을 복사합니다 — 전체 `NRAK-…` 키는 **생성 시 한 번만** 표시됩니다.

<Warning>
**User API 키**(`NRAK-…`)를 사용하세요. License, ingest, query 키는 데이터 수집용이며 쿼리에는 작동하지 않습니다 — 이것이 가장 흔한 설정 실수입니다.
</Warning>

## 설정

<Steps>
  <Step title="CloudThinker 열기">
    CloudThinker 워크스페이스에서 **Connections → New Relic**으로 이동하여 **Connect New Relic**을 클릭합니다.
  </Step>
  <Step title="연결 이름 지정">
    **Alias**(이 인스턴스의 고유 식별자, 예: `production`)와 **Description**을 입력합니다.
  </Step>
  <Step title="API 키 입력">
    New Relic **User API 키**(`NRAK-…`)를 붙여 넣습니다.
  </Step>
  <Step title="리전 선택">
    New Relic 계정에 맞게 **US**(`mcp.newrelic.com`) 또는 **EU**(`mcp.eu.newrelic.com`)를 선택합니다.
  </Step>
  <Step title="연결">
    **Connect**를 클릭합니다. CloudThinker가 자격 증명을 확인하고 **Connected** 상태를 표시합니다.
  </Step>
</Steps>

## 필요 권한

User API 키는 해당 키가 속한 사용자의 권한을 상속합니다. 최소 권한을 위해 해당 사용자를 읽기 전용 접근으로 범위를 지정하세요.

<Tip>
MCP 서버 접근을 위해 키의 사용자는 **Organization Read Only**, **Organization Manager**, **Organization Product Admin**이 할당된 그룹에 속하거나, MCP 읽기 권한을 부여하는 커스텀 역할이 있어야 합니다. 최소 권한을 위해 **Organization Read Only**를 사용하세요. NRQL 및 NerdGraph 쿼리에는 읽기 전용 역할로 충분합니다.
</Tip>

## 에이전트 기능

연결 후 에이전트는 New Relic 환경 전반에서 쿼리하고 조사할 수 있습니다.

| 기능 | 에이전트가 할 수 있는 것 |
|------|------------------------|
| **APM** | 애플리케이션 성능 검사 — 처리량, 오류율, 트랜잭션 트레이스 |
| **인프라** | 호스트 및 컨테이너 목록 조회, 리소스 사용률 검토 |
| **NRQL** | NerdGraph를 통해 모든 텔레메트리에 대한 NRQL 쿼리 실행 |
| **알림** | 알림 정책, 조건, 열린 위반 사항 검토 |
| **로그** | 서비스 및 환경 전반의 로그 검색 및 분석 |
| **엔터티** | 모니터링되는 엔터티 및 서비스 검색 및 검사 |
| **인시던트** | 열린 이슈 조사 및 전체 인시던트 세부 정보 조회 |
| **대시보드** | 대시보드 구성 검사 |
| **연결 상태** | New Relic 연결이 정상 작동하는지 확인 |

### 연결 확인

```text
@alex verify the New Relic connection and list monitored entity types and any open alert violations
```

### 예시 프롬프트

```text
@alex check error rates for the checkout service in New Relic over the last hour
@alex run an NRQL query for the slowest transactions in the production app
@alex list open New Relic alert violations and investigate the root cause
```

## 문제 해결

<Accordion title="연결 실패 또는 권한 없음">
**User API 키**(`NRAK-…`)를 사용하고 있는지 확인하세요 — license, ingest, query 키는 사용하지 마세요. New Relic에서 키가 삭제되거나 교체되지 않았는지, 키의 사용자가 여전히 계정에 접근 권한이 있는지 확인합니다.
</Accordion>

<Accordion title="빈 결과 또는 인증 실패">
선택된 리전이 계정과 일치하는지 확인합니다 — EU 계정은 EU 엔드포인트를 사용해야 합니다. 연결을 해제하고 올바른 리전으로 다시 연결합니다.
</Accordion>

<Accordion title="연결 후 권한 또는 인가 오류">
키의 사용자에게 MCP 서버 읽기 역할이 없을 수 있습니다. **Organization Read Only**, **Organization Manager**, **Organization Product Admin**, 또는 MCP 읽기 권한이 있는 커스텀 조직 범위 역할을 할당합니다. 사용자가 예상하는 데이터의 계정에 접근 권한이 있는지 확인합니다.
</Accordion>

<Accordion title="MCP 연결이 전혀 작동하지 않음">
**Administration → Previews & Trials**에서 **New Relic AI MCP server** 미리보기가 활성화되어 있는지 확인합니다. 미리보기가 켜져 있지 않으면 연결이 작동하지 않습니다.
</Accordion>
