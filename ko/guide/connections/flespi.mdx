Flespi 계정을 연결하면 [CloudThinker](/ko/guide/agents/overview)가 텔레매틱스 차량에 관한 질문에 답할 수 있습니다. 어떤 장치가 보고를 멈췄는지, 장치가 지난 하루 동안 무엇을 보냈는지, 채널이 데이터를 받고 있는지, 스트림이 데이터를 전달하고 있는지 등입니다. Flespi는 GPS 트래커와 기타 IoT 장치에서 데이터를 받는 텔레매틱스 백엔드입니다. CloudThinker는 사용자가 만든 하나의 **Flespi token**으로 로그인하여 Flespi 자체의 호스팅 MCP 서버와 통신합니다.

## 지원 플랫폼

| 플랫폼 | 지원 | 참고 |
|----------|-----------|-------|
| **Flespi cloud** (flespi.io) | 예 | CloudThinker는 `https://flespi.io/ai/mcp/develop`에 있는 Flespi의 호스팅 MCP 서버를 호출합니다. 주소가 고정되어 있으므로 데이터는 Flespi의 MCP 서버에서 CloudThinker로 흐르며, 다른 Flespi 엔드포인트는 설정할 수 없습니다 |

## 사전 요구 사항

- [flespi.io](https://flespi.io/#/)의 Flespi 패널에 접근할 수 있는 Flespi 계정.
- 해당 계정에서 토큰을 만들 수 있는 권한.

## 토큰 유형 선택

| 토큰 유형 | 접근 권한 | 용도 |
|------------|--------|------------|
| **ACL** | 모듈과 메서드별로 부여하기 전까지는 아무것도 없음 | 프로덕션. 권장 |
| **Standard** | 텔레매틱스 엔터티에 대한 전체 읽기 및 쓰기 | 짧은 테스트에만 사용 |
| **Master** | 전체 계정 관리 | CloudThinker에는 절대 사용하지 않음 |

읽기 전용 ACL 토큰의 경우, 에이전트가 봐야 할 각 모듈에 **GET**을 부여하세요.

| ACL 모듈 | 메서드 | 허용되는 것 |
|------------|--------|---------|
| `gw/devices` | GET | Devices와 Telemetry: 장치 목록, 마지막 보고 시간, 장치 메시지 |
| `gw/channels` | GET | Channels: 설정, 프로토콜, 수신 데이터 |
| `gw/streams` | GET | Streams: 상태와 전달 |
| `gw/geofences` | GET | 지오펜스 |
| `gw/calcs` | GET | 이동 감지 같은 계산기 |

에이전트에게 필요 없는 모듈은 빼세요. 에이전트가 무언가를 변경하기를 원할 때만 쓰기 메서드(POST, PUT, DELETE)를 부여하세요. [쓰기 권한](#쓰기-권한)을 참조하세요.

<Info>
ACL 토큰은 기본적으로 거부하며, 권한은 서로를 포함하지 않습니다. 장치에 대한 쓰기 권한은 읽기 권한을 함께 부여하지 않는 한 장치 읽기를 포함하지 않습니다.
</Info>

## 설정

<Steps>
  <Step title="Flespi에서 토큰 만들기">
    Flespi 패널의 왼쪽 메뉴에서 **Tokens**를 열고 **+**를 클릭합니다. 다음을 설정합니다.

    - **Name**: `CloudThinker`
    - **Type**: **ACL**. ACL 편집기에서 [ACL 표](#토큰-유형-선택)의 모듈마다 항목을 하나씩 추가하고 각각에 **GET** 메서드를 허용합니다
    - **Expiration**: Flespi는 모든 토큰에 TTL 또는 만료 날짜를 요구합니다. 90일 비활성 TTL을 사용하세요. 호출할 때마다 초기화되므로 활발히 사용하는 토큰은 계속 유효하고, 사용하지 않는 토큰은 정리됩니다

    토큰을 저장하고 값을 복사합니다.
  </Step>
  <Step title="CloudThinker에 연결 추가">
    **Settings → Workspace → Connections**를 열고 **Discover** 탭에서 **Flespi**를 선택합니다. **FLESPI_TOKEN**에 토큰을 붙여 넣습니다. `FlespiToken` 접두사 없이 토큰 값만 붙여 넣으세요. CloudThinker가 해당 헤더를 직접 추가합니다.

    **Connect**를 클릭합니다.

    **성공 상태:** 연결에 **Connecting**과 **Verifying**이 표시된 다음 **Connected**가 표시됩니다. 확인이 실패하면 **Failed**와 오류 메시지가 표시됩니다. 메시지를 [문제 해결](#문제-해결)과 대조해 보세요.
  </Step>
</Steps>

## 연결 세부 정보

| 필드 | 필수 | 설명 |
|-------|----------|-------------|
| **FLESPI_TOKEN** | 예 | Flespi ACL 또는 Standard 토큰. CloudThinker는 이를 `Authorization: FlespiToken <token>` 형식으로 Flespi의 MCP 서버에 보냅니다 |

## 에이전트 기능

에이전트가 할 수 있는 작업은 토큰이 허용하는 범위에 따라 다릅니다.

| 기능 | 에이전트가 할 수 있는 작업 | 필요한 ACL |
|------------|--------------------|-----------|
| **Devices** | 장치를 나열하고, 각 장치가 마지막으로 보고한 시간을 확인하고, 장치의 최근 메시지 읽기 | `gw/devices` GET |
| **Telemetry** | 시간 범위에 걸쳐 장치 메시지에서 위치, 속도, 센서 값 가져오기 | `gw/devices` GET |
| **Channels** | 채널 설정과 프로토콜, 채널이 데이터를 받고 있는지 검사 | `gw/channels` GET |
| **Streams** | 스트림 상태와 다운스트림 시스템으로의 전달 확인 | `gw/streams` GET |
| **Geofences and calculators** | 지오펜스 구역과 이동 감지 같은 계산기 설정 읽기 | `gw/geofences` GET, `gw/calcs` GET |

Flespi 문서 검색처럼 Flespi의 일부 AI 지원 도구는 Flespi 계정의 AI 사용량 한도를 사용합니다. 이 도구들에 의존한다면 Flespi 패널의 **AI** 타일을 확인하세요. 일반적인 장치, 채널, 스트림 읽기는 한도를 사용하지 않습니다.

### 연결 확인

```text
List my Flespi devices and when each one last reported
```

장치 이름 또는 ID 목록이 각각의 마지막 메시지 시간과 함께 표시되어야 합니다. 토큰이 읽을 수 없는 장치는 나타나지 않습니다.

### 예시 프롬프트

```text
Which Flespi devices haven't sent a message in the last 6 hours?
Show the messages from device 12345 over the last 24 hours and flag any gaps
Are all my Flespi streams delivering, and which ones have errors?
```

## 쓰기 권한

읽기 전용 ACL 토큰이 권장 설정이며, Flespi는 허용하지 않은 쓰기를 거부합니다. 쓰기 메서드를 부여하면 에이전트가 시도하는 각 쓰기는 [Approvals](/guide/approvals/overview)를 거칩니다. Rules와 Approval mode가 쓰기를 실행할지, 사람을 기다릴지, 거부할지 결정합니다. 읽기는 승인이 필요하지 않습니다.

## 문제 해결

<Accordion title="Invalid or expired token">
Flespi는 토큰이 만료되면 삭제합니다. Flespi 패널에서 토큰의 TTL을 확인하고, 사라졌다면 새 토큰을 만들어 연결의 **FLESPI_TOKEN**을 업데이트하세요.
</Accordion>

<Accordion title="Action is not permitted by ACL">
ACL 토큰에 해당 요청의 모듈과 메서드가 없습니다. Flespi 패널에서 토큰에 권한을 추가하세요. 읽기와 쓰기는 따로 부여된다는 점을 기억하세요.
</Accordion>

<Accordion title="Using token from unauthorized location">
토큰에 CloudThinker가 포함되지 않은 IP 허용 목록이 있습니다. Flespi 패널에서 토큰의 IP whitelist에 CloudThinker의 egress IP를 추가하거나 제한을 제거하세요. 이 문서는 CloudThinker의 egress IP 목록을 공개하지 않습니다. CloudThinker 담당자에게 문의하거나 [문의하기](https://cloudthinker.io/contact)를 이용하세요.
</Accordion>

<Accordion title="HTTP 429 rate limit">
Flespi는 계정의 API, MQTT, 트래픽 전반에 걸쳐 분당 사용량을 제한합니다. 범위를 좁히거나 한 번에 요청하는 장치 수를 줄이거나, 1분 기다린 후 다시 시도하세요.
</Accordion>

<Accordion title="AI 지원 조회가 거부됨">
이번 달 Flespi AI 한도를 모두 사용했습니다. 장치, 채널, 스트림 읽기는 계속 작동합니다. Flespi 패널의 **AI** 타일에서 사용량을 확인하세요.
</Accordion>

## 보안

<ConnectionSecurity />

- **CloudThinker 전용 토큰 하나**: 다른 통합과 공유하지 마세요. 그래야 따로 취소할 수 있습니다.
- **Master 토큰은 절대 사용하지 않기**: 에이전트에게 필요한 모듈과 메서드만 가진 ACL을 사용하세요.
- **90일 비활성 TTL 유지**: 사용 중인 토큰은 계속 유효합니다. 연결이 그만큼 오래 사용되지 않으면 Flespi가 토큰을 삭제하므로 새 토큰이 필요합니다. 평소의 자격 증명 교체 일정에 따라서도 교체하세요.
