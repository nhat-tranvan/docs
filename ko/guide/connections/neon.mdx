Neon 계정을 연결하면 CloudThinker 에이전트가 Neon 프로젝트를 검사하고, 데이터베이스 스키마를 검토하며, 느린 쿼리를 분석하고, Neon의 호스팅 MCP 서버를 통해 승인된 데이터베이스 작업을 지원할 수 있습니다.

Neon은 **OAuth**를 사용하므로 Neon API 키를 생성하거나 자격증명을 CloudThinker에 붙여넣을 필요가 없습니다.

---

## 사전 요구사항

- CloudThinker가 검사할 프로젝트에 접근 가능한 **Neon 계정**.
- Neon의 OAuth 흐름을 통해 CloudThinker를 인가할 권한.
- Neon이 아직 연결되지 않은 CloudThinker 워크스페이스.

<Info>
CloudThinker는 워크스페이스당 하나의 Neon 연결만 지원합니다. 계정을 전환하려면 기존 Neon 연결을 제거하고 재연결하세요.
</Info>

---

## 설정

<Steps>
  <Step title="CloudThinker 열기">
    CloudThinker 워크스페이스의 **Connections → Neon**으로 이동하세요.
  </Step>
  <Step title="OAuth 흐름 시작">
    **Connect**를 클릭하여 Neon의 인가 페이지를 여세요.
  </Step>
  <Step title="CloudThinker 인가">
    CloudThinker가 사용할 프로젝트를 소유하거나 접근할 수 있는 Neon 계정으로 로그인한 후 접근을 승인하세요.
  </Step>
  <Step title="CloudThinker로 돌아오기">
    인가 후 CloudThinker가 OAuth 토큰을 저장하고 **Connected** 상태를 표시합니다.
  </Step>
</Steps>

---

## 연결 세부 정보

Neon은 OAuth를 사용하므로 수동으로 입력할 연결 필드가 없습니다. CloudThinker는 인가 흐름이 완료된 후 OAuth 액세스 및 갱신 토큰을 자동으로 저장합니다.

| 필드 | 설명 |
|-------|-------------|
| **OAuth 토큰** | Neon이 발급하고 자동으로 저장됨; 수동 입력 불필요 |

---

## 필요 권한

CloudThinker는 OAuth 중에 부여된 Neon 접근 권한을 상속합니다.

- **읽기 작업**에는 프로젝트 목록 조회, 스키마 검사, 메타데이터 검토, 느린 쿼리 분석이 포함됩니다.
- SQL 실행, 브랜치 변경, 마이그레이션, Neon Auth 변경, Data API 프로비저닝 등의 **쓰기 작업**은 일치하는 Neon 접근 권한 **및** CloudThinker의 명시적 [승인](/ko/guide/approval)이 필요합니다.

---

## 에이전트 기능

연결이 완료되면 에이전트가 할 수 있는 작업:

| 기능 | 설명 |
|------------|-------------|
| **프로젝트 검색** | Neon 프로젝트, 공유 프로젝트, 조직, 컴퓨트, 테이블 검색 |
| **스키마 검사** | 스키마 및 테이블 메타데이터 검사 |
| **쿼리 분석** | 느린 쿼리 검토 및 최적화 제안 |
| **SQL 실행** | 명시적 사용자 승인 후에만 SQL 또는 트랜잭션 실행 |
| **브랜치 관리** | 브랜치, 마이그레이션, Neon Auth 관리 — 각 작업에 승인 필요 |

### 연결 확인

```text
@tony list my Neon projects and summarize their schemas
```

### 예시 프롬프트

```text
@tony review slow queries on the production-db project and #recommend optimizations
@tony inspect the schema for the users table in the main branch
@tony list all available tables and branches on the analytics project
```

## 문제 해결

<Accordion title="OAuth 흐름이 완료되지 않음">
잘못된 Neon 계정으로 로그인되어 있거나 브라우저 세션이 Neon에 로그인되어 있지 않을 수 있습니다. 의도한 Neon 계정으로 로그인하고 CloudThinker Neon 연결 흐름을 다시 시도하세요.
</Accordion>

<Accordion title="CloudThinker에서 Neon이 이미 연결되어 있다고 표시됨">
워크스페이스당 하나의 OAuth Neon 연결만 허용됩니다. 기존 Neon 연결을 사용하거나 재연결 전에 제거하세요.
</Accordion>

<Accordion title="에이전트가 예상한 Neon 프로젝트를 찾을 수 없음">
해당 프로젝트에 접근 권한이 없는 Neon 계정으로 OAuth 흐름이 완료되었을 수 있습니다. 해당 프로젝트를 소유하거나 접근 권한이 있는 Neon 계정을 사용하여 재연결하세요.
</Accordion>

## 보안

<ConnectionSecurity />

- **쓰기에 승인 필요** — SQL, 브랜치, 마이그레이션, Auth, Data API 변경이 CloudThinker에서 승인 필요로 유지되도록 하세요
- **신중한 재연결** — Neon 계정을 전환하기 전에 기존 워크스페이스 연결을 제거하세요
