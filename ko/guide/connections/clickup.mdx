ClickUp을 연결하면 [Anna](/ko/guide/agents/anna)가 워크스페이스 구조를 검색하고, 작업을 분류하고, 워크로드를 검토하며, 작업, 댓글, 문서, 채팅을 조사할 수 있습니다. ClickUp은 호스팅 MCP 서버를 통한 **OAuth**를 사용하므로 CloudThinker에 API 토큰을 붙여넣을 필요가 없습니다.

## 사전 요구사항

- CloudThinker가 사용할 워크스페이스에 접근할 수 있는 **ClickUp 계정**.
- ClickUp OAuth 흐름을 통해 CloudThinker를 인가할 권한.
- ClickUp이 아직 연결되지 않은 CloudThinker 워크스페이스.

<Info>
ClickUp 워크스페이스를 정확히 하나만 인가하세요. ClickUp 도구는 인가 후 워크스페이스를 전환할 수 없으며, 여러 워크스페이스에 인가된 연결은 요청을 완료할 수 없습니다.
</Info>

## 설정

<Steps>
  <Step title="연결 카탈로그 열기">
    CloudThinker 워크스페이스에서 **Settings → Connections**로 이동하고, **Builtin Connections**를 선택한 다음 **ClickUp**을 선택하세요.
  </Step>
  <Step title="OAuth 흐름 시작">
    **Connect**를 클릭하여 ClickUp 인가 페이지를 여세요.
  </Step>
  <Step title="워크스페이스 하나 인가">
    필요한 작업에 접근할 수 있는 ClickUp 계정으로 로그인하고, ClickUp 워크스페이스를 정확히 하나 선택한 다음 접근을 승인하세요.
  </Step>
  <Step title="CloudThinker로 돌아오기">
    CloudThinker가 OAuth 인가를 저장하고 연결에 **Connected** 상태가 표시됩니다.
  </Step>
</Steps>

## 연결 세부 정보

ClickUp은 OAuth를 사용하므로 수동으로 입력할 자격증명 필드가 없습니다.

| 필드 | 설명 |
|-------|-------------|
| **OAuth 인가** | ClickUp이 발급하며 접근 승인 후 자동으로 저장됨 |
| **ClickUp 워크스페이스** | 인가 중 선택한 단일 워크스페이스 |
| **MCP 엔드포인트** | `mcp.clickup.com/mcp`의 ClickUp 호스팅 서버. 고정되어 있으며 변경할 수 없음 |

## 필요 권한

CloudThinker는 인가한 사용자의 ClickUp 접근 권한을 상속합니다.

- **읽기 작업**은 사용자가 볼 수 있는 워크스페이스 구조, 작업, 댓글, 사용자 지정 필드, 워크로드, 시간 항목, 문서, 채팅 채널을 포함합니다.
- **쓰기 작업**은 작업, 댓글, 태그, 문서 페이지를 포함합니다. 일치하는 ClickUp 접근 권한 **및** CloudThinker의 명시적 [승인](/ko/guide/approval)이 필요합니다.

<Tip>
CloudThinker에 필요한 스페이스와 목록에만 접근할 수 있는 ClickUp 사용자를 인가하세요. CloudThinker는 해당 사용자가 접근할 수 없는 리소스를 읽거나 변경할 수 없습니다.
</Tip>

## 에이전트 기능

연결 후 Anna가 할 수 있는 작업:

| 기능 | 설명 |
|------------|-------------|
| **워크스페이스 검색** | 스페이스, 폴더, 목록, 최근 작업을 나열 |
| **작업 분류** | 한 목록에서 기한 초과, 미할당, 미예약 작업 검색 |
| **워크로드 검토** | 담당자와 상태별 열린 작업을 비교하고 ClickUp이 제공할 때 상태 유지 시간 측정 |
| **작업 조사** | 작업 세부 정보, 사용자 지정 필드, 댓글, 스레드 토론 읽기 |
| **문서와 채팅** | 연결된 사용자가 이용할 수 있는 문서 페이지와 채팅 메시지 읽기 |
| **작업 변경** | 승인 후 작업 생성, 업데이트, 이동, 삭제 |
| **댓글, 태그, 문서** | 승인 후 댓글 추가, 태그 변경, 문서 페이지 업데이트 |

### 연결 확인

```text
@anna #report show the ClickUp workspace structure and summarize what needs attention in Project 1
```

### 예시 프롬프트

```text
@anna #report list overdue, unassigned, and unscheduled ClickUp tasks in Project 1
@anna #report compare open ClickUp work by assignee and status age in Team Space
@anna #recommend review the comments on the oldest overdue ClickUp task and suggest the next action
```

## 문제 해결

<Accordion title="OAuth 흐름이 완료되지 않음">
브라우저가 잘못된 ClickUp 계정에 로그인되어 있을 수 있습니다. 대상 워크스페이스에 접근할 수 있는 계정으로 로그인한 다음 **Connect**를 다시 시작하세요.
</Accordion>

<Accordion title="에이전트가 여러 워크스페이스를 보고함">
연결이 둘 이상의 ClickUp 워크스페이스에 인가되었습니다. ClickUp 연결을 해제하고 다시 연결한 다음 인가 중 워크스페이스를 정확히 하나 선택하세요.
</Accordion>

<Accordion title="연결에서 401 Unauthorized를 반환함">
ClickUp 액세스 토큰이 유효하지 않거나 만료되었습니다. ClickUp이 이 연결에 갱신 토큰을 발급하지 않을 수 있으므로 연결을 해제하고 ClickUp을 다시 인가하세요.
</Accordion>

<Accordion title="에이전트가 스페이스, 목록, 작업을 찾지 못함">
인가한 사용자에게 접근 권한이 없거나 리소스가 이동되었을 수 있습니다. 사용자의 ClickUp 접근 권한을 확인한 다음 에이전트에게 워크스페이스를 다시 검색하도록 요청하세요.
</Accordion>

<Accordion title="상태 유지 시간을 사용할 수 없음">
ClickUp 워크스페이스 설정에서 **Total time in Status** ClickApp을 활성화하세요. 이 측정이 비활성화되어도 작업과 워크로드 읽기는 계속 작동합니다.
</Accordion>

<Accordion title="요청에서 속도 제한 오류를 반환함">
ClickUp 계정이 공급자 할당량에 도달했습니다. ClickUp 속도 제한 창이 재설정될 때까지 기다린 다음 같은 범위로 다시 시도하세요.
</Accordion>

## 보안

<ConnectionSecurity />

- **제한된 워크스페이스 하나 사용**: CloudThinker가 접근해야 하는 ClickUp 워크스페이스만 인가하세요.
- **최소 권한 사용**: CloudThinker가 보고 변경해야 하는 작업과 일치하는 스페이스와 목록에만 접근할 수 있는 ClickUp 사용자를 연결하세요.
