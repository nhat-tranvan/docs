**팀이 일하는 방식대로 작동합니다.**

Customize는 에이전트(기본 제공 어시스턴트인 CloudThinker와 직접 만든 커스텀 에이전트. [에이전트](/ko/guide/agents/overview) 참고)를 팀에 맞추는 방법입니다. 어떤 에이전트가 있는지, 어떤 절차를 따르는지, 어떤 시크릿을 사용할 수 있는지, 알림이 어디로 가는지, 어떤 변경에 사람이 먼저 필요한지를 정합니다. 여기의 모든 항목은 워크스페이스 단위이며 **Settings → Workspace**에 있습니다.

CloudThinker는 이 설정 없이도 작동합니다.

## 작동 방식

각 항목은 에이전트가 어떻게 동작하는지에 대한 질문 하나에 답합니다. 순서에 상관없이 설정할 수 있습니다.

1. **누가 답하는가.** 커스텀 에이전트는 고유한 이름, `@mention`, 지침, 응답 언어, 연결을 가집니다.
2. **어떻게 일하는가.** 스킬은 절차와 규칙을 담습니다.
3. **무엇에 접근할 수 있는가.** 연결은 시스템에 대한 접근 권한을 제공합니다. 자격 증명은 CLI용 공급업체 API 키 같은 기타 시크릿을 담습니다. 해당 도구에 대한 연결이 없을 때 사용합니다.
4. **무엇을 변경할 수 있는가.** 승인은 각 쓰기 작업이 실행될지, 사람을 기다릴지, 거부될지를 결정합니다. 모드는 두 가지입니다. **Manual**은 모든 쓰기 전에 사람에게 묻고, **Auto**는 Rules와 그다음 AI 판단이 결정하게 합니다.
5. **누가 알림을 받는가.** 알림은 이메일, Slack, Teams 또는 Google Chat으로 경보를 보냅니다.

선택 사항 하나가 이들 옆에 있습니다. **Memory**는 에이전트가 대화 사이에 기억하는 내용을 담습니다.

<Warning>
새 워크스페이스는 **Auto · Rules + AI · Ask me**로 시작하며, 이 모드에서는 AI 판단이 안전한 쓰기를 묻지 않고 실행할 수 있습니다. 프로덕션을 연결하기 전에 모든 쓰기 전에 사람에게 묻는 **Manual**로 전환하세요. **Ask first** [Rule](/guide/approvals/rules)은 더 좁은 제어 수단으로, 특정 종류의 쓰기 하나가 사람을 기다리게 합니다. [승인](/guide/approvals/overview#what-you-get-out-of-the-box)을 참고하세요.
</Warning>

## 에이전트별 항목과 워크스페이스 공통 항목

| 커스텀 에이전트별로 설정 | 워크스페이스의 모든 에이전트가 공유 |
|---|---|
| 이름과 `@mention`, 지침, 응답 언어, 모델 등급, Learning Mode, 연결 | 스킬, 자격 증명, 메모리, 알림, Approval Rules와 워크스페이스 Approval mode |

스킬은 **Available in**에서 체크한 각 화면(예: Chat 또는 Review)에서 모든 에이전트에 적용됩니다. 커스텀 에이전트를 특정 스킬로만 제한할 수는 없습니다. 대신 지침과 연결로 범위를 정하세요. 지침은 에이전트를 안내할 뿐 아무것도 차단하지 않습니다. 연결이 실제 한계입니다. 에이전트는 자신에게 연결된 연결에만 접근합니다.

## 각 설정의 위치

사이드바 상단의 워크스페이스 메뉴에서 **Settings**를 열거나(**Workspace**에서 열립니다) ⌘⇧,(Windows/Linux에서는 Ctrl+Shift+,)를 누르세요. **Workspace** 탭은 페이지를 다음과 같이 묶습니다.

| 그룹 | 페이지 | 설정하는 내용 | 편집 권한 | 가이드 |
|-------|------|--------------------|--------------|-------|
| Overview | **Connections** | 에이전트가 접근할 수 있는 클라우드 계정, 클러스터, 데이터베이스, 도구 | Admin | [연결](/ko/guide/connections/overview) |
| Overview | **Notifications** | 어떤 이벤트가 이메일, Slack, Teams 또는 Google Chat으로 전달되는지 | Admin | [알림](/ko/guide/notifications) |
| Agents & context | **Agents** | 커스텀 에이전트: 정체성, 지침, 모델 등급, 연결 | Admin 및 Developer | [커스텀 에이전트 빠른 시작](/guide/agents/quickstart) |
| Agents & context | **Skills** | 재사용 가능한 절차와 각 절차가 적용되는 곳 | Admin | [스킬](/ko/guide/skills/overview) |
| Agents & context | **Memory** | 에이전트가 대화 사이에 기억하는 내용 | Admin | [메모리](/guide/memory) |
| Access & keys | **Credentials** | 에이전트가 명령을 실행할 때 받는 시크릿 | Admin | [자격 증명](/guide/credentials) |
| Autonomy | **Rules**, **Approvers**, **Runbooks** | 쓰기에 대한 Rules, Approval mode, 승인자 | Admin | [승인](/guide/approvals/overview) |

같은 그룹에 **General**, **Members**, **Capabilities**, **Environments**, **BYOK** 같은 다른 워크스페이스 페이지도 있습니다.

역할별 전체 권한은 [역할](/guide/security/roles)을 참고하세요.

## 할 수 있는 일

| 목표 | 설정할 항목 | 자세히 보기 |
|------|-------------|------------|
| 베트남어로 답하는 비용 리뷰어처럼 팀 전용 전문가 두기 | 커스텀 에이전트를 만들고 **Language**를 설정한 뒤 필요한 연결만 연결 | [커스텀 에이전트 빠른 시작](/guide/agents/quickstart) |
| 에이전트가 매번 런북을 따르게 하기 | 런북을 스킬로 작성하고 **Chat** 또는 **Incident**에 연결 | [커스텀 스킬](/ko/guide/skills/custom-skills) |
| 모든 풀 리퀘스트에 리뷰 기준 적용 | 스킬을 작성하고 **Review**에 연결 | [커스텀 스킬](/ko/guide/skills/custom-skills#스킬을-적용할-곳-선택) |
| 에이전트를 특정 계정이나 도구로 제한 | 해당 연결만 에이전트에 연결 | [커스텀 에이전트 빠른 시작](/guide/agents/quickstart#give-it-a-connection) |
| 채팅에 붙여넣지 않고 에이전트에 API 토큰 제공 | **Credentials**에 추가 | [자격 증명](/guide/credentials) |
| 모든 프로덕션 쓰기 전에 사람 요구 | Approval mode를 **Manual**로 설정하거나, 특정 종류의 쓰기가 사람을 기다리도록 **Ask first** Rule 추가 | [승인](/guide/approvals/overview) |

스킬, 메모리, Learnings, 런북 소스 중 무엇을 쓸지 고르려면 [CloudThinker 가르치기](/guide/teach-cloudthinker)를 참고하세요.

## 커스텀 에이전트 한눈에 보기

| 항목 | 세부 내용 |
|------|--------|
| 생성 | **Settings → Workspace → Agents**에서 **Create agent**를 클릭합니다. **Create with AI** 또는 **Build with form**(Identity, Configuration, Connect의 3단계 다이얼로그)을 선택합니다. |
| Create with AI | 이름, `@mention`, 역할, 목표, 지침, 모델 등급, 언어, Learning Mode, 아바타, 연결을 묻는 채팅이 열립니다. `@mention`을 확인한 뒤 검토할 양식 없이 채팅에서 바로 에이전트를 만듭니다. 일반 채팅이므로 크레딧을 사용합니다. |
| `@mention` | 소문자, 숫자, 점, 밑줄, 하이픈을 사용하며 문자로 시작하고 최대 63자입니다. 한 번 설정하면 나중에 변경할 수 없습니다. |
| Instructions | 최대 4,000자의 평이한 안내입니다. 에이전트가 스킬을 사용하도록 지시할 때 쓰세요. 예: `Use the ec2-high-cpu-runbook skill for performance questions.` |
| Model Tier | **Light**(Pro 크레딧의 0.3배, 간단한 질문), **Pro**(기본값, 일상 업무), **Ultra**(Pro 크레딧의 1.7배, 어려운 문제). Free 플랜은 Light만 실행하므로 거기서는 **Light**를 선택하세요. [실행 비용이 늘어나는 요인](/ko/guide/billing/usage#실행-비용을-높이는-요인)을 참고하세요. |
| Language | 기본값은 **Match the user**로, 에이전트가 최근 메시지의 언어로 답합니다. 언어를 선택하면 모든 응답이 그 언어로 고정됩니다. |
| Learning Mode | 에이전트가 반복되는 워크플로를 스킬로 저장할지 여부입니다. [Learning Mode](#learning-mode)를 참고하세요. |
| Connections | 에이전트당 최대 64개, **Builtin** 및 **MCP** 탭에서 선택 |
| 생성 및 편집 권한 | 워크스페이스 Admin과 Developer. Viewer는 에이전트를 볼 수 있지만 채팅하거나 편집할 수 없습니다. |

워크스페이스가 가질 수 있는 커스텀 에이전트 수는 플랜에 따라 다릅니다.

| 플랜 | 커스텀 에이전트 |
|------|---------------|
| Free | 1 |
| Team | 5 |
| Scale | 10 |
| Enterprise | 무제한 |

**Create Custom Agent** 다이얼로그에는 사용한 슬롯 수가 표시됩니다(예: **3 of 5 custom agents used**). 조직 Owner는 **Settings → Organization → Billing**에서 플랜 자체를 확인합니다.

한도에 도달하면 **Create agent**가 비활성화되고, 마우스를 올리면 **Upgrade plan** 링크와 함께 **Custom agent limit reached.**가 표시됩니다. 에이전트를 삭제하면 슬롯이 즉시 비워집니다. 한도는 에이전트를 만들 때만 확인하므로, 다운그레이드 후에도 기존 에이전트는 계속 작동하지만 새 한도 아래로 내려갈 때까지 추가할 수 없습니다. 다른 플랜별 한도는 [가격](/ko/guide/billing/pricing#플랜별-ai-기능)을 참고하세요.

## Learning Mode

Learning Mode는 커스텀 에이전트가 반복하는 워크플로를 스킬로 만들게 합니다. 도구 호출이 10회 이상 실행된 대화에서 에이전트가 같은 연결에 같은 도구 호출을 3번 하면 작동합니다. 이 기준값은 워크스페이스 설정에서 변경할 수 없습니다.

| 모드 | 동작 |
|---|---|
| **Auto** (양식의 기본값) | 에이전트가 워크플로를 스스로 스킬로 저장합니다. "조사만 하고 아무것도 변경하지 마세요"처럼 요청이 읽기로 제한될 때는 저장하지 않습니다. |
| **Offer** | 에이전트가 먼저 채팅에서 묻고, 채팅에 있는 누구든 승낙할 수 있습니다. |
| **Off** | 에이전트가 스킬을 저장하지 않습니다. |

<Note>
**Settings → Workspace → Skills**에서 스킬을 만들 수 있는 사람은 Admin뿐이지만, 에이전트는 Developer도 만들 수 있습니다. **Auto** 또는 **Offer**로 설정된 커스텀 에이전트는 Admin 없이 워크스페이스 스킬을 추가하며, 그 스킬은 모든 에이전트의 **Chat**에서 바로 적용됩니다. [Audit Logs](/guide/security/audit-logs)에는 기록되지 않습니다. 프로덕션 워크스페이스의 에이전트에는 **Off**를 사용하세요. Off를 강제하는 워크스페이스 설정은 없습니다. Admin이 에이전트 설정에서 에이전트별로 지정하며, 학습된 스킬은 **Settings → Workspace → Skills**에서 편집, 범위 재설정, 삭제할 수 있습니다.
</Note>
