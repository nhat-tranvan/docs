기본 제공되는 다섯 에이전트는 별도 설정 없이 바로 사용할 수 있습니다. 사용자 정의를 통해 **대화 방식**(어조, 규칙, 언어)과 **접근 가능한 대상**(연결)을 변경할 수 있습니다. 기본 에이전트로 충분하지 않을 때는 직접 에이전트를 만들 수 있습니다.

[Agents](https://app.cloudthinker.io/agents) 페이지를 열어 시작하세요. 왼쪽 패널은 에이전트를 **Core Team**(기본 제공 다섯 에이전트)과 **Custom**(직접 만든 에이전트)으로 분류합니다. 에이전트를 클릭하면 설정 다이얼로그가 열리며 두 개의 탭(**Identity**, **Connections**)이 있습니다. 개성(Instructions, Language, Learning mode)은 **Identity** 탭의 하단에 있습니다.

<Note>
  에이전트 사용자 정의는 **워크스페이스 관리자** 권한이 필요합니다. 일반 멤버는 에이전트와 채팅할 수 있지만 편집은 불가능합니다.
</Note>

---

## 변경 가능한 항목

| 필드 | 기본 에이전트 (Alex, Oliver, Tony, Kai, Anna) | 커스텀 에이전트 |
|------|----------------------------------------------|----------------|
| @mention | 잠금 | 생성 시 한 번 설정, 이후 변경 불가 |
| 이름, 역할, 목표 | 잠금 | 편집 가능 |
| Instructions, Language, Learning mode | 편집 가능 | 편집 가능 |
| 연결 | 연결/해제 가능 (Anna는 읽기 전용 — 다른 에이전트에서 상속) | 연결/해제 가능 |
| 활성 상태 | 자동 — 연결 없을 때 꺼짐 (Anna는 항상 켜짐) | 수동 |

기본 에이전트는 전문화된 작업(클라우드, 보안, 데이터베이스, Kubernetes, 그리고 조율을 위한 Anna)에 최적화되어 제공됩니다. 튜닝이 유지되도록 ID는 잠금 상태로 유지되며, 워크플로우에 맞게 **Instructions**, **Language**, **Learning mode**, **Connections**는 조정할 수 있습니다.

## 플랜 등급

기본 에이전트 편집은 **모든 플랜**에서 가능합니다. 커스텀 에이전트 수만 플랜별로 다릅니다.

| 플랜 | 커스텀 에이전트 |
|------|----------------|
| Free | 1 |
| Team | 5 |
| Scale | 10 |
| Scale + | 10 |
| Enterprise | 무제한 |

한도에 도달했나요? 사용하지 않는 에이전트를 삭제하거나 [플랜을 업그레이드](/ko/guide/billing/pricing)하세요.

## 커스텀 에이전트 만들기

기본 에이전트가 커버하지 않는 용도의 에이전트가 필요하신가요? 청구 분석가, 온콜 요약 담당자, 문서화 전문가 등을 직접 만들 수 있습니다.

[Agents](https://app.cloudthinker.io/agents) 페이지에서 **Custom** 옆의 **+** 버튼을 클릭하고 생성 방법을 선택하세요.

<Tabs>
  <Tab title="AI로 만들기">
    에이전트가 **무엇을 해야 하는지는 알지만** 모든 필드를 직접 작성하고 싶지 않을 때 최적입니다.

    원하는 내용을 한 문장으로 설명하면 Anna가 나머지를 처리합니다. 일반적으로 다음을 확인합니다:

    - **이름과 @mention** — 설명을 기반으로 옵션을 제안합니다.
    - **역할과 목표** — 검토 또는 수정할 수 있도록 초안을 작성합니다.
    - **모델 티어** — 작업 복잡도를 기반으로 Light / Pro / Ultra를 권장합니다.
    - **Instructions** — 수정할 수 있는 첫 번째 초안을 생성합니다.
    - **Connections** — 연결할 항목을 묻습니다(클라우드, 데이터베이스, K8s, MCP).
    - **Learning mode** — Auto 또는 Offer.

    예시 프롬프트: *"AWS 지출을 모니터링하고 일일 비용이 20% 이상 급증하면 알려주는 에이전트가 필요합니다."*

    이후 에이전트 설정 다이얼로그에서 모든 필드를 편집할 수 있습니다.
  </Tab>
  <Tab title="수동으로 만들기">
    처음부터 모든 필드를 완전히 제어하고 싶을 때 최적입니다. 다이얼로그는 세 단계를 안내합니다. 헤더에는 현재 플랜의 커스텀 에이전트 할당량이 표시됩니다(예: Scale 플랜에서 "1 of 10 custom agents used").

    <Steps>
      <Step title="Identity">
        - **Avatar** — 타일을 클릭하여 변경합니다(기본값은 그라디언트 배경에 이니셜).
        - **이름** — 예: "Cost Guardian".
        - **@mention** — 채팅 핸들(예: `@cost-guardian`). 고유해야 하며 `@alex`, `@oliver`, `@tony`, `@kai`, `@anna`는 재사용 불가. **한 번 설정하면 변경 불가.**
        - **역할** — 짧은 직함(예: "FinOps Specialist").
        - **목표** — 이 에이전트가 하는 일을 한 문장으로.

        **Next**를 클릭하세요.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-1.png" alt="커스텀 에이전트 만들기 마법사, 1단계 Identity — 아바타 타일, 이름, @mention, 역할, 목표 필드" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Configuration">
        - **모델 티어** — **Light**(빠름, 최저 크레딧 비용), **Pro**(균형), **Ultra**(최고 성능, 최고 크레딧 비용) 중 선택. 현재 크레딧 배수는 [Pricing](/ko/guide/billing/pricing)을 참고하세요.
        - **Instructions** — 에이전트가 어떻게 동작해야 하는지 설명하는 텍스트 영역: 집중할 내용, 응답 방식, 피해야 할 내용. 평이한 문장으로 작성하세요 — 지침, 제약, 어조, 응답 형식이 모두 여기에 있습니다.
        - **Language** — 응답 언어.
        - **Learning mode** — **Auto**는 새 스킬을 자동으로 저장하고, **Offer**는 저장 전에 확인을 요청합니다.

        **Next**를 클릭하세요.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-2.png" alt="커스텀 에이전트 만들기 마법사, 2단계 Configuration — 모델 티어, Instructions, Language, Learning mode" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Connect">
        선택 사항입니다. **Builtin** 및 **MCP** 탭을 사용하여 이 에이전트가 접근할 수 있는 연결을 선택합니다. 나중에 에이전트 설정에서 더 추가할 수 있습니다.

        **Skip and Create**를 클릭하여 완료합니다.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-3.png" alt="커스텀 에이전트 만들기 마법사, 3단계 Connect — Builtin 및 MCP 탭과 연결 목록" style={{ maxWidth: '500px' }} />
        </Frame>
      </Step>
    </Steps>

    에이전트가 **Custom** 아래에 나타나며 채팅에서 @mention 핸들로 접근할 수 있습니다.
  </Tab>
</Tabs>

## 기본 에이전트 편집

어조, 규칙, 언어 등을 변경합니다. 에이전트의 ID(이름, @mention, 역할, 목표)는 그대로 유지되며, 말하고 행동하는 방식만 변경됩니다.

<Steps>
  <Step title="에이전트 열기">
    [Agents](https://app.cloudthinker.io/agents)로 이동하여 **Core Team**에서 에이전트를 클릭합니다. 다이얼로그가 **Identity** 탭에서 열립니다.
  </Step>
  <Step title="잠금 해제된 필드 편집">
    **Identity** 탭에서 이름, 역할, 목표는 "CloudThinker가 설정함, 변경 불가" 힌트와 함께 잠금되어 있으며, @mention에는 "한 번 설정하면 변경 불가"가 표시됩니다. 같은 탭을 스크롤하여 다음을 편집합니다:

    - **Instructions** — 자체 규칙, 제한 사항, 어조, 응답 형식을 위한 텍스트 영역. 평이한 문장으로 작성합니다(예: *"간결한 불릿 포인트로 응답하세요. 쓰기 권한이 필요한 변경 사항은 절대 제안하지 마세요. $500 이상의 이상 현상은 에스컬레이션하세요."*).
    - **Language** — 응답 언어.
    - **Learning mode** — **Auto**는 새 스킬을 자동으로 저장하고, **Offer**는 저장 전에 확인을 요청합니다.
  </Step>
  <Step title="저장">
    오른쪽 하단의 **Save**를 클릭합니다. 변경 사항은 다음 메시지부터 적용됩니다.
  </Step>
</Steps>

<Frame>
  <img src="/images/agents/customize-agent-dialog.png" alt="에이전트 설정 다이얼로그: Identity 및 Connections 탭, 잠긴 이름/@mention/역할/목표 필드, Identity 탭 하단의 편집 가능한 Instructions/Language/Learning mode" />
</Frame>

## 연결 연결하기

연결은 에이전트가 클라우드, 데이터베이스, Kubernetes 또는 MCP 서버에 접근하는 방법입니다. Alex, Oliver, Tony, Kai는 연결 없이 시작하며, 각 에이전트가 접근할 수 있는 것을 직접 결정합니다.

<Steps>
  <Step title="Connections 탭 열기">
    에이전트 다이얼로그에서 **Connections**를 클릭합니다. 헤더에 개수가 표시됩니다(예: "3 connections").
  </Step>
  <Step title="Builtin 또는 MCP 선택">
    하위 탭을 사용하여 **Builtin**(클라우드, 데이터베이스, Kubernetes)과 **MCP** 사이를 전환합니다.
  </Step>
  <Step title="추가 또는 제거">
    **Add**를 클릭하여 연결하고, **Remove**를 클릭하여 분리합니다. Save를 클릭하여 적용합니다.
  </Step>
</Steps>

<Note>
  **연결이 없는 기본 에이전트는 자동으로 꺼집니다.** 다시 켜려면 최소 하나의 연결을 추가하세요.
</Note>

<Warning>
  **Anna의 연결은 자동으로 관리됩니다.** Anna는 다른 에이전트를 조율하고 그들의 접근 권한을 상속하므로, Connections 탭이 읽기 전용입니다. 대신 Alex, Oliver, Tony 또는 Kai에 연결을 추가하세요.
</Warning>

## 예시

| 원하는 것 | 할 일 |
|-----------|-------|
| Tony가 베트남어로 엄격한 SQL 형식으로 응답 | **Language**를 베트남어로 설정하고, Instructions에 다음을 추가: *"SQL을 대문자 키워드와 줄당 하나의 절로 형식화하세요."* |
| Oliver가 권장만 하고 절대 변경하지 않음 | Instructions에 추가: *"권장만 하세요 — 쓰기 권한이 필요한 변경 사항은 절대 제안하지 마세요."* |
| Alex가 EUR로 비용을 보고하고 주간 요약 제공 | Instructions에 추가: *"비용을 EUR로 보고하세요. 지출을 주간으로 요약하세요."* 클라우드 연결을 추가합니다. |

## 알아야 할 사항

- 편집은 **다음** 메시지부터 적용됩니다 — 진행 중인 채팅은 이전 설정으로 완료됩니다.
- 커스텀 에이전트의 @mention을 신중하게 선택하세요 — 한 번 설정하면 계속 사용해야 합니다.
