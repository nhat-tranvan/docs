기본 제공 어시스턴트인 [CloudThinker](/ko/guide/agents/overview)는 별도 설정 없이 바로 작동합니다. 커스텀 에이전트는 자체 지침, 응답 언어, 연결을 갖춘 팀만의 전문가를 그 옆에 추가합니다.

## 변경 가능한 항목

**Settings → Agents**로 이동하세요. 사이드바에 워크스페이스의 **Custom** 에이전트가 나열됩니다. 기본 제공 어시스턴트에는 설정 항목이 없습니다. 에이전트를 클릭하면 **Identity**와 **Connections** 두 탭이 열립니다.

<Note>
  에이전트 사용자 정의에는 워크스페이스 **Admin** 역할이 필요합니다. [Developer와 Viewer](/ko/guide/workspace-users)는 에이전트와 채팅할 수 있지만 편집할 수는 없습니다.
</Note>

| 필드 | 변경 가능 여부 |
|------|----------------|
| @mention | 생성 시 한 번 설정 |
| Name, Role, Goal, Instructions | 가능 |
| Model Tier, Language, Skill Learning | 가능 |
| Connections | 가능 — 연결 및 해제 |
| 활성 상태 | 가능 — 연결이 없으면 에이전트가 자동으로 꺼집니다 |

## 플랜 등급

커스텀 에이전트 수는 플랜에 따라 다릅니다.

| 플랜 | 커스텀 에이전트 |
|------|----------------|
| Free | 1 |
| Team | 5 |
| Scale | 10 |
| Scale+ | 10 |
| Enterprise | 무제한 |

한도에 도달했나요? 사용하지 않는 에이전트를 삭제하거나 [플랜을 업그레이드](/ko/guide/billing/pricing)하세요.

## 커스텀 에이전트 만들기

팀의 규칙이 내장된 에이전트가 필요하신가요? 청구 분석가, 온콜 요약 담당자, 문서화 전문가 등을 직접 만들 수 있습니다.

**Settings → Agents**로 이동하여 **Create agent**를 클릭한 다음 **Create with AI** 또는 **Build with form**을 선택하세요.

<Tabs>
  <Tab title="Create with AI">
    에이전트가 **무엇을 해야 하는지는 알지만** 모든 필드를 직접 작성하고 싶지 않을 때 적합합니다.

    원하는 내용을 한 문장으로 설명하면 CloudThinker가 나머지를 처리합니다. 일반적으로 다음을 확인합니다:

    - **Name과 @mention** — 설명을 바탕으로 옵션을 제안합니다.
    - **Role과 Goal** — 승인하거나 수정할 수 있도록 둘 다 초안을 작성합니다.
    - **Model Tier** — 작업 복잡도에 따라 Light / Pro / Ultra를 권장합니다.
    - **Instructions** — 다듬을 수 있는 첫 초안을 생성합니다.
    - **Connections** — 연결할 항목을 묻습니다(클라우드, 데이터베이스, Kubernetes 또는 외부 도구를 연결하는 개방형 표준인 [MCP](/ko/guide/connections/mcp)).
    - **Skill Learning** — 에이전트가 새 [스킬](/ko/guide/skills/overview)(작업에서 익힌 재사용 가능한 노하우)을 자동으로 저장할지(**Auto**), 먼저 물어볼지(**Offer**), 저장하지 않을지(**Off**).

    예시 프롬프트: *"AWS 지출을 모니터링하고 일일 비용이 20% 이상 급증하면 알려주는 에이전트가 필요합니다."*

    이후 에이전트 설정 다이얼로그에서 모든 필드를 편집할 수 있습니다.
  </Tab>
  <Tab title="Build with form">
    처음부터 모든 필드를 완전히 제어하고 싶을 때 적합합니다. 다이얼로그가 세 단계를 안내합니다. 헤더에는 현재 플랜의 커스텀 에이전트 할당량이 표시됩니다(예: Scale 플랜에서 "1 of 10 custom agents used").

    <Steps>
      <Step title="Identity">
        - **Avatar** — 타일을 클릭하여 변경합니다(기본값은 그라디언트 배경의 이니셜).
        - **Name** — 예: "Cost Guardian".
        - **@mention** — 채팅 핸들(예: `@cost-guardian`). 소문자, 숫자, 점, 밑줄, 하이픈을 사용할 수 있고 문자로 시작해야 하며 최대 63자입니다. 고유해야 하며 CloudThinker가 예약한 이름은 사용할 수 없습니다. **한 번 설정하면 변경할 수 없습니다.**
        - **Role** — 짧은 직함(예: "FinOps Specialist").
        - **Goal** — 이 에이전트가 하는 일을 한 문장으로.

        **Next**를 클릭하세요.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-1.png" alt="커스텀 에이전트 만들기 마법사, 1단계 Identity — 아바타 타일, Name, @mention, Role, Goal 필드" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Configuration">
        - **Model Tier** — **Light**(빠름, 최저 크레딧 비용), **Pro**(균형), **Ultra**(최고 성능, 최고 크레딧 비용) 중 선택합니다. 현재 크레딧 배수는 [사용량](/ko/guide/billing/usage)을 참고하세요.
        - **Instructions** — 에이전트가 어떻게 동작해야 하는지 설명하는 텍스트 영역: 집중할 내용, 응답 방식, 피해야 할 내용. 평이한 문장으로 작성하세요 — 지침, 제약, 어조, 응답 형식이 모두 여기에 들어갑니다. 최대 4,000자입니다.
        - **Language** — 응답 언어.
        - **Skill Learning** — **Auto**는 새 스킬을 자동으로 저장하고, **Offer**는 저장 전에 확인을 요청하며, **Off**는 저장하지 않습니다.

        **Next**를 클릭하세요.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-2.png" alt="커스텀 에이전트 만들기 마법사, 2단계 Configuration — Model Tier, Instructions, Language, Learning mode" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Connect">
        선택 사항입니다. **Builtin** 및 **MCP** 탭에서 이 에이전트가 접근할 수 있는 연결을 선택합니다. 나중에 Agent Settings에서 더 추가할 수 있습니다.

        **Skip and Create**를 클릭하여 완료합니다.

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-3.png" alt="커스텀 에이전트 만들기 마법사, 3단계 Connect — Builtin 및 MCP 탭과 연결 목록" style={{ maxWidth: '500px' }} />
        </Frame>
      </Step>
    </Steps>

    에이전트가 **Custom** 아래에 나타나며 채팅에서 @mention 핸들로 호출할 수 있습니다.
  </Tab>
</Tabs>

## 연결 추가

연결은 커스텀 에이전트가 클라우드, 데이터베이스, Kubernetes 또는 MCP 서버에 접근하는 방법입니다. 각 에이전트가 무엇에 접근할 수 있는지 직접 결정합니다. 모든 에이전트는 동일한 기본 제공 도구를 가지며 에이전트별 도구 토글은 없으므로, 연결을 선택하여 에이전트의 범위를 정하세요. 에이전트 하나에 최대 64개의 연결을 추가할 수 있습니다.

<Steps>
  <Step title="Connections 탭 열기">
    에이전트 다이얼로그에서 **Connections**를 클릭합니다. 헤더에 개수가 표시됩니다(예: "3 connections").
  </Step>
  <Step title="Builtin 또는 MCP 선택">
    하위 탭을 사용하여 **Builtin**(클라우드, 데이터베이스, Kubernetes)과 **MCP** 사이를 전환합니다.
  </Step>
  <Step title="추가 또는 제거">
    **Add**를 클릭하여 연결하고, **Remove**를 클릭하여 해제합니다. 저장하여 적용합니다.
  </Step>
</Steps>

에이전트의 업무에 필요한 연결만 추가하세요 — 데이터베이스 리뷰어에게는 프로덕션 IAM 접근 권한이 필요 없습니다. **연결이 없는 커스텀 에이전트는 자동으로 꺼집니다.** 다시 켜려면 최소 하나의 연결을 추가하세요.

## 예시

| 원하는 것 | 할 일 |
|-----------|-------|
| 베트남어로 응답하는 에이전트 | 에이전트의 **Identity** 탭에서 **Language**를 베트남어로 설정합니다. |
| 권장만 하고 절대 변경하지 않는 에이전트 | Instructions에 다음을 넣어 커스텀 에이전트를 만듭니다: *"권장만 하세요 — 쓰기 권한이 필요한 변경 사항은 절대 제안하지 마세요."* |
| EUR로 비용을 보고하고 주간 요약 제공 | Instructions에 다음을 넣어 커스텀 에이전트를 만듭니다: *"비용을 EUR로 보고하세요. 지출을 주간으로 요약하세요."* 클라우드 연결을 추가합니다. |

좋은 Instructions는 세 가지 영역을 다룹니다: 역할 컨텍스트(사용자 환경에 대한 전문성), 범위 제한(에이전트가 다뤄야 할 것과 다루지 말아야 할 것), 운영 지침(절차와 에스컬레이션 경로). 예:

```text
You are the Cloud Engineer for Acme Corp.

Environment:
- Primary cloud: AWS (us-east-1, us-west-2)
- Secondary cloud: GCP (for ML workloads)
- Cost target: Reduce by 20% this quarter

Guidelines:
- Flag every security group change for review before recommending it
- Prioritize production stability over cost savings
- Flag any resource costing >$1000/month for review
```

## 알아야 할 사항

- 편집은 **다음** 메시지부터 적용됩니다 — 진행 중인 채팅은 이전 설정으로 완료됩니다.
- 커스텀 에이전트의 @mention은 신중하게 선택하세요 — 한 번 설정하면 계속 사용해야 합니다.
- 커스텀 에이전트는 워크스페이스의 자율성 모드(Manual 또는 Auto)에 따라 동작합니다. [Auto Mode](/ko/guide/auto-mode)를 참고하세요.
