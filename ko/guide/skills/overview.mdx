Skills는 범용 에이전트를 여러분의 환경 전문가로 만드는 명령 패키지입니다. 코딩 표준, 리뷰 체크리스트, 장애 대응 절차 등 팀의 컨텍스트를 한 번 작성해두면, 에이전트가 할당된 모든 작업에 자동으로 적용합니다.

에이전트는 일반적인 모범 사례를 알고 있지만, 여러분의 관행은 알지 못합니다. Skills가 그 간격을 메웁니다. 프롬프트마다 같은 규칙을 반복할 필요 없이 한 번만 인코딩하면, 시니어 엔지니어 한 명의 전문성이 워크스페이스 전체의 표준이 됩니다.

## 작동 방식

1. **생성** — `SKILL.md` 파일을 직접 작성하거나, 필요한 내용을 자연어로 설명하고 AI가 생성하게 합니다.
2. **활성화** — 워크스페이스에서 skill을 켭니다. 비활성화된 skill은 저장되지만 로드되지 않습니다.
3. **할당** — skill이 적용될 기능을 지정합니다: Code Review, Incident, Assessment 또는 조합.
4. **적용** — 에이전트가 할당된 기능에서 작업을 실행할 때 skill을 로드하고 기본 동작과 함께 지시를 따릅니다.

## Skills vs 지식 베이스

Skills는 에이전트의 행동 방식을 지정하고, [지식 베이스](/ko/guide/knowledge)는 에이전트가 참조할 정보를 제공합니다. 둘은 상호 보완적이며, skill이 특정 문서를 참조하도록 에이전트에게 지시할 수 있습니다.

| | Skills | 지식 베이스 |
| --- | --- | --- |
| 내용 | 에이전트가 따르는 규칙과 절차 | 에이전트가 참조하는 문서와 웹사이트 |
| 예시 | 리뷰 체크리스트, 네이밍 규칙, 에스컬레이션 정책 | 런북, 아키텍처 문서, 컴플라이언스 문서 |
| 에이전트 사용 방식 | 할당된 기능에 대해 자동으로 로드 | `#kb`로 검색하거나 항상 사용 가능 모드에서 자동 참조 |
| 형식 | `SKILL.md` 파일 (YAML 프론트매터가 있는 Markdown) | 업로드된 파일 또는 크롤링된 웹사이트 |
| 최적 사용처 | 에이전트 동작 변경 | 사실과 컨텍스트 추가 |

원칙: 에이전트가 매번 따라야 한다면 skill로 작성하고, 관련될 때만 참조해야 한다면 지식 베이스에 추가하세요.
