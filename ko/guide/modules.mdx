CloudThinker는 작업을 **Resolve**, **Review**, **Optimize**, **Cyber** 네 가지 모듈로 나눕니다. 각 모듈은 서로 다른 종류의 신호에 대해 동일한 [에이전틱 루프](/ko#cloudthinker-동작-방식)를 실행하며, 그 아래에는 같은 어시스턴트, 메모리, 승인이 있습니다.

## 모듈이란

모듈은 인시던트, 풀 리퀘스트, 클라우드 비용, 앱 보안처럼 흔한 문제 하나를 위한 완결된 워크플로입니다. CloudThinker가 문제를 찾아내는 것부터 조치할 결과를 전달하는 것까지 처음부터 끝까지 실행합니다. 모든 모듈은 같은 [하네스](/ko/guide/harness) 위에서 실행되고 하나의 메모리를 공유하므로, 한 모듈이 배운 것이 다른 모듈에도 도움이 됩니다.

각 모듈은 사이드바에 자체 섹션이 있으며, [Home](/guide/activity)의 **Modules** 카드에 상태 줄이 표시됩니다.

## 모듈을 사용하는 이유

- **신호 하나에 장소 하나.** 인시던트, 풀 리퀘스트, 클라우드 청구서, 앱 보안이 각각 전용 작업 공간을 가집니다.
- **공유 컨텍스트.** 한 모듈에서 CloudThinker가 배운 것 — 서비스, 컨벤션, 과거 인시던트 — 이 다른 모듈에도 반영됩니다.
- **하나부터 시작.** 각 모듈은 자체 연결만 필요하므로 하나씩 켤 수 있습니다.

## 한눈에 보기

| 모듈 | 하는 일 | 필요한 것 | 시작할 곳 |
|---|---|---|---|
| **Resolve** | 모든 인시던트를 조사하고 근본 원인을 찾아 수정 방안을 제안합니다 | 알림 소스 또는 수동으로 기록한 인시던트 | [Pulse 소스 연결](/ko/guide/pulse/setup) |
| **Review** | 실행 중인 인프라의 컨텍스트로 모든 풀 리퀘스트를 리뷰합니다 | 리포지토리가 추가된 Git 연결 | [Review 설정](/ko/guide/code-review/setup) |
| **Optimize** | 클라우드 청구서에서 비용 절감 조치의 우선순위를 매깁니다 | 청구 데이터 접근 권한이 있는 AWS, Google Cloud 또는 Azure 연결 | [Optimize 개요](/ko/guide/cost-optimization/overview) |
| **Cyber** (Beta) | 실행 중인 앱을 침투 테스트하고 각 발견 항목을 증거로 입증합니다 | 검증을 마친 대상 URL이 있는 앱 | [Cyber 개요](/guide/security/cyber-overview) |

## Resolve

Resolve는 인시던트 대응입니다. [Pulse](/ko/guide/pulse/overview)는 Datadog, PagerDuty, Grafana, 클라우드 모니터링 등의 소스에서 알림을 받아 노이즈를 제거하고 실제 문제를 Incidents로 라우팅합니다. CloudThinker가 각 인시던트를 조사하고 승인할 근본 원인과 수정 제안을 전달합니다.

**Resolve** 아래에서 찾을 수 있습니다: **Investigation**, **Overview**, **Pulse**, **Insights**, **Integrations**, **On-call**, **Runbooks**, **Settings**. 아직 알림 소스가 없나요? Investigation 페이지의 **Log Incident**를 사용하세요 — [빠른 시작](/ko/quickstart)을 참고하세요.

## Review

Review는 코드 리뷰입니다. 연결된 리포지토리 — GitHub, GitLab, Bitbucket, Azure DevOps, AWS CodeCommit — 의 모든 풀 리퀘스트에 심각도와 수정 제안이 포함된 인라인 코멘트가 달립니다. 리뷰 봇은 `@cloudthinker-ai review`와 같은 [멘션 명령](/ko/guide/code-review/mention-commands)에 응답합니다.

**Review** 아래의 **Overview**, **Reviews**, **Settings**에서 시작하세요.

## Optimize

Optimize는 클라우드 비용입니다. AWS, Google Cloud 또는 Azure 연결 하나에서 청구 데이터를 읽고, 유휴 리소스, 과도한 크기의 인스턴스, 사용하지 않는 약정, 이상 현상 중 무엇을 먼저 해결할지 순위를 매깁니다.

**Optimize** 아래에서 찾을 수 있습니다: **Overview**, **Cost Health**, **Cost Explorer**, **Findings**, **Anomalies**, **Reports**.

## Cyber

Cyber는 애플리케이션 보안이며 현재 베타입니다. 전용 보안 에이전트가 한 번에 하나의 실행 중인 앱을 침투 테스트하고, 실행 간에 공격 표면과 발견 항목을 유지하며, 다음 스캔에서 각 수정 사항을 다시 확인합니다. 첫 스캔 전에 앱 도메인의 소유권을 증명해야 합니다.

**Cyber** 아래에서 찾을 수 있습니다: **Overview**, **Pentest**, **Settings**.

## 플랜별 제공 범위

채팅은 모든 플랜에서 사용할 수 있습니다. Free 플랜에서 Review는 자격이 있는 조직에서만 실행되며, Resolve 조사와 Cyber 침투 테스트에는 유료 플랜이 필요합니다. 새 조직은 모든 모듈을 사용할 수 있는 14일 Team 체험판으로 시작합니다. [요금](/ko/guide/billing/pricing)을 참고하세요.
