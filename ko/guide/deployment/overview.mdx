<Note>
**미리 보기** — 자체 호스팅 CloudThinker는 디자인 파트너를 대상으로 얼리 액세스 단계입니다. 지원되는 토폴로지, 시스템 요구 사항, 업그레이드 경로는 정식 출시 전에 변경될 수 있습니다. 환경에 대해 논의하려면 [문의하기](https://cloudthinker.io/contact)를 클릭하세요.
</Note>

대부분의 CloudThinker 고객은 [app.cloudthinker.io](https://app.cloudthinker.io)의 멀티 테넌트 SaaS로 운영됩니다. 엄격한 데이터 거주, 컴플라이언스, 또는 네트워크 격리 요구 사항이 있는 환경을 위해 CloudThinker는 전용 및 자체 호스팅 배포도 지원합니다.

---

## 배포 모델

| 모델 | 설명 |
| --- | --- |
| SaaS (멀티 테넌트) | 기본값 — CloudThinker가 관리합니다. 가장 빠른 가치 실현, 운영 부담 없음. |
| 전용 클라우드 | 선호하는 리전 및 클라우드에 CloudThinker가 호스팅하는 단일 테넌트 인스턴스 |
| 자체 호스팅 | Kubernetes 기반의 자체 VPC에서 CloudThinker 실행 — 데이터가 경계 밖으로 나가지 않음 |
| 에어갭 | 기밀 또는 규제 환경을 위한 완전 오프라인 설치 |

---

## 시스템 요구 사항

| 리소스 | 최소 (POC) | 프로덕션 |
|----------|---------------|------------|
| **Kubernetes** | 1.34+ | 1.34+ |
| **노드** | 3 × 4 vCPU / 16 GB | 6+ × 8 vCPU / 32 GB |
| **PostgreSQL** | 14+ | HA가 적용된 15+ |
| **객체 스토리지** | S3 또는 MinIO | 동일 |
| **LLM 접근** | AWS Bedrock | 동일 |

---

## 업그레이드

| 채널 | 주기 |
|---------|---------|
| **Stable** | 월간 |
| **LTS** | 12개월 지원 포함 분기별 |
| **Patch** | 보안 및 긴급 수정 시 수시 |

Helm 기반 업그레이드는 API 및 에이전트 런타임의 무중단 상태로 인플레이스 방식으로 수행됩니다.

---

## 컴플라이언스

자체 호스팅 배포는 클러스터의 보안 태세를 상속합니다. CloudThinker는 운영 대상 워크로드와 동일한 경계 내에 배치하세요. 자체 호스팅 설치는 감사 경계가 이미 클러스터를 포함하고 있으므로 별도 재인증이 필요하지 않습니다.
