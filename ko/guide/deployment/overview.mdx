CloudThinker는 [app.cloudthinker.io](https://app.cloudthinker.io)에서 호스팅 서비스로 실행되며, 대부분의 팀은 그 외에 필요한 것이 없습니다. 일부 작업이 네트워크 안에서 이루어져야 할 때는 두 가지 옵션이 있습니다. 개별 폴더와 호스트를 위한 Environments, 또는 플랫폼 전체의 비공개 배포입니다.

## 모델 선택

| 모델 | 실행 위치 | 사용 시점 | 받는 방법 |
|---|---|---|---|
| **CloudThinker Cloud** | CloudThinker가 관리하는 공유 서비스 | 운영할 인프라 없이 오늘 바로 시작하고 싶을 때. | [가입](/ko/quickstart) |
| **CloudThinker Cloud + Environments** (Beta) | 플랫폼은 클라우드에, 파일 및 셸 작업은 직접 관리하는 머신에서 실행 | 에이전트가 비공개 리포지토리에서 작업하거나 내부 호스트에 접근해야 하지만, 연결 자격 증명은 클라우드에 있어도 될 때. | [환경 설정](/guide/workers) |
| **Dedicated cloud** | 선택한 리전에서 CloudThinker가 호스팅하는 단일 테넌트 인스턴스 | 테넌트 격리나 특정 리전이 필요할 때. 사용 가능한 리전은 온보딩 중에 확정됩니다. | [영업팀 문의](https://cloudthinker.io/contact) |
| **Bring your own cloud** (자체 호스팅 또는 에어갭) | 자체 클라우드 계정이나 데이터 센터 내부, 필요하면 오프라인 | 정책상 데이터가 경계를 벗어날 수 없을 때. | [영업팀 문의](https://cloudthinker.io/contact) |

<Note>
**얼리 액세스.** Dedicated, 자체 호스팅, 에어갭 배포는 디자인 파트너 프로그램을 통해 제공됩니다. 시스템 요구사항, 지원 토폴로지, 가격, 업그레이드 경로, 운영 주체, 인터넷 접근 없이 모델을 제공하는 방식은 여기에 게시하지 않고 온보딩 중에 확정됩니다.
</Note>

## 공급업체 검토에서 요청할 것

가동 시간 약정은 요금제별로 다릅니다. [요금제 및 가격](/ko/guide/billing/pricing)의 **SLA** 행을 참고하세요. 이 문서는 어떤 모델에 대해서도 호스팅 리전, 하위 처리자 목록, 상태 페이지, 지원 응답 시간을 게시하지 않습니다. 나중에 검토가 지연되지 않도록 [CloudThinker에 문의](https://cloudthinker.io/contact)할 때 함께 요청하세요.

## 비공개 배포 전에 Environments 시도하기

자체 호스팅 환경은 베타입니다. 정식 출시 전에 CLI 명령 이름과 플래그가 바뀔 수 있습니다. 환경은 CLI 외에 설치할 것 없이, 자체 호스팅을 요청하게 만드는 요구를 충족하는 경우가 많습니다. 환경은 CloudThinker가 파일을 읽고 명령을 실행하는 사용자 머신의 폴더이며, 인바운드 포트 없이 HTTPS로 바깥쪽으로 연결합니다. 방화벽은 `app.cloudthinker.io`로의 아웃바운드 HTTPS(포트 443)만 직접 또는 `HTTPS_PROXY`를 통해 허용하면 됩니다. 프록시가 HTTPS를 다시 서명한다면 `SSL_CERT_FILE`을 회사 CA 번들로 설정하세요. CLI 설치와 업데이트 시에는 `cloudthinker.io`와 `github.com`에도 접근합니다.

| 요구사항 | 환경으로 충족되나요? |
|---|---|
| 에이전트가 비공개 리포지토리의 코드를 편집 | 예. 파일 도구는 제공한 폴더 안에만 머뭅니다. |
| 에이전트가 내부 CLI나 스크립트를 실행 | 예. 셸 명령은 사용자의 OS 계정으로 머신에서 실행됩니다. |
| 워크스페이스 연결 자격 증명(AWS, Kubernetes 등)이 호스트에 닿지 않음 | 예. 연결 명령은 CloudThinker Cloud에서 실행됩니다. 호스트에 이미 있는 자격 증명은 셸 명령이 여전히 사용할 수 있습니다. |
| 파일 내용과 명령 출력이 호스트에 머무름 | 아니요. 에이전트가 읽는 것과 받는 출력은 CloudThinker Cloud와 모델로 전송됩니다. |
| 대화, [memory](/guide/memory), Skills가 경계 안에 머무름 | 아니요. 이들은 CloudThinker Cloud에 머뭅니다. 비공개 배포가 필요합니다. |
| 모든 구성 요소가 인터넷 접근 없이 실행 | 아니요. 환경에는 아웃바운드 HTTPS가 필요합니다. 에어갭 배포가 필요합니다. |

중요한 모든 행이 예라면 [Environments](/guide/workers)부터 시작하세요.

## 비공개 배포 요청

<Steps>
  <Step title="요구사항 정리">
    구체적인 답변을 받을 수 있도록 첫 메시지에 다음을 포함하세요.

    - 리전 또는 데이터 거주 규칙
    - 호스트의 인터넷 접근 여부
    - 로그인에 사용하는 ID 공급자
    - CloudThinker를 사용할 대략적인 인원
    - 연결할 클라우드와 계정
    - 사용하려는 LLM 공급자(있는 경우, [BYOK](/ko/guide/byok) 참고)
    - 검토에서 확인하는 규정 준수 프레임워크
  </Step>
  <Step title="CloudThinker에 문의">
    [cloudthinker.io/contact](https://cloudthinker.io/contact)로 요구사항을 보내고 Dedicated, 자체 호스팅, 또는 에어갭 배포를 요청하세요.

    **성공 상태:** 환경이 프로그램에 맞는지, 온보딩에 무엇이 필요한지 알려주는 답변을 받습니다.
  </Step>
  <Step title="그동안 호스팅 클라우드에서 평가">
    기다리는 동안 CloudThinker Cloud에 비프로덕션 계정을 연결해 실제 작업으로 에이전트를 테스트하세요. [Quickstart](/ko/quickstart)를 참고하세요.
  </Step>
</Steps>
