<Note>
**미리 보기** — CloudThinker REST API는 얼리 액세스 단계입니다. 엔드포인트, 페이로드, 인증 플로우는 정식 출시 전에 변경될 수 있습니다. 미리 보기 참여를 원하시면 [문의하기](https://cloudthinker.io/contact)를 클릭하세요.
</Note>

CloudThinker API는 웹 콘솔에서 제공하는 동일한 작업을 인증된 HTTPS 엔드포인트로 노출합니다. 자체 제품에 클라우드 운영을 임베드하거나, 워크플로를 자동화하거나, CloudThinker를 내부 도구와 연동하는 데 활용하세요.

---

## 사용 가능한 기능

| 기능 | 설명 |
| --- | --- |
| 대화 시작 | `@agent #tool` 프롬프트로 에이전트 대화를 프로그래밍 방식으로 시작하고 응답을 앱으로 스트리밍 |
| 리소스 조회 | AWS, GCP, Azure에 걸친 클라우드 리소스, 비용, 토폴로지의 통합 인벤토리 조회 |
| 권장 사항 관리 | 비용, 보안, 안정성 권장 사항 목록 조회, 수락, 무시 또는 댓글 추가 |
| 인시던트 처리 | 인시던트 생성, 신호 첨부, RCA 요청, 조사 결과 조회 |

---

## 인증

API는 베어러 토큰 헤더를 통해 전달되는 워크스페이스 범위의 API 키를 사용합니다.

```bash
curl https://api.cloudthinker.io/v1/workspaces/{workspace_id}/resources \
  -H "Authorization: Bearer $CLOUDTHINKER_API_KEY"
```

| 필드 | 설명 |
|-------|-------------|
| **범위** | 각 키는 단일 워크스페이스에 바인딩됩니다 |
| **권한** | 키를 발급한 멤버의 역할을 상속합니다 |
| **교체** | 워크스페이스 설정에서 언제든지 키를 폐기할 수 있습니다 |

---

## 엔드포인트

| 리소스 | 용도 |
|----------|---------|
| `/v1/workspaces` | 워크스페이스 메타데이터 및 멤버 |
| `/v1/conversations` | 에이전트 대화 시작, 목록 조회, 재개 |
| `/v1/resources` | 발견된 클라우드 리소스 인벤토리 |
| `/v1/recommendations` | 비용, 보안, 안정성 권장 사항 |
| `/v1/incidents` | 인시던트 생명주기 및 RCA 결과 |
| `/v1/dashboards` | 기본 제공 및 사용자 정의 대시보드 데이터 |
| `/v1/skills` | 워크스페이스 Skills 및 실행 |
| `/v1/connections` | 클라우드 및 SaaS [연동](/ko/guide/connections/overview) |

---

## 버전 관리

API는 URL 경로(`/v1/`)에 버전이 명시됩니다. 호환성이 깨지는 변경 사항은 새 버전으로 출시되며, 추가적인 변경 사항은 현재 버전에서 제공됩니다. 더 이상 사용되지 않는 버전은 후속 버전 출시 후 최소 12개월간 계속 사용할 수 있습니다.
