CloudThinker Public API는 API 토큰으로 하나의 워크스페이스를 읽고 작업하는 REST API입니다. 토큰은 선택한 스코프를 가지며, 워크스페이스 역할이 허용하는 범위를 넘어서지 않습니다.

처음이신가요? [빠른 시작](/guide/api/quickstart)을 따르면 토큰 발급부터 첫 호출까지 약 5분이 걸립니다.

## 호출할 수 있는 항목

<ApiAreas />

각 호출에는 스코프 하나가 필요하며, 워크스페이스 역할이 이를 허용해야 합니다. 모든 엔드포인트 페이지에 해당 스코프가 표시되어 있으며, [API Tokens](/guide/api/tokens#scopes)에서 스코프의 작동 방식을 설명합니다. 에이전트 실행을 시작하고 답변을 읽으려면 [Approvals for API Runs](/guide/api/approvals#start-a-run-and-get-its-answer)를 참고하세요.

다른 방식으로 CloudThinker를 호출하려면 [CloudThinker CLI](/guide/cli/api), [Claude Connector](/ko/guide/mcp/overview), ServiceNow 같은 외부 시스템용 [A2A API](/guide/api/a2a), [Webhooks](/ko/guide/webhooks/overview), 또는 Okta와 Microsoft Entra ID용 [SCIM 프로비저닝](/ko/guide/security/scim)을 사용하세요.

## 작동 방식

- **Base URL:** `https://app.cloudthinker.io/api/public`. 경로는 `/v1/workspaces/<workspace-id>/{module}/{resource}` 형식입니다.
- **인증:** 개인(`ct_pat_…`), 서비스 계정(`ct_sat_…`) 또는 OAuth(`ct_oat_…`) 토큰이나 CLI 로그인으로 `Authorization: Bearer <token>`을 보냅니다. 각 토큰은 하나의 워크스페이스에서 작동하며, `GET /v1/token`은 워크스페이스 ID, 스코프, 만료일을 반환합니다.
- **형식:** 입력과 출력 모두 JSON, UTF-8입니다. 작업에 정의되지 않은 본문 필드는 `422`를 반환합니다. OpenAPI 3.1 계약은 `https://app.cloudthinker.io/api/public/v1/openapi.json`에 있으며 토큰이 필요 없습니다.
- **페이징:** 목록 호출은 `limit`(1–100, 기본값 20)과 `cursor`를 받습니다. 한 페이지는 `{"items": [...], "next_cursor": "..."}`이며, `next_cursor`가 `null`이 될 때까지 이를 `cursor`로 다시 전달합니다. `limit`과 필터는 그대로 유지하세요. 쿼리가 바뀌면 `400` `invalid_cursor`가 반환됩니다.
- **쓰기:** 모든 `POST`에는 `Idempotency-Key` 헤더가 필요합니다. [API Errors](/guide/api/errors#retry-safe-writes)를 참고하세요.
- **버전:** 모든 경로는 버전 `v1`으로 시작합니다. 호환되지 않는 변경은 새 버전으로 출시됩니다. `v1` 안에서도 새 필드와 작업이 추가될 수 있으므로, 인식하지 못하는 응답 필드는 무시하세요.

`GET /v1/token`에서 얻은 값으로 `WORKSPACE_ID`를 설정하고 워크스페이스의 인시던트를 나열합니다.

```bash
curl -sS "https://app.cloudthinker.io/api/public/v1/workspaces/$WORKSPACE_ID/resolve/incidents?limit=20" \
  -H "Authorization: Bearer $CLOUDTHINKER_TOKEN"
```
