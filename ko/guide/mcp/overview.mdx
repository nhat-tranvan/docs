CloudThinker를 Claude에 연결하면 Claude가 워크스페이스를 읽고 CloudThinker 에이전트 실행을 시작할 수 있습니다. 이 커넥터는 원격 [Model Context Protocol](https://modelcontextprotocol.io)(MCP) 서버이며, 현재는 Claude 클라이언트만 연결할 수 있습니다.

## 사전 요구 사항

- 하나 이상의 [워크스페이스](/ko/guide/workspaces)에 접근할 수 있는 CloudThinker 계정
- Claude(claude.ai 또는 데스크톱 앱) 또는 Claude Code
- Claude Team 또는 Enterprise 플랜에서는 Claude 조직 소유자가 먼저 커넥터를 추가합니다. 그다음 각 멤버가 개별로 연결합니다.

## Claude 연결하기

서버 URL은 모든 경로에서 같습니다.

```text
https://app.cloudthinker.io/api/mcp
```

<Tabs>
  <Tab title="Claude(웹 및 데스크톱)">
    <Steps>
      <Step title="커넥터 추가">
        Claude에서 **Customize → Connectors**로 이동해 **Add**, **Add custom connector**를 차례로 클릭합니다. Team 및 Enterprise 소유자는 **Organization settings → Connectors**를 사용합니다.
      </Step>
      <Step title="URL 입력">
        이름을 **CloudThinker**로 지정하고 서버 URL을 붙여넣은 뒤 **Continue**를 클릭합니다. 감지된 로그인 설정은 그대로 두고 **Add**를 클릭합니다.
      </Step>
      <Step title="연결 및 승인">
        Claude가 브라우저에서 CloudThinker로 이동시킵니다. 로그인하고 워크스페이스를 선택한 뒤 **Allow**를 클릭합니다. Claude가 로그인을 시작하지 않으면 **Customize → Connectors**에서 커넥터를 열고 연결을 선택합니다.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude Code">
    <Steps>
      <Step title="서버 추가">
        ```bash
        claude mcp add --transport http cloudthinker https://app.cloudthinker.io/api/mcp
        ```
      </Step>
      <Step title="로그인">
        Claude Code에서 `/mcp`를 실행하고 **cloudthinker**를 선택한 뒤 브라우저의 안내를 따릅니다. 로그인하고 워크스페이스를 선택한 뒤 **Allow**를 클릭합니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

**성공 기준:** Claude에 CloudThinker가 연결됨으로 표시되고, 채팅에서 CloudThinker 도구를 사용할 수 있습니다.

<Note>
이 커넥터는 아직 Claude Connectors Directory에 등록되어 있지 않습니다. 위 URL로 사용자 지정 커넥터로 추가하세요.
</Note>

## 승인하는 내용

승인 페이지에는 연결하는 앱의 이름과 Claude가 돌아갈 호스트가 표시됩니다. 이어서 워크스페이스 하나와 세 가지 권한이 표시됩니다.

- Read incidents in this workspace
- Start CloudThinker runs that ask you before any change
- Act only as you, in the workspace you pick here

로그인은 일반 CloudThinker 로그인을 사용하므로 SSO와 MFA가 적용됩니다. 여러 워크스페이스에 속해 있다면 하나를 선택합니다. 연결은 그 워크스페이스에 묶입니다. 다른 워크스페이스를 사용하려면 다시 연결하세요.

Claude Code가 내 컴퓨터에서 연결하면 페이지에 경고가 추가로 표시됩니다. 직접 시작한 연결일 때만 **Allow**를 클릭하세요.

## Claude가 할 수 있는 일

Claude는 20개의 도구를 사용합니다. 19개는 데이터를 읽기만 합니다. 나머지 하나인 **Ask CloudThinker**는 실행을 시작합니다.

### 인시던트

| 도구 | 기능 |
| --- | --- |
| `list_incidents` | 인시던트와 조사를 최신순으로 나열합니다. 상태, 심각도, 텍스트로 필터링할 수 있습니다. |
| `get_incident` | 인시던트 하나를 읽습니다. 상태, 심각도, 최신 근본 원인 분석, 권장 수정이 포함됩니다. |

### 에이전트 실행

| 도구 | 기능 |
| --- | --- |
| `ask_cloudthinker` | 요청을 바탕으로 CloudThinker 에이전트 실행을 시작합니다. |
| `get_run` | Claude가 시작한 실행의 상태와 답변을 읽습니다. |

### Automation

| 도구 | 기능 |
| --- | --- |
| `list_automations` | 예약형 및 이벤트 기반 Automation을 나열합니다. |
| `get_automation` | Automation 하나의 지침, 트리거, 일정, 최근 실행을 읽습니다. |
| `list_automation_runs` | Automation 하나의 지난 실행을 나열합니다. |

### Review

| 도구 | 기능 |
| --- | --- |
| `list_code_reviews` | Review가 확인한 머지 리퀘스트와 풀 리퀘스트를 나열합니다. |
| `get_code_review` | 리뷰 하나와, 파일·줄·수정 제안이 포함된 발견 항목을 읽습니다. |

### Optimize

| 도구 | 기능 |
| --- | --- |
| `list_cost_connections` | CloudThinker가 분석하는 클라우드 청구 계정을 나열합니다. |
| `get_cost_overview` | 이번 달 지출, 예측, 상위 서비스, 상위 절감 항목을 읽습니다. |
| `list_cost_findings` | 열려 있는 절감 발견 항목을 절감액이 큰 순서로 나열합니다. |
| `get_cost_finding` | 절감 발견 항목 하나와 그 분석을 읽습니다. |
| `list_cost_anomalies` | 비용 급증을 영향이 큰 순서로 나열합니다. |

### Cyber

| 도구 | 기능 |
| --- | --- |
| `list_security_apps` | 침투 테스트 중인 앱을 나열합니다. |
| `get_security_app_coverage` | 앱 하나의 침투 테스트가 다룰 수 있는 범위와 이를 막는 요소를 읽습니다. |
| `get_security_finding` | 침투 테스트 발견 항목 하나를 읽습니다. |
| `list_code_audit_branches` | Code Audit 대상 리포지토리 브랜치를 나열합니다. |
| `get_code_audit_branch` | 브랜치 하나의 최신 감사와 보안 발견 항목을 읽습니다. |
| `get_code_audit` | Code Audit 실행 하나의 상태, 결과, 실패 내용을 읽습니다. |

## CloudThinker에 조사 요청하기

`ask_cloudthinker`는 일반 CloudThinker 에이전트 실행을 시작합니다. 워크스페이스에 이미 있는 연결을 사용합니다.

- **바로 반환됩니다.** Claude는 실행 ID와 링크를 받습니다. 실행이 끝나면 Claude가 `get_run`을 호출해 답변을 읽습니다.
- **크레딧을 사용합니다.** 실행은 채팅과 마찬가지로 워크스페이스에 청구됩니다. [사용량](/ko/guide/billing/usage)을 참고하세요.
- **변경 전에 항상 확인합니다.** Claude에서 시작한 실행은 워크스페이스가 [Auto Mode](/ko/guide/auto-mode)여도 Manual 승인을 사용합니다. 변경은 링크를 통해 CloudThinker에서 승인할 때까지 대기합니다. [Approval](/ko/guide/approval)을 참고하세요.

## 프롬프트 예시

연결한 뒤 Claude에 다음과 같이 입력하세요.

```text
What incidents are open in production, and what caused the latest one?
```

```text
Which cost savings findings in CloudThinker are worth the most per month? Show the top five with the evidence for each.
```

```text
List the code review findings from the last week with high severity, and tell me which ones are still unresolved.
```

```text
Ask CloudThinker to investigate why checkout latency rose after yesterday's deploy, and tell me what it finds.
```

## 접근 권한 확인 방식

Claude는 내가 선택한 워크스페이스 하나에서 나로서 동작합니다. CloudThinker는 호출할 때마다 다음을 확인합니다.

- 아직 워크스페이스 멤버인지.
- 내 역할에 해당 도구의 권한이 있는지.
- 도구가 속한 제품 모듈이 켜져 있는지.

Claude는 CloudThinker에서 내가 볼 수 있는 범위를 넘어 볼 수 없습니다.

## 접근 해제하기

CloudThinker에서 **Settings → Connected apps**를 열고 Claude 연결을 해제합니다. 접근은 즉시 종료됩니다. 다음 호출은 실패하고, Claude는 다시 연결하라고 요청합니다.

Claude의 커넥터도 제거하세요. Claude에서는 **Customize → Connectors**에서, Claude Code에서는 `claude mcp remove cloudthinker`로 제거합니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="Access to this CloudThinker workspace was removed">
    연결한 워크스페이스의 멤버가 아니게 되었거나 워크스페이스가 삭제되었습니다. 연결을 해제하고 다시 연결한 뒤 접근할 수 있는 워크스페이스를 선택하세요.
  </Accordion>
  <Accordion title="This CloudThinker role lacks a permission">
    메시지에 부족한 권한의 이름이 표시됩니다. 워크스페이스 관리자에게 해당 권한을 부여하거나 [역할](/ko/guide/workspace-users)을 변경해 달라고 요청하세요.
  </Accordion>
  <Accordion title="실행이 승인을 기다리고 있음">
    Claude가 실행이 승인 대기 중이라고 알렸습니다. Claude가 준 링크를 열고 CloudThinker에서 변경을 승인하거나 거부하세요. 그다음 Claude에게 실행을 다시 확인해 달라고 하세요.
  </Accordion>
  <Accordion title="워크스페이스 크레딧이 부족해 실행이 실패함">
    크레딧을 추가하거나 워크스페이스 한도를 높이세요. [사용량](/ko/guide/billing/usage)을 참고하세요. 그런 다음 다시 요청하세요.
  </Accordion>
  <Accordion title="연결 요청이 잘못되었거나 만료됨">
    승인 페이지는 10분 후 만료됩니다. Claude로 돌아가 다시 연결하세요.
  </Accordion>
  <Accordion title="도구가 모듈이 꺼져 있다고 알림">
    관리자가 해당 제품 모듈을 꺼 두었습니다. 관리자에게 켜 달라고 요청하세요.
  </Accordion>
</AccordionGroup>
