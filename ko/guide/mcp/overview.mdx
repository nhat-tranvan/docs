CloudThinker는 [Model Context Protocol](https://modelcontextprotocol.io) (MCP) 서버로 동작하여, 모든 MCP 호환 AI 클라이언트가 워크스페이스의 인증된 컨텍스트를 사용해 CloudThinker 도구를 호출하고 데이터를 읽을 수 있게 합니다.

이는 CloudThinker 에이전트가 _외부_ MCP 서버를 호출하는 기존의 [MCP 연동](/ko/guide/connections/mcp)과는 반대 방향입니다.

---

## 지원 기능

| 기능 | 설명 |
| --- | --- |
| IDE에서 클라우드 운영 | Cursor, Claude Desktop 또는 모든 MCP 클라이언트에서 AWS, GCP, Azure 인벤토리와 비용 조회 |
| 기존 연동 활용 | CloudThinker에 이미 연결한 데이터베이스, Kubernetes 클러스터, 관찰 가능성 도구에 접근 |
| Skills 원격 실행 | 모든 MCP 호환 호스트에서 워크스페이스 [Skills](/ko/guide/skills/overview) 호출 |
| 공유 컨텍스트 | 웹 콘솔과 동일한 방식으로 권장 사항, 대시보드, 인시던트 메모리 조회 |

---

## 노출되는 도구

MCP 서버는 에이전트 기능의 선별된 하위 집합을 노출합니다.

| 도구 패밀리 | 기능 |
|-------------|--------------|
| `resources.*` | 통합 리소스 인벤토리 및 토폴로지 조회 |
| `recommendations.*` | 최적화 권장 사항 목록 조회, 수락, 무시 또는 댓글 추가 |
| `costs.*` | 클라우드 계정 전반의 비용 쿼리 및 예측 실행 |
| `incidents.*` | 인시던트 생성, 신호 첨부, RCA 결과 조회 |
| `dashboards.*` | 기본 제공 및 사용자 정의 대시보드 조회 |
| `skills.*` | 파라미터를 지정하여 워크스페이스 Skills 실행 |

정확한 도구 목록은 MCP 디스커버리를 통해 노출됩니다. 클라이언트는 워크스페이스 API 키가 사용 권한을 가진 도구만 볼 수 있습니다.

---

## 전송 방식

| 전송 | 적합한 환경 |
|-----------|----------|
| **HTTP + SSE** | 클라우드 호스팅 클라이언트, 원격 에이전트, 팀 공유 설정 |
| **stdio** | 로컬 프록시를 통해 실행되는 로컬 IDE 및 데스크톱 앱 (Claude Desktop, Cursor, Windsurf) |

---

## 인증

MCP 서버는 REST API에서 사용하는 것과 동일한 워크스페이스 [API 키](/ko/guide/api/overview)로 인증합니다. 키는 단일 워크스페이스 범위로 제한되며, 키를 발급한 멤버의 역할을 상속합니다.
