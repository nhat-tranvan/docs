CloudThinker를 Claude에 연결하면 Claude가 워크스페이스를 읽고 CloudThinker 에이전트 실행을 시작할 수 있습니다. 이 커넥터는 원격 [Model Context Protocol](https://modelcontextprotocol.io)(MCP) 서버이며, 현재는 Claude 클라이언트만 연결할 수 있습니다.

## 사전 요구 사항

- 하나 이상의 [워크스페이스](/ko/guide/workspaces)에 접근할 수 있는 CloudThinker 계정
- Claude(claude.ai 또는 데스크톱 앱) 또는 Claude Code. 커넥터는 CloudThinker 요금제와 관계없지만, 커넥터가 시작하는 실행은 워크스페이스 크레딧을 사용합니다.
- Claude Team 또는 Enterprise 플랜에서는 Claude 조직 소유자가 먼저 커넥터를 추가합니다. 그다음 각 멤버가 개별로 연결합니다.

## Claude 연결하기

서버 URL은 모든 경로에서 같습니다.

```text
https://app.cloudthinker.io/api/mcp
```

<Tabs>
  <Tab title="Claude(웹 및 데스크톱)">
    <Steps>
      <Step title="커넥터 추가">
        Claude에서 **Customize → Connectors**로 이동해 **Add**, **Add custom connector**를 차례로 클릭합니다. Team 및 Enterprise 소유자는 대신 **Organization settings → Connectors**를 사용합니다.
      </Step>
      <Step title="URL 입력">
        이름을 **CloudThinker**로 지정하고 서버 URL을 붙여넣습니다. CloudThinker가 Claude를 스스로 식별하므로 **Advanced settings** 아래의 OAuth Client ID와 Client Secret은 비워 두세요. **Add**를 클릭합니다.
      </Step>
      <Step title="연결 및 승인">
        Claude가 브라우저에서 CloudThinker로 이동시킵니다. 로그인하고 워크스페이스를 선택한 뒤 **Allow**를 클릭합니다. Claude가 로그인을 시작하지 않으면 **Customize → Connectors**에서 커넥터를 열고 연결을 선택합니다.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude Code">
    <Steps>
      <Step title="서버 추가">
        ```bash
        claude mcp add --transport http cloudthinker https://app.cloudthinker.io/api/mcp
        ```

        이 명령은 현재 프로젝트에서만 나에게 서버를 추가합니다. 모든 프로젝트에서 사용하려면 `--scope user`를 추가하세요.
      </Step>
      <Step title="로그인">
        Claude Code에서 `/mcp`를 실행하고 **cloudthinker**를 선택한 뒤 브라우저의 안내를 따릅니다. 로그인하고 워크스페이스를 선택한 뒤 **Allow**를 클릭합니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

**성공 상태:** Claude에 CloudThinker가 연결됨으로 표시됩니다. Claude에게 "Which CloudThinker workspace are you using?"라고 물어보세요. Claude가 `whoami`를 호출하고 내가 선택한 워크스페이스의 이름을 답해야 합니다.

<Note>
이 커넥터는 아직 Claude Connectors Directory에 등록되어 있지 않습니다. 위 URL로 사용자 지정 커넥터로 추가하세요.
</Note>

## 승인하는 내용

승인 페이지에는 연결하는 앱의 이름과 Claude가 돌아갈 호스트가 표시됩니다. 이어서 Claude가 시작할 워크스페이스와, 그곳에서 Claude가 할 수 있는 일이 표시됩니다. Claude는 나로서 동작합니다. 내가 속한 다른 워크스페이스로 전환할 수 있으며, 각 도구에는 여전히 현재 워크스페이스에서의 내 역할이 필요합니다. [Claude가 할 수 있는 일](#claude가-할-수-있는-일)을 참고하세요.

Claude가 시작한 실행은 워크스페이스의 [Approval mode](/guide/approvals/approval-mode)를 따릅니다. 기본 Auto 모드에서는 AI 판단이 안전한 변경을 묻지 않고 실행하게 할 수 있으며, [Allow Rule](/guide/approvals/rules)도 마찬가지입니다. Manual은 모든 변경에 대해 묻습니다.

Claude에서 시작한 실행이 변경을 처리하는 방식은 [CloudThinker에 조사 요청하기](#cloudthinker에-조사-요청하기)를 참고하세요.

로그인은 일반 CloudThinker 로그인을 사용하므로 SSO와 MFA가 적용됩니다. 여러 워크스페이스에 속해 있다면 Claude가 시작할 워크스페이스를 선택합니다. 나중에 Claude에게 전환을 요청할 수 있습니다. [워크스페이스 전환하기](#워크스페이스-전환하기)를 참고하세요.

Claude Code가 내 컴퓨터에서 연결하면 페이지에 경고가 추가로 표시됩니다. 직접 시작한 연결일 때만 **Allow**를 클릭하세요.

## Claude가 할 수 있는 일

Claude는 48개의 도구를 사용합니다. 대부분은 데이터를 읽기만 합니다. `ask_cloudthinker`는 실행을 시작하고, `switch_workspace`는 Claude가 작업하는 워크스페이스를 바꾸며, 다섯 개의 도구는 인시던트나 Automation을 변경합니다.

`get_run`을 제외한 모든 읽기 도구는 워크스페이스 Viewer도 사용할 수 있습니다. `ask_cloudthinker`와 `get_run`에는 Developer 또는 Admin 역할이 필요하고, 인시던트나 Automation을 변경하는 도구에는 Admin 역할이 필요합니다. 인시던트, 모니터링, Review, Optimize, Cyber, assessment 도구는 워크스페이스에서 해당 모듈이 켜져 있어야 합니다.

**Access** 열은 도구가 읽기만 하는지, 무언가를 변경하는지 나타냅니다. Claude는 각 도구의 전체 입력 스키마를 보므로, 이 이름을 직접 입력할 일은 없습니다. **Inputs** 열에서 굵은 이름은 필수이고 나머지 입력은 모두 선택입니다. 목록 도구는 따로 표시하지 않으면 기본적으로 20개 결과를 반환합니다.

## 워크스페이스 전환하기

Claude에게 일상적인 말로 요청하세요. 예를 들어 "Which CloudThinker workspace are you using?" 또는 "Switch to the Staging workspace"라고 입력합니다. Claude는 `whoami`를 호출해 내 워크스페이스를 나열한 뒤 `switch_workspace`를 호출합니다. 이후의 모든 도구 호출은 새 워크스페이스에서 데이터를 읽고 실행을 시작합니다.

- **내가 속한 워크스페이스로만 전환할 수 있습니다.** CloudThinker는 전환할 때마다, 그리고 호출할 때마다 멤버십과 역할을 확인합니다.
- **전환은 연결 전체에 적용됩니다.** 이 커넥터를 사용하는 모든 Claude 채팅이 새 워크스페이스로 이동합니다. 헷갈리면 Claude에게 "Which workspace are you using?"라고 물어보세요.
- **레코드는 원래 워크스페이스에 남습니다.** 전환한 뒤에는 이전 워크스페이스로 돌아갈 때까지 Claude가 그곳의 실행이나 인시던트를 읽을 수 없습니다.

## CloudThinker에 조사 요청하기

`ask_cloudthinker`는 일반 CloudThinker 에이전트 실행을 시작합니다. 워크스페이스에 이미 있는 연결을 사용합니다.

- **바로 반환됩니다.** Claude는 실행 ID와 링크를 받습니다. 실행이 끝나면 Claude가 `get_run`을 호출해 답변을 읽습니다.
- **크레딧을 사용합니다.** 실행은 채팅과 마찬가지로 워크스페이스에 청구됩니다. [사용량](/ko/guide/billing/usage)을 참고하세요.
- **변경은 채팅과 마찬가지로 Approvals를 거칩니다.** Claude에서 시작한 실행은 워크스페이스의 [Approval mode](/guide/approvals/approval-mode)를 따릅니다. 변경에 내 결정이 필요하면(Manual에서는 항상, Auto에서는 어떤 규칙이나 AI 판단도 허용하지 않는 변경만), 실행은 링크를 통해 CloudThinker에서 승인할 때까지 대기합니다.

## 접근 권한 확인 방식

Claude는 현재 사용 중인 워크스페이스(내가 선택했거나 전환한 워크스페이스)에서 나로서 동작합니다. CloudThinker는 호출할 때마다 다음을 확인합니다.

- 아직 워크스페이스 멤버인지.
- 내 역할에 해당 도구의 권한이 있는지.
- 도구가 속한 제품 모듈이 켜져 있는지.

Claude는 CloudThinker에서 내가 볼 수 있는 범위를 넘어 볼 수 없습니다. 도구 결과는 Claude 대화에 들어가므로, 그 채팅을 CloudThinker 데이터를 붙여넣는 다른 곳과 똑같이 다루세요. Claude가 시작하는 각 실행은 워크스페이스의 일반 CloudThinker 실행이며, Claude가 그 링크를 알려줍니다.

## 제한

| 항목 | 제한 |
| --- | --- |
| 클라이언트 | Claude만(claude.ai, 데스크톱 앱, Claude Code) |
| 연결당 워크스페이스 | 한 번에 하나. 전환하면 연결을 사용하는 모든 채팅이 이동합니다. |
| 승인 페이지 | Claude가 연 뒤 10분 후 만료 |
| 액세스 토큰 | 1시간 유지. Claude가 대신 갱신합니다. |
| 로그인 유지 | 연결을 30일 동안 사용하지 않으면 Claude가 다시 연결하라고 요청합니다. |
| 시스템 변경 | 채팅과 마찬가지로 워크스페이스의 Approval mode를 따름 |

## 접근 해제하기

CloudThinker에서 **Settings → Personal → Security**를 열고 **Connected apps (MCP clients)**를 찾아 Claude 연결을 해제합니다. 접근은 즉시 종료됩니다. 다음 호출은 실패하고, Claude는 다시 연결하라고 요청합니다.

Claude의 커넥터도 제거하세요. Claude에서는 **Customize → Connectors**에서, Claude Code에서는 `claude mcp remove cloudthinker`로 제거합니다.

연결은 나만 해제할 수 있습니다. 워크스페이스 관리자가 나를 워크스페이스에서 제거하면 다음 호출부터 해당 워크스페이스에 대한 Claude의 접근이 종료됩니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="Access to this CloudThinker workspace was removed">
    Claude가 사용 중인 워크스페이스의 멤버가 아니게 되었거나 워크스페이스가 삭제되었습니다. Claude에게 내가 속한 다른 워크스페이스로 전환해 달라고 요청하세요. 그래도 실패하면 연결을 해제하고 다시 연결한 뒤 접근할 수 있는 워크스페이스를 선택하세요.
  </Accordion>
  <Accordion title="This CloudThinker role lacks a permission">
    메시지에 부족한 권한의 이름이 표시됩니다. 워크스페이스 관리자에게 해당 권한을 부여하거나 [역할](/ko/guide/workspace-users)을 변경해 달라고 요청하세요.
  </Accordion>
  <Accordion title="실행이 승인을 기다리고 있음">

  </Accordion>
  <Accordion title="워크스페이스 크레딧이 부족해 실행이 실패함">
    크레딧을 추가하거나 워크스페이스 한도를 높이세요. [사용량](/ko/guide/billing/usage)과 [Credit limits](/guide/billing/credit-limits)를 참고하세요. 그런 다음 다시 요청하세요.
  </Accordion>
  <Accordion title="연결 요청이 잘못되었거나 만료됨">
    승인 페이지는 10분 후 만료됩니다. Claude로 돌아가 다시 연결하세요.
  </Accordion>
  <Accordion title="도구가 모듈이 꺼져 있다고 알림">
    관리자가 해당 제품 모듈을 꺼 두었습니다. 관리자에게 켜 달라고 요청하세요.
  </Accordion>
