각 워크스페이스에 접근할 수 있는 사람과 그들이 할 수 있는 작업을 관리합니다. 워크스페이스 멤버는 특정 워크스페이스에 접근 권한을 부여받은 조직 멤버입니다.

## 개요

워크스페이스 멤버 관리를 통해 다음을 할 수 있습니다:

- **접근 제어** — 어떤 조직 멤버가 워크스페이스를 보고 사용할 수 있는지 결정
- **워크스페이스 역할 할당** — 조직 역할과 다를 수 있는 워크스페이스별 역할 설정
- **멤버십 모니터링** — 워크스페이스별 멤버 수 및 쿼터 사용량 확인

<Info>
멤버는 워크스페이스에 추가되기 전에 먼저 조직에 속해 있어야 합니다. 누군가를 조직에 초대하려면 **Admin Settings > Organization**으로 이동하세요.
</Info>

---

## 워크스페이스에 멤버 추가

워크스페이스 접근을 부여하는 방법은 두 가지가 있습니다:

### 워크스페이스에서

1. 관리할 워크스페이스를 엽니다
2. Members 섹션에서 **Add Member**를 클릭합니다
3. 드롭다운에서 조직 멤버를 선택합니다 (Developer와 Viewer만 표시됩니다 — Owner와 Admin은 이미 암묵적인 접근 권한이 있습니다)
4. 워크스페이스 역할을 선택합니다 (조직 역할을 기반으로 미리 채워집니다)

### 관리자 설정에서

1. **Admin Settings > Organization**으로 이동합니다
2. Members 섹션에서 멤버를 찾습니다
3. 이름 옆의 그리드 아이콘을 클릭하여 워크스페이스 접근 설정을 엽니다
4. 각 워크스페이스의 접근을 토글하고 워크스페이스별 역할을 설정합니다

<Info>
조직 Owner와 Admin은 모든 워크스페이스에 자동으로 접근 권한이 있습니다 — 수동으로 추가할 필요가 없습니다.
</Info>

## 워크스페이스 역할

각 멤버는 해당 워크스페이스에서 조직 역할을 재정의하는 워크스페이스별 역할을 가질 수 있습니다. 예를 들어, 이를 통해 Viewer 조직 멤버에게 특정 워크스페이스에서 Developer 접근을 부여할 수 있습니다.

| 역할 | 기능 |
|------|-------------|
| **Admin** | 워크스페이스 멤버 관리, 에이전트 및 연결 구성, 지식 베이스 관리, 운영 실행 |
| **Developer** | 에이전트 사용, 운영 실행, 연결 및 지식 베이스 접근 |
| **Viewer** | 워크스페이스 리소스 보기 (읽기 전용) |

**Admin Settings > Organization** (그리드 아이콘을 통해)에서 워크스페이스 접근을 관리할 때, 워크스페이스별로 선택할 수 있습니다:
- **Inherit from Org** — 조직 역할 사용
- **Admin / Developer / Viewer** — 워크스페이스별 역할로 재정의

## 워크스페이스 멤버 관리

워크스페이스 멤버 테이블에 표시되는 항목:

| 열 | 설명 |
|--------|-------------|
| **Member** | 아바타, 표시 이름, 이메일 주소 |
| **Organization Role** | 조직 수준에서의 멤버 역할 |
| **Workspace Role** | 이 특정 워크스페이스에서의 멤버 역할 (편집 가능) |
| **Actions** | 워크스페이스에서 멤버 제거 |

### 멤버 역할 변경

멤버 옆의 워크스페이스 역할 드롭다운을 클릭하여 역할을 변경합니다. 워크스페이스 Admin과 조직 Admin/Owner만 역할을 변경할 수 있습니다. 암묵적 멤버 (조직 Owner 및 Admin)는 워크스페이스 역할을 변경할 수 없습니다.

### 멤버 제거

워크스페이스에서 멤버를 제거하여 접근을 취소합니다. 이 작업은 멤버를 조직에서 제거하지 않습니다 — 나중에 다시 추가할 수 있습니다.

<Warning>
**Admin Settings > Organization**을 통해 조직에서 멤버를 제거하면 모든 워크스페이스에서 자동으로 제거됩니다.
</Warning>

## 프로비저닝 및 SSO

조직이 JIT 또는 SCIM 프로비저닝과 함께 SSO를 사용하는 경우, 새 멤버는 프로비저닝 설정에 구성된 **기본 워크스페이스**에 자동으로 추가됩니다. 자세한 내용은 [SSO 설정](/ko/guide/security/sso)을 참조하세요.
