CloudThinker는 몇 가지 구성 요소로 이루어져 있습니다: 조직은 워크스페이스를 가지고, 각 워크스페이스는 모듈이 실행되는 데 필요한 연결, 에이전트, 가드레일, 컨텍스트를 가집니다. 이 페이지는 이들이 어떻게 맞물리는지 보여주고 각 항목으로 연결합니다.

## 조직과 워크스페이스

[조직](/ko/guide/organization)은 계정입니다: 청구, 플랜, 멤버 목록을 소유합니다. [워크스페이스](/ko/guide/workspaces)는 그 안의 격리된 환경입니다 — 프로덕션과 스테이징, 또는 팀별 하나씩.

| 조직에 속하는 것 | 각 워크스페이스에 속하는 것 |
|---|---|
| 청구, 플랜, 크레딧 | 연결과 자격 증명 |
| 멤버와 조직 역할: Owner, Admin, Developer, Viewer | 커스텀 에이전트 |
| 싱글 사인온과 감사 로그 | 메모리, 지식 베이스, 스킬 |
| | 자동화, 명령, 승인 설정 |

조직 Owner와 Admin은 모든 워크스페이스에서 Admin입니다. 그 외 모든 사용자는 워크스페이스마다 Admin, Developer, Viewer 중 하나의 워크스페이스 역할을 받습니다. [워크스페이스 사용자](/ko/guide/workspace-users)를 참고하세요.

## 연결

[연결](/ko/guide/connections/overview)은 하나의 서비스에 대한 자격 증명입니다 — AWS 계정, Kubernetes 클러스터, GitHub 조직, Datadog 계정 등. 에이전트는 워크스페이스의 연결이 허용하는 것만 보고 작업할 수 있으므로, 연결의 권한이 모든 에이전트가 할 수 있는 일의 바깥 한계가 됩니다.

## 에이전트

기본 제공 어시스턴트인 **CloudThinker**가 모든 요청을 받습니다. 병렬 작업을 위해 임시 서브에이전트를 생성하고, 팀이 정의한 커스텀 에이전트에게 작업을 넘깁니다. [에이전트](/ko/guide/agents/overview)를 참고하세요.

## 가드레일

두 가지 설정이 에이전트의 쓰기 작업을 바로 실행할지, 사람을 기다릴지 결정합니다.

| 설정 | 하는 일 | 위치 |
|---|---|---|
| **Auto** (새 워크스페이스 기본값) | 쓰기 작업이 실행 전에 AI 안전 분류기의 검토를 받습니다 | 채팅 상자의 **Approval** 컨트롤 |
| **Manual** | 각 쓰기 작업을 실행 전에 직접 승인합니다 | 채팅 상자의 **Approval** 컨트롤 |
| **Tool Permissions** | Manual에서 각 연결 도구를 **Always allow**, **Needs approval**, **Never allow** 중 하나로 설정합니다 | **Settings → Approval → Tool Permissions** |

모드는 자동화와 서브에이전트를 포함해 워크스페이스 전체에 적용됩니다. [Auto Mode](/ko/guide/auto-mode)와 [승인](/ko/guide/approval)을 참고하세요.

## 컨텍스트

컨텍스트는 사용자가 아무 말도 하기 전에 에이전트가 이미 알고 있는 것입니다. 종류마다 출처가 다릅니다.

| 컨텍스트 | 담고 있는 것 | 추가하는 주체 |
|---|---|---|
| [Memory](/guide/memory) | 환경, 선호 사항, 최근 이벤트에 대한 메모 | 에이전트가 작업하면서 추가하며, 사용자가 수정할 수 있습니다 |
| [Knowledge](/ko/guide/knowledge) | 런북, 정책, 문서 | 사용자가 파일을 업로드하거나 사이트를 크롤링하여 추가합니다 |
| [Skills](/ko/guide/skills/overview) | 특정 종류의 작업을 위한 단계별 지침 | 사용자, 또는 스킬 학습이 켜져 있을 때 에이전트가 추가합니다 |

## 모듈

네 가지 [모듈](/ko/guide/modules) — Resolve, Review, Optimize, Cyber — 은 각각 같은 에이전트, 가드레일, 컨텍스트를 한 종류의 신호에 적용합니다: 인시던트, 풀 리퀘스트, 클라우드 청구서, 앱 보안.

## 결과가 표시되는 곳

| 위치 | 찾을 수 있는 것 |
|---|---|
| [Home](/guide/activity) | **Needs you** — 사용자를 기다리는 승인과 결정 — 그리고 모듈 상태와 오늘의 자동화 |
| **Investigation** (Resolve 아래) | 모든 인시던트와 그 근본 원인, 증거, 수정 제안 |
| [Artifacts](/ko/guide/artifacts/overview) | 에이전트가 만든 대시보드, 보고서, 파일 |
| 채팅 사이드 패널 | 현재 대화의 실행, 콘솔 출력, 서브에이전트, 발견 항목 |
