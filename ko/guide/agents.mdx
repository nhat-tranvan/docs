CloudThinker는 클라우드 환경 전반에서 분석하고, 보고하며, 행동하는 5가지 전문 에이전트를 제공합니다. 각 에이전트는 특정 도메인을 담당하고, 인프라에 대한 지속적인 메모리를 유지하며, 교차 도메인 작업에서 서로 협력합니다.

## 에이전트 명단

| 에이전트 | 역할 | 최적 용도 |
|-------|------|----------|
| [**Alex**](/ko/guide/agents/alex) | 클라우드 엔지니어 | 비용 분석, 인프라 최적화, 멀티 클라우드 아키텍처, 예약 용량 |
| [**Oliver**](/ko/guide/agents/oliver) | 보안 엔지니어 | 컴플라이언스 감사, 취약성 평가, IAM 검토, 위협 탐지 |
| [**Tony**](/ko/guide/agents/tony) | 데이터베이스 엔지니어 | 쿼리 최적화, 성능 튜닝, 인덱스 추천, 용량 계획 |
| [**Kai**](/ko/guide/agents/kai) | Kubernetes 엔지니어 | 클러스터 상태, 파드 적정 크기 조정, 오토스케일링, RBAC 감사, 트러블슈팅 |
| [**Anna**](/ko/guide/agents/anna) | 총괄 매니저 | 멀티 에이전트 조율, 교차 도메인 프로젝트, 경영진 보고 |

다른 톤, 제한된 액세스, 또는 완전히 커스텀 에이전트를 원하시나요? [에이전트 커스터마이즈](/ko/guide/agents/customize)를 참고하세요.

## 올바른 에이전트 선택

| 필요한 상황 | 언급할 에이전트 |
|----------|---------|
| 클라우드 비용이 너무 높을 때 | `@alex` |
| 보안 감사 또는 컴플라이언스 보고서 | `@oliver` |
| 느린 데이터베이스 진단 | `@tony` |
| Kubernetes 클러스터 문제 해결 | `@kai` |
| 여러 도메인에 걸친 문제 | `@anna` |
| 확실하지 않을 때 시작점 | `@anna` |

Anna는 다른 에이전트에게 작업을 분배하므로, 인시던트 조사와 교차 도메인 프로젝트의 안전한 기본 선택입니다.

## 에이전트와 대화하기

<PromptSyntaxBasics />

```text
@alex #dashboard build an EC2 cost dashboard for the last 30 days
@oliver #report audit security groups open to the internet on ports 22, 3306, and 5432
@anna #report run a quarterly infrastructure review across cost, security, and Kubernetes
```

## 에이전트 동작 방식

1. **프롬프트 읽기** — 에이전트가 멘션, 선택적 도구 태그, 지시사항을 파싱합니다.
2. **연결 조회** — 에이전트가 구성된 [연결](/ko/guide/connections/overview)을 읽습니다: AWS, Azure, GCP, Kubernetes 클러스터, 데이터베이스 등.
3. **소스 간 데이터 연관** — Alex가 CloudWatch 사용률을 Cost Explorer 데이터와 교차 참조하고, Tony가 실행 계획을 쿼리 빈도와 함께 읽습니다.
4. **요청한 출력 제공** — 대시보드, 보고서, 우선순위별 추천 사항, 또는 알림.
5. **자율 모드 내에서 행동** — Manual 모드에서 에이전트는 변경 사항을 실행하기 전에 [승인](/ko/guide/approval)을 기다립니다. 모든 작업은 감사 추적과 함께 기록됩니다.

## 자율성

각 에이전트는 에이전트별로 구성 가능한 두 가지 모드 중 하나로 실행됩니다:

<AutonomyModes />

Auto 실행의 범위, 가드레일, 감사 방법은 [Auto Mode](/ko/guide/auto-mode)를 참고하세요.

## 메모리와 컨텍스트

에이전트는 환경에 대해 학습한 내용을 유지하므로 시간이 지남에 따라 더 정확해집니다:

| 메모리 유형 | 유지하는 내용 |
|-------------|-----------------|
| 에피소딕 | 추천에서 제외한 리소스 등 과거 분석과 결정 |
| 작업 | 현재 대화 스레드 내의 컨텍스트 |
| 시맨틱 | 시간이 지남에 따라 인프라에 대해 학습된 패턴 |
| 파일 | 문서, 런북, [지식 베이스](/ko/guide/knowledge) 항목 |

## 에이전트 활성화 시점

에이전트는 관련 연결을 추가하면 사용 가능해집니다:

| 에이전트 | 사용 가능 시점 |
|-------|----------------|
| **Anna** | 항상 — 연결 불필요 |
| **Alex** | AWS, Azure, 또는 GCP 연결 추가 시 |
| **Oliver** | AWS, Azure, 또는 GCP 연결 추가 시 |
| **Tony** | PostgreSQL, MySQL, 또는 기타 데이터베이스 연결 추가 시 |
| **Kai** | Kubernetes 클러스터 연결 추가 시 |
