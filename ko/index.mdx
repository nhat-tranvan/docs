| 무엇에 연결되나요? | 클라우드(AWS, Google Cloud, Azure), Kubernetes, Git 호스트(GitHub, GitLab, Bitbucket, Azure DevOps, CodeCommit), Datadog과 PagerDuty 같은 알림 소스, Terraform 같은 IaC, Jira 같은 티켓팅 | [연결 카탈로그](/ko/guide/connections/overview#연결-카탈로그) |
| 에이전트는 무엇을 건드릴 수 있나요? | 연결이 허용하는 것만입니다. 에이전트는 연결의 자격 증명이 읽을 수 있는 모든 것을 읽을 수 있으므로, 역할이나 토큰을 에이전트가 보길 원하는 범위로 한정하세요. 연결에서 **Allow writes**를 끄면 그 연결에 대한 모든 변경이 거부됩니다. | [액세스 작동 방식](/ko/guide/connections/overview#접근-권한이-작동하는-방식) |
| 어디에서 실행되나요? | `app.cloudthinker.io`의 관리형 서비스인 CloudThinker Cloud입니다. [Environments](/guide/workers)는 셀프 서비스이며 베타입니다. 사용자가 관리하는 머신에서 파일과 셸 작업을 실행하도록 직접 설정합니다. 선택한 리전의 전용 클라우드, 셀프 호스팅, 에어갭 배포는 디자인 파트너 프로그램을 통해 얼리 액세스로 제공됩니다. 이 문서에는 공유 서비스의 리전이 공개되어 있지 않으므로 [문의하세요](https://cloudthinker.io/contact). | [배포](/ko/guide/deployment/overview) |
| 어디에서 사용하나요? | 웹 앱, [CLI](/ko/guide/cli/overview), [Slack](/ko/guide/slack-integration), [Google Chat](/guide/google-chat-integration), [Microsoft Teams](/ko/guide/teams-integration) | |
| 비용은 얼마인가요? | Team과 Scale은 조직당 하나의 월 요금으로, 멤버 수 제한이 없고 에이전트 작업에 사용되는 단위인 크레딧을 공유 풀로 제공합니다. Team은 월 $99에 1,000 크레딧입니다. 모든 채팅 메시지와 제품 실행이 크레딧을 사용합니다. Free 플랜은 Light 모델 채팅용으로 매일 100 무료 크레딧을 제공합니다. 제품 실행은 Team부터 가능합니다. | [요금](/ko/guide/billing/pricing), [사용량](/ko/guide/billing/usage) |
| 회사 차원에서 어떻게 검토하나요? | 아이덴티티, 데이터 처리, 액세스, 감사를 한곳에서 | [보안 개요](/ko/guide/security/overview) |
