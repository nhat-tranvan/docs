이 빠른 시작은 로그인부터 첫 AI 조사까지 안내합니다: CloudThinker가 근본 원인을 찾아내고 수정 방안을 제안합니다. **약 10분**을 허용하세요 — 데모로 시작하면 클라우드 자격 증명도 필요 없습니다.

<Info>
**필요한 것:** Google 또는 GitHub 계정, 또는 업무용 이메일. 자체 AWS, Azure, Google Cloud, Kubernetes 액세스는 선택 사항입니다 — 읽기 전용 데모는 이것 없이도 작동합니다.
</Info>

## 30초 문법

<PromptSyntaxBasics />

<Steps>
  <Step title="로그인">
    [app.cloudthinker.io](https://app.cloudthinker.io)로 이동하여 Google, GitHub 또는 SSO로 로그인하세요. 이메일을 사용하려면 주소를 입력하고 **Continue with email**을 클릭한 후 CloudThinker가 보낸 6자리 코드를 입력하세요.

    처음 로그인하면 두 가지 짧은 질문이 이어집니다: **Tell us about you**(역할)와, 조직 소유자의 경우 **How can I help you?**. 답하거나 **Skip**을 클릭하세요 — 이 가이드를 따라가려면 **Just exploring**을 선택하세요.

    **성공 기준:** 채팅 상자와 **Needs you**, **Modules**, **Automation today** 카드가 있는 Home에 진입합니다. 사이드바에 **New chat**, **Artifacts**, **Automations**, **Investigation**이 표시됩니다.

    <Tip>
    새 조직은 카드 등록 없이 14일 Team 체험판으로 시작합니다. 요금제 한도는 [요금](/ko/guide/billing/pricing)을 참고하세요.
    </Tip>
  </Step>

  <Step title="데모 또는 자체 클라우드 연결">
    <Tabs>
      <Tab title="데모 (자격 증명 불필요)">
        1. 사이드바에서 **Try a demo environment**를 클릭하거나 **Settings → Connections**로 이동하세요.
        2. **Demo available** 표시가 있는 서비스를 선택하세요 — AWS, Google Cloud, Azure, Kubernetes 중 제공되는 것.
        3. **Connect**를 클릭한 다음 **Use demo**를 클릭하세요. 설정에는 약 1분이 걸립니다.

        [데모 환경](/ko/guide/connections/overview)은 읽기 전용이며 데모를 사용하는 다른 사람들과 공유됩니다. 데모 채팅도 다른 채팅과 마찬가지로 [크레딧](/ko/guide/billing/usage)을 사용합니다.
      </Tab>
      <Tab title="자체 클라우드">
        1. **Settings → Connections**로 이동하여 공급자를 선택하세요.
        2. **Connect**를 클릭하고 공급자 양식을 따르세요. AWS의 경우 **Role-Based**(권장) 또는 **Access Keys**를 선택하세요.
        3. 시작 권한은 읽기 전용으로 유지하세요. 에이전트는 변경하기 전에 항상 [승인](/ko/guide/approval)을 요청합니다.

        전체 안내: [AWS](/ko/guide/connections/aws), [Azure](/ko/guide/connections/azure), [Google Cloud](/ko/guide/connections/gcp), [Kubernetes](/ko/guide/connections/kubernetes).
      </Tab>
    </Tabs>

    **성공 기준:** 연결이 **Connected**로 표시됩니다. **Connection error**가 표시되면 [문제 해결](#문제-해결)을 참고하세요.
  </Step>

  <Step title="첫 질문하기">
    데모에서는 CloudThinker가 *Give me an overview of this AWS account.*와 같은 편집 가능한 시작 프롬프트가 담긴 채팅을 엽니다. 그대로 보내세요.

    자체 클라우드에서는 **New chat**을 클릭하고 다음을 보내세요:

    ```text
    Give me an overview of this AWS account: resources by service and region, and anything that looks idle
    ```

    사용하는 공급자나 클러스터 이름으로 바꾸세요.

    **성공 기준:** CloudThinker가 일반적인 모범 사례가 아니라 계정에서 알아볼 수 있는 서비스, 리전, 리소스로 답변합니다.
  </Step>

  <Step title="첫 조사 실행">
    1. 사이드바에서 **Investigation**을 클릭하세요. Resolve가 첫 알림 소스 연결을 요청하면 **Skip for now**를 클릭하세요 — 다음 단계에서 다룹니다.
    2. **Log Incident**를 클릭하세요.
    3. **What's happening?**에 실제 문제를 설명하세요 — 예를 들어 이전 답변에서 지적된 내용. 또는 **Service Degradation**과 같은 **Quick Start Template**을 선택하여 양식을 미리 채우세요.
    4. **Severity**를 선택하고, **Context**에 세부 정보를 추가한 뒤 **Log Incident**를 클릭하세요.

    CloudThinker가 즉시 근본 원인 분석을 시작합니다. 수동으로 기록한 인시던트에는 알림 소스가 필요 없습니다.

    **성공 기준:** 인시던트가 Investigation 뷰의 **AI is handling** 아래에 열립니다. 조사가 완료되면 증거가 포함된 근본 원인, 타임라인, 승인할 수 있는 해결 제안이 표시됩니다 — 읽는 방법은 [조사 및 RCA](/ko/guide/incident/root-cause-analysis)를 참고하세요.
  </Step>

  <Step title="모든 인시던트를 자동으로 조사 (선택 사항)">
    **Resolve**로 이동하여 **Connect a source**를 클릭하세요. 웹훅(Datadog, PagerDuty, Grafana, Opsgenie 또는 커스텀 알림), 클라우드 폴링(AWS, Azure Monitor, Google Cloud Monitoring), 또는 Slack이나 Microsoft Teams를 선택하세요.

    **On Duty** — 자동 조사 — 는 기본적으로 켜져 있으므로, [Pulse](/ko/guide/pulse/overview)가 해당 소스에서 라우팅하는 모든 인시던트는 누구도 **Investigate**를 클릭하지 않아도 조사됩니다. 전체 설정은 [Pulse 소스 연결](/ko/guide/pulse/setup)에 있습니다.

    **성공 기준:** 도구에서 보낸 이벤트가 Pulse에 Signal로 나타납니다.
  </Step>
</Steps>

## 완료 기준

- [x] 연결(데모 또는 자체)이 **Connected**로 표시됩니다
- [x] 에이전트가 해당 환경에서 알아볼 수 있는 리소스로 답변했습니다
- [x] 기록한 인시던트에 조사 결과가 표시되고, 증거를 통해 결과를 추적할 수 있습니다

**Getting started checklist**가 이러한 첫 단계를 추적하고 완료할 때마다 크레딧을 추가합니다. 다음 로그인부터는 [Home](/guide/activity)이 시작점입니다: **Needs you**에 승인을 기다리는 항목이 나열되고, 진행 중인 인시던트가 있으면 배너가 표시됩니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="로그인 코드가 도착하지 않음" icon="envelope">
    **확인:** 스팸 또는 프로모션 폴더, 그리고 코드 화면의 주소 철자가 올바른지 확인하세요.

    **수정:** **Resend code**를 클릭하거나, Google 또는 GitHub로 로그인하세요.
  </Accordion>

  <Accordion title="'Demo available'로 표시된 서비스가 없음" icon="flask">
    **가능한 원인:** 데모는 해당 데모 대상을 사용할 수 있을 때만 제공됩니다.

    **수정:** **Show all connections**를 클릭하여 다른 공급자를 확인하거나, 나중에 다시 시도하거나, 자체 클라우드를 연결하세요.
  </Accordion>

  <Accordion title="연결이 'Connection error'로 표시됨" icon="circle-exclamation">
    **가능한 원인:** 자격 증명이 잘못되었거나 권한이 부족합니다 — AWS의 경우 보통 역할 Trust policy의 External ID 불일치입니다.

    **수정:** 클라우드 공급자에서 자격 증명을 수정한 후 연결에서 **Retry**를 클릭하세요. 공급자별 확인 사항은 [AWS 문제 해결](/ko/guide/connections/aws#문제-해결)과 같은 각 연결 가이드에 있습니다.
  </Accordion>

  <Accordion title="에이전트가 액세스 권한이 없다고 하거나 일반적인 답변을 함" icon="user-slash">
    **가능한 원인:** 연결이 현재 채팅 중인 [워크스페이스](/ko/guide/workspaces)와 다른 워크스페이스에 있습니다.

    **수정:** 사이드바 상단의 워크스페이스 선택기를 확인하고, 연결을 추가한 워크스페이스로 전환한 뒤 다시 질문하세요.
  </Accordion>

  <Accordion title="조사가 'Not found'로 종료됨" icon="magnifying-glass">
    **가능한 원인:** 사용 가능한 증거가 근본 원인을 뒷받침하지 못했습니다 — 연결된 환경에서 실제로 발생하지 않은 인시던트에서 흔합니다.

    **수정:** 해당 환경에서 실제로 일어난 일에 대해 인시던트를 기록하거나, **Context**에 세부 정보를 추가하거나, 증거를 보유한 클라우드 또는 모니터링 도구를 연결하세요.
  </Accordion>
</AccordionGroup>
