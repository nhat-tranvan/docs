신규 고객이 가장 많이 묻는 질문에 대한 짧은 답변과, 각 주제를 자세히 다루는 페이지 링크입니다. 여기에 질문이 없다면 [문의](https://cloudthinker.io/contact)하세요.

## 시작하기

<AccordionGroup>
  <Accordion title="CloudThinker는 무엇인가요?">
    CloudThinker는 Frontier Investigation Agents를 만듭니다. 이 AI [에이전트](/ko/guide/agents/overview)는 클라우드, 코드, 도구에 연결되어 인시던트, 코드 위험, 비용 낭비, 보안 격차의 근본 원인을 찾아내고, 엔지니어가 승인할 수정을 제안합니다.

    CloudThinker에는 문제 유형별로 하나씩 네 가지 제품이 있습니다. 하나씩 도입할 수 있습니다.

    | 제품 | 하는 일 |
    |---|---|
    | [Resolve](/ko/guide/incident/overview) | 인시던트를 조사하고 증거와 함께 근본 원인을 찾습니다 |
    | [Review](/ko/guide/code-review/overview) | 인라인 댓글과 제안된 수정으로 풀 리퀘스트를 리뷰합니다 |
    | [Cyber](/guide/security/cyber-overview) | 테스트 권한이 있는 앱에 동적 보안 테스트를 실행하고 각 발견 항목을 추적합니다 |
    | [Optimize](/ko/guide/cost-optimization/overview) | 유휴 리소스, 과도한 크기의 인스턴스, 비용 이상에 순위를 매깁니다 |

    세 가지 지원 영역은 직접 무언가를 조사하는 대신 네 제품 모두에 걸쳐 동작합니다.

    | 영역 | 하는 일 |
    |---|---|
    | [Approvals](/guide/approvals/overview) | 어떤 에이전트 변경이 스스로 실행되고, 사람을 기다리고, 거부될지 결정합니다 |
    | [Customize](/ko/guide/agents/customize) | 에이전트가 일하는 방식을 정합니다: 커스텀 에이전트와 스킬 |
    | [Automation](/guide/automation/automations) | 일정에 따라, 웹훅이 호출될 때, 저장소 이벤트에서, 또는 프로브 점검이 발생할 때 프롬프트를 실행합니다 |
  </Accordion>

  <Accordion title="첫 답변을 얼마나 빨리 받을 수 있나요?">
    약 10분입니다. [빠른 시작](/ko/quickstart)은 [app.cloudthinker.io](https://app.cloudthinker.io)에 로그인하고, 하나의 시스템을 읽기 전용으로 연결하고, 첫 질문을 하는 과정을 안내합니다.

    **성공 상태:** 답변에 자신의 환경에서 알아볼 수 있는 서비스, 리전, 리소스 이름이 나옵니다.
  </Accordion>

  <Accordion title="프로덕션에 위험을 주지 않고 시험해 볼 수 있나요?">
    예. 읽기 전용 역할로 스테이징이나 샌드박스 계정을 연결하고, 연결에서 **Allow writes**를 꺼서 CloudThinker가 모든 변경을 거부하게 하세요. 에이전트는 볼 수 있지만 아무것도 바꿀 수 없습니다. [빠른 시작](/ko/quickstart)을 참조하세요.
  </Accordion>

  <Accordion title="조직과 워크스페이스의 차이는 무엇인가요?">
    **조직**은 계정입니다: 플랜, 청구, 멤버 목록, SSO, BYOK, 감사 로그. 조직 역할은 Owner, Admin, Developer, Viewer입니다. **워크스페이스**는 조직 안에 있으며 실제 작업을 담습니다: 연결, 에이전트, 스킬, 대화, 승인. 워크스페이스 역할은 Admin, Developer, Viewer입니다.

    | 설정 영역 | 다루는 것 | 여는 곳 |
    |---|---|---|
    | **Settings → Organization** | 조직(Owner와 Admin만) | 워크스페이스 메뉴나 계정 메뉴의 **Settings**, 그다음 **Organization** 탭 |
    | **Settings → Workspace** | 현재 있는 워크스페이스 | 사이드바 상단의 워크스페이스 메뉴, 그다음 **Settings** |
    | **Settings → Personal** | 자신만: 프로필, 2FA, 자신의 이메일 알림 | 사이드바 하단의 계정 메뉴, 그다음 **Settings** |

    [조직](/ko/guide/organization)과 [워크스페이스](/ko/guide/workspaces)를 참조하세요.
  </Accordion>

  <Accordion title="팀을 어떻게 초대하나요?">
    조직 Owner나 Admin이 **Settings → Organization → Members**로 이동하여 **Invite people**을 클릭하거나, 사이드바 상단의 워크스페이스 메뉴에서 **Invite members**를 클릭합니다. 각 사람은 조직 역할을 받으며, **Settings → Workspace → Members**에서 하나의 워크스페이스에 대해 다른 역할을 줄 수 있습니다. [멤버 초대](/ko/guide/organization#멤버-초대)와 [워크스페이스 멤버](/ko/guide/workspace-users)를 참조하세요.
  </Accordion>

  <Accordion title="CloudThinker는 어떤 시스템에 연결할 수 있나요?">
    AWS, Google Cloud, Azure 같은 클라우드와 Kubernetes, 데이터베이스, 관측성 도구, Git 제공자, CI/CD, 그리고 Jira와 ServiceNow 같은 티켓 도구입니다. 각각은 **Settings → Workspace → Connections**에서 추가하는, 하나의 서비스에 대한 자격 증명인 **연결**입니다.

    전체 목록은 [연결 카탈로그](/ko/guide/connections/overview#연결-카탈로그)에 있습니다. 도구가 목록에 없지만 그 앞에서 MCP 서버를 운영한다면, 그 서버를 [MCP 연결](/ko/guide/connections/mcp)로 추가하면 에이전트가 그 도구를 호출할 수 있습니다.
  </Accordion>

  <Accordion title="무언가를 설치하거나 아키텍처를 바꿔야 하나요?">
    아니요. CloudThinker는 관리형 서비스로 실행되며, 부여한 자격 증명과 권한을 사용해 추가한 연결을 통해 시스템에 도달합니다.

    노트북이나 CI 러너처럼 직접 관리하는 머신에서 명령을 실행하고 싶다면 [Environment](/guide/workers)(베타)를 추가할 수 있습니다. 선택 사항입니다. 에이전트에게 비공개 저장소나 내부 호스트가 필요할 때 사용하세요. Environment는 HTTPS로 바깥쪽에 연결하므로 인바운드 포트를 열지 않습니다.

    이 문서에는 CloudThinker의 egress IP 주소가 게시되어 있지 않습니다. 방화벽에 허용 목록이 필요하다면 [문의](https://cloudthinker.io/contact)를 통해 요청하세요.
  </Accordion>

  <Accordion title="Slack이나 Teams에서 CloudThinker를 어떻게 사용하나요?">
    조직 Owner나 Admin이 **Settings → Organization → Chat integrations**로 이동하여 **Slack** 행의 **Configure**를 클릭하고 **Connect with Slack**을 클릭합니다. 그런 다음 봇을 채널에 초대합니다. 채팅 앱에는 Team 플랜 이상이 필요합니다. Slack과 Microsoft Teams에서 승인이 필요한 쓰기는 웹 앱으로 연결되며, 그곳에서 승인합니다. Google Chat은 카드 자체에 **Approve**와 **Reject** 버튼을 표시합니다. [Slack](/ko/guide/slack-integration), [Microsoft Teams](/ko/guide/teams-integration), [Google Chat](/guide/google-chat-integration)을 참조하세요.
  </Accordion>

  <Accordion title="연결을 제거하거나 데이터를 삭제하려면 어떻게 하나요?">
    워크스페이스 Admin은 **Settings → Workspace → Connections**에서 연결을 삭제할 수 있습니다. 연결, 대화, 설정을 포함한 워크스페이스 전체를 제거하려면 조직 Owner나 Admin이 **Settings → Organization → Workspaces**를 사용합니다. 복원은 없습니다. [워크스페이스 삭제](/ko/guide/workspaces#워크스페이스-삭제)를 참조하세요.
  </Accordion>
</AccordionGroup>

## 에이전트와 안전

<AccordionGroup>
  <Accordion title="에이전트는 누구인가요?">
    모든 워크스페이스에는 하나의 기본 제공 에이전트 **CloudThinker**가 있습니다. 항상 켜져 있으며, 큰 작업을 임시 서브에이전트에게 나누어 맡길 수 있습니다. 팀은 자체 지침과 스킬을 가진 커스텀 에이전트도 만들 수 있습니다. [에이전트](/ko/guide/agents/overview)와 [Customize](/ko/guide/agents/customize)를 참조하세요.
  </Accordion>

  <Accordion title="특별한 명령을 배워야 하나요?">
    아니요. 일반 언어로 동작하며, 멘션이 없으면 CloudThinker가 답합니다. 세 가지 선택적 기호로 요청을 더 정확하게 만들 수 있습니다.

    | 기호 | 고르는 것 | 예시 |
    |---|---|---|
    | `@` | 에이전트 | `@CloudThinker` |
    | `#` | 연결 | `#aws-prod` |
    | `/` | 스킬 | `/resource-rightsizing-analysis` |

    ```text
    Which EC2 instances in us-east-1 averaged under 5% CPU last week?
    @CloudThinker #aws-prod which RDS instances averaged over 80% CPU yesterday?
    Show last month's cost by service as a dashboard
    ```

    대시보드나 보고서 같은 출력 형태는 말로 요청하세요. 전체 문법: [CloudThinker Language](/guide/commands).
  </Accordion>

  <Accordion title="에이전트가 스스로 프로덕션 시스템을 변경할 수 있나요?">
    설정한 한도 안에서만 가능합니다. 읽기는 항상 실행됩니다. 모든 **쓰기**(서비스 재시작처럼 연결된 시스템을 바꾸는 에이전트 호출)는 다음 점검을 순서대로 거칩니다.

    1. **항상 차단**: CloudTrail 로깅 중지나 `kube-system` 네임스페이스 삭제처럼 절대 실행되지 않는 호출의 기본 제공 목록. 어떤 것도 이를 재정의하지 않습니다.
    2. 특정 종류의 쓰기를 허용, 먼저 묻기 또는 거부하는 **Rules**. **Manual**에서는 Allow Rule이 쓰기를 실행하게 하지 않으며, 쓰기는 여전히 사람에게 갑니다.
    3. **Approval mode**: **Manual**은 모든 쓰기에 대해 사람에게 묻습니다. **Auto**는 AI 판단이 안전한 쓰기를 허용하게 할 수 있고, 나머지는 사람에게 묻거나 거부합니다.
    4. 승인하거나 거부하는 승인자.

    하나의 예외: Review에서 **Apply fix**와 **Fix all findings**는 사람이 클릭하면 이 점검을 거치지 않고 풀 리퀘스트의 소스 브랜치에 커밋합니다.

    Approval mode 자체는 실제로 적용되며, 새 워크스페이스는 **Auto · Rules + AI · Ask me**로 시작합니다. 세 부분으로 읽으세요. 모드는 **Auto**이고, 쓰기는 **Rules + AI** 판단으로 결정되며, 여전히 허용되지 않은 것은 사람을 기다립니다(**Ask me**). 예를 들어 방금 물어본 스테이징 pod 재시작은 실행될 수 있습니다. RDS 스냅샷 삭제는 파괴적이므로 묻습니다.

    쓰기가 기다리면 채팅에 **Approve**와 **Decline**이 있는 승인 카드가 표시됩니다. 기본적으로 모든 워크스페이스 Developer나 Admin이 답할 수 있습니다. [Approvers](/guide/approvals/approvers)에서 범위를 좁히세요. Slack이나 Microsoft Teams의 요청은 웹 앱으로 연결되며, 그곳에서 승인합니다. Google Chat에서는 카드에서 승인하거나 거부할 수 있습니다.

    모든 쓰기에 사람을 요구하려면 워크스페이스를 **Manual**로 전환하세요. 그런 다음 [실행 유형 행](/guide/approvals/approval-mode#set-a-mode-for-a-run-type)에서 **Automations**(그리고 변경한 다른 실행 유형)도 **Manual**로 재정의하세요. Automations 행의 기본값은 **Auto · Rules + AI · Refuse**이며 워크스페이스를 따르지 않습니다. Automation이나 채팅도 자체 모드를 고를 수 있습니다. [Approvals](/guide/approvals/overview)와 [Approval mode](/guide/approvals/approval-mode)를 참조하세요.
  </Accordion>

  <Accordion title="CloudThinker는 클라우드에서 어떤 권한이 필요한가요?">
    시작에는 읽기 전용으로 충분합니다. 두 가지 통제가 에이전트가 할 수 있는 일을 정합니다.

    | 통제 | 위치 | 결정하는 것 |
    |---|---|---|
    | 자격 증명 자체의 권한 | 제공자(IAM 역할, 서비스 계정, API 토큰 스코프) | 상한. 에이전트는 이것이 허용하는 것 이상을 절대 하지 않습니다. |
    | **Allow writes** | 연결의 상세 패널 | 꺼짐: 모든 변경이 거부됩니다. 켜짐: 변경이 Rules와 Approval mode를 거칩니다. |

    권장하는 읽기 전용 시작 역할:

    | 클라우드 | 역할 | 설정 |
    |---|---|---|
    | AWS | CloudShell에서 실행하는 설정 스크립트가 만드는 관리형 `ReadOnlyAccess` 정책 | [AWS 설정](/ko/guide/connections/aws#설정) |
    | Google Cloud | **Viewer**(`roles/viewer`). Optimize의 경우 **BigQuery Data Viewer**와 **BigQuery Job User**를 추가합니다. | [Google Cloud](/ko/guide/connections/gcp) |
    | Azure | 구독에 대한 **Reader**, 그리고 지출을 위한 **Cost Management Reader** | [Azure](/ko/guide/connections/azure) |

    AWS, Google Cloud, Azure에서는 **Allow writes**가 기본적으로 켜져 있으므로, 변경을 막는 것은 읽기 전용 자격 증명입니다. CloudThinker에서도 막으려면 연결의 상세 패널에서 스위치를 끄세요. 에이전트가 하기를 원하는 특정 변경에 대해서만 쓰기 권한을 추가하세요. [연결](/ko/guide/connections/overview)을 참조하세요.
  </Accordion>
</AccordionGroup>

## 보안 및 컴플라이언스

<AccordionGroup>
  <Accordion title="CloudThinker는 어떤 데이터를 저장하며, 어떻게 보호하나요?">
    | 데이터 | 보호 방식 |
    |---|---|
    | 연결 자격 증명 | 저장 시 암호화됩니다. 명령이 실행될 때 CloudThinker 관리형 샌드박스에 주입되며, [Environment](/guide/workers)로는 절대 전송되지 않습니다. |
    | 대화, 발견 항목, 보고서 | 워크스페이스로 범위가 제한되고 역할에 따라 볼 수 있습니다. 알려진 시크릿(연결 자격 증명, 워크스페이스 자격 증명, 채팅에서 저장한 값)은 저장되기 전에 자리표시자로 대체됩니다. |
    | 감사 로그 | 기본적으로 365일 보관된 후 자동으로 삭제됩니다. 더 오래 보관하려면 CSV로 내보내세요 |
    | 계정 비밀번호 | bcrypt 해시로 저장됩니다 |

    앱과 API는 HTTPS로 제공됩니다. 모델 호출은 CloudThinker의 LLM 제공자로 가며, 조직이 [BYOK](/ko/guide/byok)(자체 LLM 자격 증명 사용)를 사용하는 경우에는 AWS Bedrock, Anthropic, OpenAI, Azure OpenAI, Claude Code, Codex 같은 자체 제공자 계정을 통해 라우팅됩니다.

    이 문서는 호스팅 리전, 모델 제공자의 이름과 데이터 약관, 학습 사용, 대화 보관 기간을 다루지 않습니다. 벤더 검토를 시작할 때 [문의](https://cloudthinker.io/contact)를 통해 요청하세요. 세부 정보: [보안 및 신뢰](/ko/guide/security/overview).
  </Accordion>

  <Accordion title="누군가 채팅에 시크릿을 붙여 넣으면 어떻게 되나요?">
    메시지가 전송되지 않습니다. CloudThinker는 API 키, 토큰, 비밀번호, 연결 문자열 같은 자격 증명 형태의 값을 검사하고 **Review detected secrets** 대화상자를 엽니다. 하나를 고르세요.

    | 버튼 | 결과 |
    |---|---|
    | **Redact from message** | 각 값을 `[sensitive data removed]`로 대체합니다 |
    | **Save secrets**(워크스페이스 Admin만) | 각 값을 워크스페이스 자격 증명으로 저장하고 메시지를 `$KEY`로 바꿔 씁니다 |

    오탐은 **Mark as not a secret**으로 표시하세요. 원래 값은 대화에 절대 들어가지 않습니다. [데이터 보호](/guide/security/data-protection)를 참조하세요.
  </Accordion>

  <Accordion title="SSO를 사용하고, 2FA를 강제하고, 감사 추적을 남길 수 있나요?">
    | 통제 | 위치 | 플랜 |
    |---|---|---|
    | 인증 앱(TOTP) | **Settings → Personal → Security** | 전체 |
    | SAML 2.0 또는 OIDC SSO, SCIM 동기화 | **Settings → Organization → Identity** | Scale, Enterprise |
    | 기본 365일 보관되는 감사 로그, CSV 내보내기 | **Settings → Organization → Audit log** | Scale, Enterprise |

    [싱글 사인온](/ko/guide/security/sso), [역할](/guide/security/roles), [감사 로그](/guide/security/audit-logs)를 참조하세요.
  </Accordion>

  <Accordion title="CloudThinker는 컴플라이언스 인증을 보유하고 있나요?">
    인증과 증명서는 이 문서에 게시되어 있지 않습니다. 최신 보고서, 보안 설문지, 데이터 처리 계약이 필요하면 [문의](https://cloudthinker.io/contact)하세요. 팀이 제공 가능한 것을 보내 드립니다. 벤더 검토의 나머지는 지금 [보안 및 신뢰](/ko/guide/security/overview)로 답하세요.
  </Accordion>

  <Accordion title="CloudThinker를 자체 환경 안에서 실행할 수 있나요?">
    기본적으로 `app.cloudthinker.io`의 관리형 서비스로 실행됩니다. [Environments](/guide/workers)는 셀프 서비스이며 베타로, 직접 관리하는 머신에서 파일 및 셸 작업을 실행합니다. 전용, 셀프 호스팅, 에어갭 배포는 디자인 파트너 프로그램을 통한 얼리 액세스입니다. [배포](/ko/guide/deployment/overview)를 참조하세요.
  </Accordion>
</AccordionGroup>

## 요금 및 플랜

<AccordionGroup>
  <Accordion title="CloudThinker의 요금은 어떻게 책정되나요?">
    조직당 하나의 월간 가격이며, 멤버 수는 무제한입니다. 각 유료 플랜은 에이전트 작업이 소비하는 단위인 **크레딧**의 월간 풀을 추가하며, 모든 워크스페이스가 공유합니다. 플랜은 Free, Team, Scale, Enterprise입니다.

    | 플랜 | 월간 가격 | 월간 크레딧 | 워크스페이스 |
    |---|---|---|---|
    | Free | 무료 | 없음 | — |
    | Team | $99 | 1,000 | 3 |
    | Scale | $499 | 5,000 | 10 |
    | Enterprise | 개별 제안 | Pay-As-You-Go | 무제한 |

    조직은 Light 모델 채팅용으로 매일 100 무료 크레딧도 받습니다. UTC 자정에 재설정됩니다.

    각 실행은 크레딧 청구에 배수를 곱하는 세 가지 모델 등급 중 하나를 사용합니다. 빠른 질문용 **Light**(0.3x), 일상 작업용 **Pro**(1.0x, 기본값), 가장 어려운 문제용 **Ultra**(1.7x)입니다.

    크레딧이 소진되면 더 많은 크레딧이 필요한 실행은 차단됩니다. Team 이상에서는 Owner가 [Pay-As-You-Go](/ko/guide/billing/usage#pay-as-you-go)를 켤 수 있습니다. 설정한 월간 상한까지 크레딧당 $0.10의 종량제 충전입니다. 현재 가격과 한도: [요금](/ko/guide/billing/pricing). 실행이 크레딧을 사용하는 방식: [사용량](/ko/guide/billing/usage).
  </Accordion>

  <Accordion title="Free 플랜에서는 무엇을 할 수 있나요?">
    Light 모델의 직접 채팅: 웹 채팅, Rooms(다른 사람과 공유하는 채팅), CLI의 [헤드리스 채팅](/ko/guide/cli/headless-chat). 대화형 [CLI 에이전트](/ko/guide/cli/overview)에는 Team 이상이 필요합니다. Review, Resolve, Optimize, Cyber, Automation 같은 다른 실행은 "The Free plan only supports direct chat."으로 거부됩니다. 이 기능과 Pro 및 Ultra 모델을 사용하려면 Team 이상으로 업그레이드하세요.
  </Accordion>

  <Accordion title="무료 체험이 있나요?">
    자격이 있는 Free 조직은 Team 카드에서 **Start 14-day free trial**을 볼 수 있습니다. 사이드바 하단 계정 메뉴의 **Upgrade plan**에서 연 다음 **Continue to add card**를 클릭하세요. 시작하려면 카드가 필요하며, 오늘 결제되는 금액은 없습니다. 14일 동안 Team 기능을 사용할 수 있습니다. Pay-As-You-Go(풀이 소진되면 유료로 충전하는 크레딧)는 체험 기간 동안 꺼진 상태로 유지됩니다.

    <Warning>
      체험이 끝나면 카드가 자동으로 청구되며, 이후 갱신 때마다 청구됩니다. 청구를 피하려면 체험이 끝나기 전에 **Manage in Stripe**에서 취소하세요.
    </Warning>
  </Accordion>

  <Accordion title="어떤 플랜이 필요한가요?">
    | 원하는 것 | 최저 플랜 |
    |---|---|
    | 비용 없이 채팅으로 CloudThinker 시험하기 | Free |
    | Review, Resolve, Optimize, Cyber 실행, 또는 Slack, Teams, Google Chat에서 답변받기 | Team |
    | SSO 사용, 감사 추적 유지, BYOK 사용, 또는 워크스페이스별 지출 상한 설정 | Scale |
    | 자체 인프라에서 CloudThinker 실행 | 얼리 액세스 디자인 파트너 프로그램을 통한 Enterprise |

    조직 **Owner**만 플랜을 바꿀 수 있습니다. [요금](/ko/guide/billing/pricing)을 참조하세요.
  </Accordion>
</AccordionGroup>
