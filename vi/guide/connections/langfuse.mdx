Kết nối một project Langfuse để [CloudThinker](/vi/guide/agents/overview) cho bạn biết vì sao một lệnh gọi LLM thất bại, một trace tốn bao nhiêu, và một phiên bản prompt đạt điểm thế nào. Kết nối dùng một cặp API key cấp project (public key và secret key), hoạt động với cả Langfuse Cloud lẫn Langfuse tự host.

## Điều kiện tiên quyết

- Một project Langfuse Cloud hoặc tự host đang nhận trace từ ứng dụng của bạn.
- Quyền tạo API key trong project đó.
- Host Langfuse của bạn: base URL bạn dùng để đăng nhập, chẳng hạn `https://cloud.langfuse.com` (EU) hoặc `https://us.cloud.langfuse.com` (US), hoặc domain tự host.
- Với Langfuse tự host: instance phục vụ `/api/public/mcp` qua HTTPS và nhận kết nối từ internet. Nếu nằm sau firewall, hãy cho phép các egress IP của CloudThinker. Tài liệu này không công bố danh sách egress IP của CloudThinker: hãy hỏi đầu mối liên hệ tại CloudThinker, hoặc [liên hệ với chúng tôi](https://cloudthinker.io/contact). Xem [Truy cập dịch vụ nội bộ](/vi/guide/connections/overview#truy-cập-dịch-vụ-nội-bộ) để biết các lựa chọn khác. CloudThinker từ chối host dùng `http://` thuần.
- Vai trò **Admin** trong workspace CloudThinker, vai trò có quyền thêm và sửa kết nối. Xem [Vai trò](/vi/guide/security/roles).

## Thiết lập

<Steps>
  <Step title="Tạo cặp API key trong Langfuse">
    Đăng nhập Langfuse, mở project bạn muốn CloudThinker đọc, rồi vào **Project → Settings → API Keys**. Nhấn **Create new API keys**.

    Langfuse hiển thị một **Public Key** (bắt đầu bằng `pk-lf-`) và một **Secret Key** (bắt đầu bằng `sk-lf-`). Sao chép cả hai ngay. Langfuse chỉ hiển thị secret key một lần.
  </Step>
  <Step title="Mở kết nối Langfuse trong CloudThinker">
    Trong CloudThinker, mở **More → Workspace settings → Connections**, giữ nguyên tab **Builtin Connections**, rồi chọn **Langfuse**.
  </Step>
  <Step title="Nhập host và key">
    | Trường | Nội dung cần nhập | Ví dụ |
    |-------|---------------|---------|
    | **LANGFUSE_HOST** | Base URL của instance Langfuse chứa project, không kèm path. Nếu thiếu `https://`, CloudThinker sẽ tự thêm. | `https://cloud.langfuse.com` |
    | **LANGFUSE_PUBLIC_KEY** | Public key của project | `pk-lf-...` |
    | **LANGFUSE_SECRET_KEY** | Secret key của project | `sk-lf-...` |

    Cặp key chỉ hoạt động trên host và trong project đã cấp nó. Để đọc project thứ hai, hãy thêm kết nối Langfuse thứ hai với key của project đó.
  </Step>
  <Step title="Kết nối">
    Nhấn **Connect**. CloudThinker kiểm tra kết nối bằng cách mở một phiên với MCP server của Langfuse tại `/api/public/mcp`.

    **Trạng thái thành công:** kết nối Langfuse hiển thị trạng thái **Connected**. Chạy prompt xác minh bên dưới để chắc chắn key đọc được project của bạn.
  </Step>
</Steps>

## Xác minh kết nối

```text
Summarize my Langfuse project: recent traces, error count, models in use, and prompts
```

**Trạng thái thành công:** CloudThinker liệt kê một số trace mẫu trong 7 ngày qua, các observation gần đây, prompt và dataset của project này. Project chưa có trace nào sẽ trả về danh sách rỗng, không phải lỗi. Lỗi 401 nghĩa là key sai; xem [Khắc phục sự cố](#khắc-phục-sự-cố).

## Quyền yêu cầu

Cặp key Langfuse thuộc về một project và truy cập được trace, score, dataset và prompt của project đó. Chọn project chính là cách bạn giới hạn những gì CloudThinker nhìn thấy.

Cặp key cũng có thể ghi vào project đó, ví dụ score, comment và mục trong annotation queue. CloudThinker chỉ ghi khi bạn yêu cầu một thay đổi cụ thể, và mọi thao tác ghi đều đi qua [Approvals](/vi/guide/approvals/overview).

<ApprovalDefault />

<Tip>
Hãy tạo một cặp key chỉ dành cho CloudThinker, tách biệt với key mà SDK dùng để gửi trace. Khi đó bạn có thể thu hồi key mà không làm gián đoạn việc nhận dữ liệu.
</Tip>

## Khả năng của agent

| Khả năng | CloudThinker làm gì |
|------------|------------------------|
| **Điều tra trace** | Xếp hạng các observation thất bại hoặc chậm gần đây, và đối chiếu lỗi, độ trễ với model được dùng |
| **Lần theo hội thoại** | Dựng lại một hội thoại hoặc session thành chuỗi lệnh gọi model và tool theo thứ tự, có đánh dấu lỗi |
| **Báo cáo mức sử dụng** | Tổng hợp token, chi phí và độ trễ trong một khoảng thời gian, chia theo model và session |
| **Rà soát chất lượng** | Xem lại score, dataset, annotation queue, comment và phiên bản prompt, đồng thời chỉ ra chỗ còn thiếu đánh giá |
| **Thay đổi theo yêu cầu** | Thao tác ghi như thêm score hoặc comment, hay thay đổi một mục trong annotation queue, chỉ khi bạn nêu rõ đối tượng và nội dung thay đổi. CloudThinker không bao giờ ghi trong lúc điều tra, lập báo cáo hay rà soát. Lệnh gọi đi qua [Approvals](/vi/guide/approvals/overview). |

## Ví dụ prompt

```text
Which Langfuse traces failed in the last hour, and what do the errors have in common?
Break down LLM cost and latency by model for the last 24 hours in Langfuse
Which prompt versions have the lowest evaluation scores this week?
```

Hãy nêu khoảng thời gian trong mỗi yêu cầu. Truy vấn trace và mức sử dụng có giới hạn, và khoảng thời gian ngắn cho câu trả lời tập trung, nhanh hơn.

## Khắc phục sự cố

<Accordion title="401 Unauthorized">
Public key hoặc secret key sai, đã bị xóa, hoặc hai key thuộc hai project khác nhau. Sao chép lại cả hai key từ cùng một project, kiểm tra khoảng trắng thừa, rồi cập nhật kết nối.
</Accordion>

<Accordion title="Kết nối tới Langfuse Cloud thất bại">
Mỗi region của Langfuse Cloud lưu dữ liệu riêng, nên cặp key chỉ hoạt động trên host đã cấp nó. Đặt **LANGFUSE_HOST** thành base URL bạn dùng để đăng nhập, ví dụ `https://cloud.langfuse.com` cho EU hoặc `https://us.cloud.langfuse.com` cho US.
</Accordion>

<Accordion title="Mọi request đều trả về 404">
**LANGFUSE_HOST** có path phía sau domain. Chỉ đặt base URL. Lỗi 404 trên một trace hoặc dataset cụ thể nghĩa là ID đó không tồn tại trong project này.
</Accordion>

<Accordion title="Langfuse tự host trả về 503 hoặc không phản hồi">
Kiểm tra instance có phục vụ `/api/public/mcp` qua HTTPS không, proxy có giữ nguyên header `Host` công khai không, và có firewall nào chặn CloudThinker truy cập host không. Để cho phép CloudThinker, xem [Truy cập dịch vụ nội bộ](/vi/guide/connections/overview#truy-cập-dịch-vụ-nội-bộ).
</Accordion>

<Accordion title="Tìm kiếm không trả về kết quả">
Câu trả lời rỗng không có nghĩa kết nối bị hỏng. Mở rộng khoảng thời gian từng bước, và xác nhận project đang nhận trace từ ứng dụng của bạn.
</Accordion>

## Bảo mật

<ConnectionSecurity />

- **Mỗi cặp key một project**: cặp key truy cập được toàn bộ project, nên chỉ kết nối project mà CloudThinker cần đọc.
- **Chỉ HTTPS**: CloudThinker từ chối host không dùng HTTPS, nên key không bao giờ được truyền dưới dạng văn bản thuần.
