Kết nối tài khoản New Relic của bạn để cho phép các agent CloudThinker giám sát hiệu suất ứng dụng, kiểm tra hạ tầng, chạy truy vấn NRQL, xem lại alert và điều tra sự cố trên toàn bộ stack quan sát.

New Relic xác thực bằng **User API key** (`NRAK-…`) và kết nối thông qua **New Relic AI MCP server**, cần được bật trước khi kết nối.

---

## Khu vực hỗ trợ

| Khu vực | MCP endpoint |
|---------|--------------|
| **US** | `mcp.newrelic.com` |
| **EU** | `mcp.eu.newrelic.com` |

<Warning>
Chọn khu vực phù hợp với tài khoản của bạn. Tài khoản EU kết nối với khu vực US (hoặc ngược lại) sẽ thất bại xác thực hoặc trả về kết quả rỗng.
</Warning>

---

## Điều kiện tiên quyết

Bạn cần **New Relic AI MCP server** được bật và **User API key** (`NRAK-…`).

**Bật New Relic AI MCP server:**

CloudThinker kết nối với New Relic qua New Relic AI MCP server, hiện đang ở public preview và phải được bật trước khi kết nối. Việc sử dụng với tài khoản FedRAMP hoặc HIPAA bị nghiêm cấm theo điều khoản của New Relic.

1. Trong New Relic, nhấn **tên người dùng** ở góc dưới bên trái.
2. Vào **Administration → Previews & Trials**.
3. Bật nút bật tắt preview **New Relic AI MCP server**.

**Tạo User API key:**

1. Mở **API keys** (menu người dùng → **API keys**, hoặc vào `one.newrelic.com/api-keys`; EU: `one.eu.newrelic.com/api-keys`).
2. Nhấn **Create a key** và đặt **Key type** thành **User**.
3. Đặt tên (ví dụ: `CloudThinker`) và lưu.
4. Sao chép giá trị key — key `NRAK-…` đầy đủ chỉ được hiển thị **một lần** khi tạo.

<Warning>
Dùng **User API key** (`NRAK-…`). License, ingest và query key dành cho việc nhập dữ liệu và sẽ không hoạt động để truy vấn — đây là lỗi thiết lập phổ biến nhất.
</Warning>

## Thiết lập

<Steps>
  <Step title="Mở CloudThinker">
    Điều hướng đến **Connections → New Relic** trong workspace CloudThinker của bạn và nhấn **Connect New Relic**.
  </Step>
  <Step title="Đặt tên kết nối">
    Nhập **Alias** (tên định danh duy nhất cho instance này, ví dụ: `production`) và **Description**.
  </Step>
  <Step title="Nhập API key">
    Dán **User API key** New Relic của bạn (`NRAK-…`).
  </Step>
  <Step title="Chọn khu vực">
    Chọn **US** (`mcp.newrelic.com`) hoặc **EU** (`mcp.eu.newrelic.com`) phù hợp với tài khoản New Relic của bạn.
  </Step>
  <Step title="Kết nối">
    Nhấn **Connect**. CloudThinker xác minh thông tin xác thực và hiển thị trạng thái **Connected**.
  </Step>
</Steps>

## Chi tiết kết nối

| Trường | Mô tả | Ví dụ |
|--------|-------|-------|
| **NEWRELIC_API_KEY** | User API key New Relic của bạn (tiền tố `NRAK-`) | `NRAK-XXXXXXXXXXXXXXXXXXXX` |
| **NEWRELIC_REGION** | Khu vực phù hợp với tài khoản của bạn | `US` / `EU` |

## Quyền yêu cầu

User API key kế thừa quyền của người dùng sở hữu nó. Để áp dụng quyền tối thiểu, giới hạn người dùng đó chỉ có quyền chỉ đọc.

<Tip>
Để truy cập MCP server, người dùng của key phải thuộc nhóm được gán **Organization Read Only**, **Organization Manager** hoặc **Organization Product Admin** — hoặc role tùy chỉnh cấp quyền đọc MCP. Để áp dụng quyền tối thiểu, dùng **Organization Read Only**. Để truy vấn NRQL và NerdGraph, role chỉ đọc là đủ.
</Tip>

## Khả năng của agent

Sau khi kết nối, các agent có thể truy vấn và điều tra trên môi trường New Relic của bạn.

| Khả năng | Những gì agent có thể làm |
|----------|--------------------------|
| **APM** | Kiểm tra hiệu suất ứng dụng — throughput, tỷ lệ lỗi và transaction trace |
| **Hạ tầng** | Liệt kê host và container, xem lại mức sử dụng tài nguyên |
| **NRQL** | Chạy truy vấn NRQL qua NerdGraph trên bất kỳ telemetry nào |
| **Alert** | Xem lại chính sách alert, điều kiện và vi phạm đang mở |
| **Log** | Tìm kiếm và phân tích log trên các dịch vụ và môi trường |
| **Entity** | Khám phá và kiểm tra các entity và dịch vụ được giám sát |
| **Sự cố** | Điều tra vấn đề đang mở và lấy chi tiết sự cố đầy đủ |
| **Dashboard** | Kiểm tra cấu hình dashboard |
| **Sức khỏe kết nối** | Xác nhận kết nối New Relic đang hoạt động |

### Xác minh kết nối

```text
@alex verify the New Relic connection and list monitored entity types and any open alert violations
```

### Ví dụ prompt

```text
@alex check error rates for the checkout service in New Relic over the last hour
@alex run an NRQL query for the slowest transactions in the production app
@alex list open New Relic alert violations and investigate the root cause
```

## Xử lý sự cố

<Accordion title="Kết nối thất bại hoặc không được phép">
Xác minh bạn đang dùng **User API key** (`NRAK-…`), không phải license, ingest hay query key. Xác nhận key chưa bị xóa hoặc xoay vòng trong New Relic và người dùng của key vẫn có quyền truy cập tài khoản.
</Accordion>

<Accordion title="Kết quả rỗng hoặc xác thực thất bại">
Kiểm tra khu vực đã chọn phù hợp với tài khoản của bạn — tài khoản EU phải dùng endpoint EU. Ngắt kết nối và kết nối lại với khu vực đúng.
</Accordion>

<Accordion title="Lỗi quyền hoặc ủy quyền sau khi kết nối">
Người dùng của key có thể thiếu role đọc MCP server. Gán **Organization Read Only**, **Organization Manager**, **Organization Product Admin**, hoặc role tùy chỉnh có phạm vi tổ chức với quyền đọc MCP. Xác nhận người dùng có quyền truy cập tài khoản có dữ liệu bạn mong đợi.
</Accordion>

<Accordion title="Kết nối MCP hoàn toàn không hoạt động">
Xác nhận preview **New Relic AI MCP server** được bật trong **Administration → Previews & Trials**. Kết nối không thể hoạt động cho đến khi preview được bật.
</Accordion>

## Bảo mật

<ConnectionSecurity />

- **Chỉ User API key** — dùng User key (`NRAK-…`); license, ingest và query key không xác thực yêu cầu MCP.
- **Service user chỉ đọc riêng biệt** — tạo key dưới người dùng chỉ đọc để key kế thừa quyền tối thiểu.
