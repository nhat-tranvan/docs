Kết nối một team Coralogix để các agent CloudThinker phân loại sự cố đang mở, tìm kiếm log và trace, truy vấn metric, xem cảnh báo và dashboard, và kiểm tra data pipeline để tìm parsing rule bị tắt hoặc connector cấu hình sai. Kết nối dùng MCP server do Coralogix host, đăng nhập bằng một **API key** cho một **region**. Bạn chọn region và CloudThinker tự định tuyến tới endpoint Coralogix tương ứng, nên không cần nhập URL.

## Điều kiện tiên quyết

- Một team Coralogix chứa dữ liệu bạn muốn agent đọc.
- Quyền tạo API key cho team đó.
- Region của team, đọc từ địa chỉ đăng nhập (xem [bảng region](#chi-tiết-kết-nối)).

## Thiết lập

<Steps>
  <Step title="Xác định region">
    Đăng nhập Coralogix và đối chiếu thanh địa chỉ với [bảng region](#chi-tiết-kết-nối). Một số region không có tên trong địa chỉ: `acme.coralogix.com` là EU1, còn `acme.app.cx498.coralogix.com` là US2.
  </Step>
  <Step title="Tạo API key">
    Vào **Settings → API Keys** và tạo key mới:

    - **Name**: `cloudthinker`
    - **Type**: **Team key**. Personal key gắn với một người dùng và ngừng hoạt động khi người đó mất quyền truy cập.
    - **Permissions**: quyền đọc với dữ liệu mà agent cần truy cập (xem [Quyền yêu cầu](#quyền-yêu-cầu))

    Sao chép key ngay. Nếu làm mất, bạn sẽ phải tạo key mới.
  </Step>
  <Step title="Thêm kết nối trong CloudThinker">
    Mở **More → Workspace settings → Connections**, giữ nguyên tab **Builtin Connections**, rồi chọn **Coralogix**. Điền:

    - **CORALOGIX_API_KEY**: key bạn vừa tạo
    - **CORALOGIX_REGION**: chọn region trong danh sách, ví dụ **EU2 (eu2.coralogix.com)**. Giá trị mặc định là **US2 (us2.coralogix.com)**, nên hãy đổi nếu team của bạn ở region khác.

    Nhấn **Connect**.

    **Trạng thái thành công:** Coralogix hiển thị **Connected**. Chạy prompt xác minh bên dưới để chắc chắn key và region khớp nhau.
  </Step>
</Steps>

<Warning>
Key chỉ hoạt động trong region nơi nó được tạo. Chọn sai region sẽ trả về **404 Not Found**, trông giống như thiếu dữ liệu. Hãy kiểm tra địa chỉ đăng nhập trước khi debug bất cứ thứ gì khác.
</Warning>

## Chi tiết kết nối

| Trường | Mô tả | Ví dụ |
|-------|-------------|---------|
| **CORALOGIX_API_KEY** | API key cấp team của Coralogix | `<your-api-key>` |
| **CORALOGIX_REGION** | Region khớp với địa chỉ đăng nhập của team | **EU2 (eu2.coralogix.com)** |

Tìm địa chỉ đăng nhập ở cột bên trái, rồi chọn giá trị tương ứng ở cột bên phải:

| Địa chỉ đăng nhập | Chọn trong **CORALOGIX_REGION** |
|---------------|------------------------------|
| `<team>.app.coralogix.us` | **US1 (us1.coralogix.com)** |
| `<team>.app.cx498.coralogix.com` | **US2 (us2.coralogix.com)**, giá trị mặc định |
| `<team>.app.us3.coralogix.com` | **US3 (us3.coralogix.com)** |
| `<team>.coralogix.com` | **EU1 (eu1.coralogix.com)** |
| `<team>.app.eu2.coralogix.com` | **EU2 (eu2.coralogix.com)** |
| `<team>.app.coralogix.in` | **AP1 (ap1.coralogix.com)** |
| `<team>.app.coralogixsg.com` | **AP2 (ap2.coralogix.com)** |
| `<team>.app.ap3.coralogix.com` | **AP3 (ap3.coralogix.com)** |

Để truy cập team hoặc region khác, hãy thêm một kết nối riêng với key riêng.

## Quyền yêu cầu

Cấp cho key quyền đọc với dữ liệu mà agent cần điều tra:

| Dữ liệu | Dùng cho |
|------|----------|
| Incidents | Phân loại và khám phá sự cố |
| Logs and traces | Tìm lỗi và lần theo request |
| Metrics | Truy vấn metric và danh mục metric |
| Alerts and dashboards | Xem định nghĩa cảnh báo và dashboard |
| Parsing rules, connectors, presets | Kiểm tra tình trạng pipeline |

Đừng cấp quyền ghi cho key, trừ khi bạn muốn agent thay đổi tài nguyên Coralogix, chẳng hạn bật một parsing rule. Key chỉ đọc đủ cho mọi cuộc điều tra trên trang này.

## Khả năng của agent

| Khả năng | Agent làm được gì | Phê duyệt |
|------------|--------------------|----------|
| **Khám phá** | Tóm tắt sự cố đang mở, số connector, parsing rule bị tắt, preset, và tìm kiếm metric có hoạt động hay không | Không |
| **Phân loại sự cố** | Liệt kê sự cố gần đây và đang mở, kèm mức độ nghiêm trọng, trạng thái và thời điểm | Không |
| **Log** | Tìm kiếm log trong một khoảng thời gian | Không |
| **Trace** | Xem distributed trace | Không |
| **Metric** | Truy vấn metric và tìm trong danh mục metric | Không |
| **Tình trạng pipeline** | Tìm parsing rule bị tắt hoặc bị ẩn, xem lại connector và preset | Không |
| **Cảnh báo và dashboard** | Đọc định nghĩa cảnh báo và dashboard | Không |
| **Thay đổi** | Tạo, cập nhật, bật, tắt hoặc xóa một tài nguyên Coralogix. Key cần có quyền ghi | Có |

Agent không bao giờ thay đổi gì trong lúc khám phá, phân loại hay kiểm tra tình trạng. Thay đổi chỉ xảy ra khi bạn yêu cầu trong cuộc hội thoại, nêu rõ tài nguyên và nội dung thay đổi, và thay đổi đó đi qua [Approvals](/vi/guide/approvals/overview). Theo mặc định, agent chỉ lấy tối đa 10 mục mẫu để danh mục lớn không làm ngập câu trả lời.

### Xác minh kết nối

```text
Run Coralogix discovery and summarize open incidents, connector count, disabled parsing rules, and whether metric search is healthy
```

Kết quả mong đợi gồm số lượng sự cố, connector, parsing rule và preset, cùng một mẫu ngắn cho từng loại. Thông báo "No metrics matched" ở bước kiểm tra metric là bình thường: bước khám phá thử bằng một tên metric không tồn tại. Nếu bản tóm tắt báo **degraded**, agent sẽ liệt kê các bước kiểm tra thất bại: incidents, connectors, parsing rules, presets hoặc metrics. Bước nào thất bại thường có nghĩa key thiếu quyền đọc dữ liệu đó. Nếu mọi bước đều thất bại, hãy kiểm tra key và region trước.

### Ví dụ prompt

```text
Triage open Coralogix incidents and flag anything affecting production
Search Coralogix logs for 5xx errors from the api-gateway service in the last hour
Check Coralogix pipeline health and list disabled parsing rules
Which Coralogix alerts fired for the payments service today?
```

Hãy nêu tên service và một khoảng thời gian ngắn. Truy vấn càng hẹp thì kết quả trả về càng nhanh và dễ đọc.

## Khắc phục sự cố

<Accordion title="Kết nối thất bại hoặc request trả về 401">
Key bị thiếu, đã hết hạn hoặc bị thu hồi. Tạo team key mới, sửa kết nối và dán key vào **CORALOGIX_API_KEY**.
</Accordion>

<Accordion title="Mọi request đều trả về 404">
Key thuộc một region khác. Kiểm tra địa chỉ đăng nhập và đổi **CORALOGIX_REGION** cho khớp.
</Accordion>

<Accordion title="Một số loại dữ liệu lỗi, số khác vẫn chạy">
Key thiếu quyền đọc với dữ liệu đó. Thêm quyền trong Coralogix, rồi chạy lại yêu cầu. Không cần kết nối lại nếu bản thân key không đổi.
</Accordion>

<Accordion title="Truy vấn metric không trả về gì">
Không có metric nào khớp với tên đó, hoặc team không gửi metric. Agent coi đây là kết quả rỗng. Hãy thử một tên metric bạn biết chắc tồn tại, hoặc tiếp tục với sự cố và log.
</Accordion>

<Accordion title="Request trả về 429 hoặc 503">
Coralogix đang giới hạn tần suất request hoặc đang bảo trì. Đợi một phút, thu hẹp yêu cầu, rồi hỏi lại.
</Accordion>

## Bảo mật

<ConnectionSecurity />

- **Team key, ưu tiên quyền đọc**: chỉ thêm quyền ghi cho những thay đổi bạn muốn agent có thể đề xuất.
- **Mỗi kết nối một key**: tạo key chỉ dành cho CloudThinker để bạn có thể thu hồi mà không làm hỏng công cụ khác.
