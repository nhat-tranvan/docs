Model Context Protocol (MCP) là chuẩn mở để cung cấp công cụ cho AI agent. Nếu bạn vận hành một MCP server, chẳng hạn đặt trước API số liệu nội bộ, hệ thống ticket hay một dịch vụ cũ, bạn có thể thêm server đó thành một [kết nối](/vi/guide/connections/overview) tùy chỉnh, và mọi công cụ server cung cấp đều trở thành công cụ agent có thể gọi.

## Điều kiện tiên quyết

- Một MCP server hỗ trợ **Streamable HTTP** hoặc **Server-Sent Events** (SSE), truy cập được từ internet. Để giới hạn ai có thể truy cập server, hãy đưa các egress IP của CloudThinker vào allowlist. Tài liệu này không công bố danh sách egress IP của CloudThinker: hãy hỏi đầu mối liên hệ CloudThinker của bạn, hoặc [liên hệ với chúng tôi](https://cloudthinker.io/contact).
- URL endpoint của server, ví dụ `https://mcp.example.com/mcp`.
- Thông tin xác thực cho server, nếu server yêu cầu. Chỉ cấp riêng cho CloudThinker (xem [Quyền yêu cầu](#quyền-yêu-cầu)).
- Quyền chỉnh sửa kết nối trong workspace của bạn.

<Note>
CloudThinker truy cập server của bạn qua internet công cộng và xác thực bằng các HTTP header tĩnh bạn đặt trên kết nối, thường là header `Authorization` chứa token mà server kiểm tra. Form MCP không có đăng nhập OAuth, nên không thể kết nối server chỉ chấp nhận OAuth.
</Note>

## Thiết lập

<Steps>
  <Step title="Mở form MCP">
    Trong thanh bên, nhấn **More → Workspace settings → Connections**, chọn tab **MCP Connections** rồi nhấn **+** (**New MCP connection**). Hộp thoại **Create MCP Connection** mở ra.
  </Step>
  <Step title="Điền Basic Information">
    - **Connection Name**: tên mà nhóm bạn dễ nhận ra, ví dụ `Internal metrics`.
    - **Description**: không bắt buộc, tối đa 500 ký tự.
    - **Prefix**: tên ngắn cho server này, ví dụ `metrics`. Công cụ hiển thị dưới dạng `metrics__tool_name`, và bạn sẽ thấy prefix này trong các yêu cầu phê duyệt và Rules.
    - **Transport Type**: **Streamable HTTP** hoặc **Server-Sent Events**, tùy server của bạn dùng giao thức nào.
  </Step>
  <Step title="Thêm header">
    Trong **Headers Configuration (Optional)**, thêm từng header server cần dưới dạng **Key** và **Value**, ví dụ `Authorization` và `Bearer <your-token>`. CloudThinker gửi các header này trong mọi request. Key của header không được trùng nhau.
  </Step>
  <Step title="Điền Connection Configuration">
    - **URL**: endpoint của server, ví dụ `https://mcp.example.com/mcp`. Xem [Quy tắc URL của server](#quy-tắc-url-của-server).
    - **Timeout (seconds)**: thời gian chờ server phản hồi. Mặc định 30, cho phép từ 0.1 đến 300. Giữ 30, trừ khi công cụ của bạn chạy truy vấn lâu thì hãy tăng lên.
    - **SSE Read Timeout (seconds)**: thời gian chờ trên luồng sự kiện. Mặc định 300, cho phép từ 1 đến 600.
  </Step>
  <Step title="Tạo kết nối">
    Nhấn **Create**. CloudThinker liên hệ server và tải danh sách công cụ.

    **Trạng thái thành công:** kết nối hiển thị **Connected** trong danh sách **MCP Connections**, và bảng chi tiết hiển thị transport cùng URL trong **Server config**. Nếu thất bại, cảnh báo **Connection error** sẽ giải thích lý do. Xem [Khắc phục sự cố](#khắc-phục-sự-cố).
  </Step>
</Steps>

<Warning>
Đừng đặt thông tin xác thực trong URL (`https://user:password@host/mcp`). Form sẽ từ chối URL này. Với basic auth, hãy thêm header có key `Authorization` và value `Basic <base64 of user:password>`.
</Warning>

## Chi tiết kết nối

| Trường | Bắt buộc | Mô tả | Ví dụ |
|-------|----------|-------------|---------|
| **Connection Name** | Có | Tên mà nhóm bạn dễ nhận ra | `Internal metrics` |
| **Description** | Không | Tối đa 500 ký tự | `Internal metrics API` |
| **Prefix** | Có | Tên ngắn. Công cụ hiển thị dưới dạng `prefix__tool_name` | `metrics` |
| **Transport Type** | Có | **Streamable HTTP** hoặc **Server-Sent Events** | **Streamable HTTP** |
| **URL** | Có | Endpoint của server. Xem [Quy tắc URL của server](#quy-tắc-url-của-server) | `https://mcp.example.com/mcp` |
| **Headers Configuration** | Không | Mỗi header gồm một **Key** và **Value**, gửi trong mọi request | `Authorization` / `Bearer <your-token>` |
| **Timeout (seconds)** | Có, đã điền sẵn | Thời gian chờ phản hồi. Mặc định 30, cho phép từ 0.1 đến 300 | `30` |
| **SSE Read Timeout (seconds)** | Có, đã điền sẵn | Thời gian chờ trên luồng sự kiện. Mặc định 300, cho phép từ 1 đến 600 | `300` |

### Quy tắc URL của server

| URL | Kết quả |
|---|---|
| `https://mcp.example.com/mcp` | Khuyến nghị. Chứng chỉ phải do một certificate authority công khai cấp. Chứng chỉ tự ký bị từ chối. |
| `http://203.0.113.10:8000/mcp` | Được chấp nhận, kèm cảnh báo "Not encrypted. Headers and tool results are sent as plain text." Token của bạn được truyền đi không mã hóa. |
| `http://localhost:8000/mcp`, `http://10.0.0.5/mcp`, `http://192.168.1.20/mcp` | Bị từ chối. CloudThinker không thể truy cập địa chỉ loopback, địa chỉ private hoặc địa chỉ metadata của cloud. |
| Host name phân giải ra địa chỉ private | Bị từ chối, kể cả khi tên trông như địa chỉ công khai. |

<Warning>
Không có thiết lập workspace nào chặn URL `http://`. Hãy dùng `https://` cho mọi server nhận token, và [thêm HTTPS](#thêm-https-bằng-reverse-proxy) nếu server chỉ hỗ trợ HTTP.
</Warning>

### Thêm HTTPS bằng reverse proxy

Nếu server chỉ hỗ trợ HTTP, hãy đặt một reverse proxy phía trước. Với [Caddy](https://caddyserver.com/docs/install):

<Steps>
  <Step title="Trỏ DNS về server">
    Tạo một bản ghi DNS `A`, ví dụ `mcp.example.com`, trỏ về IP công khai của server.
  </Step>
  <Step title="Cấu hình Caddy">
    Lưu nội dung sau thành `Caddyfile`, thay port bằng port mà MCP server của bạn đang lắng nghe:

    ```text
    mcp.example.com {
        reverse_proxy localhost:8000
    }
    ```
  </Step>
  <Step title="Khởi động Caddy">
    Mở port 80 và 443 rồi khởi động Caddy. Caddy tự yêu cầu chứng chỉ công khai.

    **Trạng thái thành công:** `https://mcp.example.com` mở được trên trình duyệt với chứng chỉ hợp lệ. Nhập `https://mcp.example.com/mcp` vào **URL**.
  </Step>
</Steps>

## Quyền yêu cầu

Server của bạn quyết định kết nối được làm gì. CloudThinker chỉ giữ các giá trị header bạn cung cấp.

<Tip>
Cấp một token chỉ dành cho CloudThinker để bạn có thể thu hồi mà không ảnh hưởng đến hệ thống khác. Giới hạn token ở quyền tối thiểu mà các công cụ được cung cấp cần, bắt đầu chỉ với công cụ đọc, và để server kiểm tra token trong mọi request.
</Tip>

## Khả năng của agent

Sau khi kết nối, CloudThinker tải danh sách công cụ của server. Mỗi công cụ có sẵn cho agent dưới dạng `prefix__tool_name`, với prefix là giá trị bạn đặt trên kết nối. Server có prefix `weather` cung cấp `get_forecast` sẽ cho agent một công cụ tên `weather__get_forecast`.

Agent chỉ gọi được công cụ mà server của bạn cung cấp. Kết nối MCP không có công tắc **Allow writes**, nên hãy chọn **Manual** để mọi lần gọi công cụ ghi đều cần một người phê duyệt. Gỡ công cụ khỏi server là cách kiểm soát còn lại luôn có hiệu lực, và cũng là cách duy nhất để chặn một thao tác đọc: thao tác đọc luôn chạy mà không hỏi.

Khi CloudThinker bật [Rule enforcement](/vi/guide/approvals/rules#khắc-phục-sự-cố) cho workspace của bạn, một [Rule](/vi/guide/approvals/rules) **Deny** có thể từ chối hẳn một công cụ ghi trong khi các công cụ ghi khác vẫn hỏi phê duyệt.

### Cách phân loại đọc và ghi

CloudThinker xếp mỗi công cụ vào nhóm đọc hoặc ghi khi tải danh sách công cụ:

| Kiểm tra, theo thứ tự | Kết quả |
|---|---|
| Công cụ khai báo `readOnlyHint: true` | Đọc |
| Công cụ khai báo `destructiveHint: true` | Ghi |
| Tên công cụ chứa một từ đọc: `get`, `list`, `search`, `query`, `read`, `describe`, `show`, `find`, `fetch`, `check`, `count`, `view`, `lookup`, `browse`, `inspect`, `export`, `download` | Đọc |
| Mọi trường hợp còn lại | Ghi |

Tên công cụ được tách thành từ theo `_` và `-`, nên `list_tickets` và `get-status` là công cụ đọc, còn `listTickets` (một từ) và `close_ticket` là công cụ ghi. Thao tác đọc chạy mà không hỏi. Thao tác ghi đi qua [Rules](/vi/guide/approvals/rules) và [Approval mode](/vi/guide/approvals/approval-mode) của bạn.

<Warning>
Chỉ cần một từ đọc xuất hiện ở bất kỳ đâu trong tên, công cụ sẽ được xếp là đọc, trừ khi công cụ khai báo `destructiveHint: true`. `get_and_delete_user` và `check_and_fix` được tính là công cụ đọc và chạy mà không cần phê duyệt. Hãy đặt `destructiveHint: true` cho mọi công cụ thay đổi dữ liệu.
</Warning>

CloudThinker tải lại danh sách công cụ và phân loại lại mọi công cụ khi bạn nhấn **Edit** và lưu thay đổi ở URL, header hoặc transport. Chỉ đổi tên hoặc mô tả thì danh sách không được tải lại.

### Xác minh kết nối

Mở một cuộc chat, gõ `#` để chọn kết nối, rồi hỏi:

```text
#Internal metrics List the tools this connection exposes, then call the simplest read-only one and show me the result.
```

**Trạng thái thành công:** CloudThinker liệt kê các công cụ theo tên `prefix__tool_name` và trả về kết quả từ một công cụ đọc, không có yêu cầu phê duyệt nào.

### Ví dụ prompt

Thay `#Internal metrics` bằng tên kết nối của bạn.

```text
#Internal metrics What is the current status of the checkout service?
#Internal metrics Compare today's error counts with the last 7 days and flag anything unusual.
#Internal metrics Which tools here can change data? Describe what each one does before calling any of them.
```

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="This connection did not respond in time. Try connecting again.">
    Server không phản hồi trong khoảng **Timeout (seconds)**. Kiểm tra server đang chạy và tường lửa cho phép các egress IP của CloudThinker, sau đó tăng timeout và thử lại.
  </Accordion>
  <Accordion title="This server does not use HTTPS on this port.">
    URL bắt đầu bằng `https://`, nhưng server dùng HTTP thường trên port đó. Đổi URL thành `http://`, hoặc [thêm HTTPS](#thêm-https-bằng-reverse-proxy).
  </Accordion>
  <Accordion title="This server's TLS certificate is not trusted: it is self-signed, expired, or issued for another name.">
    Thay chứng chỉ tự ký bằng chứng chỉ do certificate authority công khai cấp, chẳng hạn Let's Encrypt. Gia hạn chứng chỉ đã hết hạn. Đảm bảo host name trong **URL** khớp với chứng chỉ.
  </Accordion>
  <Accordion title="This server refused the connection.">
    Không có tiến trình nào lắng nghe tại host và port đó. Sửa URL hoặc khởi động server.
  </Accordion>
  <Accordion title="URL points to a private or metadata IP address / URL resolves to a private or metadata IP address">
    URL chứa địa chỉ private, hoặc DNS phân giải host name ra địa chỉ private. Thông báo "URL points to a blocked internal hostname" áp dụng cho các tên như `localhost`. Hãy dùng host name hoặc địa chỉ IP công khai.
  </Accordion>
  <Accordion title="Could not resolve hostname">
    DNS không có bản ghi cho host name trong **URL**. Kiểm tra chính tả. Tên chỉ tồn tại trong mạng nội bộ của bạn sẽ không phân giải được.
  </Accordion>
  <Accordion title="The provider rejected these credentials. Update them, then connect again.">
    Server của bạn trả về 401 hoặc 403. Kiểm tra key và value của header, xác nhận token vẫn hợp lệ trên server, và kiểm tra server yêu cầu token theo cách nào (ví dụ `Bearer` hay một header tùy chỉnh).
  </Accordion>
  <Accordion title="The provider endpoint was not found. Check the connection settings.">
    Host có phản hồi nhưng path sai. Nhiều server cung cấp MCP tại `/mcp` hoặc `/sse`. Xem tài liệu của server để biết path chính xác.
  </Accordion>
  <Accordion title="Connected, but tools are missing">
    Kiểm tra server có trả về công cụ trong phản hồi danh sách công cụ không, và xem log của chính server. Công cụ không có trong danh sách server trả về thì không thể gọi.
  </Accordion>
  <Accordion title="SSE connection drops">
    Tăng **SSE Read Timeout (seconds)**, kiểm tra không có proxy nào giữa CloudThinker và server đang buffer hoặc cắt kết nối dài, và cấu hình server gửi sự kiện keepalive.
  </Accordion>
</AccordionGroup>

## Bảo mật

<ConnectionSecurity />

- **Dùng HTTPS.** Qua `http://`, header (kể cả token) và kết quả công cụ đều được truyền dưới dạng văn bản thường.
- **Đánh dấu hint cho công cụ.** Đặt `readOnlyHint` và `destructiveHint` để CloudThinker xử lý từng công cụ đúng như bạn muốn.
- **Xoay vòng thông tin xác thực trong header.** Thay token trên server, sau đó chỉnh sửa kết nối và cập nhật giá trị header.
