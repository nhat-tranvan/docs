Kết nối một workspace LangSmith và hỏi [CloudThinker](/vi/guide/agents/overview) vì sao một lượt chạy LLM thất bại, lượt chạy nào tốn kém nhất hôm qua, hoặc hai experiment so sánh thế nào về độ trễ, chi phí và feedback. Bạn cần ba giá trị: một API key, một workspace ID và API URL của region bạn.

## Điều kiện tiên quyết

- Tài khoản LangSmith có quyền truy cập workspace mà bạn muốn CloudThinker đọc.
- Quyền tạo API key trong LangSmith. Chỉ admin của organization mới tạo được service key.
- Vai trò **Admin** trong workspace CloudThinker, cần để thêm và sửa kết nối. Xem [Vai trò](/vi/guide/security/roles).

## Thiết lập

<Steps>
  <Step title="Tạo API key">
    Trong LangSmith, mở **Settings → API Keys**. Chọn loại key theo [Quyền yêu cầu](#quyền-yêu-cầu). Với service key giới hạn trong workspace, hãy chọn workspace. Đặt thời hạn, rồi nhấn **Create API Key**.
  </Step>
  <Step title="Sao chép key">
    Sao chép key ngay. LangSmith chỉ hiển thị key một lần.
  </Step>
  <Step title="Sao chép workspace ID">
    Nếu bạn thuộc nhiều workspace, hãy chuyển sang workspace mà CloudThinker cần đọc trước. Sau đó, trên trang **Settings**, sao chép **Workspace ID** trong **General**.
  </Step>
  <Step title="Thêm kết nối trong CloudThinker">
    Mở **More → Workspace settings → Connections**, ở lại tab **Builtin Connections** và chọn **LangSmith**. Điền cả ba trường trong [Chi tiết kết nối](#chi-tiết-kết-nối), bao gồm API URL của region bạn, rồi nhấn **Connect**.

    **Trạng thái thành công:** thẻ LangSmith hiển thị **Connected**.

    <Warning>
    **Connected** chỉ có nghĩa là CloudThinker đã lưu kết nối. Key, workspace ID hoặc URL sai chỉ lộ ra khi CloudThinker đọc LangSmith lần đầu, vì vậy hãy chạy [prompt xác minh](#xác-minh-kết-nối) trước khi dựa vào kết nối.
    </Warning>
  </Step>
</Steps>

## Chi tiết kết nối

| Trường | Bắt buộc | Mô tả | Ví dụ |
|-------|----------|-------------|---------|
| **LANGSMITH_API_KEY** | Có | Personal access token hoặc service key từ **Settings → API Keys** | `<your-api-key>` |
| **LANGSMITH_WORKSPACE_ID** | Có | Workspace ID từ **Settings → General** | `<your-workspace-id>` |
| **LANGSMITH_ENDPOINT** | Có | API URL của region bạn, theo bảng bên dưới | `https://api.smith.langchain.com` |

Cả ba trường đều bắt buộc. LangSmith cần workspace ID khi một key bao gồm nhiều workspace, và điều này không gây hại gì với key chỉ có một workspace.

| Region | API URL |
|--------|---------|
| GCP US (mặc định) | `https://api.smith.langchain.com` |
| GCP EU | `https://eu.api.smith.langchain.com` |
| GCP APAC | `https://apac.api.smith.langchain.com` |
| AWS US | `https://aws.api.smith.langchain.com` |

Với LangSmith tự host, hãy dùng API URL của triển khai đó. URL phải chấp nhận kết nối từ internet; nếu nằm sau tường lửa, xem [Truy cập dịch vụ private](/vi/guide/connections/overview#truy-cập-dịch-vụ-nội-bộ).

## Quyền yêu cầu

| Loại key | Hoạt động dưới danh nghĩa | Dùng khi |
|----------|----------------|-------------|
| **Personal access token** | Người dùng đã tạo key, với toàn bộ quyền truy cập của người đó | Bạn đang tự thử nghiệm |
| **Service key, giới hạn workspace** | Chỉ các workspace bạn chọn | Khuyến nghị cho workspace CloudThinker dùng chung |
| **Service key, giới hạn organization** | Mọi workspace trong organization | Tránh dùng trừ khi CloudThinker cần mọi workspace |

<Tip>
Tạo một service key giới hạn trong workspace cho đúng workspace mà CloudThinker cần đọc. Trên LangSmith Enterprise, cấp cho key vai trò **Workspace Viewer** để có quyền chỉ đọc. Nếu không có vai trò chỉ đọc, key có thể ghi, và chỉ cài đặt Approvals của bạn quyết định một thao tác ghi có chạy mà không hỏi bạn hay không.
</Tip>

## Khả năng của agent

| Khả năng | Bạn nhận được gì |
|------------|--------------|
| **Project và lượt chạy** | Các lượt chạy lỗi, chậm hoặc tốn kém trong một project cụ thể, xếp hạng theo lỗi, độ trễ hoặc chi phí |
| **Trace và thread** | Một trace, hoặc lịch sử tin nhắn của một thread hội thoại |
| **Dataset và example** | Các dataset của bạn và các example bên trong một dataset |
| **Experiment** | Kết quả experiment cho một dataset, bao gồm độ trễ, chi phí và feedback |
| **Prompt** | Các prompt của bạn và template của một prompt |

CloudThinker tóm tắt những gì tìm thấy. CloudThinker không in toàn bộ input, output hay nội dung tin nhắn của lượt chạy, và không đọc dữ liệu thanh toán hay mức sử dụng LangSmith qua kết nối này.

### Xác minh kết nối

```text
List my LangSmith projects and datasets
```

**Trạng thái thành công:** bạn nhận được tên project và dataset khớp với workspace của bạn trong LangSmith. Danh sách trống mà không có lỗi vẫn là kết nối hoạt động: workspace có thể chỉ đơn giản là chưa có dữ liệu.

### Ví dụ prompt

Nêu chính xác tên project hoặc dataset. Xếp hạng lượt chạy cần tên project, còn experiment và example cần tên dataset.

```text
Show the five most expensive runs in the support-bot project from the last day and what drove their cost
Find failed runs in the support-bot project and group them by error
Compare the latest experiments on the support-eval dataset by latency, cost, and feedback
```

## Quyền ghi

CloudThinker mặc định chỉ đọc. CloudThinker chỉ ghi khi bạn yêu cầu chính xác thay đổi đó theo tên trong cuộc hội thoại: push một prompt, tạo hoặc cập nhật một dataset hay các example của nó, hoặc bắt đầu một experiment.

<ApprovalDefault />

Để loại trừ hoàn toàn thao tác ghi, hãy dùng key có vai trò chỉ đọc (xem [Quyền yêu cầu](#quyền-yêu-cầu)).

## Khắc phục sự cố

<Accordion title="401 Unauthorized">
Key bị thiếu, gõ sai, đã hết hạn hoặc bị xóa. Key LangSmith đã hết hạn không thể kích hoạt lại. Tạo key mới, rồi mở **More → Workspace settings → Connections**, chọn **LangSmith** và thay **LANGSMITH_API_KEY**.
</Accordion>

<Accordion title="403 Forbidden">
Key không đọc được workspace đó. Key giới hạn organization cần **LANGSMITH_WORKSPACE_ID** đúng, và key giới hạn workspace chỉ hoạt động với các workspace bạn đã chọn. Kiểm tra cả hai, cùng với vai trò của key.
</Accordion>

<Accordion title="Request thất bại hoặc danh sách trả về trống, dù key đúng">
**LANGSMITH_ENDPOINT** có thể không khớp với region của workspace. Đặt endpoint thành URL của region bạn trong [Chi tiết kết nối](#chi-tiết-kết-nối).
</Accordion>

<Accordion title="404, hoặc không tìm thấy project hay dataset">
Tên đó không tồn tại trong workspace này. Hãy yêu cầu CloudThinker liệt kê project hoặc dataset trước, rồi dùng tên chính xác.
</Accordion>

<Accordion title="429 Too Many Requests">
LangSmith giới hạn số request mỗi phút của một key. Chờ một phút, rồi đặt câu hỏi hẹp hơn, ví dụ một project và khoảng thời gian ngắn hơn.
</Accordion>

## Bảo mật

<ConnectionSecurity />

- **Key giới hạn workspace**: giới hạn key trong một workspace để các workspace khác nằm ngoài tầm truy cập.
- **Thời hạn**: đặt thời hạn cho key và thay key trước khi hết hạn.
