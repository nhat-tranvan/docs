Kết nối Firebase để CloudThinker liệt kê project và ứng dụng, đọc cấu hình SDK, kiểm tra security rules của Firestore, Storage và Realtime Database, và xem trạng thái deploy. Firebase xác thực bằng **Google Cloud service-account key** (file JSON), và các IAM role của service account quyết định CloudThinker truy cập được gì.

## Chọn Firebase hay Google Cloud

| Kết nối | Bao gồm những gì | Kết nối khi |
|---|---|---|
| Firebase | Project, ứng dụng, cấu hình SDK, security rules và deploy, qua `firebase-tools` | Bạn muốn kiểm tra hoặc deploy ứng dụng Firebase |
| [Google Cloud](/vi/guide/connections/gcp) | Compute, GKE, BigQuery, IAM và chi phí, qua Google Cloud CLI | Bạn cần câu trả lời về hạ tầng, danh tính hoặc chi phí |

Hai kết nối này độc lập với nhau. Bạn có thể kết nối cả hai cho cùng một project, mỗi kết nối một service account riêng.

## Điều kiện tiên quyết

- Một project Firebase mà bạn muốn CloudThinker kiểm tra.
- Quyền trong Google Cloud của project đó để tạo service account và key, và gán IAM role.
- Cho phép tạo service account key. Nếu tổ chức của bạn áp dụng `constraints/iam.disableServiceAccountKeyCreation` (mặc định trên các tổ chức tạo từ tháng 5/2024), hãy nhờ organization policy admin cấp ngoại lệ cho project này trước.

## Thiết lập

Trước tiên, hãy quyết định cách bao quát nhiều project. Phần lớn các đội dùng mỗi project một kết nối.

| Lựa chọn | Cách hoạt động | Phù hợp khi |
|---|---|---|
| Mỗi project một kết nối | Mỗi project có service account, key, alias và **Environment** riêng. Không cần chuyển đổi. | Bạn thường xuyên làm việc trên nhiều project, hoặc muốn quy tắc phê duyệt khác nhau cho từng project |
| Một service account, nhiều project | Một kết nối truy cập mọi project mà service account thấy được, nhưng mỗi lúc chỉ làm việc trên một project đang hoạt động. Mỗi lần chuyển project đều đi qua phê duyệt của bạn. | Bạn chủ yếu làm trong một project và thỉnh thoảng xem các project khác |

<Warning>
Đừng dùng **Generate new private key** trong **Project settings** của Firebase. Nút này tạo key cho tài khoản mặc định `firebase-adminsdk-…@<project-id>.iam.gserviceaccount.com`, vốn có quyền admin rộng và có thể đang được chính ứng dụng của bạn sử dụng. Cũng đừng gỡ role khỏi tài khoản đó.
</Warning>

<Tabs>
  <Tab title="Google Cloud console">
    <Steps>
      <Step title="Tạo service account riêng">
        Trong [Google Cloud console](https://console.cloud.google.com/), chọn project Firebase và vào **IAM & Admin → Service Accounts**. Nhấn **Create service account**, đặt tên `cloudthinker-firebase`, rồi nhấn **Create and continue**.
      </Step>
      <Step title="Cấp role Firebase chỉ đọc">
        Thêm **Firebase Viewer** (`roles/firebase.viewer`) và nhấn **Done**. Chỉ thêm role ghi nếu bạn muốn CloudThinker tạo ứng dụng hoặc deploy thông qua phê duyệt của bạn. Xem [Quyền yêu cầu](#quyền-yêu-cầu).
      </Step>
      <Step title="Tạo JSON key">
        Mở service account, vào tab **Keys**, rồi nhấn **Add key → Create new key**. Chọn **JSON** và nhấn **Create**.

        **Trạng thái thành công:** trình duyệt tải xuống một file key `.json`.
      </Step>
    </Steps>
  </Tab>
  <Tab title="gcloud CLI">
    Chạy các lệnh sau trong [Cloud Shell](https://shell.cloud.google.com/) hoặc bất kỳ terminal nào đã đăng nhập Google Cloud.

    ```bash
    PROJECT_ID=your-firebase-project-id
    SA=cloudthinker-firebase@$PROJECT_ID.iam.gserviceaccount.com

    gcloud iam service-accounts create cloudthinker-firebase \
      --project="$PROJECT_ID" --display-name="CloudThinker Firebase"

    gcloud projects add-iam-policy-binding "$PROJECT_ID" \
      --member="serviceAccount:$SA" --role="roles/firebase.viewer"

    gcloud iam service-accounts keys create cloudthinker-firebase-key.json --iam-account="$SA"
    ```

    Lệnh cuối ghi key vào `cloudthinker-firebase-key.json`. Trong Cloud Shell, tải file xuống bằng `cloudshell download cloudthinker-firebase-key.json`, và sau khi đã tải lên CloudThinker, xóa bản trong Cloud Shell bằng `rm cloudthinker-firebase-key.json`. Chỉ bind thêm role ghi nếu bạn muốn CloudThinker tạo ứng dụng hoặc deploy thông qua phê duyệt của bạn. Xem [Quyền yêu cầu](#quyền-yêu-cầu).
  </Tab>
</Tabs>

Sau đó kết nối trong CloudThinker:

<Steps>
  <Step title="Mở hộp thoại kết nối">
    Trên thanh bên, nhấn **More → Workspace settings → Connections**, chọn **Firebase**, rồi nhấn **Connect**.
  </Step>
  <Step title="Đặt tên kết nối">
    Điền **Alias** (ví dụ `prod-firebase`) và **Description** (ví dụ `Production Firebase project, mobile app`). Agent đọc phần mô tả để chọn đúng kết nối khi bạn có nhiều kết nối.
  </Step>
  <Step title="Tải key lên">
    Kéo file `.json` vào vùng tải lên, hoặc nhấn **choose a JSON file** để chọn file. Nhấn **Connect**.

    **Trạng thái thành công:** kết nối hiển thị **Connected**, và `project_id` của key là project đang hoạt động. Sau đó bước khám phá chạy một lần ở chế độ nền và tiêu tốn credit. Bước này không bao giờ chờ phê duyệt, nên bỏ qua việc chuyển project và kiểm tra trạng thái deploy. Xem [Điều gì xảy ra sau khi kết nối](/vi/guide/connections/overview#điều-gì-xảy-ra-sau-khi-kết-nối).
  </Step>
  <Step title="Đặt environment">
    Mở **Firebase** trong **More → Workspace settings → Connections**, nhấn biểu tượng bút chì trên dòng của kết nối, rồi đặt **Environment** trong **Edit Instance**. Trường này gắn nhãn cho kết nối để người và agent dễ nhận biết.
  </Step>
</Steps>

## Chi tiết kết nối

| Trường | Nhập gì | Ví dụ |
|-------|---------------|---------|
| **Alias** | Tên ngắn cho kết nối. Để trống thì CloudThinker tự đặt. | `prod-firebase` |
| **Description** | Project này là gì. Agent dùng trường này để chọn giữa các kết nối. | `Production Firebase project` |
| **GOOGLE_SERVICE_ACCOUNT_KEY** | File JSON key của service account, tải lên. `project_id` trong file đặt project Firebase đang hoạt động. | `cloudthinker-firebase-key.json` |

Bạn không cần project ID riêng hay file cấu hình Firebase. Để bao quát nhiều project, xem các lựa chọn trong [Thiết lập](#thiết-lập).

## Quyền yêu cầu

| Bạn muốn | IAM role trên service account | Phê duyệt trong CloudThinker |
|---------------|---------------------------------|--------------------------|
| Kiểm kê project và ứng dụng, đọc cấu hình SDK, kiểm tra security rules | Firebase Viewer (`roles/firebase.viewer`) | Không |
| Chuyển project đang hoạt động | Quyền truy cập project đích, ví dụ Firebase Viewer trên project đó | Qua Approvals |
| Kiểm tra trạng thái deploy | Firebase Viewer (`roles/firebase.viewer`) | Qua Approvals |
| Tạo project, ứng dụng hoặc Android SHA key, khởi tạo tính năng, deploy | Firebase Admin (`roles/firebase.admin`), hoặc role hẹp hơn cho một sản phẩm, như Firebase Hosting Admin (`roles/firebasehosting.admin`) hay Firebase Rules Admin (`roles/firebaserules.admin`) | Qua Approvals |

Google yêu cầu thêm role cho một số loại deploy. Ví dụ, deploy Cloud Functions cần thêm Cloud Functions Developer (`roles/cloudfunctions.developer`) và Service Account User (`roles/iam.serviceAccountUser`).

<Tip>
Firebase không có công tắc **Allow writes**. Mọi thay đổi đều đi qua [Approvals](/vi/guide/approvals/overview), và chỉ chạy khi IAM role cũng cho phép. Hãy cấp Firebase Viewer cho việc kiểm tra.
</Tip>

## Khả năng của agent

CloudThinker dùng bộ công cụ Firebase CLI chính thức (`firebase-tools`) qua kết nối này.

| Khả năng | CloudThinker làm gì | Phê duyệt |
|------------|------------------------|----------|
| **Project và ứng dụng** | Liệt kê các project truy cập được, kiểm tra project đang hoạt động, liệt kê ứng dụng iOS, Android và web | Không |
| **Cấu hình SDK** | Đọc cấu hình Firebase SDK của một ứng dụng | Không |
| **Kiểm tra security rules** | Đọc rules của Firestore, Storage và Realtime Database, và đánh dấu các rule có vẻ để ngỏ | Không |
| **Tài liệu Firebase** | Tìm trong tài liệu Firebase và Google developer | Không |
| **Điều khiển project và ứng dụng** | Chuyển project đang hoạt động, tạo project, ứng dụng và Android SHA key, khởi tạo tính năng, deploy, kiểm tra trạng thái deploy | Qua Approvals |

Kết nối bao gồm những gì `firebase-tools` cung cấp. Kết nối không đọc document Firestore, user của Authentication, Crashlytics hay Remote Config.

### Xác minh kết nối

```text
Show my Firebase environment and list the projects you can access
```

Câu trả lời nêu đúng `project_id` thật của bạn là project đang hoạt động.

### Ví dụ prompt

```text
Audit the Firestore and Storage security rules and flag anything that allows unauthenticated writes
List the apps registered in the active Firebase project as a table
Show the Firebase SDK config for my web app
```

## Khắc phục sự cố

<Accordion title="Xác thực thất bại hoặc thông tin xác thực không khả dụng">
**Nguyên nhân:** JSON key không hợp lệ, không đầy đủ, hoặc thuộc về một service account đã bị xóa.

**Cách sửa:** tạo JSON key mới cho service account. Trong **More → Workspace settings → Connections**, mở **Firebase**, nhấn biểu tượng bút chì trên dòng của kết nối, rồi dùng **Replace…** trong **Edit Instance** để tải key lên.
</Accordion>

<Accordion title="CloudThinker báo chưa chọn project đang hoạt động">
**Nguyên nhân:** lỗi ghi `PRECONDITION_FAILED` và nhắc tới project đang hoạt động. CloudThinker đặt project đang hoạt động từ `project_id` của key mỗi khi kết nối khởi động. Nếu không đọc được key đã lưu, ví dụ vì key bị sửa trước khi tải lên, sẽ không có project nào được chọn. Tài nguyên không hề bị thiếu.

**Cách sửa:** với prompt này, hãy nêu tên project. Việc chuyển project đang hoạt động đi qua phê duyệt của bạn. Để sửa hẳn, hãy tạo JSON key mới và tải nguyên file đã tải xuống, không chỉnh sửa, bằng **Replace…** trong **Edit Instance**.
</Accordion>

<Accordion title="Bị từ chối quyền trên project, rules hoặc deploy">
**Nguyên nhân:** service account thiếu IAM role cho sản phẩm Firebase đó, hoặc không nhìn thấy project.

**Cách sửa:** trong **Google Cloud console → IAM**, cấp Firebase Viewer cho thao tác đọc và rules, hoặc Firebase Admin (hay role hẹp hơn trong [Quyền yêu cầu](#quyền-yêu-cầu)) cho thao tác tạo và deploy. Sau đó thử lại.
</Accordion>

<Accordion title="Một project không xuất hiện trong danh sách project">
**Nguyên nhân:** service account không có role nào trong project đó.

**Cách sửa:** trong **Google Cloud console → IAM** của project đó, cấp cho service account role Firebase Viewer (`roles/firebase.viewer`), rồi hỏi lại.
</Accordion>

<Accordion title="Bước kiểm tra hiển thị Timed out">
**Nguyên nhân:** bước kiểm tra không hoàn tất kịp thời. Endpoint của Firebase là công khai, nên hiếm khi do mạng của bạn.

**Cách sửa:** kết nối lại. Nếu vẫn tiếp tục timeout, hãy [liên hệ chúng tôi](https://cloudthinker.io/contact).
</Accordion>

<Accordion title="Thao tác tạo hoặc deploy không chạy">
**Nguyên nhân:** thao tác ghi cần cả IAM role cho phép lẫn phê duyệt trong CloudThinker. Nếu bạn đã từ chối yêu cầu, CloudThinker sẽ không thử lại.

**Cách sửa:** kiểm tra role của service account, rồi hỏi lại.
</Accordion>

## Bảo mật

<ConnectionSecurity />

- **Bảo vệ key**: JSON key là thông tin xác thực đầy đủ của service account. Xóa bản sao cục bộ sau khi tải lên, và không bao giờ commit hay dán key vào chat.
- **Xoay vòng key ít nhất mỗi 90 ngày**: tạo key mới, tải lên bằng **Replace…** trong **Edit Instance**, rồi xóa key cũ. Xem [Xoay vòng thông tin xác thực](/vi/guide/connections/overview#xoay-vòng-thông-tin-xác-thực).
