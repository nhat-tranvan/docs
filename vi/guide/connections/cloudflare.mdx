Kết nối Cloudflare để CloudThinker liệt kê account và zone, tóm tắt lưu lượng HTTP và hành vi cache, xem xét sự kiện firewall và tra cứu tài liệu Cloudflare. CloudThinker dùng MCP server do Cloudflare host và xác thực bằng một **API token**, quyền của token quyết định CloudThinker truy cập được những gì.

## Điều kiện tiên quyết

- Một tài khoản Cloudflare có ít nhất một zone.
- Quyền tạo API token trong [Cloudflare dashboard](https://dash.cloudflare.com/).

## Thiết lập

<Steps>
  <Step title="Tạo custom API token">
    Trong Cloudflare dashboard, vào **My Profile → API Tokens → Create Token**. Dưới **Create Custom Token**, nhấn **Get started**. Thêm từng quyền trong bảng [Quyền yêu cầu](#quyền-yêu-cầu). Mỗi hàng trong form của Cloudflare có ba dropdown, nên **Zone → Analytics → Read** nghĩa là nhóm **Zone**, quyền **Analytics**, mức truy cập **Read**.
  </Step>
  <Step title="Giới hạn token cho account và zone bạn cần">
    Dưới **Account Resources**, chọn **Include → your account**. Dưới **Zone Resources**, chọn **Include → Specific zone** cho từng zone CloudThinker cần thấy. Chỉ dùng **All zones** nếu bạn muốn CloudThinker bao quát mọi zone.
  </Step>
  <Step title="Đặt thời hạn, rồi tạo và sao chép token">
    Dưới **TTL**, đặt ngày kết thúc, ví dụ 90 ngày kể từ hôm nay. Để trống **Client IP Address Filtering**: các lệnh gọi API đến Cloudflare đi qua MCP server do Cloudflare host, không phải từ địa chỉ bạn kiểm soát. Nhấn **Continue to summary → Create Token**. Sao chép token ngay. Cloudflare chỉ hiển thị token một lần.

    Để kiểm tra token trước khi dán:

    ```bash
    curl -H "Authorization: Bearer <token>" https://api.cloudflare.com/client/v4/user/tokens/verify
    ```

    **Trạng thái thành công:** phản hồi có `"status": "active"`.
  </Step>
  <Step title="Thêm kết nối trong CloudThinker">
    Trong thanh bên, nhấn **More → Workspace settings → Connections**, chọn **Cloudflare** và nhấn **Connect**. Điền **Alias** (ví dụ `main-account`) và **Description** (ví dụ `Main Cloudflare account, production zones`). Agent đọc mô tả để chọn đúng kết nối khi bạn có nhiều kết nối. Dán token vào **CLOUDFLARE_API_TOKEN** và nhấn **Connect**.

    **Trạng thái thành công:** kết nối hiển thị **Connecting** và **Verifying**, rồi trạng thái **Connected**. Discovery sau đó chạy một lần ở chế độ nền và tiêu tốn credit. Xem [Sau khi kết nối](/vi/guide/connections/overview#điều-gì-xảy-ra-sau-khi-kết-nối).
  </Step>
  <Step title="Đặt environment">
    Mở **Cloudflare** trong **More → Workspace settings → Connections**, nhấn biểu tượng bút chì trên hàng của kết nối và đặt **Environment** trong **Edit Instance**. Giá trị này gắn nhãn kết nối cho người dùng và agent.
  </Step>
</Steps>

## Chi tiết kết nối

| Trường | Nội dung cần nhập |
|-------|---------------|
| **Alias** | Tên ngắn cho kết nối này. Để trống thì hệ thống tự chọn. |
| **Description** | Account này dùng cho những gì. Agent dùng mô tả này để chọn giữa các kết nối. |
| **CLOUDFLARE_API_TOKEN** | API token bạn đã tạo. CloudThinker gửi token dưới dạng Bearer token đến MCP server do Cloudflare host tại `https://mcp.cloudflare.com/mcp`, trực tiếp từ CloudThinker Cloud. |

Luồng dữ liệu là CloudThinker Cloud → [MCP server do Cloudflare host](https://github.com/cloudflare/mcp-server-cloudflare) → Cloudflare API, nên token và phản hồi API đi qua dịch vụ của chính Cloudflare.

Bạn không cần nhập account ID. CloudThinker tự tìm các account và zone mà token thấy được. Nếu token bao quát nhiều zone và yêu cầu của bạn khớp với hơn một zone, CloudThinker sẽ hỏi bạn muốn zone nào. Bạn có thể thêm nhiều kết nối Cloudflare, ví dụ mỗi account một token.

## Quyền yêu cầu

Mỗi quyền được viết như trong form Cloudflare: nhóm → quyền → mức truy cập.

| Quyền | Cho phép | Cần thiết |
|---|---|---|
| **Account → Account Settings → Read** | Liệt kê account | Có |
| **Account → Account Analytics → Read** | Analytics cấp account | Có |
| **Zone → Zone → Read** | Liệt kê zone và đọc cài đặt zone | Có |
| **Zone → DNS → Read** | Đọc bản ghi DNS | Có |
| **Zone → Analytics → Read** | Analytics lưu lượng và sự kiện firewall | Có |
| **Account → Workers Scripts → Read** | Kiểm tra Workers | Chỉ khi cần kiểm tra Workers |

CloudThinker chỉ truy cập được những gì token cho phép.

<Tip>
Giữ token ở chế độ chỉ đọc và giới hạn cho các zone cụ thể. Không có danh sách cố định các thao tác ghi: **execute** có thể gọi bất kỳ endpoint nào của Cloudflare API, nên mọi quyền chỉnh sửa bạn thêm vào token, như **Zone → DNS → Edit**, đều trở thành thay đổi mà agent có thể đề xuất. Mỗi lệnh gọi vẫn đi qua phê duyệt của bạn.
</Tip>

## Khả năng của agent

Kết nối có ba công cụ. Hai công cụ chạy mà không cần phê duyệt. Công cụ thứ ba gọi Cloudflare API và luôn đi qua [Approvals](/vi/guide/approvals/overview), kể cả với thao tác đọc, vì cùng công cụ đó cũng có thể thực hiện thay đổi.

| Công cụ | CloudThinker làm gì | Phê duyệt |
|------|------------------------|----------|
| **docs** | Tìm kiếm tài liệu Cloudflare | Không |
| **search** | Tìm đúng endpoint Cloudflare API cho một yêu cầu | Không |
| **execute** | Gọi Cloudflare API: liệt kê account và zone, đọc cài đặt zone và bản ghi DNS, chạy GraphQL analytics, đọc sự kiện firewall, kiểm tra Workers | Có |

<ApprovalDefault />

Discovery không bao giờ chờ người duyệt, nên Discovery bỏ qua mọi lệnh gọi **execute** cần hỏi và tìm được rất ít trên Cloudflare. Automation gọi **execute** dùng Approval mode riêng, mặc định là **Refuse**, nên lệnh gọi cần hỏi sẽ bị từ chối.

Giới hạn truy vấn tích hợp giữ kết quả gọn: bản tóm tắt lưu lượng bao quát tối đa 7 ngày dữ liệu theo giờ cho một zone, và bản xem xét firewall bao quát tối đa 24 giờ và 50 sự kiện mẫu. Output firewall không chứa địa chỉ IP của client.

### Xác minh kết nối

```text
List the Cloudflare accounts and zones this token can see
```

Câu trả lời đến từ công cụ **execute**, nên phải qua phê duyệt của bạn trước. Nếu CloudThinker đăng yêu cầu phê duyệt trong chat, hãy phê duyệt. Câu trả lời liệt kê tên account và tên zone thực của bạn.

### Ví dụ prompt

```text
Summarize HTTP requests, bandwidth, and cache behavior for example.com over the last 7 days
Show which firewall rules blocked or challenged requests on example.com in the last 24 hours
How do I set up a WAF custom rule to rate limit a login path? Use the Cloudflare docs
```

## Khắc phục sự cố

<Accordion title="Permission denied">
CloudThinker báo `CLOUDFLARE_PERMISSION_DENIED`. Token thiếu quyền đọc cho thứ bạn hỏi. Sửa token trong **My Profile → API Tokens**, thêm quyền và hỏi lại.
</Accordion>

<Accordion title="Không tìm thấy zone nào hoặc không tìm thấy zone">
`CLOUDFLARE_NO_ZONES` nghĩa là token không liệt kê được zone nào. `CLOUDFLARE_ZONE_NOT_FOUND` nghĩa là token không thấy zone bạn nêu tên. Kiểm tra **Zone Resources** trên token và dùng đúng tên zone.
</Accordion>

<Accordion title="Không có gì xảy ra sau khi tôi đặt câu hỏi">
Mọi lệnh gọi Cloudflare API đều đi qua phê duyệt của bạn, và một số chờ người duyệt. Kiểm tra chat xem có yêu cầu phê duyệt đang chờ không, hoặc xem lại [Approval mode](/vi/guide/approvals/approval-mode). Nếu bạn từ chối một yêu cầu, CloudThinker sẽ không thử lại.
</Accordion>

<Accordion title="Analytics trả về rỗng">
Zone mới hoặc zone có ít lưu lượng có thể chưa có analytics. Xác nhận zone nhận lưu lượng qua Cloudflare và token có **Zone → Analytics → Read**.
</Accordion>

<Accordion title="Legacy: kết nối cũ hiển thị 'Cloudflare moved to Cloudflare's hosted endpoint'">
Kết nối mới không bao giờ gặp lỗi này. Kết nối được tạo trước khi chuyển sang MCP server do Cloudflare host sẽ hiển thị **Error** với thông báo này, và CloudThinker tự kết nối lại. Nếu trạng thái không đổi, mở kết nối và nhấn **Retry**. Các giá trị Account ID và Enabled Services cũ không còn được dùng.
</Accordion>

## Bảo mật
