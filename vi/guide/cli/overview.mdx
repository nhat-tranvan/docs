<Note>
**Xem trước** — CloudThinker CLI đang trong giai đoạn truy cập sớm. Tên lệnh, cờ và định dạng cấu hình có thể thay đổi trước khi phát hành chính thức. [Liên hệ chúng tôi](https://cloudthinker.io/contact) để tham gia xem trước.
</Note>

`cloudthinker` CLI mang các cuộc hội thoại với agent, truy vấn tài nguyên và quản lý hoạt động đến terminal — hữu ích cho shell scripting, CI pipeline và các kỹ sư thích bàn phím hơn giao diện đồ họa.

---

## Bạn có thể làm gì

| Khả năng | Mô tả |
| --- | --- |
| Trò chuyện với Agent | Mở phiên tương tác với Alex, Oliver, Tony, Kai hoặc Anna từ terminal |
| Prompt một lần | Chạy một prompt `@agent #tool ...` duy nhất và pipe kết quả vào các công cụ khác |
| Tự động hóa hoạt động | Đóng gói các tác vụ cloud-ops thường xuyên vào shell script và chạy trong CI |
| Quản lý tài nguyên | Kiểm tra kết nối, tài nguyên, đề xuất và sự cố |

---

## Cài đặt

| Nền tảng | Phương thức |
|----------|--------|
| **macOS** | `brew install cloudthinker/tap/cloudthinker` |
| **Linux** | `curl -fsSL https://install.cloudthinker.io \| sh` |
| **Windows** | `winget install CloudThinker.CLI` |
| **Docker** | `docker run cloudthinker/cli` |

---

## Xác thực

```bash
cloudthinker login
```

CLI sử dụng cùng [API key](/vi/guide/api/overview) workspace như REST API. Key được lưu trong OS keychain — không bao giờ ghi vào file cấu hình dạng văn bản thuần.

---

## Bề mặt lệnh

| Lệnh | Mục đích |
|---------|---------|
| `cloudthinker chat` | Mở cuộc hội thoại tương tác với agent |
| `cloudthinker ask "@alex #cost ..."` | Prompt một lần, in phản hồi |
| `cloudthinker resources list` | Truy vấn kho tài nguyên thống nhất |
| `cloudthinker recommendations list` | Liệt kê các đề xuất chi phí, bảo mật và độ tin cậy đang hoạt động |
| `cloudthinker incidents create` | Mở sự cố từ terminal |
| `cloudthinker skills run <name>` | Thực thi một [workspace skill](/vi/guide/skills/overview) |
| `cloudthinker connections list` | Xem các [kết nối](/vi/guide/connections/overview) đã cấu hình |

---

## Định dạng đầu ra

| Cờ | Định dạng |
|------|--------|
| `--format text` | Mặc định — dễ đọc cho terminal |
| `--format json` | Dạng máy đọc được để pipe vào `jq`, script hoặc CI |
| `--format yaml` | Đầu ra thân thiện với cấu hình |
