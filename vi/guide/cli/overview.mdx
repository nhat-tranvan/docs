<Note>
**Xem trước** — CloudThinker CLI đang trong giai đoạn truy cập sớm. Tên lệnh, cờ và định dạng cấu hình có thể thay đổi trước khi phát hành chính thức. [Liên hệ chúng tôi](https://cloudthinker.io/contact) để tham gia xem trước.
</Note>

`cloudthinker` đưa workspace của bạn vào terminal: nó chạy agent lập trình CloudThinker ngay trên máy bạn, và gửi prompt tới Anna từ bất kỳ script nào. Chỉ một file nhị phân, không cần cài runtime.

## Bạn có thể làm gì

| Khả năng | Mô tả |
| --- | --- |
| Chạy agent lập trình | `cloudthinker` mở phiên agent ngay trong thư mục hiện tại. Agent sửa file và chạy lệnh cục bộ, và chỉ chạm tới cloud của bạn qua CloudThinker Sandbox với các [kết nối](/vi/guide/connections/overview) của workspace |
| Gửi prompt headless | `cloudthinker chat -p "..."` gửi một prompt tới Anna và in câu trả lời ra stdout, sẵn sàng để pipe |
| Theo dõi run dài | Gửi rồi không chờ, liệt kê các run gần đây, và lấy câu trả lời sau từ bất kỳ máy nào |
| Kiểm tra một review | Đọc trạng thái, kết luận và finding của [Review](/vi/guide/code-review/overview) trên một merge request hoặc pull request |
| Xác thực cho script | In ra bearer token ngắn hạn cho công cụ cần credential riêng |

## Cài đặt

```bash
curl -fsSL https://cloudthinker.ai/install.sh | sh
```

Trình cài đặt tự nhận diện nền tảng, đặt file nhị phân `cloudthinker` vào `~/.local/bin` và thêm thư mục đó vào `PATH`. Mở shell mới rồi kiểm tra:

```bash
cloudthinker --version
```

Hỗ trợ macOS (Apple Silicon và Intel) và Linux (x86_64 và arm64). Cập nhật bất cứ lúc nào bằng `cloudthinker update`.

## Phiên làm việc đầu tiên

<Steps>
  <Step title="Đăng nhập qua trình duyệt">
    ```bash
    cloudthinker login
    ```

    CLI in ra URL đồng ý và mở nó. Bạn phê duyệt yêu cầu, chọn workspace nếu tài khoản có nhiều hơn một, và terminal xác nhận workspace đã được lưu.

    <Frame>
      <img src="/images/cli/login-consent-url.png" alt="cloudthinker login in ra URL đồng ý" />
    </Frame>
  </Step>

  <Step title="Xác nhận bạn là ai">
    ```bash
    cloudthinker whoami
    ```

    **Trạng thái thành công:** một dòng gồm host, email của bạn và workspace đang hoạt động.
  </Step>

  <Step title="Chạy agent, hoặc hỏi Anna">
    ```bash
    cloudthinker                                   # phiên agent trong thư mục này
    cloudthinker chat -p "Check production health" # một prompt headless
    ```

    Lệnh trống chạy [Agent CLI](/vi/guide/cli/agent). Lần chạy đầu tiên sẽ tải bản agent khớp với phiên bản CLI của bạn.
  </Step>
</Steps>

## Bộ lệnh

| Lệnh | Mục đích |
| --- | --- |
| `cloudthinker` | Chạy agent lập trình cục bộ trong thư mục hiện tại |
| `cloudthinker login` | Đăng nhập qua trình duyệt, hoặc bằng mã thiết bị |
| `cloudthinker logout` | Xóa credential đã lưu của một workspace, hoặc của mọi workspace |
| `cloudthinker whoami` | Hiển thị tài khoản và workspace thực tế đứng sau credential đã lưu |
| `cloudthinker auth token` | In access token hiện tại cho công cụ cần bearer |
| `cloudthinker chat` | Gửi prompt headless, kiểm tra một run, hoặc liệt kê các run gần đây |
| `cloudthinker review` | Đọc một review đang được theo dõi qua URL merge request |
| `cloudthinker agent` | Chạy agent lập trình cục bộ, mọi tham số được truyền thẳng. Xem [Agent CLI](/vi/guide/cli/agent) |
| `cloudthinker update` | Cài bản phát hành mới nhất |
