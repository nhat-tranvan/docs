CloudThinker CLI (`cloudthinker`) đưa workspace CloudThinker của bạn vào terminal. Gõ `cloudthinker`, mô tả công việc bằng ngôn ngữ tự nhiên, và agent làm việc ngay trong thư mục hiện tại; script dùng `cloudthinker chat -p` để nhận câu trả lời trên stdout.

<Note>
**Beta.** CLI đang ở giai đoạn beta. Tên lệnh và cờ có thể thay đổi trước khi phát hành chính thức. CLI gọi [Worker](/vi/guide/workers) là **outpost**, nên bạn sẽ thấy `--outpost` trong các lệnh. Chạy `cloudthinker --version` để xem phiên bản của bạn, và xem [trang releases](https://github.com/cloudthinker-ai/cloudthinker-cli/releases) để biết những gì đã thay đổi.
</Note>

## Bạn có thể làm gì

| Công việc | Lệnh |
| --- | --- |
| Bắt đầu phiên agent trong thư mục hiện tại | `cloudthinker`, rồi mô tả công việc |
| Chạy pentest cục bộ cho ứng dụng bạn đang xây dựng. Chỉ kiểm thử ứng dụng bạn sở hữu hoặc được phép kiểm thử. Xem [Pentest](/vi/guide/security/pentest) | `cloudthinker`, rồi nói "Pentest http://localhost:3000" |
| Hỏi một câu và pipe câu trả lời | `cloudthinker chat -p "Check production health"` |
| Review các thay đổi Git cục bộ trước khi push | `cloudthinker review` |
| Theo dõi [Review](/vi/guide/code-review/overview) trên một merge request hoặc pull request | `cloudthinker review watch <MR_URL>` |
| Cho một cuộc hội thoại CloudThinker làm việc trong một thư mục trên máy này | `cloudthinker worker start --outpost <name> --workdir "$PWD"`. Xem [Workers](/vi/guide/workers) |

<Warning>
Trên máy của bạn, agent đọc và sửa tệp, chạy lệnh shell với danh nghĩa người dùng hệ điều hành của bạn, và CloudThinker không hỏi phê duyệt trước. Với repository bạn không tin cậy, hãy chạy agent trong container hoặc một bản checkout dùng một lần.
</Warning>

| Ở đâu | Điều gì xảy ra | Những gì đi qua mạng |
| --- | --- | --- |
| Máy của bạn | Agent đọc và sửa tệp, chạy lệnh shell với danh nghĩa người dùng hệ điều hành của bạn, không cần CloudThinker phê duyệt | Kết quả công cụ, ví dụ nội dung tệp agent đọc và đầu ra lệnh, được gửi tới mô hình trên cloud |
| Cloud | Mô hình chạy ở đây, và các [connection](/vi/guide/connections/overview) của workspace (tài khoản cloud và công cụ bạn đã liên kết) được dùng ở đây | Thông tin xác thực của connection không bao giờ đến máy của bạn. Thao tác ghi trên cloud tuân theo cấu hình [Approvals](/vi/guide/approvals/overview) |

Chỉ chạy agent trong thư mục có nội dung bạn chấp nhận gửi tới mô hình. Xem [Nơi công việc chạy](/vi/guide/cli/agent#công-việc-chạy-ở-đâu) để biết chi tiết.

## Điều kiện tiên quyết

- macOS (Apple Silicon hoặc Intel) hoặc Linux (x86_64 hoặc arm64). Chưa có bản build gốc cho Windows.
- Tài khoản CloudThinker có quyền truy cập ít nhất một workspace. Headless chat (`cloudthinker chat`) dùng được trên mọi gói, kể cả Free. Agent tương tác (`cloudthinker`) cần gói Team, Scale, Scale Plus hoặc Enterprise; trên gói Free, agent từ chối khởi động và hiển thị lời nhắc nâng cấp. Xem [Pricing](/vi/guide/billing/pricing).
- HTTPS đi ra tới `cloudthinker.io` (trình cài đặt), `github.com` (tải CLI và agent) và `app.cloudthinker.io` (API). Nếu đi qua proxy, đặt `HTTPS_PROXY`. Nếu proxy ký lại HTTPS, đặt `SSL_CERT_FILE` trỏ tới CA bundle của công ty.

## Cài đặt và chạy phiên đầu tiên

<Steps>
  <Step title="Cài đặt CLI">
    ```bash
    curl -fsSL https://cloudthinker.io/install.sh | sh
    ```

    Trình cài đặt đặt tệp nhị phân `cloudthinker` vào `~/.local/bin` và thêm thư mục đó vào `PATH` trong shell profile của bạn. Khi chạy trong terminal, trình cài đặt tiếp tục mở bước đăng nhập, trừ khi bạn đã đăng nhập. Bước đăng nhập bị bỏ qua trong CI, hoặc khi bạn đặt `CLOUDTHINKER_CLI_NO_LOGIN=1`. Mở shell mới khi cài xong.

    Nếu máy của bạn chặn việc pipe script vào `sh`, hoặc bạn cần một phiên bản cụ thể, hãy tải gói nén và tệp `.sha256` cho nền tảng của bạn từ [trang releases](https://github.com/cloudthinker-ai/cloudthinker-cli/releases):

    ```bash
    shasum -a 256 -c <archive>.sha256   # prints "<archive>: OK"
    tar xf <archive>
    mkdir -p ~/.local/bin && mv <extracted-folder>/cloudthinker ~/.local/bin/
    ```

    **Trạng thái thành công:** `cloudthinker --version` in ra số phiên bản.
  </Step>

  <Step title="Đăng nhập">
    Bỏ qua bước này nếu trình cài đặt đã in `Logged in to <workspace>.`

    ```bash
    cloudthinker login
    ```

    CLI hỏi **How would you like to log in?** Chọn **Log in with browser** trên máy của bạn, hoặc **Log in with a code** khi dùng SSH. Phê duyệt yêu cầu trên trình duyệt và chọn workspace nếu bạn có nhiều workspace.

    <Frame>
      <img src="/images/cli/login-consent-url.png" alt="cloudthinker login in ra URL đồng ý" />
    </Frame>

    **Trạng thái thành công:** terminal in ra `Logged in to <workspace>.` Xem [Xác thực CLI](/vi/guide/cli/authentication) cho máy từ xa, nhiều workspace và CI.
  </Step>

  <Step title="Kiểm tra danh tính">
    ```bash
    cloudthinker whoami
    ```

    **Trạng thái thành công:** một dòng như `host=https://app.cloudthinker.io email=you@example.com workspace=Production (<workspace-id>)`.
  </Step>

  <Step title="Khởi động agent, hoặc hỏi một câu">
    ```bash
    cloudthinker                                    # interactive agent in this folder
    cloudthinker chat -p "Check production health"  # one headless prompt, answer on stdout
    ```

    Lần chạy `cloudthinker` đầu tiên tải bản build agent khớp với phiên bản CLI của bạn vào `~/.cloudthinker/agent/bin/<version>/` và đối chiếu với checksum SHA-256 của bản phát hành. Các lần sau dùng lại bản build này.

    **Trạng thái thành công:** phần đầu của agent hiển thị workspace, người dùng và Approval mode của workspace (`· Auto` hoặc `· Manual`), và ô prompt sẵn sàng nhận yêu cầu. Xem [Agent CLI](/vi/guide/cli/agent).
  </Step>
</Steps>

## Các lệnh

| Lệnh | Tác dụng |
| --- | --- |
| `cloudthinker` hoặc `cloudthinker agent` | Khởi động agent tương tác trong thư mục này. Xem [Agent CLI](/vi/guide/cli/agent) |
| `cloudthinker chat` | Gửi prompt headless, kiểm tra một lượt chạy hoặc liệt kê các lượt chạy gần đây. Xem [Headless chat](/vi/guide/cli/headless-chat) |
| `cloudthinker review` | Review thay đổi cục bộ, hoặc đọc một review đang theo dõi bằng URL merge request. Xem [Lệnh review](/vi/guide/cli/reference#review) |
| `cloudthinker incident` | Liệt kê sự cố, hoặc chờ một sự cố được giải quyết, cho script trực on-call và CI. Xem [Sự cố và khuyến nghị](/vi/guide/cli/reference#sự-cố-và-khuyến-nghị) |
| `cloudthinker recommendations` | Liệt kê khuyến nghị về chi phí và hiệu quả cùng khoản tiết kiệm hằng tháng. Xem [Sự cố và khuyến nghị](/vi/guide/cli/reference#sự-cố-và-khuyến-nghị) |
| `cloudthinker cyber` | Liệt kê ứng dụng, domain, lượt chạy và phát hiện của Cyber. Xem [Lệnh Cyber](/vi/guide/cli/reference#cyber) |
| `cloudthinker worker` | Chạy máy này như một Worker và quản lý các outpost |
| `cloudthinker remote` | Chạy agent trên máy từ xa qua SSH. Agent vẫn chạy khi kết nối bị ngắt. Cả hai máy đều cần CLI. Xem [Agent từ xa](/vi/guide/cli/reference#agent-từ-xa) |
| `cloudthinker login` / `logout` / `whoami` | Đăng nhập, đăng xuất và kiểm tra tài khoản cùng workspace đang dùng |
| `cloudthinker auth` | In access token, liệt kê các workspace đã đăng nhập, hoặc chuyển workspace đang hoạt động |
| `cloudthinker update` | Cài bản phát hành mới nhất |
| `cloudthinker completion <shell>` | In script tự hoàn thành cho bash, zsh hoặc fish |

Mọi cờ, biến môi trường và mã thoát đều có trong [Tra cứu CLI](/vi/guide/cli/reference).

## Cập nhật CLI

Chạy `cloudthinker update` bất cứ lúc nào. Trên terminal tương tác, CLI cũng đề xuất cập nhật khi có bản phát hành mới hơn, kiểm tra tối đa 20 giờ một lần. CLI hỏi `Install it now? [y/N] (s skips this version)`:

| Trả lời | Kết quả |
| --- | --- |
| `y` | Cài bản phát hành mới ngay |
| Enter, hoặc bất kỳ phím nào khác | Để sau. CLI sẽ đề xuất lại |
| `s` | Bỏ qua phiên bản đó. Bạn sẽ được đề xuất phiên bản tiếp theo |

Đặt `CLOUDTHINKER_NO_UPDATE_CHECK=1` để tắt đề xuất, ví dụ trong CI. Để ghim một phiên bản, cài thủ công gói nén của bản phát hành đó như ở bước 1.

## Dùng CLI từ một coding agent khác

Tệp nhị phân kèm theo một hướng dẫn vận hành dạy coding agent AI cách dùng CLI: chat, theo dõi cuộc hội thoại, đọc code review và chạy pentest Cyber cục bộ. In hướng dẫn này không cần đăng nhập hay mạng. Lưu vào nơi coding agent của bạn đọc skill, ví dụ:

```bash
mkdir -p .agents/skills/cloudthinker-cli
cloudthinker --skill > .agents/skills/cloudthinker-cli/SKILL.md
```

## Gỡ cài đặt

```bash
cloudthinker logout --all
rm ~/.local/bin/cloudthinker
rm -rf ~/.cloudthinker   # agent builds, agent settings, session transcripts, Cyber tools
```

Sau đó xóa thư mục `cloudthinker` trong thư mục cấu hình (`~/Library/Application Support/cloudthinker` trên macOS, `$XDG_CONFIG_HOME/cloudthinker` hoặc `~/.config/cloudthinker` trên Linux), và xóa dòng `PATH` mà trình cài đặt đã thêm vào shell profile. Xem [Tệp](/vi/guide/cli/reference#tập-tin) để biết mọi đường dẫn CLI ghi vào.

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="cloudthinker: command not found">
    Trình cài đặt đã thêm `~/.local/bin` vào `PATH`, nhưng shell hiện tại khởi động trước thời điểm đó. Mở shell mới, hoặc chạy trực tiếp `~/.local/bin/cloudthinker --version`.
  </Accordion>
  <Accordion title="Lệnh báo bạn chưa đăng nhập (mã thoát 3)">
    Thông tin xác thực bị thiếu hoặc đã hết hạn, hoặc máy chủ từ chối truy cập. Chạy `cloudthinker login`, rồi `cloudthinker whoami` để xác nhận. Xem [Xác thực CLI](/vi/guide/cli/authentication).
  </Accordion>
  <Accordion title="Ctrl-C dừng chat trước khi có câu trả lời">
    Chỉ việc chờ bị dừng. Lượt chạy vẫn tiếp tục trên máy chủ, và CLI in ra lệnh để chờ tiếp.
  </Accordion>
</AccordionGroup>
