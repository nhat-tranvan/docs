Toàn bộ lệnh của file nhị phân `cloudthinker`, kèm các cờ nó nhận và mã nó trả về. Nếu chưa cài, hãy bắt đầu từ [tổng quan CLI](/vi/guide/cli/overview).

## Tùy chọn toàn cục

Những tùy chọn này đứng trước subcommand và áp dụng cho mọi lệnh cần xác thực.

| Tùy chọn | Mô tả |
| --- | --- |
| `--url <URL>` | URL gốc của API. Mặc định `https://app.cloudthinker.io`. Truyền origin trần, không kèm đường dẫn con |
| `--workspace <ID hoặc TÊN>` | Dùng credential đã lưu của workspace này. Không dùng chung với `CLOUDTHINKER_TOKEN` |
| `-h`, `--help` | In trợ giúp của lệnh |
| `-V`, `--version` | In phiên bản CLI |

## Lệnh xác thực

| Lệnh | Mô tả |
| --- | --- |
| `login` | Đăng nhập trình duyệt qua callback loopback |
| `login --no-browser` | In URL đồng ý thay vì mở trình duyệt |
| `login --device-auth` | Cấp quyền bằng mã ngắn trên thiết bị khác |
| `logout` | Xóa credential của workspace đang chọn hoặc đang hoạt động |
| `logout --all` | Xóa mọi credential đã lưu cho host này |
| `whoami` | In host, tài khoản và workspace thực tế đứng sau credential |
| `auth token` | In access token hiện tại ra stdout, tự làm mới trước nếu sắp hết hạn |

Chi tiết và mẫu dùng cho CI nằm ở [xác thực CLI](/vi/guide/cli/authentication).

## Agent

| Lệnh | Mô tả |
| --- | --- |
| `agent` | Chạy agent lập trình cục bộ trong thư mục hiện tại |
| `agent <args...>` | Truyền mọi tham số cho agent nguyên vẹn |
| `agent -- <args...>` | Ép truyền thẳng khi tùy chọn của agent trùng tên với tùy chọn của CLI |

`cloudthinker` trống sẽ chạy `agent`. Xem [Agent CLI](/vi/guide/cli/agent).

## Chat

| Lệnh | Mô tả |
| --- | --- |
| `chat -p <PROMPT>` | Gửi prompt và chờ câu trả lời của Anna |
| `chat -p ... --continue <UUID>` | Tiếp tục một hội thoại, bằng run ID hoặc conversation ID |
| `chat -p ... --no-wait` | Trả về ngay khi run được xếp hàng |
| `chat -p ... --timeout <GIÂY>` | Ngừng chờ sau số giây này. Mặc định 2400. Run vẫn chạy tiếp trên server |
| `chat -p ... --json` | Xuất một gói JSON thay cho câu trả lời thuần văn bản |
| `chat status <RUN_ID>` | Hiển thị trạng thái hiện tại của run, kèm câu trả lời nếu đã có |
| `chat status <RUN_ID> --wait` | Chờ tới khi run đạt trạng thái kết thúc |
| `chat ls` | Liệt kê các run headless gần đây, mới nhất trước |
| `chat ls --conversation <UUID>` | Chỉ liệt kê các run trong một hội thoại |
| `chat ls --limit <N>` | Trả về tối đa N run, từ 1 đến 50. Mặc định 10 |

Ở chế độ người đọc, `chat -p` chỉ ghi câu trả lời ra stdout; tiến trình và gợi ý `continue_with=` đi ra stderr. Xem [chat headless](/vi/guide/cli/headless-chat).

## Review

Đọc một [Review](/vi/guide/code-review/overview) mà CloudThinker đang theo dõi, bằng cách dán URL merge request hoặc pull request. Các lệnh này không bao giờ khởi động một review mới.

| Lệnh | Mô tả |
| --- | --- |
| `review status <MR_URL>` | Tóm tắt một lần: merge request, nhà cung cấp, tiêu đề, trạng thái, kết luận, số finding |
| `review findings <MR_URL>` | Liệt kê các finding, nghiêm trọng nhất trước |
| `review watch <MR_URL>` | Chờ tới khi review đạt trạng thái kết thúc |

Cả ba đều nhận `--json`, và `watch` nhận thêm `--timeout <GIÂY>`.

```bash
cloudthinker review status https://gitlab.com/acme/api/-/merge_requests/128
cloudthinker review findings https://github.com/acme/api/pull/412 --json
```

Một dòng finding có dạng `[severity] file:line (category) — title`, kèm `[resolved]` khi agent đã xử lý xong.

| Giá trị | Xuất hiện ở |
| --- | --- |
| `in review`, `review complete`, `filtered`, `failed` | Trạng thái review |
| `in review`, `approved`, `review suggested`, `changes requested`, `failed`, `filtered` | Kết luận review |

## Cập nhật

| Lệnh | Mô tả |
| --- | --- |
| `update` | Cài bản phát hành mới nhất đè lên bản đang chạy |
| `update --force` | Cài lại bản mới nhất kể cả khi đã là bản hiện hành |
| `update --json` | Xuất `{ updated, old_version, new_version }` thay cho một dòng cho người đọc |

Trên terminal tương tác, CLI cũng đề nghị cập nhật lúc khởi động khi có bản mới hơn. Lượt kiểm tra này có ngân sách hai giây và không bao giờ làm chậm hay làm hỏng lần khởi động. `CLOUDTHINKER_NO_UPDATE_CHECK=1` sẽ tắt nó.

`update` chỉ hoạt động với bản cài do trình cài đặt của CLI tạo ra. Một file nhị phân được chép tay vào máy sẽ bị từ chối, kèm lệnh cài lại cần chạy.

## Biến môi trường

| Biến | Tác dụng |
| --- | --- |
| `CLOUDTHINKER_URL` | URL gốc của API, tương đương `--url` |
| `CLOUDTHINKER_WORKSPACE` | Workspace ID hoặc đúng tên, tương đương `--workspace` |
| `CLOUDTHINKER_TOKEN` | Bearer token dùng thay cho credential đã lưu. Không dùng chung với `--workspace` |
| `CLOUDTHINKER_NO_UPDATE_CHECK` | Đặt `1` để tắt lời mời cập nhật lúc khởi động |
| `NO_COLOR` | Tắt màu ở đầu ra stderr. Màu tự tắt khi stderr không phải terminal |

## Mã thoát

| Mã | Ý nghĩa |
| --- | --- |
| 0 | Thành công |
| 1 | Công việc thất bại: run thất bại, run hoặc review không tồn tại, hoặc hết lượt thử lại kết nối |
| 2 | Sai cách dùng, hoặc yêu cầu bị chính sách workspace từ chối |
| 3 | Chưa đăng nhập, hoặc credential đã hết hạn |
| 4 | CLI ngừng chờ. Công việc vẫn tiếp tục trên server |
| 5 | Run tạm dừng chờ phê duyệt trên trình duyệt |

## Tập tin

| Đường dẫn | Nội dung |
| --- | --- |
| `<thư mục cấu hình>/cloudthinker/credentials.json` | Một credential cho mỗi workspace của từng host, chỉ chủ sở hữu đọc được |
| `~/.cloudthinker/agent/bin/<version>/` | Bundle agent đã cài cho phiên bản CLI đó |
| `~/.local/bin/cloudthinker` | File nhị phân trình cài đặt đặt vào `PATH` của bạn |

Để gỡ CLI, chạy `cloudthinker logout --all` để xóa credential đã lưu, rồi xóa file nhị phân và thư mục `~/.cloudthinker`.
