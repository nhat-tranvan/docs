Cấu hình những gì mỗi agent có thể sử dụng và cách nó hoạt động từ [Agents](https://app.cloudthinker.io/agents) trong bảng điều khiển CloudThinker. Nhấp vào một agent để mở hộp thoại **Agent Settings**.

## Điều kiện tiên quyết

- Quyền workspace admin — [thành viên](/vi/guide/workspace-users) có thể chat với agent nhưng không thể chỉnh sửa
- Ít nhất một [kết nối](/vi/guide/connections/overview) trong workspace của bạn

## Các tab cài đặt

<Frame>
  <img src="/images/agents/agent-settings.png" alt="Cấu hình Agent Settings" />
</Frame>

Hộp thoại **Agent Settings** có ba tab:

| Tab | Điều khiển gì |
|-----|------------------|
| **Builtin Tools** | Những công cụ tích hợp nào agent có thể sử dụng |
| **Connections** | Những kết nối nào agent có thể truy cập |
| **Instructions** | Hành vi tùy chỉnh, ngữ cảnh và hướng dẫn vận hành |

## Bật hoặc tắt agent

<Steps>
  <Step title="Mở trang Agents">
    Vào [Agents](https://app.cloudthinker.io/agents) trong bảng điều khiển CloudThinker.
  </Step>
  <Step title="Chuyển đổi agent">
    Sử dụng nút **Enable/Disable** để kích hoạt hoặc vô hiệu hóa agent.
  </Step>
</Steps>

Tắt agent để giới hạn workspace của bạn trong các lĩnh vực cụ thể, giảm nhiễu trong công việc tập trung, hoặc hạn chế truy cập trong quá trình bảo trì.

## Cấu hình công cụ tích hợp

<Steps>
  <Step title="Chọn agent">
    Vào [Agents](https://app.cloudthinker.io/agents) và nhấp vào agent.
  </Step>
  <Step title="Mở tab Builtin Tools">
    Chọn **Builtin Tools** trong hộp thoại Agent Settings.
  </Step>
  <Step title="Chọn hoặc bỏ chọn công cụ">
    Chỉ bật những công cụ mà agent này cần.
  </Step>
</Steps>

| Công cụ | Mô tả |
|------|-------------|
| **Create Memory** | Lưu trữ thông tin để tham khảo sau |
| **Fetch URL** | Lấy nội dung từ URL web |
| **Planning** | Tạo và quản lý kế hoạch hành động |
| **Push Alert** | Gửi thông báo cảnh báo |
| **Recommendation** | Tạo khuyến nghị có thể thực thi |
| **Search Internet** | Tìm kiếm thông tin trên web |
| **Search Knowledge Base** | Truy vấn [cơ sở kiến thức](/vi/guide/knowledge) của tổ chức bạn |

## Gán kết nối

<Steps>
  <Step title="Chọn agent">
    Vào [Agents](https://app.cloudthinker.io/agents) và nhấp vào agent.
  </Step>
  <Step title="Mở tab Connections">
    Chọn **Connections** trong hộp thoại Agent Settings.
  </Step>
  <Step title="Chọn kết nối">
    Chọn kết nối mà agent này có thể sử dụng, rồi lưu.
  </Step>
</Steps>

<Tip>
  Chỉ gán cho mỗi agent những kết nối mà vai trò của nó yêu cầu. [Tony](/vi/guide/agents/tony) không cần quyền truy cập IAM production để tinh chỉnh cơ sở dữ liệu.
</Tip>

| Agent | Kết nối được khuyến nghị |
|-------|------------------------|
| [Alex](/vi/guide/agents/alex) | Tất cả tài khoản nhà cung cấp đám mây |
| [Oliver](/vi/guide/agents/oliver) | Tài khoản đám mây + dịch vụ giám sát bảo mật |
| [Tony](/vi/guide/agents/tony) | Kết nối cơ sở dữ liệu + công cụ giám sát |
| [Kai](/vi/guide/agents/kai) | Cụm Kubernetes + nền tảng quan sát |
| [Anna](/vi/guide/agents/anna) | Tất cả kết nối (để điều phối) |

## Đặt hướng dẫn tùy chỉnh

<Steps>
  <Step title="Chọn agent">
    Vào [Agents](https://app.cloudthinker.io/agents) và nhấp vào agent.
  </Step>
  <Step title="Mở tab Instructions">
    Chọn **Instructions** trong hộp thoại Agent Settings.
  </Step>
  <Step title="Viết hướng dẫn">
    Bao gồm ba lĩnh vực: ngữ cảnh vai trò (chuyên môn cho môi trường của bạn), giới hạn phạm vi (những gì agent nên và không nên truy cập), và hướng dẫn vận hành (quy trình và đường leo thang).
  </Step>
</Steps>

Ví dụ:

```text
You are Alex, the Cloud Engineer for Acme Corp.

Environment:
- Primary cloud: AWS (us-east-1, us-west-2)
- Secondary cloud: GCP (for ML workloads)
- Cost target: Reduce by 20% this quarter

Guidelines:
- Always check with @oliver before recommending security group changes
- Prioritize production stability over cost savings
- Flag any resource costing >$1000/month for review
```
