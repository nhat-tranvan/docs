<Note>
**Xem trước** — CloudThinker MCP server đang trong giai đoạn truy cập sớm. Bề mặt công cụ và tùy chọn transport có thể thay đổi trước khi phát hành chính thức. [Liên hệ chúng tôi](https://cloudthinker.io/contact) để tham gia xem trước.
</Note>

CloudThinker có thể hoạt động như một [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server, cho phép bất kỳ AI client tương thích MCP nào gọi các công cụ CloudThinker và đọc dữ liệu CloudThinker bằng ngữ cảnh được xác thực trong workspace của bạn.

Đây là chiều ngược lại so với [kết nối MCP](/vi/guide/connections/mcp) hiện có, cho phép các agent CloudThinker gọi _MCP server bên ngoài_ của bạn.

---

## Tính năng mở ra

| Khả năng | Mô tả |
| --- | --- |
| Cloud Ops trong IDE của bạn | Truy vấn kho tài nguyên và chi phí AWS, GCP, Azure từ Cursor, Claude Desktop hoặc bất kỳ MCP client nào |
| Sử dụng kết nối của bạn | Truy cập cơ sở dữ liệu, Kubernetes cluster và công cụ quan sát bạn đã kết nối với CloudThinker |
| Chạy Skills từ xa | Gọi [skills](/vi/guide/skills/overview) workspace của bạn từ bất kỳ host tương thích MCP nào |
| Ngữ cảnh chung | Đọc đề xuất, dashboard và bộ nhớ sự cố theo cách tương tự như giao diện web console |

---

## Công cụ được expose

MCP server cung cấp một tập hợp con được tuyển chọn các khả năng của agent:

| Nhóm công cụ | Chức năng |
|-------------|--------------|
| `resources.*` | Truy vấn kho tài nguyên thống nhất và cấu trúc liên kết |
| `recommendations.*` | Liệt kê, chấp nhận, bác bỏ hoặc bình luận về đề xuất tối ưu hóa |
| `costs.*` | Chạy truy vấn chi phí và dự báo trên các tài khoản đám mây |
| `incidents.*` | Tạo sự cố, đính kèm tín hiệu và đọc kết quả phân tích nguyên nhân gốc rễ |
| `dashboards.*` | Đọc dashboard tích hợp sẵn và tùy chỉnh |
| `skills.*` | Thực thi workspace skills với các tham số |

Danh sách công cụ chính xác được expose qua MCP discovery — client sẽ thấy bất kỳ thứ gì mà API key của workspace được phép sử dụng.

---

## Transport

| Transport | Phù hợp nhất cho |
|-----------|----------|
| **HTTP + SSE** | Client được host trên đám mây, agent từ xa và thiết lập chia sẻ theo nhóm |
| **stdio** | IDE cục bộ và ứng dụng desktop (Claude Desktop, Cursor, Windsurf) khởi chạy qua proxy cục bộ |

---

## Xác thực

MCP server xác thực bằng cùng [API key](/vi/guide/api/overview) workspace được sử dụng bởi REST API. Key được gắn với một workspace duy nhất và kế thừa vai trò của thành viên phát hành.
