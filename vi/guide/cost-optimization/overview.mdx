CostOps liên tục phân tích các tài khoản đám mây đã kết nối để phát hiện cơ hội tiết kiệm, tạo khuyến nghị có thứ tự ưu tiên, và theo dõi các tối ưu hóa bạn thực hiện. Lãng phí đám mây — instance không dùng, volume chưa gắn kết, dung lượng reserved bị trượt — tích lũy lặng lẽ giữa các hóa đơn, nên CostOps theo dõi liên tục thay vì chờ đến khi hóa đơn đến.

## Cách hoạt động

1. **Khám phá** — CloudThinker quét các tài khoản AWS, GCP, và Azure đã kết nối để kiểm kê tài nguyên, cấu hình, và mô hình chi tiêu.
2. **Phân tích** — Các agent đánh giá mức sử dụng tài nguyên, xu hướng chi tiêu, và mô hình cấu hình so với các best practice gốc đám mây.
3. **Đề xuất** — [Alex](/vi/guide/agents/alex) tạo các khuyến nghị có thứ tự ưu tiên, mỗi khuyến nghị kèm ước tính tiết kiệm bằng đô la, mức nỗ lực (Thấp/Trung bình/Cao), đánh giá rủi ro (Thấp/Trung bình/Cao), và các bước thực hiện.
4. **Triển khai** — Với [sự chấp thuận](/vi/guide/approval) của bạn, CloudThinker thực hiện khuyến nghị hoặc cung cấp hướng dẫn chi tiết để thực hiện thủ công.
5. **Theo dõi** — [Savings tracking](/vi/guide/cost-optimization/savings) đo lường tiết kiệm thực tế so với dự báo sau khi triển khai.

Alex dẫn dắt công việc chi phí trên tất cả đám mây; [Kai](/vi/guide/agents/kai) xử lý hiệu quả Kubernetes và [Tony](/vi/guide/agents/tony) tối ưu chi tiêu cơ sở dữ liệu.

## Những gì bạn có thể làm

| Tính năng | Mô tả | Tìm hiểu thêm |
|---|---|---|
| Khuyến nghị | Xem xét các khuyến nghị tiết kiệm chi phí do AI tạo ra với tiết kiệm, nỗ lực, và rủi ro cho từng khuyến nghị | [Recommendations](/vi/guide/cost-optimization/recommendations) |
| Cost analytics | Khám phá xu hướng chi tiêu, dự báo, và phân bổ theo tài khoản và dịch vụ | [Analytics](/vi/guide/cost-optimization/analytics) |
| Tối ưu hóa tài nguyên | Right-size instance, phát hiện tài nguyên không dùng, và phân tích mức sử dụng | [Resources](/vi/guide/infrastructure/resources) |
| Savings tracking | Theo dõi các khuyến nghị đã triển khai và đo lường tiết kiệm thực tế so với dự báo | [Savings](/vi/guide/cost-optimization/savings) |
| Bảo vệ liên tục | Chạy [CloudKeepers](/vi/guide/infrastructure/cloudkeepers) kiểm tra chi phí theo lịch để lãng phí xuất hiện dưới dạng phát hiện, không phải bất ngờ | [CloudKeepers](/vi/guide/infrastructure/cloudkeepers) |

## Loại tài nguyên được hỗ trợ

CostOps phân tích hơn 58 loại tài nguyên AWS cộng với các dịch vụ GCP và Azure cốt lõi.

| Nhà cung cấp | Lĩnh vực | Phạm vi |
|---|---|---|
| AWS | Compute | EC2 (right-sizing, reserved instances, spot), ECS, EKS, Lambda memory tuning, Batch, EMR, App Runner |
| AWS | Storage | S3 lifecycle và storage classes, EBS (unattached, oversized), EFS throughput, Glacier archiving |
| AWS | Database | RDS sizing và reserved instances, DynamoDB capacity modes, DocumentDB, Neptune, Redshift, ElastiCache |
| AWS | Networking | CloudFront caching, ELB/ALB/NLB idle detection, NAT Gateway efficiency, Route 53, API Gateway |
| AWS | Analytics & AI | SageMaker endpoints, notebooks, và training jobs, OpenSearch, Kinesis, Firehose, Glue |
| GCP | Tất cả | Compute Engine (right-sizing, committed use discounts), Cloud Run, Cloud Functions, Cloud SQL, GKE, Cloud Storage classes |
| Azure | Tất cả | Virtual Machines, Azure Kubernetes Service, Azure SQL Database, Blob Storage, App Services |

## Bắt đầu nhanh

Yêu cầu Alex phân tích chi phí đầu tiên từ bất kỳ workspace chat nào:

```text
@alex #recommend cost-saving opportunities for production workloads
@alex #dashboard current month spending by service
@alex #report unattached EBS volumes and unused Elastic IPs across all regions
```

Mỗi kết quả bao gồm dữ liệu cơ bản, để bạn có thể xác minh khuyến nghị trước khi hành động.
