CloudThinker Public API là một REST API đọc và thao tác trên một workspace bằng API token. Token mang các scope bạn chọn và không bao giờ làm được nhiều hơn những gì vai trò workspace của bạn cho phép.

Mới bắt đầu? [Quickstart](/guide/api/quickstart) đưa bạn từ lúc có token đến lời gọi đầu tiên trong khoảng năm phút.

## Bạn có thể gọi gì

<ApiAreas />

Mỗi lời gọi cần một scope, và vai trò workspace của bạn phải cho phép scope đó. Mỗi trang endpoint đều ghi scope của nó; [API Tokens](/guide/api/tokens#scopes) giải thích cách scope hoạt động. Xem [Approvals for API Runs](/guide/api/approvals#start-a-run-and-get-its-answer) để khởi chạy agent run và đọc câu trả lời của nó.

Để gọi CloudThinker theo cách khác, hãy dùng [CloudThinker CLI](/guide/cli/api), [Claude Connector](/vi/guide/mcp/overview), [A2A API](/guide/api/a2a) cho một hệ thống bên ngoài như ServiceNow, [Webhooks](/vi/guide/webhooks/overview), hoặc [SCIM provisioning](/vi/guide/security/scim) cho Okta và Microsoft Entra ID.

## Cách hoạt động

- **Base URL:** `https://app.cloudthinker.io/api/public`. Đường dẫn có dạng `/v1/workspaces/<workspace-id>/{module}/{resource}`.
- **Xác thực:** gửi `Authorization: Bearer <token>` với token cá nhân (`ct_pat_…`), token service account (`ct_sat_…`) hoặc token OAuth (`ct_oat_…`), hoặc một phiên đăng nhập CLI. Mỗi token hoạt động trong một workspace; `GET /v1/token` trả về workspace ID, scope và thời hạn của token.
- **Định dạng:** JSON vào và ra, UTF-8. Một trường trong body mà thao tác không định nghĩa sẽ trả về `422`. Hợp đồng OpenAPI 3.1 nằm tại `https://app.cloudthinker.io/api/public/v1/openapi.json`, không cần token.
- **Phân trang:** lời gọi liệt kê nhận `limit` (1–100, mặc định 20) và `cursor`. Một trang có dạng `{"items": [...], "next_cursor": "..."}`; truyền lại `next_cursor` làm `cursor` cho đến khi nó là `null`. Giữ nguyên `limit` và bộ lọc; truy vấn bị thay đổi sẽ trả về `400` `invalid_cursor`.
- **Thao tác ghi:** mọi `POST` cần header `Idempotency-Key`. Xem [API Errors](/guide/api/errors#retry-safe-writes).
- **Phiên bản:** mọi đường dẫn bắt đầu bằng phiên bản, `v1`. Thay đổi phá vỡ tương thích sẽ ra mắt dưới dạng phiên bản mới. Trong `v1`, trường và thao tác mới có thể xuất hiện, nên hãy bỏ qua các trường phản hồi bạn không nhận ra.

Liệt kê sự cố trong workspace của bạn, với `WORKSPACE_ID` lấy từ `GET /v1/token`:

```bash
curl -sS "https://app.cloudthinker.io/api/public/v1/workspaces/$WORKSPACE_ID/resolve/incidents?limit=20" \
  -H "Authorization: Bearer $CLOUDTHINKER_TOKEN"
```
