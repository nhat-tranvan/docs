Anna là chuyên gia điều phối của CloudThinker, chuyên về điều phối đa agent, quản lý dự án phức tạp, báo cáo điều hành và các vận hành chiến lược trải dài trên nhiều lĩnh vực.

---

## Vấn đề Anna giải quyết

Các vận hành đám mây phức tạp trải dài trên nhiều lĩnh vực — một cuộc di chuyển đám mây bao gồm hạ tầng (AWS), yêu cầu bảo mật (IAM, tuân thủ), chiến lược cơ sở dữ liệu (di chuyển, nhân bản) và điều phối container (Kubernetes). Nhưng các agent và công cụ chuyên biệt bị cô lập: Cost Explorer không giao tiếp với Security Hub, Security Hub không giao tiếp với hệ thống giám sát cơ sở dữ liệu, và cả hai không giao tiếp với công cụ Kubernetes.

Khi một sự cố production hoặc dự án lớn cần điều phối liên lĩnh vực, công việc đổ lên các kỹ sư cấp cao phải thực hiện thủ công:
- Chuyển ngữ cảnh giữa các dashboard và công cụ để thu thập dữ liệu từ từng lĩnh vực
- Tổng hợp phát hiện thành một bức tranh mạch lạc
- Viết báo cáo trạng thái, tóm tắt điều hành và trình bày cho hội đồng
- Theo dõi phụ thuộc và tiến độ giữa các đội với toolchain khác nhau

Chi phí điều phối này là lý do tại sao các sáng kiến lớn (di chuyển đám mây, khắc phục bảo mật, đánh giá hàng quý) mất vài tuần thay vì vài ngày.

---

## Những gì các công cụ khác bỏ lỡ

| Công cụ | Chức năng | Điểm còn thiếu |
|------|-------------|----------------|
| **Jira / Linear** | Theo dõi dự án và quản lý ticket | Theo dõi nhiệm vụ nhưng không điều tra, phân tích hay tổng hợp phát hiện |
| **ServiceNow** | Quy trình ITSM và quản lý sự cố | Nặng quy trình, chậm, không có phân tích AI đa lĩnh vực |
| **Confluence / Notion** | Tài liệu và quản lý kiến thức | Tài liệu thụ động, cần nhập dữ liệu thủ công |
| **Bảng tính + slide** | Điều phối và báo cáo thủ công | Hoàn toàn thủ công, không kết nối với dữ liệu hạ tầng trực tiếp |
| **Công cụ AI đơn agent** | Một AI cho một lĩnh vực | Không thể điều phối chi phí + bảo mật + cơ sở dữ liệu + K8s trong một quy trình duy nhất |

Anna là agent duy nhất có thể điều phối một vận hành đa lĩnh vực, tổng hợp phát hiện từ [Alex](/vi/guide/agents/alex), [Oliver](/vi/guide/agents/oliver), [Tony](/vi/guide/agents/tony) và [Kai](/vi/guide/agents/kai) đồng thời, và tạo ra kết quả sẵn sàng cho cấp điều hành — tất cả từ một prompt duy nhất.

---

## Anna hoạt động như thế nào

1. **Nhận yêu cầu phức tạp** — một dự án, điều tra, hoặc yêu cầu báo cáo trải dài trên nhiều lĩnh vực
2. **Phân tách thành các nhiệm vụ song song** — xác định agent nào cần đóng góp và mỗi agent cần điều tra gì
3. **Điều phối thực thi agent** — giao nhiệm vụ cho [Alex](/vi/guide/agents/alex), [Oliver](/vi/guide/agents/oliver), [Tony](/vi/guide/agents/tony) và [Kai](/vi/guide/agents/kai) đồng thời, với các phụ thuộc được quản lý tự động
4. **Tổng hợp phát hiện** — thu thập kết quả từ tất cả agent và xây dựng một câu chuyện mạch lạc kết nối các insight đa lĩnh vực
5. **Tạo ra kết quả** — tóm tắt điều hành, kế hoạch hành động, trình bày cho hội đồng, hoặc lộ trình khắc phục — sẵn sàng chia sẻ mà không cần chỉnh sửa thủ công

| **Vận hành phức tạp** | Di chuyển đám mây, chuyển đổi bảo mật, cải tạo hạ tầng |

## Khi nào nên dùng Anna

Sử dụng Anna khi vận hành cần:

- **Nhiều agent** làm việc trên các khía cạnh liên quan của một vấn đề
- **Chuyên môn đa lĩnh vực** (ví dụ: bảo mật + hạ tầng + cơ sở dữ liệu)
- **Khả năng hiển thị cấp điều hành** hoặc báo cáo
- **Điều phối dự án** với phụ thuộc và tiến độ

Với các nhiệm vụ đơn lĩnh vực, hãy dùng trực tiếp agent chuyên biệt tương ứng.

## Mẫu prompt

### Điều phối đa agent

```text
# Parallel investigation
@anna coordinate investigation of production outage:
  - @alex: infrastructure and resource issues
  - @tony: database performance and connections
  - @kai: pod health and networking

# Project orchestration
@anna manage AWS to Azure migration:
  - @alex: infrastructure planning and cost analysis
  - @oliver: security requirements and compliance
  - @tony: database migration strategy
  - @kai: container workload transition

# Cross-functional analysis
@anna coordinate quarterly infrastructure review:
  - @alex: cost and performance
  - @oliver: security posture
  - @tony: database health
  - @kai: Kubernetes efficiency
```

### Vận hành phức tạp

```text
# Cloud migration
@anna orchestrate multi-cloud migration project with timeline and risk assessment

# Security transformation
@anna coordinate enterprise security remediation with @oliver leading

# Infrastructure modernization
@anna manage Kubernetes adoption across all environments

# Cost optimization initiative
@anna coordinate company-wide cost reduction targeting 30% savings
```

### Báo cáo điều hành

```text
# Strategic summary
@anna #report quarterly infrastructure status for executive team

# Board presentation
@anna prepare board-level cloud transformation summary

# KPI dashboard
@anna #dashboard executive infrastructure KPIs

# ROI analysis
@anna analyze ROI of cloud optimization initiatives
```

### Lập kế hoạch chiến lược

```text
# Technology roadmap
@anna create 12-month infrastructure modernization roadmap

# Capacity planning
@anna forecast infrastructure needs for 3x growth

# Risk assessment
@anna assess risks of current infrastructure with mitigation plan

# Investment analysis
@anna evaluate cloud investment options with cost-benefit analysis
```

## Sử dụng công cụ

| Công cụ | Trường hợp sử dụng của Anna |
|------|---------------|
| `#dashboard` | KPI điều hành, trạng thái dự án, số liệu đa lĩnh vực |
| `#report` | Tóm tắt chiến lược, đánh giá hàng quý, trình bày hội đồng |
| `#recommend` | Sáng kiến chiến lược, ưu tiên đầu tư, sắp xếp trình tự dự án |
| `#alert` | Cột mốc dự án, ngưỡng rủi ro, phát hiện quan trọng |
| `#chart` | Phân tích xu hướng, số liệu so sánh, theo dõi tiến độ |

### Ví dụ với công cụ

```text
@anna #dashboard executive infrastructure overview
@anna #report quarterly review with findings from all agents
@anna #recommend priority initiatives for next quarter
@anna #schedule monthly executive infrastructure summary
```

## Prompt hiệu quả

**Mẹo: Xác định vai trò agent**

```text
# Good
@anna coordinate security audit:
@oliver leads assessment
@alex reviews infrastructure impact
@kai checks container security

# Avoid
@anna do a security check
```

**Mẹo: Chỉ định kết quả đầu ra**

```text
# Good
@anna #report quarterly review:
- Executive summary
- Cost trends and savings
- Security posture
- Recommendations

# Avoid
@anna summarize things
```

## Quy trình làm việc phổ biến

### Điều phối sự cố

```text
# Step 1: Parallel investigation
@anna coordinate investigation:
  @alex check infrastructure and load balancers
  @tony analyze database performance
  @kai review pod health and networking

# Step 2: Synthesize findings
@anna summarize findings and identify root cause

# Step 3: Remediation plan
@anna #recommend remediation actions with owner assignment

# Step 4: Post-incident
@anna #report incident analysis with prevention measures
```

### Đánh giá hàng quý

```text
# Step 1: Gather data
@anna compile infrastructure metrics from @alex @oliver @tony @kai

# Step 2: Analyze
@anna identify trends, risks, and opportunities

# Step 3: Report
@anna #report quarterly infrastructure review for executives

# Step 4: Plan
@anna #recommend priorities for next quarter
```

### Di chuyển đám mây

```text
# Step 1: Assessment
@anna coordinate migration assessment:
  @alex: current state and target architecture
  @oliver: security and compliance requirements
  @tony: data migration strategy
  @kai: container migration plan

# Step 2: Planning
@anna create phased migration plan with dependencies

# Step 3: Execution tracking
@anna #dashboard migration progress and risk status

# Step 4: Validation
@anna coordinate post-migration validation across all domains
```
