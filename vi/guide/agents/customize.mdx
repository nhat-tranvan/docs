**Works the way your team works.**

Customize là nơi bạn điều chỉnh các agent (trợ lý tích hợp sẵn CloudThinker và mọi agent tùy chỉnh bạn tạo; xem [Agent](/vi/guide/agents/overview)) cho phù hợp với nhóm: có những agent nào, agent theo quy trình nào, được dùng tài liệu và bí mật nào, cảnh báo gửi về đâu, và thay đổi nào cần một người duyệt trước. Mọi thiết lập ở đây áp dụng theo từng workspace và nằm trong **More → Workspace settings**.

CloudThinker vẫn hoạt động mà không cần bất kỳ thiết lập nào trong số này.

## Cách hoạt động

Mỗi phần trả lời một câu hỏi về cách agent hành xử. Bạn có thể thiết lập theo bất kỳ thứ tự nào.

1. **Ai trả lời.** Agent tùy chỉnh có tên, `@mention`, hướng dẫn, ngôn ngữ phản hồi và kết nối riêng.
2. **Làm việc thế nào.** Skill chứa quy trình và quy tắc của bạn. Knowledge chứa tài liệu để agent tra cứu.
3. **Truy cập được gì.** Kết nối cho phép truy cập hệ thống của bạn. Credentials chứa các bí mật khác, chẳng hạn API key của một nhà cung cấp dùng cho CLI. Dùng Credentials khi công cụ đó chưa có kết nối.
4. **Được thay đổi gì.** Approvals quyết định mỗi thao tác ghi được chạy, phải chờ người duyệt, hay bị từ chối. Có hai chế độ: **Manual** hỏi người duyệt trước mọi thao tác ghi, còn **Auto** để Rules của bạn quyết định trước, rồi đến đánh giá của AI.
5. **Ai được báo.** Notifications chuyển cảnh báo đến email, Slack, Teams hoặc Google Chat.

Bên cạnh đó có hai phần tùy chọn: **Memory** lưu những gì agent ghi nhớ giữa các cuộc trò chuyện, và **Commands** lưu các prompt bạn chạy lại bằng `/`.

<Warning>
Workspace mới bắt đầu ở chế độ **Auto · Rules + AI · Ask me**, trong đó đánh giá của AI có thể cho một thao tác ghi an toàn chạy mà không hỏi. Trước khi kết nối production, hãy chuyển sang **Manual** để mọi thao tác ghi đều phải hỏi người duyệt. Rules **Ask first** là cách kiểm soát hẹp hơn về sau: Rule enforcement mặc định tắt, và khi bước **Rules** còn ghi **In preview** thì Rules chỉ ghi lại quyết định mà chúng sẽ đưa ra. Xem [Approvals](/vi/guide/approvals/overview#cấu-hình-mặc-định).
</Warning>

## Thiết lập theo agent và thiết lập chung cho workspace

| Đặt riêng cho từng agent tùy chỉnh | Dùng chung cho mọi agent trong workspace |
|---|---|
| Tên và `@mention`, hướng dẫn, ngôn ngữ phản hồi, model tier, Learning Mode, kết nối | Skill, knowledge base, credentials, memory, commands, notifications, Approval Rules và Approval mode của workspace |

Skill có hiệu lực với mọi agent trên từng bề mặt được đánh dấu trong mục **Available in** của skill đó, chẳng hạn Chat hoặc Review. Bạn không thể giới hạn agent tùy chỉnh chỉ dùng một số skill hay knowledge base nhất định. Hãy giới hạn phạm vi qua hướng dẫn và kết nối. Hướng dẫn định hướng agent nhưng không chặn được gì. Kết nối mới là giới hạn cứng: agent chỉ truy cập được những kết nối gắn với nó.

## Vị trí của từng thiết lập

Trên thanh bên, nhấn **More**, rồi **Workspace settings**. Thanh cài đặt nhóm các trang như sau:

| Nhóm | Trang | Bạn thiết lập gì ở đó | Ai được chỉnh sửa | Hướng dẫn |
|-------|------|--------------------|--------------|-------|
| Agent Configuration | **Connections** | Tài khoản cloud, cluster, cơ sở dữ liệu và công cụ mà agent truy cập được | Admin | [Kết nối](/vi/guide/connections/overview) |
| Agent Configuration | **Skills** | Quy trình tái sử dụng và nơi áp dụng từng quy trình | Admin | [Skill](/vi/guide/skills/overview) |
| Agent Configuration | **Memory** | Những gì agent ghi nhớ giữa các cuộc trò chuyện | Admin | [Memory](/vi/guide/memory) |
| Agent Configuration | **Agents** | Agent tùy chỉnh: danh tính, hướng dẫn, model tier, kết nối | Admin và Developer | [Bắt đầu nhanh với agent tùy chỉnh](/vi/guide/agents/quickstart) |
| Agent Configuration | **Knowledge** | Tài liệu và website mà agent tìm kiếm | Admin | [Knowledge base](/vi/guide/knowledge) |
| Agent Configuration | **Credentials** | Bí mật agent nhận được khi chạy lệnh | Admin | [Credentials](/vi/guide/credentials) |
| Workflow | **Commands** | Prompt đã lưu, chạy bằng `/` | Admin và Developer | [Commands](/vi/guide/commands) |
| Workflow | **Approvals** | Rules, Approval mode và người phê duyệt cho thao tác ghi | Admin | [Approvals](/vi/guide/approvals/overview) |
| Integrations | **Notifications** | Sự kiện nào được gửi đến email, Slack, Teams hoặc Google Chat | Admin | [Thông báo](/vi/guide/notifications) |

Để xem mọi quyền theo vai trò, xem [vai trò](/vi/guide/security/roles).

## Bạn có thể làm gì

| Mục tiêu | Cần thiết lập gì | Tìm hiểu thêm |
|------|-------------|------------|
| Cho một nhóm có chuyên gia riêng, chẳng hạn agent review chi phí trả lời bằng tiếng Việt | Tạo agent tùy chỉnh, đặt **Language**, chỉ gắn những kết nối agent cần | [Bắt đầu nhanh với agent tùy chỉnh](/vi/guide/agents/quickstart) |
| Buộc agent luôn làm theo runbook của bạn | Viết runbook thành skill và gắn vào **Chat** hoặc **Incident** | [Skill tùy chỉnh](/vi/guide/skills/custom-skills) |
| Áp dụng tiêu chuẩn review cho mọi pull request | Viết skill và gắn vào **Review** | [Skill tùy chỉnh](/vi/guide/skills/custom-skills#chọn-nơi-áp-dụng-skill) |
| Cho agent trích dẫn tài liệu kiến trúc của bạn | Tải tài liệu lên một knowledge base | [Knowledge base](/vi/guide/knowledge) |
| Giới hạn agent ở một số tài khoản hoặc công cụ | Chỉ gắn những kết nối đó cho agent | [Bắt đầu nhanh với agent tùy chỉnh](/vi/guide/agents/quickstart#gắn-kết-nối-cho-agent) |
| Cấp API token cho agent mà không dán vào chat | Thêm token trong **Credentials** | [Credentials](/vi/guide/credentials) |
| Bắt buộc có người duyệt trước mọi thao tác ghi trên production | Đặt Approval mode thành **Manual**, cách kiểm soát có hiệu lực ngay hôm nay. Về sau, Rule **Ask first** thu hẹp yêu cầu này về đúng một thao tác ghi, khi CloudThinker bật Rule enforcement (mặc định đang tắt) | [Approvals](/vi/guide/approvals/overview) |

Để chọn giữa skill, knowledge base, memory, Learnings và nguồn runbook, xem [Dạy CloudThinker](/vi/guide/teach-cloudthinker).

## Tóm tắt về agent tùy chỉnh

| Mục | Chi tiết |
|------|--------|
| Tạo | Vào **More → Workspace settings → Agents**, rồi nhấn **Create agent**. Chọn **Create with AI** hoặc **Build with form** (hộp thoại ba bước: Identity, Configuration, Connect). |
| Create with AI | Mở một cuộc chat hỏi tên, `@mention`, vai trò, mục tiêu, hướng dẫn, model tier, ngôn ngữ, Learning Mode, avatar và kết nối. Chat xác nhận `@mention`, rồi tạo agent ngay trong chat, không có biểu mẫu để xem lại. Đây là cuộc chat bình thường nên có tiêu tốn credit. |
| `@mention` | Gồm chữ thường, số, dấu chấm, dấu gạch dưới và dấu gạch ngang, bắt đầu bằng chữ cái, tối đa 63 ký tự. Chỉ đặt một lần, không đổi được về sau. |
| Instructions | Tối đa 4.000 ký tự hướng dẫn bằng ngôn ngữ thông thường. Dùng phần này để chỉ agent đến skill và kiến thức, ví dụ: `Use the ec2-high-cpu-runbook skill for performance questions. Look up procedures in the Payments runbooks knowledge base first.` |
| Model Tier | **Light** (bằng 0.3x credit của Pro, cho câu hỏi đơn giản), **Pro** (mặc định, cho công việc hằng ngày) hoặc **Ultra** (bằng 1.7x credit của Pro, cho bài toán khó). Gói Free chỉ chạy Light, nên hãy chọn **Light** khi dùng gói này. Xem [điều gì khiến một lượt chạy tốn nhiều hơn](/vi/guide/billing/usage#điều-gì-khiến-một-lượt-chạy-tốn-nhiều-hơn). |
| Language | Mặc định là **Match the user**: agent trả lời bằng ngôn ngữ trong tin nhắn gần nhất của bạn. Chọn một ngôn ngữ cụ thể để mọi câu trả lời luôn dùng ngôn ngữ đó. |
| Learning Mode | Agent có lưu các quy trình lặp lại thành skill hay không. Xem [Learning Mode](#learning-mode). |
| Kết nối | Tối đa 64 kết nối mỗi agent, chọn từ tab **Builtin** và **MCP** |
| Ai được tạo và chỉnh sửa | Admin và Developer của workspace. Viewer xem được agent nhưng không chat hay chỉnh sửa được. |

Số agent tùy chỉnh mỗi workspace có được tùy theo gói của bạn:

| Gói | Agent tùy chỉnh |
|------|---------------|
| Free | 1 |
| Team | 5 |
| Scale và Scale Plus | 10 |
| Enterprise | Không giới hạn |

Hộp thoại **Create Custom Agent** hiển thị số chỗ bạn đã dùng, ví dụ **3 of 5 custom agents used**. Owner của tổ chức xem chính gói đang dùng trong **Admin Settings → Billing**.

Khi đạt giới hạn, nút **Create agent** bị vô hiệu hóa, và khi rê chuột lên sẽ thấy **Custom agent limit reached.** kèm liên kết **Upgrade plan**. Xóa một agent sẽ giải phóng chỗ ngay lập tức. Giới hạn chỉ được kiểm tra khi bạn tạo agent, nên sau khi hạ gói, các agent hiện có vẫn hoạt động, nhưng bạn không thêm được agent mới cho đến khi số agent thấp hơn giới hạn mới. Với các giới hạn khác theo gói, xem [bảng giá](/vi/guide/billing/pricing#tính-năng-ai-theo-gói).

## Learning Mode

Learning Mode cho phép agent tùy chỉnh biến một quy trình mà agent cứ lặp lại thành skill. Tính năng này kích hoạt khi agent thực hiện cùng một lời gọi công cụ trên cùng một kết nối 3 lần, trong cuộc trò chuyện đã chạy ít nhất 10 lời gọi công cụ. Bạn không thay đổi được các ngưỡng này trong cài đặt workspace.

| Chế độ | Điều gì xảy ra |
|---|---|
| **Auto** (mặc định của biểu mẫu) | Agent tự lưu quy trình thành skill. Agent sẽ không lưu khi yêu cầu của bạn chỉ cho phép đọc, chẳng hạn "investigate only, don't change anything". |
| **Offer** | Agent hỏi trong chat trước, và bất kỳ ai đang ở trong chat đều có thể đồng ý. |
| **Off** | Agent không bao giờ lưu skill. |

<Note>
Chỉ Admin mới tạo được skill trong **More → Workspace settings → Skills**, nhưng Developer lại tạo được agent. Agent tùy chỉnh ở chế độ **Auto** hoặc **Offer** có thể thêm skill cho workspace mà không cần Admin, và các skill đó có hiệu lực ngay trong **Chat** cho mọi agent. [Audit Logs](/vi/guide/security/audit-logs) không ghi lại các skill này. Hãy dùng **Off** cho agent trong workspace production. Không có cài đặt workspace nào ép buộc Off: Admin đặt chế độ này cho từng agent trong phần cài đặt của agent, và có thể sửa, đổi phạm vi hoặc xóa skill đã học trong **More → Workspace settings → Skills**.
</Note>
