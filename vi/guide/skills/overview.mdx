Skill là một quy trình hoặc bộ quy tắc viết thành văn bản, lưu dưới dạng file `SKILL.md`, mà agent làm theo khi công việc trước mắt khớp với nó. Hãy viết các bước phân loại sự cố, checklist review hay quy ước đặt tên một lần, và agent sẽ áp dụng mà bạn không phải nhắc lại trong từng prompt.

## Khi nào nên dùng skill

Chỉ cần một phép thử: nếu agent cần làm theo từng bước, hãy viết thành skill. Nếu agent cần tra cứu, hãy đưa vào [knowledge base](/vi/guide/knowledge). Runbook phân loại sự cố kiểu "kiểm tra CPU, rồi credit, rồi lưu lượng" là skill. Một tài liệu hướng dẫn của nhà cung cấp dài 40 trang hay danh mục dịch vụ thì thuộc về knowledge base.

| | Skill | Knowledge base |
|---|---|---|
| Chứa | Quy trình và quy tắc agent làm theo | Tài liệu và website agent tìm kiếm |
| Ví dụ | Runbook phân loại sự cố từng bước, checklist review, chính sách gắn tag | Tài liệu kiến trúc, hướng dẫn của nhà cung cấp, các postmortem cũ |
| Thay đổi | Cách agent làm việc | Những gì agent biết |
| Định dạng | File `SKILL.md`, viết trong CloudThinker hoặc tải lên trong file `.zip` | File tải lên hoặc website được thu thập |

Skill có thể trỏ agent tới một tài liệu trong knowledge base, nên hai thứ này bổ trợ tốt cho nhau. Skill là một trong nhiều nơi chứa ngữ cảnh bạn cung cấp cho CloudThinker; [Dạy CloudThinker](/vi/guide/teach-cloudthinker) so sánh tất cả các nơi đó.

## Skill được dùng khi nào

Skill chỉ được dùng khi thỏa cả ba điều kiện:

1. **Skill đang bật.** Công tắc trên skill đang bật. Skill mới tạo bật sẵn.
2. **Skill khả dụng trên bề mặt đó.** Bề mặt nơi công việc diễn ra được đánh dấu trong **Available in** (xem bảng bên dưới). Skill mới chỉ bật sẵn **Chat**. Điều này áp dụng cả cho `/`: menu `/` liệt kê mọi skill đang bật, nhưng chat không dùng được skill nếu chưa đánh dấu **Chat**, và agent tiếp tục làm mà không có skill đó. Hãy đánh dấu **Chat** cho mọi skill bạn định gọi theo tên.
3. **Skill khớp với công việc.** Trên mọi bề mặt, kể cả Review, agent chỉ thấy các skill khả dụng ở đó và tải những skill có tên và mô tả khớp với công việc. Agent có thể tải nhiều skill cho một việc. Vì vậy hãy viết mô tả bằng chính từ ngữ của yêu cầu. Chưa tốt: "CPU stuff". Tốt: "Investigate high CPU or a slow EC2 instance".

| Bề mặt | Nơi skill chạy |
|---|---|
| **Chat** | Chat trong workspace, cùng các lượt chạy không có bề mặt riêng, chẳng hạn automation và webhook |
| **Review** | Review merge request và pull request trong [Review](/vi/guide/code-review/overview) |
| **Incident** | Phân tích sự cố và nguyên nhân gốc trong [Resolve](/vi/guide/incident/overview) |
| **Assessment** | Đánh giá well-architected và đánh giá tư thế bảo mật |

Bạn cũng có thể gọi skill theo tên: gõ `/` trong ô prompt chat rồi chọn skill từ menu. Khi agent dùng một skill, hoạt động của agent hiển thị bước **Load Skill**.

CloudThinker cũng phát hành các skill dựng sẵn trong [Skills Hub](https://www.cloudthinker.io/skills). Skill cài từ hub trở thành skill của workspace để bạn quản lý như skill tự viết, và không thay đổi khi phiên bản trên hub thay đổi. Để cài, xem [skill tùy chỉnh](/vi/guide/skills/custom-skills#tạo-skill).

Danh sách skill của workspace mới ban đầu trống. Các skill tích hợp sẵn của CloudThinker, chẳng hạn `pdf`, `docx`, `pptx`, `xlsx` và `deep-research`, hoạt động mà không cần thiết lập. Các skill này không hiện trong danh sách, nên bạn không sửa hay tắt được. Tên của chúng được giữ chỗ: skill của bạn không được dùng các tên đó.

## Ai được làm gì

Trong **More → Workspace settings → Skills**, chỉ **Admin** của workspace mới tạo, sửa, gắn hoặc xóa được skill, kể cả bật tắt công tắc và thay đổi **Available in**. Developer xem được danh sách skill và chạy skill bằng `/`. Viewer xem được skill nhưng không chat được, nên không chạy được skill. Xem [vai trò](/vi/guide/security/roles).

<Note>
Có ba cách thêm skill mà không cần Admin, và mỗi cách đều đưa skill vào hoạt động trong **Chat** cho mọi agent:

- **Cài từ Skills Hub.** Thao tác cài không kiểm tra vai trò trong workspace. Thành viên nào mở liên kết cài đặt của một skill trong [danh mục công khai](https://www.cloudthinker.io/skills) cũng cài được skill đó vào workspace hiện tại của mình.
- **`/create-skill` trong chat.** Thành viên nào chat được cũng chạy được lệnh này, và agent tự viết skill.
- **[Learning Mode](/vi/guide/agents/customize#learning-mode).** Custom agent ở chế độ **Auto** hoặc **Offer** lưu skill từ chat. [Audit Logs](/vi/guide/security/audit-logs) không ghi lại các skill này. Hãy đặt **Off** nếu mọi skill đều phải do Admin tạo.

Thỉnh thoảng hãy kiểm tra **More → Workspace settings → Skills**. Admin có thể tắt, đổi phạm vi áp dụng hoặc xóa bất kỳ skill nào trong số này tại đó.
</Note>

## Các cách tạo skill

| Cách | Phù hợp nhất cho |
|---|---|
| **Create with CloudThinker** | Skill đầu tiên: CloudThinker phỏng vấn bạn và soạn file |
| **Write skill instructions** | Quy tắc bạn đã nắm rõ: form gồm tên, mô tả và hướng dẫn |
| **Upload zip file** | Skill bạn lưu trong repository, hoặc skill kèm script và file tham khảo |
| **Browse Skills Hub** | Skill dựng sẵn từ CloudThinker |

[Skill tùy chỉnh](/vi/guide/skills/custom-skills) có các bước chi tiết. Về bản thân file, xem [Định dạng skill](/vi/guide/skills/skill-format).
