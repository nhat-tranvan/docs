Skills là các gói hướng dẫn giúp biến agent đa năng thành chuyên gia về môi trường của bạn. Bạn chỉ cần viết một lần các thông tin ngữ cảnh của nhóm — tiêu chuẩn code, danh sách kiểm tra review, quy trình xử lý sự cố — và agent sẽ tự động áp dụng chúng cho mọi tác vụ được phân công.

Agent được trang bị kiến thức về các phương pháp tốt nhất nói chung, không phải quy ước riêng của bạn. Skills lấp đầy khoảng trống đó: thay vì phải nhắc lại cùng một quy tắc trong mọi prompt, bạn mã hóa chúng một lần, và kiến thức chuyên môn của một kỹ sư cấp cao trở thành tiêu chuẩn mà cả workspace kế thừa.

## Cách hoạt động

1. **Tạo** — viết file `SKILL.md` thủ công, hoặc mô tả nhu cầu bằng ngôn ngữ thông thường và để AI tạo cho bạn.
2. **Bật** — kích hoạt skill trong workspace của bạn. Skill bị tắt vẫn được lưu nhưng không bao giờ được nạp.
3. **Gán** — giới hạn phạm vi skill cho các tính năng phù hợp: Code Review, Incident, Assessment, hoặc bất kỳ sự kết hợp nào.
4. **Áp dụng** — khi agent thực hiện tác vụ trong một tính năng được gán, nó nạp skill và tuân theo các hướng dẫn song song với hành vi mặc định.

## Bạn có thể làm gì

| Khả năng | Mô tả | Tìm hiểu thêm |
| --- | --- | --- |
| Tạo custom skill | Xây dựng skill riêng cho workspace thủ công hoặc tạo bằng AI từ mô tả ngôn ngữ thông thường | [Custom skills](/vi/guide/skills/custom-skills) |
| Gán cho tính năng | Giới hạn mỗi skill cho Code Review, Incident, hoặc Assessment để chỉ nạp đúng nơi cần thiết | [Custom skills](/vi/guide/skills/custom-skills) |
| Chỉnh sửa với AI | Tinh chỉnh skill hiện có qua hội thoại — thêm ví dụ, loại bỏ sự mơ hồ, tái cấu trúc các phần | [Custom skills](/vi/guide/skills/custom-skills) |

## Skills và knowledge base

Skills cho agent biết cách hành động; [knowledge base](/vi/guide/knowledge) cung cấp thông tin để agent tra cứu. Chúng bổ sung cho nhau — một skill có thể chỉ dẫn agent tham khảo các tài liệu cụ thể.

| | Skills | Knowledge base |
| --- | --- | --- |
| Nội dung | Quy tắc và quy trình mà agent tuân theo | Tài liệu và website mà agent tham khảo |
| Ví dụ | Danh sách kiểm tra review, quy ước đặt tên, chính sách leo thang | Runbook, tài liệu kiến trúc, tài liệu tuân thủ |
| Cách agent sử dụng | Tự động nạp cho các tính năng được gán | Tìm kiếm bằng `#kb` hoặc tự động tham khảo ở chế độ always-available |
| Định dạng | File `SKILL.md` (Markdown với YAML frontmatter) | File tải lên hoặc website được crawl |
| Phù hợp nhất cho | Thay đổi hành vi của agent | Thêm dữ kiện và ngữ cảnh |

Nguyên tắc: nếu agent phải tuân theo mỗi lần chạy, hãy viết skill. Nếu agent chỉ cần tra cứu khi có liên quan, hãy thêm vào knowledge base.
