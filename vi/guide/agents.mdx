CloudThinker đi kèm năm agent chuyên biệt phân tích, báo cáo và hành động trên toàn bộ môi trường cloud của bạn. Mỗi agent phụ trách một lĩnh vực, duy trì bộ nhớ bền vững về hạ tầng của bạn và phối hợp với các agent khác cho công việc liên lĩnh vực.

## Danh sách agent

| Agent | Vai trò | Phù hợp nhất |
|-------|------|----------|
| [**Alex**](/vi/guide/agents/alex) | Cloud Engineer | Phân tích chi phí, tối ưu hạ tầng, kiến trúc đa cloud, dung lượng dự trữ |
| [**Oliver**](/vi/guide/agents/oliver) | Security Engineer | Kiểm toán tuân thủ, đánh giá lỗ hổng bảo mật, xem xét IAM, phát hiện mối đe dọa |
| [**Tony**](/vi/guide/agents/tony) | Database Engineer | Tối ưu truy vấn, điều chỉnh hiệu suất, đề xuất index, lập kế hoạch dung lượng |
| [**Kai**](/vi/guide/agents/kai) | Kubernetes Engineer | Sức khỏe cluster, điều chỉnh kích thước pod, tự động co giãn, kiểm toán RBAC, xử lý sự cố |
| [**Anna**](/vi/guide/agents/anna) | General Manager | Điều phối đa agent, dự án liên lĩnh vực, báo cáo điều hành |

Muốn giọng điệu khác, quyền truy cập hạn chế hoặc agent tùy chỉnh hoàn toàn? Xem [Tùy chỉnh agent](/vi/guide/agents/customize).

## Chọn agent phù hợp

| Bạn cần | Đề cập |
|----------|---------|
| Chi phí cloud quá cao | `@alex` |
| Kiểm toán bảo mật hoặc báo cáo tuân thủ | `@oliver` |
| Chẩn đoán cơ sở dữ liệu chậm | `@tony` |
| Giải quyết vấn đề Kubernetes cluster | `@kai` |
| Vấn đề liên quan nhiều lĩnh vực | `@anna` |
| Điểm khởi đầu khi chưa chắc chắn | `@anna` |

Anna phân phối công việc cho các agent khác, vì vậy cô ấy là lựa chọn mặc định an toàn cho điều tra sự cố và dự án liên lĩnh vực.

## Giao tiếp với agent

<PromptSyntaxBasics />

```text
@alex #dashboard build an EC2 cost dashboard for the last 30 days
@oliver #report audit security groups open to the internet on ports 22, 3306, and 5432
@anna #report run a quarterly infrastructure review across cost, security, and Kubernetes
```

## Cách agent hoạt động

1. **Đọc prompt của bạn** — agent phân tích đề cập của bạn, thẻ tool tùy chọn và hướng dẫn của bạn.
2. **Truy vấn các kết nối của bạn** — agent đọc các [kết nối](/vi/guide/connections/overview) bạn đã cấu hình: AWS, Azure, GCP, Kubernetes cluster, cơ sở dữ liệu và nhiều hơn nữa.
3. **Liên kết dữ liệu từ nhiều nguồn** — Alex tham chiếu chéo mức sử dụng CloudWatch với dữ liệu Cost Explorer; Tony đọc kế hoạch thực thi cùng với tần suất truy vấn.
4. **Cung cấp đầu ra bạn yêu cầu** — dashboard, báo cáo, đề xuất ưu tiên hoặc cảnh báo.
5. **Hành động trong chế độ tự động** — ở chế độ Manual, agent chờ [phê duyệt](/vi/guide/approval) của bạn trước khi thực thi thay đổi. Mọi hành động đều được ghi nhật ký với audit trail.

## Bộ nhớ và ngữ cảnh

Các agent ngày càng chính xác hơn theo thời gian vì chúng lưu giữ những gì học được về môi trường của bạn:

| Loại bộ nhớ | Lưu giữ |
|-------------|-----------------|
| Episodic | Các phân tích và quyết định trong quá khứ, chẳng hạn như tài nguyên bạn đã miễn khỏi đề xuất |
| Working | Ngữ cảnh trong luồng hội thoại hiện tại |
| Semantic | Các mẫu học được về hạ tầng của bạn theo thời gian |
| File | Tài liệu, runbook và mục [cơ sở kiến thức](/vi/guide/knowledge) |

## Khi nào agent kích hoạt

Các agent trở nên khả dụng khi bạn thêm các kết nối liên quan:

| Agent | Khả dụng khi |
|-------|----------------|
| **Anna** | Luôn luôn — không cần kết nối |
| **Alex** | Kết nối AWS, Azure hoặc GCP được thêm vào |
| **Oliver** | Kết nối AWS, Azure hoặc GCP được thêm vào |
| **Tony** | Kết nối PostgreSQL, MySQL hoặc cơ sở dữ liệu khác được thêm vào |
| **Kai** | Kết nối Kubernetes cluster được thêm vào |
