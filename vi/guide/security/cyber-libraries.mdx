Tab **Issues** của một repository [Code Audit](/vi/guide/security/code-audit) liệt kê các thư viện mà nhánh của bạn dùng và khớp với một lỗ hổng đã công bố, bên cạnh các issue trong code. Việc khớp phiên bản và tác động lên chính code của bạn được đánh giá riêng, tách biệt với các issue mã nguồn trên cùng nhánh.

## Điều kiện tiên quyết

- Một repository được Code Audit theo dõi, có file lock hoặc file dependency mà Code Audit đọc được.
- Một lượt audit đã hoàn tất. Lượt audit thu thập các thư viện; việc kiểm tra advisory mới cần bản kiểm kê đó.
- **Run library scan now** và **Open fix pull request** cần vai trò Admin hoặc Developer. Viewer có thể đọc thư viện và báo cáo.

## Cách kiểm tra thư viện hoạt động

- Mỗi lượt audit thu thập các thư viện mà commit được cố định khai báo, kể cả khi phần còn lại của lượt audit thất bại.
- Sau đó, Code Audit tự tiếp tục kiểm tra bản kiểm kê để tìm các advisory mới được công bố, không cần thêm lượt audit nào. Bạn không cần tạm dừng hay tiếp tục việc này.
- Với mỗi advisory khớp, một agent đánh giá xem code của bạn có dùng hành vi bị ảnh hưởng hay không. Agent tìm hiểu advisory trên web công khai, và không bao giờ gửi nội dung repository của bạn trong một lượt tìm kiếm.

Bản kiểm kê liệt kê những gì repository khai báo, không phải những gì đang chạy trên production. Thư viện mà Code Audit không xác nhận được, chẳng hạn package riêng tư hoặc package không có phiên bản chính xác, được đánh dấu là chưa kiểm tra, không phải là an toàn.

## Tìm thư viện trong danh sách Issues

Mở repository từ **Code audit** và chọn tab **Issues**. Đặt bộ lọc **Type** thành **Libraries** để chỉ xem thư viện, hoặc giữ **All types** để xếp hạng thư viện cùng các issue trong code. Mỗi dòng thư viện hiển thị tên, phiên bản và hệ sinh thái, cùng điểm yếu **A06** (thành phần có lỗ hổng).

| Nhãn | Cách đọc |
| --- | --- |
| **Affected** | Thư viện đang mở có kết quả khớp advisory đã được xác nhận |
| **Needs review** | Thư viện đang mở mà lượt kiểm tra chưa kết luận được |
| **Last checked** / **Next check** | Thời điểm kiểm tra advisory gần nhất và lần kiểm tra tiếp theo, hiển thị phía trên danh sách |
| **Collection is incomplete. A clean result cannot be established.** | Một số file dependency không đọc được, nên danh sách trống không phải là bằng chứng an toàn |

## Đọc tác động của một thư viện

Nhấn vào một thư viện để mở trang issue của nó, cũng là trang mà các issue trong code sử dụng. Trang hiển thị **CVE**, hệ sinh thái, dependency và cách nó được dùng, **Matched advisories**, **Source trace**, **Source evidence** và **Verification** của agent.

Advisory khớp cho biết thư viện có thể bị ảnh hưởng. Bước đánh giá đi xa hơn và xem code của bạn có chạm tới hành vi có lỗ hổng hay không. Khi chưa kết luận được, bản đánh giá liệt kê những bằng chứng hoặc điều kiện còn thiếu.

Đánh giá không bị ảnh hưởng không xóa đi kết quả khớp advisory. Issue mã nguồn, bằng chứng về thư viện và bằng chứng [Pentest](/vi/guide/security/security-testing) trả lời ba câu hỏi khác nhau. Chọn **Download Markdown** trong các thao tác của thư viện để chia sẻ.

## Quét ngay hoặc sửa một thư viện

- **Run library scan now**, phía trên danh sách **Issues** của repository, kiểm tra ngay bản kiểm kê đã lưu với các advisory hiện tại. Thao tác này chỉ chạy trên các nhánh đang được theo dõi.
- **Open fix pull request** trên trang issue của một thư viện mở một cuộc chat, trong đó CloudThinker nâng cấp hoặc ghim phiên bản thư viện và mở một pull request để bạn review.
- **Retry library assessment** chạy lại một lượt đánh giá tác động đã thất bại.

Pull request sửa lỗi không thay đổi bằng chứng đã lưu. Lượt audit hoặc lượt kiểm tra thư viện tiếp theo sẽ đọc phiên bản mới.
