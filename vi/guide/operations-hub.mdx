Operations Hub cung cấp các mẫu tác vụ vận hành dựng sẵn được tổ chức theo danh mục. Mỗi tác vụ kết hợp một agent, một thẻ tool và một hướng dẫn đã được kiểm thử — sẵn sàng chạy mà không cần viết prompt từ đầu.

## Định dạng gọi

```text
@agent #tool instruction
```

| Phần | Mô tả |
|---|---|
| `@agent` | Agent chịu trách nhiệm cho tác vụ (Alex, Oliver, Tony, Kai hoặc Anna) |
| `#tool` | Loại đầu ra: `#dashboard`, `#report`, `#recommend`, `#alert`, `#chart` |
| `instruction` | Mô tả tác vụ bằng ngôn ngữ tự nhiên — phạm vi, khung thời gian và bộ lọc đặt ở đây |

Xem [CloudThinker Language](/vi/guide/language) để có tài liệu tham khảo cú pháp đầy đủ.

## Danh mục tác vụ

| Danh mục | Trọng tâm | Agent chính |
|---|---|---|
| Tối ưu chi phí | Điều chỉnh cấu hình, reserved instance, tài nguyên chưa dùng, phân tích chi tiêu | Alex |
| Bảo mật | Kiểm toán, kiểm tra tuân thủ, quét lỗ hổng, xem xét IAM | Oliver |
| Hiệu suất | Phát hiện nút thắt cổ chai, tối ưu truy vấn, phân tích co giãn | Alex, Tony |
| Vận hành | Xác minh sao lưu, tuân thủ vá lỗi, tác vụ bảo trì | Alex |
| Khả năng co giãn | Tự động co giãn, cân bằng tải, lập kế hoạch dung lượng | Alex |
| Kubernetes | Sức khỏe cluster, tối ưu pod, kiểm toán RBAC | Kai |

## Tác vụ mẫu

### Tối ưu chi phí

| Tác vụ | Agent | Prompt mẫu |
|---|---|---|
| Điều chỉnh cấu hình EC2 instance | Alex | `@alex #recommend right-size EC2 instances in us-east-1 over past 30 days` |
| Phạm vi bao phủ reserved instance | Alex | `@alex #report reserved instance coverage vs on-demand spend` |
| Phát hiện EBS volume chưa sử dụng | Alex | `@alex #report unused EBS volumes across all regions` |
| Tối ưu chi phí RDS | Alex, Tony | `@alex @tony #recommend RDS cost reduction for production databases` |

### Bảo mật

| Tác vụ | Agent | Prompt mẫu |
|---|---|---|
| Kiểm toán security group | Oliver | `@oliver #report open security groups exposing public internet access` |
| Xem xét quyền IAM | Oliver | `@oliver #recommend least-privilege IAM policy changes` |
| Kiểm tra quyền truy cập công khai S3 | Oliver | `@oliver #report S3 buckets with public read or write access` |
| Đánh giá tuân thủ SOC 2 | Oliver | `@oliver #report SOC 2 control gaps across AWS account` |

### Hiệu suất

| Tác vụ | Agent | Prompt mẫu |
|---|---|---|
| Phân tích truy vấn chậm | Tony | `@tony #report top slow queries in production RDS over past 7 days` |
| Dashboard hiệu suất cơ sở dữ liệu | Tony | `@tony #dashboard database performance metrics for all RDS instances` |
| Tối ưu auto scaling group | Alex | `@alex #recommend auto scaling policy changes for web tier` |
| Sử dụng tài nguyên EKS | Kai | `@kai #report pod resource utilization across production cluster` |

## Tác vụ tùy chỉnh

Kết hợp bất kỳ agent, thẻ tool và hướng dẫn nào để xây dựng tác vụ vượt ra ngoài danh mục:

```text
@alex #recommend cost optimization for EC2 instances
  in us-east-1
  with <20% CPU utilization
  over past 30 days
  excluding production-critical
```

```text
@anna coordinate security review:
  @oliver audit security groups and IAM
  @alex check for public resources
  @kai review Kubernetes RBAC
```

Xem [CloudThinker Language](/vi/guide/language) để biết cú pháp đa agent và tất cả thẻ tool có sẵn.

## Lập lịch

Để chạy tác vụ theo lịch định kỳ, sử dụng [Tasks](/vi/guide/automation/tasks). Tasks cho phép bạn cấu hình tần suất, phạm vi và tùy chọn thông báo cho bất kỳ tác vụ nào.
