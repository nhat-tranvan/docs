<div className="ct-section">
  <div className="ct-kicker">よくある質問への短い回答</div>
  <h2>自社に合うか？</h2>

| 質問 | 短い回答 | 詳細 |
|---|---|---|
| 何に接続できるか | クラウド（AWS、Google Cloud、Azure）、Kubernetes、Git ホスト（GitHub、GitLab、Bitbucket、Azure DevOps、CodeCommit）、Datadog や PagerDuty などのアラートソース、Terraform などの IaC、Jira などのチケット管理 | [接続カタログ](/ja/guide/connections/overview#接続カタログ) |
| エージェントは何に触れられるか | 接続が許可するものだけです。エージェントは接続の認証情報で読めるものをすべて読めるため、ロールやトークンは見せたい範囲にスコープを絞ってください。接続で **Allow writes** をオフにすると、その接続へのすべての変更が拒否されます。 | [アクセスの仕組み](/ja/guide/connections/overview#アクセスの仕組み) |
| どこで動くか | CloudThinker Cloud（`app.cloudthinker.io` のマネージドサービス）です。[Environments](/guide/workers) はセルフサービスでベータ版です。自分で設定し、自分が管理するマシン上でファイルとシェルの作業を実行します。選択したリージョンの専用クラウド、セルフホスト、エアギャップのデプロイは、デザインパートナープログラムを通じたアーリーアクセスです。このドキュメントでは共有サービスのリージョンを公開していないため、[お問い合わせください](https://cloudthinker.io/contact)。 | [デプロイ](/ja/guide/deployment/overview) |
| どこで使うか | Web アプリ、[CLI](/ja/guide/cli/overview)、[Slack](/ja/guide/slack-integration)、[Google Chat](/guide/google-chat-integration)、[Microsoft Teams](/ja/guide/teams-integration) | |
| 費用はいくらか | Team と Scale は組織単位の月額料金で、メンバー数は無制限、クレジット（エージェントの作業に使う単位）を共有のプールで使います。Team は月額 $99 で 1,000 クレジットです。チャットのメッセージや製品の実行ごとにクレジットを消費します。Free プランでは、Light モデルでのチャット用に毎日 100 の無料クレジットが付与されます。製品の実行は Team から利用できます。 | [料金](/ja/guide/billing/pricing)、[使用量](/ja/guide/billing/usage) |
| 自社向けにどうレビューするか | アイデンティティ、データの取り扱い、アクセス、監査を1か所にまとめています | [セキュリティの概要](/ja/guide/security/overview) |
