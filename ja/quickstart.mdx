---
title: "クイックスタート"
description: "1つのシステムを読み取り専用で接続し、今起きている問題や先週のインシデントを、CloudThinker に約10分で調査させます。"
icon: bolt
---

実際の問題を用意してください。今まさに起きている不具合でも、先週のインシデントでもかまいません。約10分で、CloudThinker があなた自身の環境でそれを調査し、タイムライン、証拠付きの根本原因、そしてあなたが判断する修正案を示します。

<Info>
**必要なもの：** サインインの手段（Google、GitHub、SSO、またはメールアドレス）と、問題が起きた場所への読み取り専用のアクセス（AWS、Google Cloud、Azure のアカウント、または Kubernetes クラスター）。
</Info>

<Steps>
  <Step title="サインインする">
    [app.cloudthinker.io](https://app.cloudthinker.io) にアクセスし、Google、GitHub、SSO、またはメールアドレスでサインインします。これにより、組織と最初のワークスペースが作成されます。

    **成功状態：** チャットボックスのある Home に移動します。
  </Step>

  <Step title="問題が起きた場所を接続する">
    **Settings → Workspace → Connections** を開き、プロバイダーを選んで、読み取り専用のロールで接続します。

    | プロバイダー | セットアップガイド |
    |---|---|
    | AWS | [AWS を接続する](/ja/guide/connections/aws)（CloudShell スクリプトが `ReadOnlyAccess` ロールを作成します） |
    | Kubernetes | [Kubernetes を接続する](/ja/guide/connections/kubernetes)（`get`、`list`、`watch` のみが可能な kubeconfig） |
    | Google Cloud または Azure | [Google Cloud を接続する](/ja/guide/connections/gcp)または [Azure を接続する](/ja/guide/connections/azure) |

    メトリクスやログが [Datadog](/ja/guide/connections/datadog) や [Grafana](/ja/guide/connections/grafana) などの別のツールにある場合は、それも接続してください。

    **成功状態：** 接続に **Connected** と表示されます。
  </Step>

  <Step title="CloudThinker に調査を依頼する">
    **New chat** をクリックし、角括弧の部分を埋めて送信します。

    <Tabs>
      <Tab title="今起きている問題">
        ```text wrap
        Investigate [checkout-api] in [production]: [5xx errors started about 30 minutes ago]. Find the root cause and show the evidence.
        ```
      </Tab>
      <Tab title="先週のインシデント">
        ```text wrap
        Investigate the incident on [Tuesday 14:00 to 15:30 UTC]: [orders failed to process]. Build a timeline, find the root cause, and show the evidence.
        ```
      </Tab>
      <Tab title="まだ分からない">
        ```text wrap
        What's unhealthy in this account right now? Investigate the worst issue.
        ```
      </Tab>
    </Tabs>

    **成功状態：** 環境内の時刻が入った**タイムライン**、それを証明するメトリクス・ログ・変更を伴う**根本原因**、そして**修正案**が返ってきます。
  </Step>

  <Step title="修正について判断する">
    新しいワークスペースは **Auto · Rules + AI · Ask me** で始まります。この設定では、AI の判断で安全な書き込みを確認なしで実行できます。このチャットで承認カードを表示するには、送信ボタンの横にある承認コントロールをクリックし、**Manual** を選びます。

    次に *Apply the fix you proposed* と依頼します。CloudThinker は正確なコマンドを含む承認カードを表示します（**Allow writes** をオフにしている場合は、この接続では書き込みがオフになっていると伝えます）。ここでは **Decline** をクリックしてください。読み取り専用のロールであれば、いずれにしてもプロバイダーが変更を拒否します。

    **成功状態：** 環境内では何も変更されていません。ワークスペースのデフォルトは [Approvals](/guide/approvals/approval-mode) で設定します。
  </Step>
</Steps>

<Tip>
うまくいかない場合は、SSO サインインの問題、接続エラー、**Approve** ボタンが表示されない問題を [Troubleshooting](/guide/troubleshooting) で扱っています。
</Tip>
