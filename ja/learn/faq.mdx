## はじめに

<AccordionGroup>
  <Accordion title="CloudThinker とは何ですか?">
    CloudThinker は Frontier Investigation Agents を構築しています。これらの AI [エージェント](/ja/guide/agents/overview)は、クラウド、コード、ツールに接続し、インシデント、コードのリスク、コストの無駄、セキュリティのギャップの根本原因を突き止め、エンジニアが承認する修正を提案します。

    CloudThinker には、問題の種類ごとに 1 つずつ、4 つのプロダクトがあります。1 つずつ導入できます。

    | プロダクト | すること |
    |---|---|
    | [Resolve](/ja/guide/incident/overview) | インシデントを調査し、証拠とともに根本原因を見つけます |
    | [Review](/ja/guide/code-review/overview) | インラインのコメントと修正の提案でプルリクエストをレビューします |
    | [Cyber](/guide/security/cyber-overview) | テストを許可されたアプリに動的なセキュリティテストを実行し、各検出事項を追跡します |
    | [Optimize](/ja/guide/cost-optimization/overview) | アイドルなリソース、過大なインスタンス、コストの異常をランク付けします |

    3 つの補助的な領域は、自ら何かを調査するのではなく、4 つのプロダクトすべてにまたがって機能します。

    | 領域 | すること |
    |---|---|
    | [Approvals](/guide/approvals/overview) | どのエージェントの変更を単独で実行し、人を待たせ、拒否するかを決めます |
    | [Customize](/ja/guide/agents/customize) | エージェントの作業方法を形作ります: カスタムエージェントとスキル |
    | [Automation](/guide/automation/automations) | スケジュール、Webhook の発火、リポジトリのイベント、プローブのチェックの発火で、プロンプトを実行します |
  </Accordion>

  <Accordion title="最初の答えはどれくらいで得られますか?">
    約 10 分です。[クイックスタート](/ja/quickstart)では、[app.cloudthinker.io](https://app.cloudthinker.io) へのサインイン、1 つのシステムの読み取り専用での接続、最初の質問までを案内します。

    **成功時の状態:** 回答に、あなたの環境で見覚えのあるサービス、リージョン、リソースの名前が示されます。
  </Accordion>

  <Accordion title="本番をリスクにさらさずに試せますか?">
    はい。読み取り専用のロールでステージングやサンドボックスのアカウントを接続し、CloudThinker がすべての変更を拒否するよう、接続で **Allow writes** をオフにしてください。エージェントは見ることはできますが、何も変更できません。[クイックスタート](/ja/quickstart)を参照してください。
  </Accordion>

  <Accordion title="組織とワークスペースの違いは何ですか?">
    **組織** はあなたのアカウントです: プラン、請求、メンバーの一覧、SSO、BYOK、監査ログ。そのロールは Owner、Admin、Developer、Viewer です。**ワークスペース** はその中にあり、実際の作業を保持します: 接続、エージェント、スキル、会話、承認。そのロールは Admin、Developer、Viewer です。

    | 設定の領域 | 対象 | 開き方 |
    |---|---|---|
    | **Settings → Organization** | 組織（Owner と Admin のみ） | ワークスペースメニューまたはアカウントメニューの **Settings** から、**Organization** タブ |
    | **Settings → Workspace** | 今いるワークスペース | サイドバー上部のワークスペースメニューから **Settings** |
    | **Settings → Personal** | あなただけ: プロフィール、2FA、自分のメールの通知 | サイドバー下部のアカウントメニューから **Settings** |

    [組織](/ja/guide/organization)と[ワークスペース](/ja/guide/workspaces)を参照してください。
  </Accordion>

  <Accordion title="チームを招待するにはどうすればよいですか?">
    組織の Owner または Admin が **Settings → Organization → Members** に移動して **Invite people** をクリックするか、サイドバー上部のワークスペースメニューで **Invite members** をクリックします。各人に組織のロールが付与され、**Settings → Workspace → Members** から 1 つのワークスペースで別のロールを与えられます。[メンバーを招待する](/ja/guide/organization#メンバーを招待する)と[ワークスペースのメンバー](/ja/guide/workspace-users)を参照してください。
  </Accordion>

  <Accordion title="CloudThinker はどのシステムに接続できますか?">
    AWS、Google Cloud、Azure などのクラウドに加え、Kubernetes、データベース、オブザーバビリティのツール、Git のプロバイダー、CI/CD、Jira や ServiceNow などのチケットのツールです。それぞれが **接続** です。1 つのサービスの認証情報で、**Settings → Workspace → Connections** で追加します。

    完全な一覧は[接続のカタログ](/ja/guide/connections/overview#接続カタログ)にあります。ツールが一覧にない場合でも、その前で MCP サーバーを動かしていれば、そのサーバーを [MCP 接続](/ja/guide/connections/mcp)として追加でき、エージェントがそのツールを呼び出せます。
  </Accordion>

  <Accordion title="何かをインストールしたり、アーキテクチャを変更したりする必要はありますか?">
    いいえ。CloudThinker はマネージドサービスとして動作し、あなたが付与した認証情報と権限を使って、追加した接続を通じてシステムに到達します。

    ノート PC や CI のランナーなど、自分が管理するマシンでコマンドを実行させたい場合は、[Environment](/guide/workers)（ベータ）を追加できます。これは任意です。エージェントがプライベートリポジトリや社内のホストを必要とする場合に使ってください。Environment は HTTPS で外向きに接続するため、受信ポートを開く必要はありません。

    このドキュメントでは、CloudThinker の送信元 IP アドレスを公開していません。ファイアウォールに許可リストが必要な場合は、[お問い合わせ](https://cloudthinker.io/contact)からご依頼ください。
  </Accordion>

  <Accordion title="Slack や Teams から CloudThinker を使うにはどうすればよいですか?">
    組織の Owner または Admin が **Settings → Organization → Chat integrations** に移動し、**Slack** の行で **Configure** をクリックして、**Connect with Slack** をクリックします。その後、ボットをチャネルに招待します。チャットアプリには Team プラン以上が必要です。Slack と Microsoft Teams では、承認が必要な書き込みは Web アプリにリンクし、そこで承認します。Google Chat では、カード自体に **Approve** と **Reject** のボタンが表示されます。[Slack](/ja/guide/slack-integration)、[Microsoft Teams](/ja/guide/teams-integration)、[Google Chat](/guide/google-chat-integration) を参照してください。
  </Accordion>

  <Accordion title="接続を削除したり、データを消去したりするにはどうすればよいですか?">
    ワークスペースの Admin は、**Settings → Workspace → Connections** から接続を削除できます。接続、会話、設定を含めてワークスペース全体を削除するには、組織の Owner または Admin が **Settings → Organization → Workspaces** を使います。復元はできません。[ワークスペースを削除する](/ja/guide/workspaces#ワークスペースを削除する)を参照してください。
  </Accordion>
</AccordionGroup>

## エージェントと安全性

<AccordionGroup>
  <Accordion title="エージェントとは誰ですか?">
    すべてのワークスペースには、組み込みのエージェント **CloudThinker** が 1 つあります。常に有効で、大きなタスクを一時的なサブエージェントに分割できます。チームは、独自の指示とスキルを持つカスタムエージェントも作成できます。[エージェント](/ja/guide/agents/overview)と [Customize](/ja/guide/agents/customize) を参照してください。
  </Accordion>

  <Accordion title="特別なコマンドを覚える必要はありますか?">
    いいえ。平易な言葉で機能し、メンションがなければ CloudThinker が答えます。任意の 3 つの記号で、リクエストをより正確にできます。

    | 記号 | 選ぶもの | 例 |
    |---|---|---|
    | `@` | エージェント | `@CloudThinker` |
    | `#` | 接続 | `#aws-prod` |
    | `/` | スキル | `/resource-rightsizing-analysis` |

    ```text
    Which EC2 instances in us-east-1 averaged under 5% CPU last week?
    @CloudThinker #aws-prod which RDS instances averaged over 80% CPU yesterday?
    Show last month's cost by service as a dashboard
    ```

    ダッシュボードやレポートなどの出力の形は、言葉で依頼してください。完全な構文: [CloudThinker Language](/guide/commands)。
  </Accordion>

  <Accordion title="エージェントは本番のシステムを単独で変更できますか?">
    あなたが設定した範囲内でのみです。読み取りは常に実行されます。すべての **書き込み**（サービスの再起動など、接続されたシステムを変更するエージェントの呼び出し）は、次のチェックを順に通ります。

    1. **常にブロック**: CloudTrail のログ記録の停止や `kube-system` 名前空間の削除など、決して実行されない呼び出しの組み込みの一覧。何もこれを上書きできません。
    2. あなたの **Rules**。特定の種類の書き込みを許可、先に確認、拒否します。**Manual** の下では、Allow の Rule でも書き込みは実行されず、引き続き人に回ります。
    3. **Approval mode**: **Manual** はすべての書き込みで人に確認します。**Auto** は AI の判断で安全な書き込みを許可し、残りは人に確認するか拒否します。
    4. 承認者。承認または却下します。

    1 つの例外: Review では、**Apply fix** と **Fix all findings** は、人がクリックすると、これらのチェックを通らずにプルリクエストのソースブランチにコミットします。

    Approval mode 自体は有効で、新しいワークスペースは **Auto · Rules + AI · Ask me** で始まります。3 つの部分に分けて読んでください: モードは **Auto**、書き込みは **Rules + AI** の判断で決まり、それでも許可されないものは人を待ちます（**Ask me**）。たとえば、尋ねたばかりのステージングの Pod の再起動は実行できます。RDS のスナップショットの削除は破壊的なため、確認されます。

    書き込みが待機すると、チャットに **Approve** と **Decline** の付いた承認のカードが表示されます。デフォルトでは、ワークスペースの Developer または Admin なら誰でも答えられます。[Approvers](/guide/approvals/approvers) で絞り込んでください。Slack や Microsoft Teams からのリクエストは Web アプリにリンクし、そこで承認します。Google Chat では、カードで承認または拒否できます。

    すべての書き込みで人を必須にするには、ワークスペースを **Manual** に切り替えます。その後、[実行タイプの行](/guide/approvals/approval-mode#set-a-mode-for-a-run-type)で **Automations**（および変更した他の実行タイプ）も **Manual** にオーバーライドします。Automations の行はデフォルトで **Auto · Rules + AI · Refuse** で、ワークスペースには従いません。Automation やチャットも独自のモードを選べます。[Approvals](/guide/approvals/overview) と [Approval mode](/guide/approvals/approval-mode) を参照してください。
  </Accordion>

  <Accordion title="CloudThinker はクラウドでどの権限が必要ですか?">
    始めるには読み取り専用で十分です。2 つの制御が、エージェントにできることを決めます。

    | 制御 | 場所 | 決めること |
    |---|---|---|
    | 認証情報自体の権限 | プロバイダー（IAM ロール、サービスアカウント、API トークンのスコープ） | 上限。エージェントがそれ以上のことをすることはありません。 |
    | **Allow writes** | 接続の詳細パネル | オフ: すべての変更が拒否されます。オン: 変更は Rules と Approval mode を通ります。 |

    推奨される読み取り専用の出発点のロール:

    | クラウド | ロール | セットアップ |
    |---|---|---|
    | AWS | CloudShell で実行するセットアップのスクリプトが作成する、管理ポリシーの `ReadOnlyAccess` | [AWS のセットアップ](/ja/guide/connections/aws#セットアップ) |
    | Google Cloud | **Viewer**（`roles/viewer`）。Optimize には、**BigQuery Data Viewer** と **BigQuery Job User** を追加します。 | [Google Cloud](/ja/guide/connections/gcp) |
    | Azure | サブスクリプションの **Reader** と、支出のための **Cost Management Reader** | [Azure](/ja/guide/connections/azure) |

    **Allow writes** は AWS、Google Cloud、Azure ではデフォルトでオンのため、変更をブロックするのは読み取り専用の認証情報です。CloudThinker でもブロックするには、接続の詳細パネルでスイッチをオフにしてください。書き込みの権限は、エージェントに行わせたい特定の変更にだけ追加してください。[接続](/ja/guide/connections/overview)を参照してください。
  </Accordion>
</AccordionGroup>

## セキュリティとコンプライアンス

<AccordionGroup>
  <Accordion title="CloudThinker はどのデータを保存し、どのように保護されていますか?">
    | データ | 保護の方法 |
    |---|---|
    | 接続の認証情報 | 保存時に暗号化されます。コマンドの実行時に CloudThinker のマネージドのサンドボックスに注入され、[Environment](/guide/workers) に送られることはありません。 |
    | 会話、検出事項、レポート | ワークスペースに限定され、ロールに応じて表示されます。既知のシークレット（接続の認証情報、ワークスペースの認証情報、チャットから保存した値）は、保存前にプレースホルダーに置き換えられます。 |
    | 監査ログ | デフォルトで 365 日保持され、その後自動で削除されます。より長く保持するには CSV にエクスポートします |
    | アカウントのパスワード | bcrypt のハッシュとして保存されます |

    アプリと API は HTTPS で提供されます。モデルの呼び出しは、組織が [BYOK](/ja/guide/byok)（独自の LLM の認証情報を使う）を使っていない限り、CloudThinker の LLM プロバイダーに送られます。BYOK では、AWS Bedrock、Anthropic、OpenAI、Azure OpenAI、Claude Code、Codex など、自社のプロバイダーのアカウントを経由します。

    このドキュメントでは、ホスティングのリージョン、モデルのプロバイダーの名前とデータの条件、学習への利用、会話の保持については説明していません。ベンダーレビューを始める際に、[お問い合わせ](https://cloudthinker.io/contact)からご確認ください。詳細: [セキュリティと信頼](/ja/guide/security/overview)。
  </Accordion>

  <Accordion title="誰かがチャットにシークレットを貼り付けたらどうなりますか?">
    メッセージは送信されません。CloudThinker は、API キー、トークン、パスワード、接続文字列など、認証情報の形をした値をスキャンし、**Review detected secrets** ダイアログを開きます。次のいずれかを選びます。

    | ボタン | 結果 |
    |---|---|
    | **Redact from message** | 各値を `[sensitive data removed]` に置き換えます |
    | **Save secrets**（ワークスペースの Admin のみ） | 各値をワークスペースの認証情報として保存し、メッセージを `$KEY` に書き換えます |

    誤検知は **Mark as not a secret** でマークします。生の値が会話に入ることはありません。[Data protection](/guide/security/data-protection) を参照してください。
  </Accordion>

  <Accordion title="SSO を使い、2FA を強制し、監査証跡を残せますか?">
    | 制御 | 場所 | プラン |
    |---|---|---|
    | 認証アプリ（TOTP） | **Settings → Personal → Security** | すべて |
    | SAML 2.0 または OIDC の SSO、SCIM の同期 | **Settings → Organization → Identity** | Scale、Enterprise |
    | 監査ログ（デフォルトで 365 日保持、CSV のエクスポート） | **Settings → Organization → Audit log** | Scale、Enterprise |

    [シングルサインオン](/ja/guide/security/sso)、[Roles](/guide/security/roles)、[監査ログ](/guide/security/audit-logs)を参照してください。
  </Accordion>

  <Accordion title="CloudThinker はコンプライアンスの認証を取得していますか?">
    認証や証明は、このドキュメントでは公開していません。最新のレポート、セキュリティの質問票、データ処理契約については、[お問い合わせ](https://cloudthinker.io/contact)いただければ、チームが利用可能なものをお送りします。ベンダーレビューの残りに今すぐ答えるには、[セキュリティと信頼](/ja/guide/security/overview)を使ってください。
  </Accordion>

  <Accordion title="CloudThinker を自社の環境の中で実行できますか?">
    デフォルトでは、`app.cloudthinker.io` でマネージドサービスとして動作します。[Environments](/guide/workers) はセルフサービスのベータ版で、ファイルとシェルの作業を自分が管理するマシンで実行します。Dedicated、セルフホスト、エアギャップのデプロイは、デザインパートナープログラムを通じたアーリーアクセスです。[デプロイ](/ja/guide/deployment/overview)を参照してください。
  </Accordion>
</AccordionGroup>

## 料金とプラン

<AccordionGroup>
  <Accordion title="CloudThinker の料金はどのように決まりますか?">
    組織ごとに 1 つの月額料金で、メンバーは無制限です。各有料プランには、すべてのワークスペースで共有される、エージェントの作業が消費する単位である **クレジット** の月間のプールが付きます。プランは Free、Team、Scale、Enterprise です。

    | プラン | 月額料金 | 月間クレジット | ワークスペース |
    |---|---|---|---|
    | Free | 無料 | なし | — |
    | Team | $99 | 1,000 | 3 |
    | Scale | $499 | 5,000 | 10 |
    | Enterprise | 個別のオファー | Pay-As-You-Go | 無制限 |

    組織には、Light モデルでのチャットのための 1 日 100 の無料クレジットも付きます。UTC の午前 0 時にリセットされます。

    各実行は 3 つのモデルのティアのいずれかを使い、それがクレジットの請求に掛かります: 手早い質問には **Light**（0.3x）、日常の作業には **Pro**（1.0x、デフォルト）、最も難しい問題には **Ultra**（1.7x）。

    クレジットがなくなると、さらにクレジットが必要な実行はブロックされます。Team 以上では、Owner が [Pay-As-You-Go](/ja/guide/billing/usage#pay-as-you-go) をオンにできます: 1 クレジットあたり $0.10 の従量課金の追加で、設定した月間の上限までです。現在の料金と上限: [料金](/ja/guide/billing/pricing)。実行がクレジットをどう使うか: [使用量](/ja/guide/billing/usage)。
  </Accordion>

  <Accordion title="Free プランでは何ができますか?">
    Light モデルでの直接のチャットです: Web のチャット、Rooms（他の人と共有するチャット）、CLI からの[ヘッドレスチャット](/ja/guide/cli/headless-chat)。対話型の [CLI エージェント](/ja/guide/cli/overview)には Team 以上が必要です。Review、Resolve、Optimize、Cyber、Automation など、その他の実行は "The Free plan only supports direct chat." で拒否されます。それらと Pro、Ultra のモデルを利用するには、Team 以上にアップグレードしてください。
  </Accordion>

  <Accordion title="無料トライアルはありますか?">
    対象の Free の組織には、Team のカードに **Start 14-day free trial** が表示されます。サイドバー下部のアカウントメニューの **Upgrade plan** から開き、**Continue to add card** をクリックします。開始にはカードが必要ですが、今日の支払いはありません。14 日間、Team の機能を利用できます。Pay-As-You-Go（プールがなくなった後の有料の追加クレジット）は、トライアル中はオフのままです。

    <Warning>
      トライアルが終わると、その後は更新ごとに、カードに自動で請求されます。請求を避けるには、トライアルが終わる前に **Manage in Stripe** でキャンセルしてください。
    </Warning>
  </Accordion>

  <Accordion title="どのプランが必要ですか?">
    | したいこと | 最も低いプラン |
    |---|---|
    | 無料でチャットで CloudThinker を試す | Free |
    | Review、Resolve、Optimize、Cyber を実行する、または Slack、Teams、Google Chat から答える | Team |
    | SSO を使う、監査証跡を残す、BYOK を使う、またはワークスペースごとに支出の上限を設ける | Scale |
    | 自社のインフラで CloudThinker を実行する | Enterprise（アーリーアクセスのデザインパートナープログラムを通じて） |

    プランを変更できるのは、組織の **Owner** だけです。[料金](/ja/guide/billing/pricing)を参照してください。
  </Accordion>
</AccordionGroup>
