CloudThinker Public API は、API トークンを使って 1 つのワークスペースを読み取り、操作する REST API です。トークンは選択したスコープを持ち、ワークスペースでのあなたのロールが許可する範囲を超えることはありません。

初めての方は、[クイックスタート](/guide/api/quickstart)でトークンの作成から最初の呼び出しまで約 5 分で進められます。

## 呼び出せるもの

<ApiAreas />

各呼び出しには 1 つのスコープが必要で、ワークスペースでのロールがそれを許可している必要があります。各エンドポイントのページにはそのスコープが記載されています。スコープの仕組みは [API Tokens](/guide/api/tokens#scopes) で説明しています。エージェントの実行を開始して回答を読み取るには、[Approvals for API Runs](/guide/api/approvals#start-a-run-and-get-its-answer) を参照してください。

別の方法で CloudThinker を呼び出すには、[CloudThinker CLI](/guide/cli/api)、[Claude Connector](/ja/guide/mcp/overview)、ServiceNow などの外部システム向けの [A2A API](/guide/api/a2a)、[Webhooks](/ja/guide/webhooks/overview)、または Okta と Microsoft Entra ID 向けの [SCIM プロビジョニング](/ja/guide/security/scim)を使います。

## 仕組み

- **Base URL:** `https://app.cloudthinker.io/api/public`。パスは `/v1/workspaces/<workspace-id>/{module}/{resource}` の形式です。
- **認証:** 個人用（`ct_pat_…`）、サービスアカウント（`ct_sat_…`）、OAuth（`ct_oat_…`）のトークン、または CLI ログインを使って `Authorization: Bearer <token>` を送ります。各トークンは 1 つのワークスペースで有効です。`GET /v1/token` は、そのワークスペース ID、スコープ、有効期限を返します。
- **形式:** 入出力とも JSON、UTF-8 です。操作で定義されていないボディフィールドを送ると `422` が返ります。OpenAPI 3.1 の仕様は `https://app.cloudthinker.io/api/public/v1/openapi.json` にあり、トークンは不要です。
- **ページング:** 一覧の呼び出しは `limit`（1〜100、デフォルト 20）と `cursor` を受け取ります。ページは `{"items": [...], "next_cursor": "..."}` の形式です。`next_cursor` が `null` になるまで、`next_cursor` を `cursor` として渡します。`limit` とフィルターは同じままにしてください。クエリを変えると `400` `invalid_cursor` が返ります。
- **書き込み:** すべての `POST` には `Idempotency-Key` ヘッダーが必要です。[API Errors](/guide/api/errors#retry-safe-writes) を参照してください。
- **バージョン:** すべてのパスはバージョン `v1` から始まります。破壊的変更は新しいバージョンとしてリリースされます。`v1` の中でも新しいフィールドや操作が追加されることがあるため、認識できないレスポンスフィールドは無視してください。

`GET /v1/token` から `WORKSPACE_ID` を設定して、ワークスペースのインシデントを一覧表示します。

```bash
curl -sS "https://app.cloudthinker.io/api/public/v1/workspaces/$WORKSPACE_ID/resolve/incidents?limit=20" \
  -H "Authorization: Bearer $CLOUDTHINKER_TOKEN"
```
