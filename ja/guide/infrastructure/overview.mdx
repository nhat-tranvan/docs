Infrastructureモジュールは、接続されたすべてのクラウド上のすべてのリソースを一元的に把握し、そこから行動できるエージェントを提供します。コンソールを切り替えることなく、アセットの検出・依存関係の追跡・アーキテクチャの評価・修復の追跡が可能です。

クラウド環境はアカウント・リージョン・プロバイダーをまたいで広がるため、何が動いているか・どうつながっているか・ベストプラクティスに従っているかを一つのコンソールで把握することは困難です。Infrastructure Managementは、[Alex](/ja/guide/agents/alex)・[Oliver](/ja/guide/agents/oliver)・[Kai](/ja/guide/agents/kai)・[Tony](/ja/guide/agents/tony)・[Anna](/ja/guide/agents/anna)が共通して使用する共有インベントリに置き換えることで、コストの急増とその背後にある設定ミスを同じ調査の中で浮かび上がらせます。

## 仕組み

1. **検出** — [Resources](/ja/guide/infrastructure/resources) が接続されたクラウドアカウントをスキャンし、コンピュート・ストレージ・データベース・ネットワークアセットのライブインベントリを維持します。
2. **マッピング** — [Topology](/ja/guide/infrastructure/topology) がそのインベントリから依存グラフを構築し、どのサービスが何に依存しているか、障害の影響範囲を明示します。
3. **評価** — [Assessment](/ja/guide/infrastructure/assessment) がすべての6つの柱をまたいで自動Well-Architectedレビューを実行し、実装手順付きの優先度付き調査結果を生成します。
4. **分析** — [Analytics](/ja/guide/infrastructure/analytics) がクラウドをまたいで健全性・パフォーマンス・コストのシグナルを相関させ、リソースの競合と過剰支出を区別します。
5. **対応** — [Plan](/ja/guide/infrastructure/plan) が調査結果と推奨事項を追跡可能な作業項目に変換し、特定から実装まで追跡します。

## 主な機能

| 機能 | 説明 | 詳細 |
|---|---|---|
| リソースインベントリ | AWS・GCP・Azure全体のすべてのアセットをフィルタリング・タグ付け・対応 | [Resources](/ja/guide/infrastructure/resources) |
| 依存関係マッピング | サービスの関係と影響範囲を追跡してRoot Cause分析を迅速化 | [Topology](/ja/guide/infrastructure/topology) |
| Well-Architectedアセスメント | 6つすべての柱にわたる自動レビューを優先度付き調査結果で実行 | [Assessment](/ja/guide/infrastructure/assessment) |
| クロスクラウド分析 | 健全性・パフォーマンス・コストのシグナルを一つのビューで相関 | [Analytics](/ja/guide/infrastructure/analytics) |
| 作業プランニング | 特定から実装まで調査結果と推奨事項を追跡 | [Plan](/ja/guide/infrastructure/plan) |

<Info>
節約分析や常時監視をお探しですか？コスト推奨事項と節約の追跡は [CostOps](/ja/guide/cost-optimization/overview) にあります。継続的なドリフト・無駄・設定ミスのチェックは [CloudKeepers](/ja/guide/infrastructure/cloudkeepers) として実行されます。
</Info>
