CloudThinker を Claude に接続すると、Claude がワークスペースを読み、CloudThinker のエージェントの実行を開始できるようになります。コネクターはリモートの [Model Context Protocol](https://modelcontextprotocol.io)（MCP）サーバーで、現在接続できるのは Claude のクライアントだけです。

## 前提条件

- 少なくとも 1 つの[ワークスペース](/ja/guide/workspaces)にアクセスできる CloudThinker アカウント
- Claude（claude.ai またはデスクトップアプリ）または Claude Code。コネクターは CloudThinker のプランに縛られませんが、開始した実行はワークスペースのクレジットを使います。
- Claude の Team または Enterprise プランでは、まず Claude の組織のオーナーがコネクターを追加します。その後、各メンバーがそれぞれ接続します。

## Claude を接続する

サーバーの URL はどの方法でも同じです。

```text
https://app.cloudthinker.io/api/mcp
```

<Tabs>
  <Tab title="Claude（Web とデスクトップ）">
    <Steps>
      <Step title="コネクターを追加する">
        Claude で **Customize → Connectors** に移動し、**Add**、続いて **Add custom connector** をクリックします。Team と Enterprise のオーナーは、代わりに **Organization settings → Connectors** を使います。
      </Step>
      <Step title="URL を入力する">
        名前を **CloudThinker** にして、サーバーの URL を貼り付けます。CloudThinker が自分で Claude を識別するため、**Advanced settings** の OAuth Client ID と Client Secret は空のままにします。**Add** をクリックします。
      </Step>
      <Step title="接続して承認する">
        Claude がブラウザで CloudThinker に移動させます。サインインし、ワークスペースを選んで、**Allow** をクリックします。Claude がサインインを開始しない場合は、**Customize → Connectors** でコネクターを開き、接続を選びます。
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude Code">
    <Steps>
      <Step title="サーバーを追加する">
        ```bash
        claude mcp add --transport http cloudthinker https://app.cloudthinker.io/api/mcp
        ```

        これにより、現在のプロジェクトでのみ、あなたのためにサーバーが追加されます。すべてのプロジェクトで使うには `--scope user` を追加します。
      </Step>
      <Step title="サインインする">
        Claude Code で `/mcp` を実行し、**cloudthinker** を選んで、ブラウザの手順に従います。サインインし、ワークスペースを選んで、**Allow** をクリックします。
      </Step>
    </Steps>
  </Tab>
</Tabs>

**成功時の状態:** Claude に CloudThinker が接続済みとして表示されます。Claude に「Which CloudThinker workspace are you using?」と尋ねてください。Claude は `whoami` を呼び出し、選んだワークスペースの名前を答えるはずです。

<Note>
コネクターはまだ Claude の Connectors Directory にはありません。上の URL でカスタムコネクターとして追加してください。
</Note>

## 承認する内容

承認ページには、接続しようとしているアプリと、Claude が戻るホストが表示されます。続いて、Claude が開始するワークスペースと、Claude がそこで何をしてよいかが表示されます。Claude はあなたとして動作します。あなたが所属する他のワークスペースに切り替えることができ、各ツールには引き続き現在のワークスペースでのあなたのロールが必要です。[Claude ができること](#claude-ができること)を参照してください。

Claude が開始した実行は、ワークスペースの [Approval mode](/guide/approvals/approval-mode) に従います。デフォルトの Auto モードでは、AI の判断によって安全な変更があなたに確認せず実行されることがあり、[Allow Rule](/guide/approvals/rules) でも同様です。Manual では、すべての変更であなたに確認します。

Claude からの実行が変更をどう扱うかは、[CloudThinker に調査を依頼する](#cloudthinker-に調査を依頼する)を参照してください。

サインインには通常の CloudThinker のログインを使うため、SSO と MFA が適用されます。複数のワークスペースに所属している場合は、Claude が開始するワークスペースを選びます。後で Claude に切り替えを依頼できます。[ワークスペースを切り替える](#ワークスペースを切り替える)を参照してください。

Claude Code が自分のコンピューターから接続する場合、ページに警告が追加されます。その接続を自分で開始した場合にのみ **Allow** をクリックしてください。

## Claude ができること

Claude は 48 のツールを得ます。ほとんどはデータを読むだけです。`ask_cloudthinker` は実行を開始し、`switch_workspace` は Claude が作業するワークスペースを変更し、5 つのツールはインシデントやオートメーションを変更します。

`get_run` を除くすべての読み取りツールは、ワークスペースの Viewer でも機能します。`ask_cloudthinker` と `get_run` には Developer または Admin のロールが、インシデントやオートメーションを変更するツールには Admin のロールが必要です。インシデント、モニタリング、Review、Optimize、Cyber、アセスメントのツールには、ワークスペースでそのモジュールが有効になっていることも必要です。

**Access** の列は、ツールが読むだけか、何かを変更するかを示します。Claude は各ツールの完全な入力スキーマを見るため、これらの名前を自分で入力することはありません。**Inputs** の列では、太字の名前が必須で、それ以外の入力はすべて任意です。一覧のツールは、特記がない限りデフォルトで 20 件の結果を返します。

### ワークスペース

| ツール | Inputs | Access | 動作 |
| --- | --- | --- | --- |
| `whoami` | なし | 読み取り | Claude が誰として動作しているか、現在作業しているワークスペース、切り替え可能なワークスペースを表示します。 |
| `switch_workspace` | **`workspace_id`**（`whoami` から） | 接続を変更 | Claude を、あなたが所属する別のワークスペースに移します。ワークスペース内では何も変わりません。 |

### インシデント

| ツール | Inputs | Access | 動作 |
| --- | --- | --- | --- |
| `list_incidents` | `status`（リスト）、`severity`（リスト）、`queue`（1 つの調査キュー。`status` か `queue` のどちらかを使い、両方は使いません）、`search`（タイトルのテキスト、最大 200 文字）、`days`（1〜90、デフォルト 30）、`limit`（1〜50） | 読み取り | インシデントと調査を新しい順に一覧表示します。 |
| `get_incident` | **`incident_id`**（完全な ID または 8 文字の短い ID） | 読み取り | 1 つのインシデントを読みます: ステータス、重大度、説明、最新の根本原因分析、修正の提案。 |
| `get_incident_overview` | `days` | 読み取り | 最近の期間のインシデントをキュー、ステータス、重大度別に数え、根本原因までの平均時間を示します。 |
| `list_incident_signals` | **`incident_id`** | 読み取り | 1 つのインシデントの背後にあるアラートと元のイベントを一覧表示します。 |
| `set_incident_status` | **`incident_id`**、**`status`** | データを変更 | 宣言された 1 つのインシデントのステータスを、人がそのページで行うのと同じように変更します。 |
| `set_incident_severity` | **`incident_id`**、**`severity`** | データを変更 | 1 つのインシデントの重大度を変更します。 |

### モニタリング

| ツール | Inputs | Access | 動作 |
| --- | --- | --- | --- |
| `get_monitoring_overview` | なし | 読み取り | 稼働中のモニターの数、最近のインシデントのうちモニターが最初に捉えた数、注意が必要なモニターを読みます。 |
| `list_monitors` | `scope`、`search`、`limit` | 読み取り | CloudThinker があなた自身のアラートと並行して実行するモニターを一覧表示します。 |
| `get_monitor` | **`monitor_id`** | 読み取り | 1 つのモニターを読みます: 存在する理由、チェックの健全性、バックテストの結果、最近の発火。 |
| `list_monitoring_findings` | `severity`、`status`、`search`、`limit` | 読み取り | 古いモニタリングの検出事項を一覧表示します。新しいモニターの発火は、代わりに Resolve のインシデントになります。 |
| `get_monitoring_finding` | **`finding_id`** | 読み取り | 古いモニタリングの検出事項を 1 つ読みます。 |

### エージェントの実行

| ツール | Inputs | Access | 動作 |
| --- | --- | --- | --- |
| `ask_cloudthinker` | **`prompt`**（最大 50,000 文字。CloudThinker は Claude のチャットを見ないため、プロンプトにすべての詳細を含めます） | 実行を開始 | CloudThinker のエージェントの実行を開始し、`run_id` とリンクをすぐに返します。 |
| `get_run` | **`run_id`**（`ask_cloudthinker` から） | 読み取り | `ask_cloudthinker` があなたのために開始した実行のステータスと回答を読みます。 |

## ワークスペースを切り替える

Claude に平易な言葉で依頼します。たとえば「Which CloudThinker workspace are you using?」や「Switch to the Staging workspace」です。Claude は `whoami` を呼び出してワークスペースを一覧表示し、次に `switch_workspace` を呼び出します。以降のすべてのツールの呼び出しは、新しいワークスペースで読み取りと実行の開始を行います。

- **切り替えられるのは、所属しているワークスペースだけです。** CloudThinker は、切り替えと呼び出しのたびにメンバーシップとロールを確認します。
- **切り替えは接続全体に適用されます。** このコネクターを使うすべての Claude のチャットが、新しいワークスペースに移ります。迷ったら Claude に「Which workspace are you using?」と尋ねてください。
- **記録はそのワークスペースにとどまります。** 切り替えた後、Claude は元のワークスペースに戻るまで、古いワークスペースの実行やインシデントを読めません。

## CloudThinker に調査を依頼する

`ask_cloudthinker` は、通常の CloudThinker のエージェントの実行を開始します。ワークスペースにすでにある接続を使います。

- **すぐに返ります。** Claude は実行 ID とリンクを受け取ります。その後、実行が終わったときに `get_run` を呼び出して回答を読みます。
- **クレジットを使います。** 実行はチャットと同様にワークスペースに課金されます。[使用量](/ja/guide/billing/usage)を参照してください。
- **変更はチャットと同様に Approvals を経由します。** Claude からの実行は、ワークスペースの [Approval mode](/guide/approvals/approval-mode) に従います。変更にあなたの判断が必要な場合（Manual では常に、Auto ではルールや AI の判断が許可しない変更の場合のみ）、リンクから CloudThinker で承認するまで実行は待機します。

## アクセスの確認方法

Claude は、現在使っているワークスペース（あなたが選んだもの、または切り替えたもの）で、あなたとして動作します。CloudThinker は呼び出しのたびに次のことを確認します。

- あなたがまだそのワークスペースのメンバーであること。
- あなたのロールにそのツールの権限があること。
- ツールの背後にあるプロダクトのモジュールが有効になっていること。

Claude が、CloudThinker であなたが見られる以上のものを見ることはありません。ツールの結果は Claude の会話に入るため、そのチャットは CloudThinker のデータを貼り付ける他の場所と同じように扱ってください。Claude が開始する各実行は、ワークスペース内の通常の CloudThinker の実行で、Claude はそのリンクを渡します。

## 制限

| 項目 | 制限 |
| --- | --- |
| クライアント | Claude のみ（claude.ai、デスクトップアプリ、Claude Code） |
| 接続あたりのワークスペース | 一度に 1 つ。切り替えると、その接続を使うすべてのチャットが移ります。 |
| 承認ページ | Claude が開いてから 10 分で期限切れになります |
| アクセストークン | 1 時間有効です。Claude が自動で更新します。 |
| サインインの維持 | 接続が 30 日間使われないと、Claude は再度の接続を求めます。 |
| システムへの変更 | チャットと同様に、ワークスペースの Approval mode に従います |

## アクセスを取り消す

CloudThinker で **Settings → Personal → Security** を開き、**Connected apps (MCP clients)** を見つけて、Claude の接続を取り消します。アクセスはすぐに終了します。次の呼び出しは失敗し、Claude は再度の接続をあなたに求める必要があります。

Claude でもコネクターを削除してください。Claude では **Customize → Connectors** で、Claude Code では `claude mcp remove cloudthinker` で削除します。

接続を取り消せるのはあなただけです。ワークスペースの Admin があなたをワークスペースから削除すると、次の呼び出しで Claude のそのワークスペースへのアクセスが終了します。

    Claude が使っているワークスペースのメンバーではなくなったか、ワークスペースがなくなりました。あなたが所属する別のワークスペースに切り替えるよう Claude に依頼してください。それが失敗する場合は、切断して再度接続し、アクセスできるワークスペースを選びます。
  </Accordion>
  <Accordion title="This CloudThinker role lacks a permission">
    メッセージに不足している権限が示されます。ワークスペースの Admin に、その権限を付与するか、[ロール](/ja/guide/workspace-users)を変更するよう依頼してください。
  </Accordion>
  <Accordion title="実行が承認待ちになっている">
    Claude が実行を待機中と報告しました。Claude が渡したリンクを開き、CloudThinker で変更を承認または拒否します。Claude に実行を再度確認するよう依頼してください。
  </Accordion>
  <Accordion title="ワークスペースのクレジットが不足して実行が失敗した">
    クレジットを追加するか、ワークスペースの上限を引き上げます。[使用量](/ja/guide/billing/usage)と[クレジット上限](/guide/billing/credit-limits)を参照してください。その後、再度依頼します。
  </Accordion>
  <Accordion title="接続のリクエストが無効、または期限切れ">
    承認ページは 10 分後に期限切れになります。Claude に戻って再度接続してください。
  </Accordion>
  <Accordion title="ツールがモジュールがオフになっていると表示する">
    管理者がそのプロダクトのモジュールをオフにしています。オンにするよう依頼してください。
  </Accordion>
</AccordionGroup>
