<Note>
**プレビュー** — CloudThinker MCP サーバーは早期アクセス段階です。ツールのインターフェースとトランスポートオプションは一般提供前に変更される場合があります。プレビューへの参加は[こちらからお問い合わせ](https://cloudthinker.io/contact)ください。
</Note>

CloudThinker は [Model Context Protocol](https://modelcontextprotocol.io)（MCP）サーバーとして動作でき、MCP 対応の AI クライアントがワークスペースの認証済みコンテキストを使って CloudThinker のツールを呼び出したり、CloudThinker のデータを読み取ったりできます。

これは、CloudThinker エージェントが _外部の_ MCP サーバーを呼び出せるようにする既存の [MCP コネクション](/ja/guide/connections/mcp)とは逆の関係です。

---

## できること

| 機能 | 説明 |
| --- | --- |
| IDE でのクラウド運用 | Cursor、Claude Desktop、または任意の MCP クライアントから AWS、GCP、Azure のインベントリとコストを照会する |
| 既存コネクションの活用 | CloudThinker に接続済みのデータベース、Kubernetes クラスター、オブザーバビリティツールにアクセスする |
| Skills のリモート実行 | MCP 対応ホストからワークスペースの [Skills](/ja/guide/skills/overview) を呼び出す |
| 共有コンテキスト | ウェブコンソールと同じ方法で推奨事項、ダッシュボード、インシデントメモリを読み取る |

---

## 公開されるツール

MCP サーバーはエージェント機能のうち厳選されたサブセットを提供します。

| ツールファミリー | 機能 |
|-------------|--------------|
| `resources.*` | 統合リソースインベントリとトポロジーの照会 |
| `recommendations.*` | 最適化推奨事項の一覧表示、承認、却下、コメント |
| `costs.*` | クラウドアカウント横断のコスト照会と予測の実行 |
| `incidents.*` | インシデントの作成、シグナルの添付、RCA 結果の読み取り |
| `dashboards.*` | 組み込みおよびカスタムダッシュボードの読み取り |
| `skills.*` | パラメータ付きでワークスペースの Skills を実行 |

ツールの正確な一覧は MCP ディスカバリーを通じて公開されます — クライアントはワークスペース API キーが使用を許可されているツールを確認できます。

---

## トランスポート

| トランスポート | 最適なユースケース |
|-----------|----------|
| **HTTP + SSE** | クラウドホスト型クライアント、リモートエージェント、チーム共有のセットアップ |
| **stdio** | ローカルプロキシ経由で起動するローカル IDE とデスクトップアプリ（Claude Desktop、Cursor、Windsurf） |

---

## 認証

MCP サーバーは、REST API と同じワークスペース [API キー](/ja/guide/api/overview)で認証します。キーは単一のワークスペースにスコープされ、発行したメンバーのロールを継承します。
