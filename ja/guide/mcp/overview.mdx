CloudThinker を Claude に接続すると、Claude がワークスペースを読み取り、CloudThinker のエージェント実行を開始できます。このコネクタはリモートの [Model Context Protocol](https://modelcontextprotocol.io)（MCP）サーバーで、現在接続できるのは Claude のクライアントだけです。

## 前提条件

- 少なくとも 1 つの[ワークスペース](/ja/guide/workspaces)にアクセスできる CloudThinker アカウント
- Claude（claude.ai またはデスクトップアプリ）または Claude Code
- Claude の Team または Enterprise プランでは、まず Claude 組織のオーナーがコネクタを追加します。その後、各メンバーが個別に接続します。

## Claude を接続する

サーバー URL はどの方法でも同じです。

```text
https://app.cloudthinker.io/api/mcp
```

<Tabs>
  <Tab title="Claude（Web とデスクトップ）">
    <Steps>
      <Step title="コネクタを追加する">
        Claude で **Customize → Connectors** を開き、**Add**、**Add custom connector** の順にクリックします。Team と Enterprise のオーナーは、代わりに **Organization settings → Connectors** を使います。
      </Step>
      <Step title="URL を入力する">
        名前を **CloudThinker** にし、サーバー URL を貼り付けて **Continue** をクリックします。検出された認証設定はそのままにして、**Add** をクリックします。
      </Step>
      <Step title="接続して承認する">
        Claude がブラウザーで CloudThinker を開きます。サインインし、ワークスペースを選んで **Allow** をクリックします。Claude がサインインを開始しない場合は、**Customize → Connectors** でコネクタを開き、接続を選びます。
      </Step>
    </Steps>
  </Tab>
  <Tab title="Claude Code">
    <Steps>
      <Step title="サーバーを追加する">
        ```bash
        claude mcp add --transport http cloudthinker https://app.cloudthinker.io/api/mcp
        ```
      </Step>
      <Step title="サインインする">
        Claude Code で `/mcp` を実行し、**cloudthinker** を選んで、ブラウザーの手順に従います。サインインし、ワークスペースを選んで **Allow** をクリックします。
      </Step>
    </Steps>
  </Tab>
</Tabs>

**成功の目安:** Claude に CloudThinker が接続済みとして表示され、チャットでそのツールを使えます。

<Note>
このコネクタは、まだ Claude の Connectors Directory に掲載されていません。上の URL でカスタムコネクタとして追加してください。
</Note>

## 承認する内容

承認ページには、接続するアプリの名前と、Claude が戻る先のホストが表示されます。続いて、1 つのワークスペースと 3 つの権限が表示されます。

- Read incidents, costs, code reviews, automations, and security findings in this workspace
- Start CloudThinker runs that ask you before any change
- Act only as you, in the workspace you pick here

サインインには通常の CloudThinker ログインを使うため、SSO と MFA が適用されます。複数のワークスペースに所属している場合は、1 つ選びます。接続はそのワークスペースに紐づきます。別のワークスペースを使うには、もう一度接続します。

Claude Code が自分のコンピューターから接続する場合、ページに警告が追加されます。その接続を自分で開始した場合だけ **Allow** をクリックしてください。

## Claude にできること

Claude は 20 個のツールを使えます。19 個はデータの読み取り専用です。残りの 1 つ、**Ask CloudThinker** は実行を開始します。

### インシデント

| ツール | できること |
| --- | --- |
| `list_incidents` | インシデントと調査を新しい順に一覧表示します。ステータス、重大度、テキストで絞り込めます。 |
| `get_incident` | 1 件のインシデントを読み取ります。ステータス、重大度、最新の根本原因分析、推奨される修正が含まれます。 |

### エージェント実行

| ツール | できること |
| --- | --- |
| `ask_cloudthinker` | リクエストから CloudThinker のエージェント実行を開始します。 |
| `get_run` | Claude が開始した実行のステータスと回答を読み取ります。 |

### Automation

| ツール | できること |
| --- | --- |
| `list_automations` | スケジュール型とイベント型の Automation を一覧表示します。 |
| `get_automation` | 1 件の Automation の指示、トリガー、スケジュール、最近の実行を読み取ります。 |
| `list_automation_runs` | 1 件の Automation の過去の実行を一覧表示します。 |

### Review

| ツール | できること |
| --- | --- |
| `list_code_reviews` | Review がチェックしたマージリクエストとプルリクエストを一覧表示します。 |
| `get_code_review` | 1 件のレビューと、ファイル、行、修正案を含む検出結果を読み取ります。 |

### Optimize

| ツール | できること |
| --- | --- |
| `list_cost_connections` | CloudThinker が分析するクラウド請求アカウントを一覧表示します。 |
| `get_cost_overview` | 今月の支出、予測、上位サービス、上位の削減額を読み取ります。 |
| `list_cost_findings` | 未対応の削減の検出結果を、削減額の大きい順に一覧表示します。 |
| `get_cost_finding` | 1 件の削減の検出結果と、その分析を読み取ります。 |
| `list_cost_anomalies` | コストの急増を、影響の大きい順に一覧表示します。 |

### Cyber

| ツール | できること |
| --- | --- |
| `list_security_apps` | ペネトレーションテスト対象のアプリを一覧表示します。 |
| `get_security_app_coverage` | 1 つのアプリのペネトレーションテストがカバーできる範囲と、妨げになる点を読み取ります。 |
| `get_security_finding` | 1 件のペネトレーションテストの検出結果を読み取ります。 |
| `list_code_audit_branches` | Code Audit の対象になっているリポジトリのブランチを一覧表示します。 |
| `get_code_audit_branch` | 1 つのブランチの最新の監査とセキュリティの検出結果を読み取ります。 |
| `get_code_audit` | 1 回の Code Audit の実行について、ステータス、結果、失敗内容を読み取ります。 |

## CloudThinker に調査を依頼する

`ask_cloudthinker` は、通常の CloudThinker エージェント実行を開始します。ワークスペースにある既存のコネクションを使います。

- **すぐに返ります。** Claude は実行 ID とリンクを受け取ります。実行が終わったら、Claude が `get_run` を呼んで回答を読みます。
- **クレジットを消費します。** 実行は、チャットと同じようにワークスペースに課金されます。[使用状況](/ja/guide/billing/usage)を参照してください。
- **変更の前に必ず確認します。** Claude から開始した実行は、ワークスペースが [Auto Mode](/ja/guide/auto-mode) でも Manual 承認を使います。変更は、リンク先の CloudThinker で承認するまで待機します。[承認](/ja/guide/approval)を参照してください。

## プロンプトの例

接続したら、Claude に次のように入力します。

```text
What incidents are open in production, and what caused the latest one?
```

```text
Which cost savings findings in CloudThinker are worth the most per month? Show the top five with the evidence for each.
```

```text
List the code review findings from the last week with high severity, and tell me which ones are still unresolved.
```

```text
Ask CloudThinker to investigate why checkout latency rose after yesterday's deploy, and tell me what it finds.
```

## アクセスの確認方法

Claude は、あなたが選んだ 1 つのワークスペースで、あなたとして動作します。CloudThinker は呼び出しのたびに次を確認します。

- あなたがまだワークスペースのメンバーであること。
- あなたのロールに、そのツールの権限があること。
- そのツールの元になっているプロダクトモジュールが有効であること。

Claude は、CloudThinker であなたが見られる範囲を超えて見ることはありません。

## アクセスを取り消す

CloudThinker で **Account settings → Connected apps** を開き、Claude の接続を取り消します。アクセスはすぐに終了します。次の呼び出しは失敗し、Claude は再度の接続を求めます。

Claude 側のコネクタも削除してください。Claude では **Customize → Connectors** から、Claude Code では `claude mcp remove cloudthinker` で削除します。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Access to this CloudThinker workspace was removed">
    接続したワークスペースのメンバーではなくなったか、ワークスペースが削除されています。接続を解除してもう一度接続し、アクセスできるワークスペースを選んでください。
  </Accordion>
  <Accordion title="This CloudThinker role lacks a permission">
    メッセージに不足している権限の名前が表示されます。ワークスペース管理者に、その権限の付与、または[ロール](/ja/guide/workspace-users)の変更を依頼してください。
  </Accordion>
  <Accordion title="実行が承認待ちになっている">
    Claude が実行を承認待ちと報告しています。Claude が示したリンクを開き、CloudThinker で変更を承認または却下します。その後、Claude に実行をもう一度確認してもらってください。
  </Accordion>
  <Accordion title="ワークスペースのクレジットが不足して実行が失敗した">
    クレジットを追加するか、ワークスペースの上限を引き上げてください。[使用状況](/ja/guide/billing/usage)を参照してください。その後、もう一度依頼します。
  </Accordion>
  <Accordion title="接続リクエストが無効、または期限切れ">
    承認ページの有効期限は 10 分です。Claude に戻って、もう一度接続してください。
  </Accordion>
  <Accordion title="ツールがモジュールはオフだと返す">
    管理者がそのプロダクトモジュールをオフにしています。オンにするよう管理者に依頼してください。
  </Accordion>
</AccordionGroup>
