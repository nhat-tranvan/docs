Team と Scale は組織単位の月額固定料金プランで、メンバー数は無制限です。クレジットは組織内のすべてのワークスペースで共有します。

## プランを選ぶ

| | **Team** | **Scale** | **Enterprise** |
|---|---|---|---|
| **月額料金（チーム全体）** | $99 | $499 | 個別見積もり |
| **月間クレジット** | 1,000 | 5,000 | Pay-As-You-Go |
| **メンバー** | 無制限 | 無制限 | 無制限 |
| **ワークスペース** | 3 | 10 | 無制限 |
| **専用サンドボックスのサイズ** | 中規模 | 大規模 | カスタム |
| **デプロイ** | SaaS | SaaS | Self-host / BYOC |
| **BYOK** | — | ✓ | ✓ |
| **SSO / SCIM** | — | ✓ | ✓ |
| **監査ログ** | — | ✓ | ✓ |
| **従量課金** | ✓ | ✓ | ✓ |
| **サポート** | メールサポート | 優先サポート | 専任サポート |
| **SLA** | — | 99.9% | 99.95% |

メンバーを追加しても、月額料金や毎月のクレジット割り当ては変わりません。Enterprise の料金については[お問い合わせください](https://cloudthinker.io/contact)。

## 無料アクセス

Free では、Light モデルのチャットに使える無料クレジットが毎日100クレジット付与されます。このクレジットは組織全体で共有します。
