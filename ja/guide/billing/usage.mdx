クレジットは AI エージェント操作の通貨です。エージェントとのやり取りは、複雑さに応じてクレジットを消費します。

## クレジットの仕組み

クレジットはプランに含まれており、すべてのエージェント会話と API 使用に適用されます。

- すべてのプランで**毎日100クレジットが無料**で付与され、毎日リセットされます。**Light モデルとチャット専用**です。
- **プレミアムクレジット**（プランの席数ごとの割り当て）は**全モデルと全機能**を解放します — すべてのアプリ機能（エージェント、Code Review、インシデント RCA、ダッシュボード、連携、API 使用）にわたる Light・Pro・Ultra の各モデルティアが使えます。

## 消費順序

クレジットを使用すると、次の順序で消費されます。

<Steps>
  <Step title="毎日クレジット">
    毎日リセットされる100クレジットの無料枠で、**Light モデルとチャット専用**です。全プランで利用可能です。
  </Step>
  <Step title="ボーナスクレジット">
    紹介や特別オファーによるプロモーションクレジットです。**全モデル**で使用可能で、**有効期限はありません**。
  </Step>
  <Step title="プレミアムクレジット">
    プランの席数ごとのクレジット割り当てで、請求サイクルごとにリセットされます。毎日クレジットとは異なり、プレミアムクレジットは**全モデル**（Light、Pro、Ultra）と**すべてのアプリ機能**で使用可能で、モデルや機能の制限はありません。
  </Step>
  <Step title="Pay-As-You-Go">
    他のすべてのクレジットを使い切った際の自動トップアップです。$0.10/クレジットで課金されます。[PAYG](#pay-as-you-go) が有効な場合のみ。
  </Step>
</Steps>

**管理設定 > 使用状況** から、残高・当期使用量・使用履歴・トランザクション履歴をリアルタイムで確認できます。

## Pay-As-You-Go

重要な操作中にクレジットが切れることはありません。Pay-As-You-Go（PAYG）は、他のすべてのクレジットを使い切った際に自動的に起動します。

|                        | 詳細                                                                              |
| ---------------------- | --------------------------------------------------------------------------------- |
| **レート**             | クレジットあたり $0.10                                                            |
| **利用可能プラン**     | Team、Scale、Scale +、Enterprise プラン                                           |
| **支出上限**           | 月間上限を独自に設定できます — 最低 \$100、最大値はプランティアによって異なります |
| **請求方式**           | 従量制 — 各請求サイクルの終了時に実際に使用した分のみ課金されます                |
| **制御**               | サブスクリプション設定からいつでも有効・無効を切り替えられます                    |

<Warning>
  PAYG は Free プランでは利用できず、トライアル期間中はロックされます。
  有効にするには Team 以上にアップグレードしてください。
</Warning>

### PAYG の有効化・無効化

1. **管理設定 > 請求** に移動する
2. **Pay-As-You-Go** を開く
3. PAYG をオン（またはオフ）に切り替える
4. 確認する — 変更はすぐに反映されます

### 支出上限の設定

月間上限は、1回の請求サイクルで PAYG が請求できる金額を制限します。上限に達すると、次のサイクルまで PAYG は停止します。

1. **管理設定 > 請求 > Pay-As-You-Go** で**月間上限**を設定する
2. 最低上限は **\$100/月**、最高値はプランティアによって異なり、プランのデフォルト上限が事前入力されています
3. 保存する — 上限を超えた使用は次の請求サイクルまでブロックされます

<Info>
  上限は請求サイクルごとに設定され、各サイクルでリセットされます。サイクル途中での上限引き下げは、すでに発生した使用分の返金には適用されません。
</Info>
