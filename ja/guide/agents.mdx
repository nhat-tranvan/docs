CloudThinker は、クラウド環境全体を分析、レポート、操作する 5 つの専門エージェントを備えています。各エージェントはドメインを担当し、インフラの永続的なメモリを保持し、クロスドメインの作業では他のエージェントと連携します。

## エージェント一覧

| エージェント | ロール | 得意な作業 |
|-------|------|----------|
| [**Alex**](/ja/guide/agents/alex) | クラウドエンジニア | コスト分析、インフラ最適化、マルチクラウドアーキテクチャ、予約キャパシティ |
| [**Oliver**](/ja/guide/agents/oliver) | セキュリティエンジニア | コンプライアンス監査、脆弱性評価、IAM レビュー、脅威検出 |
| [**Tony**](/ja/guide/agents/tony) | データベースエンジニア | クエリ最適化、パフォーマンスチューニング、インデックス推奨、キャパシティプランニング |
| [**Kai**](/ja/guide/agents/kai) | Kubernetes エンジニア | クラスターヘルス、ポッドの適正サイズ化、オートスケーリング、RBAC 監査、トラブルシューティング |
| [**Anna**](/ja/guide/agents/anna) | ゼネラルマネージャー | マルチエージェント調整、クロスドメインプロジェクト、エグゼクティブレポート |

トーンの変更、アクセス制限、または完全なカスタムエージェントが必要な場合は [エージェントのカスタマイズ](/ja/guide/agents/customize) をご覧ください。

## 適切なエージェントを選ぶ

| 必要な作業 | 使うエージェント |
|----------|---------|
| クラウドコストが高すぎる | `@alex` |
| セキュリティ監査またはコンプライアンスレポート | `@oliver` |
| 遅いデータベースの診断 | `@tony` |
| Kubernetes クラスターの問題解決 | `@kai` |
| 複数のドメインにまたがる問題 | `@anna` |
| どこから始めればいいかわからない | `@anna` |

Anna は他のエージェントに作業を割り振るため、インシデント調査やクロスドメインプロジェクトの安全なデフォルトとして機能します。

## エージェントと話す

<PromptSyntaxBasics />

```text
@alex #dashboard build an EC2 cost dashboard for the last 30 days
@oliver #report audit security groups open to the internet on ports 22, 3306, and 5432
@anna #report run a quarterly infrastructure review across cost, security, and Kubernetes
```

## エージェントの仕組み

1. **プロンプトを読む** — エージェントがメンション、オプションのツールタグ、指示を解析します。
2. **接続を照会する** — エージェントが設定した [接続](/ja/guide/connections/overview) (AWS、Azure、GCP、Kubernetes クラスター、データベースなど) を読み取ります。
3. **ソース間でデータを照合する** — Alex が CloudWatch の使用率と Cost Explorer のデータを相互参照し、Tony がクエリの頻度とともに実行計画を読み取ります。
4. **要求された出力を提供する** — ダッシュボード、レポート、優先順位付きの推奨事項、またはアラートを返します。
5. **自律モードの範囲内で行動する** — Manual モードではエージェントが変更を実行する前に [承認](/ja/guide/approval) を待ちます。すべてのアクションは監査証跡とともに記録されます。

## メモリとコンテキスト

エージェントは環境について学習した内容を保持するため、時間の経過とともに精度が向上します:

| メモリの種類 | 保持する内容 |
|-------------|-----------------|
| エピソード | 過去の分析と決定 (推奨事項から除外したリソースなど) |
| ワーキング | 現在の会話スレッド内のコンテキスト |
| セマンティック | 時間をかけてインフラについて学習したパターン |
| ファイル | ドキュメント、ランブック、[ナレッジベース](/ja/guide/knowledge) のエントリ |

## エージェントが有効になるタイミング

エージェントは関連する接続を追加すると利用可能になります:

| エージェント | 有効になる条件 |
|-------|----------------|
| **Anna** | 常時 — 接続不要 |
| **Alex** | AWS、Azure、または GCP 接続が追加されたとき |
| **Oliver** | AWS、Azure、または GCP 接続が追加されたとき |
| **Tony** | PostgreSQL、MySQL、またはその他のデータベース接続が追加されたとき |
| **Kai** | Kubernetes クラスター接続が追加されたとき |
