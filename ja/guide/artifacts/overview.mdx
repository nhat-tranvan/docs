アーティファクトとは、CloudThinker が会話の中で作成する、保存されバージョン管理される出力です。レポート、ダッシュボード、生成されたファイルのいずれかです。平易な言葉で依頼すると、CloudThinker が[接続](/ja/guide/connections/overview)にクエリを実行し、結果が **Library** に保存されます。ワークスペースのメンバーはそこで開き、ダウンロードし、共有できます。Library には Docs も保存されます。

## 前提条件

- アーティファクトに含めたいデータを持つ[接続](/ja/guide/connections/overview)が少なくとも 1 つ（たとえばコストなら AWS、クエリ性能ならデータベース）
- ライブデータ（**Use live data**、**Refresh**）を使う場合は有料[プラン](/ja/guide/billing/pricing)。Free プランでは、アーティファクトは公開時のスナップショットのみを表示します。
- 実行したい操作が許可された[ワークスペースロール](/ja/guide/workspace-users):

| 操作 | Admin | Developer | Viewer |
|---|---|---|---|
| 会話でアーティファクトを作成する | Yes | Yes | No |
| アーティファクトを開いてダウンロードする | Yes | Yes | Yes |
| ライブデータを実行する（**Use live data**、**Refresh**） | Yes | Yes | No |
| 公開リンクを作成またはオフにする | Yes | Yes | No |

デフォルトでは、ワークスペースのすべてのメンバーがすべてのアーティファクトを開けます。オーナーは **Share** の **General access** で **Only people with access** に絞り込めます。共有フィルターの **Private** は、そのアーティファクトに公開リンクがないことを意味します。

## アーティファクトの種類

| 種類 | 内容 | 表示場所 |
|---|---|---|
| **Report** | 表、グラフ、検出事項、推奨事項を含む文章による分析 | **Visuals** タブ |
| **Dashboard** | 関連するメトリクスとグラフを 1 ページにまとめたビュー | **Visuals** タブ |
| **File** | CloudThinker が会話で生成し、あなたが保存を選んだファイル（CSV やスクリプトなど） | **Files** タブ |

レポートとダッシュボードはすべてバージョンとして保存されます。CloudThinker が更新すると新しいバージョンを公開し、古いバージョンはそのまま残ります。

## アーティファクトを作成する

<Steps>
  <Step title="出力の形を言葉で依頼する">
    会話を開始し、何をどの形式で欲しいかを伝えます。特別な構文は不要です。

    ```text
    Build a dashboard of AWS spend by service for the last 30 days, with the top 10 cost drivers and month-over-month change.
    ```

    ```text
    Write a report on Aurora cluster prod-aurora: p50, p95 and p99 query latency over the past 7 days, split by reads and writes, with queries over 200 ms called out.
    ```

    リクエストを 1 つのアカウントに限定するには、`#` を入力して接続を選びます。

    ```text
    #aws-production Build a dashboard of EC2 and RDS spend for the last 30 days.
    ```

    **成功時の状態:** CloudThinker が会話内にアーティファクトカードを返します。クリックすると会話内でアーティファクトパネルが開きます（**View fullscreen** で拡大します）。CloudThinker がまだ作成中の間、カードの操作には **Available after this artifact finishes** と表示されます。
  </Step>
  <Step title="同じ会話で改善する">
    「`team` タグ別の内訳を追加して」「直前の 30 日間と比較して」など、変更をフォローアップで依頼します。

    **成功時の状態:** CloudThinker が新しいバージョンを公開します。すでにアーティファクトを開いている場合は、**Version N is available** という通知が **Show vN** ボタンとともに表示されます。ビューが自動でバージョンを切り替えることはありません。
  </Step>
  <Step title="生成されたファイルを保存する（任意）">
    CloudThinker が会話でファイルを生成したら、そのファイルカードの **Save to artifacts** をクリックします。もう一度クリック（**Remove from artifacts**）すると取り消せます。

    **成功時の状態:** ファイルが Library の **Files** タブに表示されます。
  </Step>
</Steps>

<Tip>
期間、グループ化の単位（サービス、アカウント、タグ）、比較期間を指定してください。省略した部分は CloudThinker が選ぶため、目的の切り口にするにはフォローアップが必要になることがあります。
</Tip>

## バージョン

バージョンピッカー（**v1**、**v2** など）はアーティファクトページの右上にあります。任意のバージョンを選んで閲覧できます。古いバージョンは公開時のスナップショットのみを表示し、ライブデータは現在のバージョンで実行されます。

復元ボタンはありません。以前の切り口に戻したい場合は、同じ会話で CloudThinker に依頼すると、それを新しいバージョンとして公開します。

## Library でアーティファクトを探す

サイドバーで **More → Library** をクリックするか、[app.cloudthinker.io/library](https://app.cloudthinker.io/library) にアクセスします。

| コントロール | オプション |
|---|---|
| タブ | **All**、**Docs**、**Visuals**（レポートとダッシュボード）、**Files** |
| 表示 | **Recent**、**All**、**Shared with me**、**Private**、**Trash** |
| 検索 | **Search library** で入力に合わせて一覧を絞り込みます |
| フィルター | 共有（**Shared** または **Private**）と **Category** |
| 並べ替え | **By source**、**Newest**、**Recently updated**、**Title** |
| ビュー | **Grid** または **List** |

CloudThinker はアーティファクトを作成するときに短いカテゴリラベルを付けます。固定の一覧はないため、**Category** フィルターにはワークスペースで使われているラベルだけが表示されます。独自の方法でグループ化したい場合は、リクエストでカテゴリ名を指定してください。カード上のカテゴリタグをクリックすると、そのカテゴリで絞り込めます。

カードを開くと、アーティファクトが専用ページに表示されます。レポートとダッシュボードには、ページ上部に **Download**、**More actions**（⋯）メニューに **Download PDF** があり、その隣の **Open publishing conversation** で作成元のチャットに戻れます。保存したファイルは、**Files** タブのカードにある **Download** を使います。

## アーティファクトを管理する

アーティファクトを削除するには、**More actions**（⋯）を開いて **Move to trash…** をクリックします。**Trash** に 30 日間残った後に完全に削除され、復元するまでユーザーはアクセスできなくなります。**Trash** で **Restore** をクリックすると元に戻り、**Delete forever** をクリックするとすべてのバージョン、ファイル、公開リンクがすぐに削除されます。古いバージョンはバージョンピッカーで引き続き閲覧できます。外部に出すべきでないデータを含むアーティファクトは、まず[公開リンク](/guide/sharing#revoke-a-link)をオフにしてください。保存したファイルを Library から外すには、**Files** タブのカードで **Remove from artifacts** をクリックします。これではファイルの公開リンクはオフにならないため、ファイルを外す前にオフにしてください。CloudThinker が機密データをどう扱うかは [Data protection](/guide/security/data-protection) を参照してください。

## スナップショットとライブデータ

レポートやダッシュボードはスナップショットとともに公開されます。これは、そのバージョンが公開された時点のデータです。アーティファクトページ上部のピルで、どのデータを見ているかが分かります。

| ピル | 意味 | できること |
|---|---|---|
| **Snapshot** | 公開時のデータを、その「Data from」時刻とともに表示しています | **Use live data** をクリックするか、フィルターを変更すると、アーティファクトのクエリが現在のデータに対して実行されます |
| **Live** | たった今、接続に対してクエリが実行されました | **Refresh** をクリックすると再実行します |
| **Paused** | ページで一定時間（15 分）操作がなかったため、ライブデータのポーリングが停止しました | **Resume** をクリックします |
| **Refresh failed** | 前回の実行が失敗したため、最後に成功したデータを表示しています | **Retry** をクリックします |

ライブデータは、アーティファクトの読み取り専用クエリを、公開時の接続に対して、あなた自身のアクセス権で実行します。開始前にページが接続名を表示します。有料[プラン](/ja/guide/billing/pricing)と、ライブデータを実行できるロールが必要です。各実行は [Audit Logs](/guide/security/audit-logs) に記録されます。

古いバージョンを見ている場合や、そのバージョンに保存済みクエリがない場合（アップロードしたファイルや貼り付けたデータだけで作成した場合など）、アーティファクトはスナップショットのみになります。その場合、ピルの下に **This artifact shows its published snapshot only.** と表示されます。

## アーティファクトを共有する

アーティファクトのページで **Share** をクリックします。**General access** で、ワークスペース内の誰が開けるかを選ぶか、名前やメールでユーザーを追加します。**Public link** で **Anyone with the link can view** をオンにすると、サインインせずに誰でも開けるリンクを取得できます。レポートやダッシュボードでは、カードの **⋯** メニューにある **Share** から、公開リンクの作成と取り消しだけができる簡易ダイアログが開きます。閲覧者に何が見えるか、リンクを取り消す方法は [Sharing](/guide/sharing) を参照してください。

<Warning>
リンクは公開されており、CloudThinker が以降に公開するすべてのバージョンが同じ URL に表示されます。送信する前に [Sharing の警告](/guide/sharing#what-viewers-see)を読んでください。
</Warning>

## スケジュールで再実行する

[オートメーション](/guide/automation/automations)を使うと、同じリクエストをスケジュールで実行できます。各実行は新しい会話になるため、デフォルトでは毎回新しいアーティファクトが作成され、すでに共有したリンクは更新されません。CloudThinker はワークスペース内のどのアーティファクトでも見つけられるため、関係者向けに 1 つの URL を最新に保つには、オートメーションのリクエストで既存のアーティファクトを名指ししてください（例: 「update the AWS spend by service dashboard」）。すると各実行がその新しいバージョンを公開します。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="アーティファクトにデータが欠けている、またはグラフが空になる">
    **原因:** CloudThinker がそのソースを読み取れませんでした。**確認:** [Connections](/ja/guide/connections/overview) に接続が存在し **Connected** になっていること、その期間にデータがあること。**対処:** 再接続するか期間を広げてから、CloudThinker にアーティファクトの更新を依頼します。
  </Accordion>
  <Accordion title="Use live data が表示されない、またはピルが Snapshot のまま">
    **原因:** ワークスペースが Free プランである、ロールが **Viewer** である、古いバージョンを見ている、またはそのバージョンに保存済みの接続がない。**確認:** ピルの下のメッセージに理由が表示されます。**対処:** [プラン](/ja/guide/billing/pricing)をアップグレードするか、Admin にロールを相談するか、バージョンピッカーで最新バージョンに切り替えます。
  </Accordion>
  <Accordion title="ライブデータで接続へのアクセス権がないと表示される">
    **原因:** メッセージに **You do not have access to** と接続名が表示されます。その接続が削除されたか、あなたのアカウントから見えません。ライブデータはそのバージョンに保存された接続だけを使います。**対処:** アーティファクトの会話で、現在の接続を使って作り直すよう CloudThinker に依頼します。新しいバージョンはその接続でライブ実行されます。
  </Accordion>
  <Accordion title="生成されたファイルが Library にない">
    **原因:** 生成されたファイルは、保存するまで会話の中にとどまります。**対処:** 会話を開き、ファイルカードの **Save to artifacts** をクリックします。
  </Accordion>
  <Accordion title="Download PDF が失敗する">
    **原因:** 印刷エラー、または 1 分あたりの上限（ユーザーあたり 10 件）を超える PDF リクエスト。**対処:** 1 分待ってから、ページ上部の **Retry download**、または **More actions** メニューの **Print failed. Retry** をクリックします。
  </Accordion>
</AccordionGroup>
