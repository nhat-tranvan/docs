CloudThinker は [app.cloudthinker.io](https://app.cloudthinker.io) でホスト型のサービスとして動作し、ほとんどのチームはそれ以外を必要としません。一部の作業をネットワーク内で行う必要がある場合は、2 つの選択肢があります。個々のフォルダーやホストのための Environments と、プラットフォーム全体のプライベートデプロイです。

## モデルを選ぶ

| モデル | 実行場所 | 使う場面 | 入手方法 |
|---|---|---|---|
| **CloudThinker Cloud** | CloudThinker が管理する共有サービス | 運用するインフラなしで今日から始めたい場合。 | [サインアップ](/ja/quickstart) |
| **CloudThinker Cloud + Environments**（ベータ） | プラットフォームはクラウドで、ファイルとシェルの作業はあなたが管理するマシンで実行します。 | エージェントがプライベートリポジトリで作業したり社内のホストに到達したりする必要があるが、接続の認証情報はクラウドに置いたままでよい場合。 | [Environment をセットアップする](/guide/workers) |
| **Dedicated cloud** | 選んだリージョンで CloudThinker がホストするシングルテナントのインスタンス | テナントの分離や特定のリージョンが必要な場合。利用可能なリージョンはオンボーディング時に確認します。 | [営業へのお問い合わせ](https://cloudthinker.io/contact) |
| **Bring your own cloud**（セルフホストまたはエアギャップ） | 自社のクラウドアカウントやデータセンター内。必要ならオフライン | ポリシーでデータを境界の外に出せない場合。 | [営業へのお問い合わせ](https://cloudthinker.io/contact) |

<Note>
**アーリーアクセス。** Dedicated、セルフホスト、エアギャップのデプロイは、デザインパートナープログラムを通じて提供されます。システム要件、対応するトポロジー、料金、アップグレードの方法、誰が運用を担うか、インターネットアクセスなしでモデルをどう提供するかは、ここでは公開せず、オンボーディング時に確認します。
</Note>

## プライベートデプロイの前に Environments を試す

セルフホストの Environments はベータ版で、一般提供の前に CLI のコマンド名とフラグが変わる可能性があります。Environment は、CLI 以外に何もインストールせずに、セルフホストの依頼のきっかけとなるニーズをカバーできることがよくあります。これはマシン上のフォルダーで、CloudThinker がファイルを読みコマンドを実行し、受信ポートなしで HTTPS により外向きに接続します。ファイアウォールでは、`app.cloudthinker.io` への外向きの HTTPS（ポート 443）を、直接または `HTTPS_PROXY` 経由で許可するだけで済みます。プロキシが HTTPS を再署名する場合は、`SSL_CERT_FILE` を会社の CA バンドルに設定してください。CLI のインストールと更新では、`cloudthinker.io` と `github.com` にも接続します。

| 要件 | Environment でカバーできるか |
|---|---|
| エージェントがプライベートリポジトリのコードを編集する | はい。ファイルツールは提供するフォルダーの中にとどまります。 |
| エージェントが社内の CLI やスクリプトを実行する | はい。シェルコマンドは、マシン上であなたの OS アカウントとして実行されます。 |
| ワークスペースの接続の認証情報（AWS、Kubernetes など）がホストに一切触れない | はい。接続のコマンドは CloudThinker Cloud で実行されます。ホストにすでにある認証情報は、シェルコマンドで引き続き使われることがあります。 |
| ファイルの内容とコマンドの出力がホストにとどまる | いいえ。エージェントが読んだものと得た出力は、CloudThinker Cloud とモデルに送られます。 |
| 会話、[メモリ](/guide/memory)、Skills が境界内にとどまる | いいえ。これらは CloudThinker Cloud にとどまります。プライベートデプロイが必要です。 |
| すべてのコンポーネントがインターネットアクセスなしで動作する | いいえ。Environment には外向きの HTTPS が必要です。エアギャップのデプロイが必要です。 |

気にしている行がすべて「はい」であれば、[Environments](/guide/workers) から始めてください。

## プライベートデプロイを依頼する

<Steps>
  <Step title="要件を集める">
    具体的な返答が得られるよう、最初のメッセージに次の内容を含めてください。

    - リージョンやデータ所在地のルール
    - ホストがインターネットにアクセスできるかどうか
    - サインインに使う ID プロバイダー
    - CloudThinker を使うおおよその人数
    - 接続する予定のクラウドとアカウント
    - 使いたい LLM プロバイダー（あれば。[BYOK](/ja/guide/byok) を参照）
    - レビューで照合するコンプライアンスのフレームワーク
  </Step>
  <Step title="CloudThinker に連絡する">
    それらの要件を [cloudthinker.io/contact](https://cloudthinker.io/contact) から送信し、Dedicated、セルフホスト、エアギャップのいずれかのデプロイを依頼します。

    **成功時の状態:** あなたの環境がプログラムに適合するかどうかと、オンボーディングで何が必要かを記した返答が届きます。
  </Step>
  <Step title="その間はホスト型のクラウドで評価する">
    待っている間に、CloudThinker Cloud で非本番のアカウントを接続し、実際の作業でエージェントをテストしてください。[Quickstart](/ja/quickstart) を参照してください。
  </Step>
</Steps>
