<Note>
**プレビュー** — セルフホスト版 CloudThinker はデザインパートナー向けの早期アクセス段階です。サポートされるトポロジー、システム要件、アップグレードパスは一般提供前に変更される場合があります。環境についての相談は[こちらからお問い合わせ](https://cloudthinker.io/contact)ください。
</Note>

大多数の CloudThinker ユーザーは [app.cloudthinker.io](https://app.cloudthinker.io) のマルチテナント SaaS を利用しています。厳格なデータレジデンシー、コンプライアンス、またはネットワーク分離の要件がある環境向けに、CloudThinker は専用デプロイとセルフホストデプロイもサポートしています。

---

## デプロイモデル

| モデル | 説明 |
| --- | --- |
| SaaS（マルチテナント） | デフォルト — CloudThinker が管理。最短で価値を実現でき、運用の負担なし。 |
| 専用クラウド | 希望するリージョンとクラウドで CloudThinker がホストするシングルテナントインスタンス |
| セルフホスト | 自社 VPC 内の Kubernetes で CloudThinker を実行 — データが外部に出ることはない |
| エアギャップ | 機密または規制対象環境向けの完全オフラインインストール |

---

## システム要件

| リソース | 最小（POC） | 本番環境 |
|----------|---------------|------------|
| **Kubernetes** | 1.34+ | 1.34+ |
| **ノード** | 3 × 4 vCPU / 16 GB | 6+ × 8 vCPU / 32 GB |
| **PostgreSQL** | 14+ | 15+（HA あり） |
| **オブジェクトストレージ** | S3 または MinIO | 同上 |
| **LLM アクセス** | AWS Bedrock | 同上 |

---

## アップグレード

| チャンネル | サイクル |
|---------|---------|
| **Stable** | 月次 |
| **LTS** | 四半期ごと、12か月サポート |
| **Patch** | セキュリティおよび重大な修正が必要な場合 |

Helm ベースのアップグレードは API とエージェントランタイムのダウンタイムなしでインプレースで実行されます。

---

## コンプライアンス

セルフホストデプロイはクラスターのセキュリティポスチャーを継承します — CloudThinker は運用対象のワークロードと同じ境界内に配置してください。セルフホストインストールは、クラスターがすでに監査境界に含まれているため、再認証は不要です。
