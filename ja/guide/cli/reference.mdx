`cloudthinker` バイナリのすべてのコマンドと、受け付けるフラグ、返す終了コードの一覧です。未インストールの場合は [CLI 概要](/ja/guide/cli/overview)から始めてください。

## グローバルオプション

サブコマンドの前に置き、認証が必要なすべてのコマンドに適用されます。

| オプション | 説明 |
| --- | --- |
| `--url <URL>` | API のベース URL。既定は `https://app.cloudthinker.io`。配下のパスではなくオリジンのみを渡します |
| `--workspace <ID または名前>` | このワークスペースの保存済み認証情報を使用。`CLOUDTHINKER_TOKEN` とは併用不可 |
| `-h`, `--help` | コマンドのヘルプを表示 |
| `-V`, `--version` | CLI のバージョンを表示 |

## 認証コマンド

| コマンド | 説明 |
| --- | --- |
| `login` | ループバックコールバックによるブラウザーログイン |
| `login --no-browser` | ブラウザーを開かず同意 URL を表示 |
| `login --device-auth` | 別デバイスで短いコードを入力して認可 |
| `logout` | 選択中または有効なワークスペースの認証情報を削除 |
| `logout --all` | このホストに保存されたすべての認証情報を削除 |
| `whoami` | 認証情報に対応するホスト、アカウント、ワークスペースを表示 |
| `auth token` | 現在のアクセストークンを stdout に出力。期限が近ければ先に更新 |

詳細と CI での使い方は [CLI 認証](/ja/guide/cli/authentication)にあります。

## エージェント

| コマンド | 説明 |
| --- | --- |
| `agent` | カレントディレクトリでローカルコーディングエージェントを実行 |
| `agent <args...>` | すべての引数をそのままエージェントへ渡す |
| `agent -- <args...>` | エージェントのオプション名が CLI と重なる場合に引き渡しを強制 |

引数なしの `cloudthinker` は `agent` を実行します。[ローカルコーディングエージェント](/ja/guide/cli/agent)を参照してください。

## チャット

| コマンド | 説明 |
| --- | --- |
| `chat -p <PROMPT>` | プロンプトを送信し、Anna の回答を待つ |
| `chat -p ... --continue <UUID>` | 実行 ID または会話 ID で会話を継続 |
| `chat -p ... --no-wait` | 実行がキューに入った時点で戻る |
| `chat -p ... --timeout <秒>` | 指定秒数で待機を終了。既定は 2400。実行はサーバー側で継続 |
| `chat -p ... --json` | 平文の回答の代わりに JSON エンベロープを出力 |
| `chat status <RUN_ID>` | 実行の現在の状態と、あれば回答を表示 |
| `chat status <RUN_ID> --wait` | 終了状態になるまで実行を追跡 |
| `chat ls` | 最近のヘッドレス実行を新しい順に一覧 |
| `chat ls --conversation <UUID>` | 1 つの会話に属する実行だけを一覧 |
| `chat ls --limit <N>` | 最大 N 件（1〜50）を返す。既定は 10 |

人間向けモードでは `chat -p` は stdout に回答だけを書き、進捗と `continue_with=` のヒントは stderr に出ます。[ヘッドレスチャット](/ja/guide/cli/headless-chat)を参照してください。

## レビュー

CloudThinker がすでに追跡している [Review](/ja/guide/code-review/overview) を、マージリクエストまたはプルリクエストの URL から読み取ります。これらのコマンドがレビューを開始することはありません。

| コマンド | 説明 |
| --- | --- |
| `review status <MR_URL>` | 単発の要約: マージリクエスト、プロバイダー、タイトル、ステータス、判定、指摘件数 |
| `review findings <MR_URL>` | 指摘を重大度の高い順に一覧 |
| `review watch <MR_URL>` | 終了状態になるまでレビューを追跡 |

3 つとも `--json` を受け付け、`watch` はさらに `--timeout <秒>` を受け付けます。

```bash
cloudthinker review status https://gitlab.com/acme/api/-/merge_requests/128
cloudthinker review findings https://github.com/acme/api/pull/412 --json
```

指摘の 1 行は `[severity] file:line (category) — title` の形式で、エージェントが解決済みにすると末尾に `[resolved]` が付きます。

| 値 | 表示される場所 |
| --- | --- |
| `in review`、`review complete`、`filtered`、`failed` | レビューのステータス |
| `in review`、`approved`、`review suggested`、`changes requested`、`failed`、`filtered` | レビューの判定 |

## 更新

| コマンド | 説明 |
| --- | --- |
| `update` | 実行中のバイナリに最新リリースを上書きインストール |
| `update --force` | 既に最新でも最新リリースを再インストール |
| `update --json` | 人間向けの 1 行の代わりに `{ updated, old_version, new_version }` を出力 |

対話型ターミナルでは、新しいリリースがあると起動時にも更新を提案します。このチェックは 2 秒の予算内で行われ、起動を遅らせたり失敗させたりしません。`CLOUDTHINKER_NO_UPDATE_CHECK=1` で無効にできます。

`update` が使えるのは、CLI のインストーラーが作成したインストールだけです。手動でコピーしたバイナリは拒否され、代わりに実行すべき再インストールコマンドが表示されます。

## 環境変数

| 変数 | 効果 |
| --- | --- |
| `CLOUDTHINKER_URL` | API のベース URL。`--url` と同じ |
| `CLOUDTHINKER_WORKSPACE` | ワークスペース ID または正確な名前。`--workspace` と同じ |
| `CLOUDTHINKER_TOKEN` | 保存済み認証情報の代わりに使うベアラートークン。`--workspace` とは併用不可 |
| `CLOUDTHINKER_NO_UPDATE_CHECK` | `1` を設定すると起動時の更新提案を抑制 |
| `NO_COLOR` | stderr の色を抑制。stderr が端末でない場合は自動で無効 |

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 成功 |
| 1 | ジョブの失敗: 実行の失敗、存在しない実行やレビュー、または通信リトライの上限到達 |
| 2 | 使用方法の誤り、またはワークスペースのポリシーによる拒否 |
| 3 | 未ログイン、または認証情報の期限切れ |
| 4 | CLI が待機をやめた。処理はサーバー側で継続中 |
| 5 | ブラウザーでの承認待ちで実行が一時停止した |

## ファイル

| パス | 内容 |
| --- | --- |
| `<設定ディレクトリ>/cloudthinker/credentials.json` | ホストごと、ワークスペースごとの認証情報。所有者のみ読み取り可 |
| `~/.cloudthinker/agent/bin/<version>/` | その CLI バージョン用にインストールされたエージェントバンドル |
| `~/.local/bin/cloudthinker` | インストーラーが `PATH` 上に配置するバイナリ |

CLI を削除するには、`cloudthinker logout --all` で保存済みの認証情報を消してから、バイナリと `~/.cloudthinker` ディレクトリを削除します。
