AppDynamics（Cisco）Controller を接続すると、CloudThinker エージェントがアプリケーション、ティア、ノード、ビジネストランザクションを一覧表示し、最も遅い、またはエラーの多いトランザクションをランク付けし、アクティブなヘルスルール違反をトリアージし、遅いリクエストの時間がデータベース、外部呼び出し、キュー、自社コードのどこで費やされたかを示せるようになります。この接続は AppDynamics の **API client**（OAuth2 クライアントクレデンシャル）でサインインし、エージェントが Controller に対して実行するコマンドはすべて読み取りです。

## 前提条件

- 対象のアプリケーションを監視している AppDynamics Controller（SaaS またはオンプレミス）。
- API クライアントを作成できる Controller の管理者アクセス。
- Controller がオンプレミスの場合: CloudThinker Cloud からの HTTPS を受け付ける必要があります。このドキュメントでは CloudThinker の送信元 IP リストを公開していません。CloudThinker の担当者に問い合わせるか、[お問い合わせ](https://cloudthinker.io/contact)ください。その他の方法は [Reaching private services](/ja/guide/connections/overview#プライベートサービスへの到達) を参照してください。

## セットアップ

<Steps>
  <Step title="Controller URL とアカウント名を控える">
    Controller にサインインし、ベースアドレス（例: `https://myaccount.saas.appdynamics.com`）をコピーします。`/controller` などのパスは含めないでください。

    SaaS では、アカウント名は通常サブドメインです（例では `myaccount`）。**Settings → License** でも確認できます。
  </Step>
  <Step title="API クライアントを作成する">
    **Settings → Administration → API Clients** に移動し、**Create** をクリックします。

    - **Client Name**: `cloudthinker`
    - **Description**: `Read-only access for CloudThinker agents`
    - **Roles**: エージェントに読み取らせるアプリケーションを参照できる閲覧専用ロール

    シークレットを生成し、すぐにコピーしてください。AppDynamics は一度しか表示しません。

    トークンの有効期限はデフォルトのままにしてください。CloudThinker は必要になるたびに新しい短期トークンを要求するため、この設定は接続に影響しません。
  </Step>
  <Step title="CloudThinker で接続を追加する">
    **Settings → Workspace → Connections** を開き、**Discover** タブを開いて **AppDynamics** を選択します。4 つのフィールドをすべて入力します。

    - **APPD_CONTROLLER_URL**: Controller のベース URL
    - **APPD_ACCOUNT_NAME**: アカウント名
    - **APPD_CLIENT_NAME**: クライアント名のみ（例: `cloudthinker`）
    - **APPD_CLIENT_SECRET**: コピーしたシークレット

    **Connect** をクリックします。CloudThinker はこれらの認証情報で Controller にテスト呼び出しを行います。

    **成功時の状態:** AppDynamics に **Connected** と表示されます。下の確認用プロンプトを実行して、クライアントがアプリケーションを参照できることを確認してください。
  </Step>
</Steps>

<Warning>
クライアント名は `@<account>` を付けずに入力してください。CloudThinker が OAuth2 クライアント ID を `<APPD_CLIENT_NAME>@<APPD_ACCOUNT_NAME>` として自動で組み立てるため、名前フィールドに `cloudthinker@myaccount` と入力すると `cloudthinker@myaccount@myaccount` になり、401 で失敗します。
</Warning>

## 接続の詳細

| フィールド | 説明 | 例 |
|-------|-------------|---------|
| **APPD_CONTROLLER_URL** | Controller のベース URL（HTTPS） | `https://myaccount.saas.appdynamics.com` |
| **APPD_ACCOUNT_NAME** | AppDynamics のアカウント名 | `myaccount` |
| **APPD_CLIENT_NAME** | アカウントのサフィックスを除いた API クライアント名 | `cloudthinker` |
| **APPD_CLIENT_SECRET** | API クライアントシークレット | `<your-client-secret>` |

4 つのフィールドはすべて必須です。1 つのワークスペースには AppDynamics 接続を 1 つだけ持てるため、接続できる Controller は 1 つです。

## 必要な権限

API クライアントには、エージェントに読み取らせるアプリケーションにスコープした閲覧専用ロールを付与してください。エージェントが参照する必要があるデータは次のとおりです。

| データ | 用途 |
|------|----------|
| アプリケーション、ティア、ノード | 検出と、正しい対象の特定 |
| ビジネストランザクション | 遅いトランザクションやエラーのあるトランザクションのランク付け |
| メトリクス | レスポンスタイム、1 分あたりのコール数、1 分あたりのエラー数、バックエンドおよび外部呼び出しのレイテンシ、ノードの CPU |
| ヘルスルールと違反 | 設定されたしきい値と、現在違反しているもの |
| イベント | アプリケーションの最近のエラーと変更 |
| スナップショット | データベース、外部、キュー呼び出しへのリクエスト単位のドリルダウン |

エージェントは AppDynamics の設定を一切変更しないため、このロールには設定権限や管理権限を付与しないでください。結果にアプリケーションが表示されない場合は、ロールがそのアプリケーションを参照できていません。

## エージェントの機能

| 機能 | エージェントができること | 承認 |
|------------|--------------------|----------|
| **Discovery** | Controller の概要をまとめる: アプリケーション、ティア、ノード、未解決のヘルスルール違反 | 不要 |
| **Application health** | アプリケーションの平均レスポンスタイム、1 分あたりのコール数、1 分あたりのエラー数、エンドユーザーのレスポンスタイムを指定期間で取得する | 不要 |
| **Transaction hotspots** | ビジネストランザクションをレスポンスタイム、1 分あたりのエラー数、遅い呼び出しでランク付けする | 不要 |
| **Violation triage** | アプリケーションの未解決の違反を、最近のイベントと関係するティアとともに、重大度で絞り込んで一覧表示する | 不要 |
| **Bottleneck drilldown** | 遅いリクエストやエラーのあるリクエストのスナップショットを読み、時間をデータベース、外部、キュー、アプリケーションコードに振り分ける | 不要 |
| **Health rules** | 現在違反しているものとは別に、アラート対象のしきい値を一覧表示する | 不要 |

エージェントは直近 60 分などの短い期間から始め、シグナルがない場合にのみ期間を広げます。ID を推測せず、検出で得た実際のアプリケーション名、ティア名、トランザクション名を使います。

### 接続の確認

```text
Run AppDynamics discovery and summarize applications, tiers, nodes, and any open health-rule violations
```

アカウント、ティア数とノード数付きのアプリケーション一覧、未解決の違反が返ってくるはずです。アプリケーション一覧が空の場合、通常はロールがどのアプリケーションも参照できていません。

### プロンプト例

```text
Which AppDynamics business transactions in the checkout application were slowest in the last hour?
List open critical health-rule violations for the payments application and the events around them
Show response time and errors per minute for the checkout application over the last 24 hours
Where is the slow /api/orders request spending its time: database, external calls, or our code?
```

大規模な Controller では、すべてのプロンプトでアプリケーション名を指定してください。各リクエストを少数の呼び出しに抑えられます。

## トラブルシューティング

<Accordion title="Connect が 401 で失敗する">
クライアント名、シークレット、アカウント名のいずれかが間違っているか、名前に `@<account>` が含まれています。**APPD_CLIENT_NAME** が名前のみであること、**APPD_ACCOUNT_NAME** が Controller と一致していることを確認してください。シークレットを紛失した、または再生成した場合は、**API Clients** で新しいシークレットを生成し、接続を編集してください。
</Accordion>

<Accordion title="Connect がタイムアウトする、または Controller に到達できない">
**APPD_CONTROLLER_URL** を確認してください。パスを含まない HTTPS のベースアドレスである必要があります。オンプレミスの Controller では、CloudThinker の送信元 IP からの HTTPS トラフィックを受け付けていることを確認してください。
</Accordion>

<Accordion title="アプリケーションやメトリクスが返ってこない">
API クライアントのロールがそれらのアプリケーションを参照できないか、Controller にその期間のデータがありません。アプリケーションへの閲覧アクセスを付与してから、既知のアプリケーション名と直近 1 時間で再試行してください。
</Accordion>

<Accordion title="アプリケーションやトランザクションが見つからない（404）">
名前のスペルが間違っているか、アプリケーションの名前が変更されています。まずエージェントにアプリケーションまたはビジネストランザクションを一覧表示させ、正確な名前を使ってください。
</Accordion>

<Accordion title="リクエストが 429 または 503 を返す">
Controller がレート制限中か、過負荷状態です。1 分待ち、期間を絞ってから再度依頼してください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **設計上読み取り専用**: エージェントはアプリケーション、メトリクス、違反、イベント、スナップショットを読み取るだけです。Controller を変更するコマンドはありません。
- **専用 API クライアント**: CloudThinker 専用のクライアントを作成すれば、他のツールに影響を与えずに失効させられます。
- **HTTPS のみ**: クライアントシークレットを転送中に保護するため、常に `https://` の Controller URL を使用してください。
