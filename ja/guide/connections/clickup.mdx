ClickUp を接続すると、[Anna](/ja/guide/agents/anna) がワークスペース構造を検出し、作業をトリアージし、ワークロードを確認し、タスク、コメント、ドキュメント、チャットを調査できます。ClickUp はホスト型 MCP サーバー経由の **OAuth** を使用するため、CloudThinker に API トークンを貼り付ける必要はありません。

## 前提条件

- CloudThinker に使用させるワークスペースへのアクセス権を持つ **ClickUp アカウント**。
- ClickUp の OAuth フローで CloudThinker を承認する権限。
- ClickUp がまだ接続されていない CloudThinker ワークスペース。

<Info>
ClickUp ワークスペースを 1 つだけ承認してください。ClickUp ツールは承認後にワークスペースを切り替えられず、複数のワークスペースを承認した接続はリクエストを完了できません。
</Info>

## セットアップ

<Steps>
  <Step title="接続カタログを開く">
    CloudThinker ワークスペースで **Settings → Connections** に移動し、**Builtin Connections**、**ClickUp** の順に選択します。
  </Step>
  <Step title="OAuth フローを開始する">
    **Connect** をクリックして ClickUp の認可ページを開きます。
  </Step>
  <Step title="1 つのワークスペースを承認する">
    対象の作業にアクセスできる ClickUp アカウントにサインインし、ClickUp ワークスペースを 1 つだけ選択してアクセスを承認します。
  </Step>
  <Step title="CloudThinker に戻る">
    CloudThinker が OAuth 認可を保存し、接続に **Connected** ステータスが表示されます。
  </Step>
</Steps>

## 接続詳細

ClickUp は OAuth を使用するため、手動で入力するクレデンシャルフィールドはありません。

| フィールド | 説明 |
|-------|-------------|
| **OAuth 認可** | ClickUp が発行し、アクセス承認後に自動保存されます |
| **ClickUp ワークスペース** | 認可時に選択した 1 つのワークスペース |
| **MCP エンドポイント** | `mcp.clickup.com/mcp` にある ClickUp のホスト型サーバー。固定されており変更できません |

## 必要な権限

CloudThinker は認可したユーザーの ClickUp アクセス権を引き継ぎます。

- **読み取り操作**は、そのユーザーが表示できるワークスペース構造、タスク、コメント、カスタムフィールド、ワークロード、時間エントリ、ドキュメント、チャットチャンネルを対象とします。
- **書き込み操作**は、タスク、コメント、タグ、ドキュメントページを対象とします。対応する ClickUp アクセス権と CloudThinker での明示的な[承認](/ja/guide/approval)が必要です。

<Tip>
CloudThinker に必要なスペースとリストだけへアクセスできる ClickUp ユーザーを承認してください。CloudThinker は、そのユーザーがアクセスできないリソースを読み取りまたは変更できません。
</Tip>

## エージェントの機能

接続後、Anna は以下を実行できます。

| 機能 | 説明 |
|------------|-------------|
| **ワークスペース検出** | スペース、フォルダ、リスト、最近の作業を一覧表示 |
| **タスクトリアージ** | 1 つのリストで期限超過、未割り当て、未スケジュールのタスクを検索 |
| **ワークロード確認** | 担当者とステータス別に未完了作業を比較し、ClickUp が提供する場合はステータス滞在時間を測定 |
| **タスク調査** | タスク詳細、カスタムフィールド、コメント、スレッド形式の議論を読み取り |
| **ドキュメントとチャット** | 接続ユーザーが利用できるドキュメントページとチャットメッセージを読み取り |
| **タスク変更** | 承認後にタスクを作成、更新、移動、削除 |
| **コメント、タグ、ドキュメント** | 承認後にコメント追加、タグ変更、ドキュメントページ更新 |

### 接続を確認する

```text
@anna #report show the ClickUp workspace structure and summarize what needs attention in Project 1
```

### プロンプト例

```text
@anna #report list overdue, unassigned, and unscheduled ClickUp tasks in Project 1
@anna #report compare open ClickUp work by assignee and status age in Team Space
@anna #recommend review the comments on the oldest overdue ClickUp task and suggest the next action
```

## トラブルシューティング

<Accordion title="OAuth フローが完了しない">
ブラウザが別の ClickUp アカウントにサインインしている可能性があります。対象ワークスペースにアクセスできるアカウントでサインインし、**Connect** を再度開始してください。
</Accordion>

<Accordion title="エージェントが複数のワークスペースを報告する">
接続が複数の ClickUp ワークスペースに対して承認されています。ClickUp を切断して再接続し、認可時にワークスペースを 1 つだけ選択してください。
</Accordion>

<Accordion title="接続が 401 Unauthorized を返す">
ClickUp アクセストークンが無効または期限切れです。この接続では ClickUp がリフレッシュトークンを発行しない場合があるため、切断して ClickUp を再承認してください。
</Accordion>

<Accordion title="エージェントがスペース、リスト、タスクを見つけられない">
認可したユーザーにアクセス権がないか、リソースが移動した可能性があります。ユーザーの ClickUp アクセス権を確認し、エージェントにワークスペースを再検出させてください。
</Accordion>

<Accordion title="ステータス滞在時間を取得できない">
ClickUp ワークスペース設定で **Total time in Status** ClickApp を有効にしてください。この測定が無効でもタスクとワークロードの読み取りは動作します。
</Accordion>

<Accordion title="リクエストがレート制限エラーを返す">
ClickUp アカウントがプロバイダーのクォータに達しています。ClickUp のレート制限ウィンドウがリセットされるまで待ち、同じスコープで再試行してください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **1 つの限定ワークスペースを使用**: CloudThinker が到達すべき ClickUp ワークスペースだけを承認してください。
- **最小権限を使用**: CloudThinker が表示および変更する作業に合うスペースとリストだけへアクセスできる ClickUp ユーザーを接続してください。
