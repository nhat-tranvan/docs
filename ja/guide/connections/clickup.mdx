ClickUp を接続すると、CloudThinker のエージェントがリスト内で対応が必要なものを見つけ、担当者間の作業量を比較し、タスクのディスカッション、ドキュメント、チャットチャネルを読み、承認を経てタスクを更新できるようになります。サインインには **OAuth**（ClickUp 自身のページでアクセスを承認します）を使うため、API トークンを作成したり貼り付けたりする必要はありません。リストやタスクの ID を調べる必要もありません。エージェントがまずワークスペースの構造を読み、「Platform Team」のような名前を自分で解決します。

## 前提条件

- エージェントに扱わせたいスペースとリストを閲覧できる ClickUp アカウント。
- CloudThinker ワークスペースで接続を編集する権限。
- この CloudThinker ワークスペースに既存の ClickUp 接続がないこと。各 CloudThinker ワークスペースが持てるのは 1 つです。確認するには、**Settings → Workspace → Connections** で ClickUp を開きます。**Connected** と表示されている場合は、先に詳細パネルの **Disconnect** をクリックします。

<Warning>
認可するときは、ClickUp ワークスペースを正確に **1 つ**選んでください。ClickUp のツールはサインイン後にワークスペースを切り替えられず、複数のワークスペースで認可された接続はすべてのリクエストに失敗します。
</Warning>

## セットアップ

<Steps>
  <Step title="CloudThinker で ClickUp を開く">
    **Settings → Workspace → Connections** を開きます。**Discover** タブで **ClickUp** を検索し、**Connect** をクリックします。
  </Step>
  <Step title="ClickUp にサインインする">
    ClickUp の認可ページが開きます。エージェントに見せたい範囲と一致するアクセス権を持つアカウントでサインインします。ブラウザがすでに別の ClickUp アカウントにサインインしている場合は、先にそこでサインアウトしてください。
  </Step>
  <Step title="1 つのワークスペースを認可する">
    CloudThinker に使わせる ClickUp ワークスペースを 1 つだけ選び、アクセスを承認します。

    **成功時の状態:** CloudThinker に戻り、ClickUp の接続に **Connected** と表示されます。
  </Step>
</Steps>

## 接続の詳細

| フィールド | 説明 |
|-------|-------------|
| **OAuth authorization** | アクセスを承認したときに ClickUp が発行し、CloudThinker が暗号化して保存します |
| **ClickUp workspace** | 認可時に選んだ 1 つのワークスペース |

## 必要な権限

エージェントは、接続を認可した ClickUp ユーザーとして動作します。そのユーザーができることだけを読み取り・変更でき、変更は ClickUp 上でそのユーザーの名前で表示されます。

| アクセス | 対象 | 承認 |
|--------|--------|----------|
| **Read** | ワークスペースの階層、リスト、フォルダー、タスク、カスタムフィールド、コメントとスレッド、メンバー、時間エントリ、ステータス滞留時間、ドキュメントのページ、チャットチャネルとメッセージ | 確認なしで実行されます |
| **Write** | タスクの作成、更新、移動、削除。コメントの追加。タグの追加・削除。既存の Doc 内のページの追加・編集 | 書き込みのため、[Approvals](/guide/approvals/overview) が判断します |

<Tip>
CloudThinker が必要とするスペースだけを閲覧できる ClickUp ユーザー（または専用のサービスアカウント）で認可してください。エージェントは、そのユーザーが開けないスペースには決して到達できません。サービスアカウントは通常の ClickUp ユーザーなので、ClickUp のプランではメンバーとしてカウントされます。CloudThinker が必要とするスペースにだけ招待してください。
</Tip>

### エージェントができないこと

CloudThinker は ClickUp が提供するよりも狭いツールセットを保持しているため、承認があっても意図的にオフにしている操作があります。

| 利用できないもの | 理由 |
|---------------|-----|
| スペース、フォルダー、リスト、Doc の作成、またはスペース、フォルダー、リストの編集 | エージェントは既存の構造の中で作業し、構造を作り変えることはしません。既存の Doc 内のページは追加・編集できます。 |
| タスクの統合、コメントの削除、他の人のコメントの編集 | 元に戻せないか、人自身の言葉を変えてしまうため |
| 時間計測の開始・停止 | ClickUp ではユーザーごとに実行中のタイマーが 1 つのため、エージェントがあなたのタイマーを止めてしまう可能性があるため |
| チャットメッセージの送信 | 人のチャネルへの不要な投稿を避けるため |
| 添付ファイル、リマインダー、タスクの依存関係とリンク | 現時点では対象外 |

## エージェントの機能

| 機能 | エージェントができること |
|------------|--------------------|
| **Workspace discovery** | スペース、フォルダー、リスト、最近の作業を把握し、入力された名前を ClickUp の ID に解決します |
| **List triage** | 1 つのリスト内の期限切れ、未割り当て、未スケジュールのタスクを見つけます |
| **Workload review** | 担当者とステータス別にオープンな作業を比較し、タスクが各ステータスにとどまっている時間を測定します |
| **Task investigation** | タスクの詳細、カスタムフィールド、コメント、スレッドの返信を読みます |
| **Documents and chat** | 接続したユーザーが閲覧できるドキュメントのページとチャットチャネルのメッセージを読みます |
| **Task changes** | タスクの作成、更新、移動、削除、タグの変更を行います |
| **Comments and docs** | コメントを追加し、既存の Doc 内のページを追加・編集します |

5 つのタスクのタグを付け直すなど、エージェントが一度に複数の変更を計画する場合、何かが実行される前に、承認カードにすべての変更が一覧表示されます。

### 接続を確認する

```text
Show the structure of our ClickUp workspace and list what needs attention in the biggest list
```

正常な接続では、実際のスペースとリストの名前が示され、そのうちの 1 つから期限切れ、未割り当て、または未スケジュールのタスクが返されます。認可エラーが出た場合は、再接続が必要です。

### プロンプトの例

```text
List overdue, unassigned, and unscheduled tasks in the Platform Team → Sprint 42 list
Compare open ClickUp work by assignee in the Engineering space and flag anyone with more than 10 tasks in progress
Which tasks in the Backend list have been in "In review" the longest?
Read the comments on the oldest overdue task in Sprint 42 and suggest the next step
Move every task tagged blocked in Sprint 42 to Sprint 43 and add a comment explaining why
```

## トラブルシューティング

<Accordion title="OAuth ページが完了しない、または別のアカウントが接続される">
ブラウザが別の ClickUp アカウントにサインインしている可能性があります。ClickUp からサインアウトし、正しいアカウントでサインインしてから、もう一度 **Connect** をクリックしてください。
</Accordion>

<Accordion title="すべてのリクエストが複数ワークスペースのエラーで失敗する">
接続が複数の ClickUp ワークスペースで認可されています。**Settings → Workspace → Connections** で ClickUp を開き、詳細パネルの **Disconnect** をクリックしてから、**Connect** をクリックしてワークスペースを正確に 1 つ選んでください。
</Accordion>

<Accordion title="リクエストが突然 401 Unauthorized で失敗する">
ClickUp の認可が期限切れになったか、取り消されました。**Settings → Workspace → Connections** で ClickUp を開き、**Connect** をクリックして再度サインインしてください。
</Accordion>

<Accordion title="エージェントがスペース、リスト、タスクを見つけられない">
認可したユーザーにアクセス権がないか、項目が移動された可能性があります。そのユーザーが ClickUp でそれを開けることを確認してから、ワークスペースの構造をもう一度読むようエージェントに依頼してください。
</Accordion>

<Accordion title="ステータス滞留時間が利用不可と表示される">
ステータス滞留時間には **Total time in Status** の ClickApp が必要です。ClickUp ワークスペースのオーナーまたは管理者が、ワークスペース設定の **ClickApps** でオンにできます。タスクと作業量の読み取りはこれがなくても動作し、CloudThinker は測定値をゼロではなく利用不可として報告します。
</Accordion>

<Accordion title="リクエストがレート制限のエラーで失敗する">
ClickUp アカウントが API のクォータに達しました。上限は ClickUp のプランによって異なります。[ClickUp's rate limits](https://developer.clickup.com/docs/rate-limits) を参照してください。期間がリセットされるのを待ってから、同じリクエストを再試行してください。
</Accordion>

<Accordion title="変更が待機中のまま進まない">
書き込みが人の判断を待っています。チャットで承認カードを探して **Approve** をクリックするか、自分で承認できない場合は **Notify approvers** をクリックしてください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **接続ごとに 1 つのワークスペース。** CloudThinker が到達すべき ClickUp ワークスペースだけを認可してください。
- **認可するユーザーは意図して選ぶ。** すべての読み取りと書き込みは、そのユーザーの ClickUp のアクセス権で実行されます。そのユーザーが退職したら、別のアカウントで再接続してください。
