Better Stack を接続すると、CloudThinker のエージェントが、どのモニターがダウンしているかを確認し、オープン中のインシデントと現在のオンコール担当者を読み、テレメトリーソースのログとエラーを検索できるようになります。Better Stack へのサインインは OAuth で一度行うだけなので、API トークンを作成したり貼り付けたりする必要はありません。

## 前提条件

- エージェントに読ませたいモニター、インシデント、テレメトリーソースを閲覧できる Better Stack アカウント。
- Better Stack でサードパーティアプリを認可する権限。

## セットアップ

<Steps>
  <Step title="接続を開始する">
    **Settings → Workspace → Connections** を開き、**Better Stack** を選んで **Connect** をクリックします。CloudThinker が Better Stack の認可ページを開きます。
  </Step>
  <Step title="CloudThinker を認可する">
    エージェントに使わせる Better Stack アカウントでサインインし、アクセスを承認します。ブラウザが別の Better Stack アカウントにサインインしている場合は、先にサインアウトしてください。
  </Step>
  <Step title="CloudThinker に戻る">
    Better Stack から CloudThinker に戻り、CloudThinker がトークンを保存します。

    **成功時の状態:** 接続に **Connected** と表示されます。新しいチャットで[接続を確認する](#接続を確認する)のプロンプトを実行し、アカウントが到達できる範囲を確認してください。
  </Step>
</Steps>

## 接続の詳細

入力するフィールドはありません。

| 項目 | 値 |
|------|-------|
| **Authentication** | OAuth。Better Stack がトークンを発行し、CloudThinker が保存します |
| **Endpoint** | `https://mcp.betterstack.com`（Better Stack がホストする MCP サーバー） |

エージェントのリクエストは CloudThinker からそのサーバーに送られ、サーバーがあなたの Better Stack アカウントを読み取ります。あなたのネットワークへの接続はないため、ファイアウォールのルールを追加する必要はありません。

## 必要な権限

エージェントには、認可した Better Stack アカウントが見られるものが見えます。CloudThinker はその権限を絞り込めないため、エージェントに使わせたいチームだけに到達できるアカウントで認可して、アクセスを制限してください。

<Tip>
認可するアカウント自身の Better Stack の権限が上限になります。読み取り専用の接続にするには、インシデントやダッシュボードを変更できないアカウントで認可してください。すべての変更を人が承認するよう **Manual** を選ぶか、**Deny** の [Rule](/guide/approvals/rules) を追加して Better Stack の変更を完全にブロックします。
</Tip>

## エージェントの機能

| 機能 | エージェントができること |
|------------|--------------------|
| **Discovery** | モニター、過去 24 時間のインシデント、テレメトリーソース、ステータスページを一度に一覧表示します |
| **Uptime** | 期間内のモニターの可用性と応答時間、および cron やスケジュールされたジョブのハートビートのヒット率を読みます |
| **Incidents and on-call** | インシデント、タイムライン、コメント、オンコールのスケジュールと現在のローテーション、エスカレーションポリシー、重大度を読みます |
| **Status pages** | ステータスページ、そのコンポーネント、過去のレポートを読みます |
| **Telemetry** | 指定したソースのログとメトリクスをクエリし、ダッシュボード、チャート、アラート、エラー、アプリケーション、リリースを読みます |
| **Changes (through your Approvals)** | インシデントの確認（acknowledge）、解決、再オープン、エスカレーション、コメント、作成。ステータスページのレポートや更新の公開。ダッシュボード、チャート、アラートの作成、編集、削除 |

Better Stack はすべてのリソースを ID で管理するため、エージェントはまずモニター、インシデント、ソースを名前で検索し、何かを変更する前に一致を確認します。インシデントを確認（acknowledge）するとオンコールの呼び出しが止まるため、実際に誰かがインシデントに対応している場合にのみ承認してください。どの変更を事前確認にし、どれを完全に拒否するかを決めるには、[Rules](/guide/approvals/rules) を参照してください。

<ApprovalDefault />

<Note>
Better Stack の MCP サーバーは、モニターを一時停止・再開できません。メンテナンスウィンドウは Better Stack のダッシュボードで設定してください。
</Note>

### 接続を確認する

新しいチャットで CloudThinker に次のように質問します。

```text
List open Better Stack incidents, monitors that are down, and who is on call now
```

オープン中のインシデントとそのモニターおよび開始時刻、現在失敗しているモニター、スケジュールごとの現在のオンコール担当者が返されることを確認します。すべてが稼働している場合は、空の一覧も正しい回答です。

### プロンプトの例

```text
24-hour availability and p95 response time for every production monitor
Count 5xx errors by status code in the api-gateway logs over the last hour
Which heartbeats missed a check-in today?
```

Better Stack には全体のログ検索はなく、すべてのクエリは 1 つのソースに対して実行されます。上の `api-gateway` のようにプロンプトでソース名を指定するか、先にソースの一覧を表示するようエージェントに依頼してください。

## トラブルシューティング

<Accordion title="OAuth フローが完了しない">
ブラウザが別の Better Stack アカウントにサインインしている可能性があります。Better Stack で正しいアカウントにサインインしてから、もう一度 **Connect** をクリックしてください。
</Accordion>

<Accordion title="呼び出しが 401 Unauthorized で失敗する">
OAuth トークンが期限切れになったか、Better Stack でアクセスが取り消されました。Better Stack の接続を開き、**Connect** をクリックして再度認可してください。接続のエージェント、設定、メモリは保持されます。
</Accordion>

<Accordion title="モニターやインシデントが 404 Not Found を返す">
そのリソースが、認可したアカウントから見えないチームに属しているか、削除されています。現在の ID を取得するため、モニターやインシデントをもう一度一覧表示するようエージェントに依頼してください。
</Accordion>

<Accordion title="ログのクエリが構文エラーを返す">
Better Stack のログクエリは独自のクエリ言語を使います。エージェントは Better Stack のクエリ構文を読み込み、自動で再試行します。それでも失敗する場合は、平易な言葉でソース名を指定してもう一度質問してください。例: 「count 5xx errors in api-gateway over the last hour」。
</Accordion>

<Accordion title="リクエストが 429 Too Many Requests で失敗する">
Better Stack のレート制限に達しました。エージェントは間隔を空けて再試行します。繰り返し発生する場合は、質問の期間やモニターの数を絞ってください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **使わないときは取り消す**: 接続を使わなくなった場合は、Better Stack で CloudThinker の認可を削除してから、CloudThinker で接続を削除します。
- **アカウントの切り替え**: 切断してから、別の Better Stack アカウントにサインインした状態で再度接続します。
