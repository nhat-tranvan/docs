Rollbar を接続すると、CloudThinker エージェントは上位エラーをランク付けし、新しいエラーを最近のデプロイやバージョンと結び付け、セッションリプレイのコンテキストを取得し、[Approvals](/guide/approvals/overview) を通してアイテムの状態を変更できます。各 Rollbar プロジェクトをそのプロジェクトアクセストークンに対応付ける JSON 設定を 1 つ貼り付けるので、1 つの接続で多くのプロジェクトをカバーできます。

## 前提条件

- エージェントに読ませたい各プロジェクトにアクセスできる Rollbar アカウント。
- それぞれのプロジェクトのプロジェクトアクセストークン。Rollbar のトークンはプロジェクトごとなので、1 つのトークンで 2 つのプロジェクトはカバーできません。

## セットアップ

<Steps>
  <Step title="プロジェクトアクセストークンを作成する">
    Rollbar でプロジェクトを開き、**Settings → Project Access Tokens** に移動します。**Create new access token** をクリックして **read** にチェックを入れ、エージェントにアイテムの状態を変更させたい場合にのみ **write** を追加します。**post_server_item** と **post_client_item** はチェックしないでください。これらは Rollbar にエラーを送信するためのもので、CloudThinker は送信を行いません。プロジェクトごとに繰り返します。
  </Step>
  <Step title="プロジェクト設定を書く">
    `projects` 配列を持つ JSON オブジェクトを作り、プロジェクトごとに 1 エントリを入れます。各エントリには `name` と `token` があります。`name` はプロンプトで使う自分用のラベルなので、Rollbar のプロジェクト名と一致させる必要はありません。`backend` のような短い名前が入力しやすいです。

    ```json
    {
      "projects": [
        { "name": "backend", "token": "<backend-project-token>" },
        { "name": "frontend", "token": "<frontend-project-token>" }
      ]
    }
    ```
  </Step>
  <Step title="接続を追加する">
    **Settings → Workspace → Connections** を開き、**Discover** タブで **Rollbar** を選択し、JSON を **ROLLBAR_CONFIG_JSON** に貼り付けて **Connect** をクリックします。

    **成功の状態:** 接続に **Connected** と表示されます。Connect は各トークンで Rollbar を呼び出さないため、無効なトークンは最初のリクエストで初めて判明します。すぐに新しいチャットで[接続を確認する](#接続を確認する)のプロンプトを実行してください。
  </Step>
</Steps>

## 接続の詳細

| フィールド | 説明 | 例 |
|-------|-------------|---------|
| **ROLLBAR_CONFIG_JSON** | `projects` 配列。各エントリに `name` と `token` があります。キーは `access_token` ではなく `token` です | `{"projects":[{"name":"backend","token":"..."}]}` |

形式は Rollbar の [MCP server multi-project configuration](https://docs.rollbar.com/docs/mcp-server-setup#configuration) と同じです。

## 必要な権限

| トークンのスコープ | 許可される操作 |
|-------------|----------------|
| **read** | プロジェクト、アイテム、上位エラー、デプロイ、バージョン、セッションリプレイ |
| **write** | アイテムの状態の変更（解決やミュートなど）。各変更は Approvals も通ります |

<Tip>
まずは読み取り専用のトークンで始めてください。write スコープは、エージェントにアイテムを解決またはミュートさせたいプロジェクトにだけ追加します。
</Tip>

## エージェントの機能

| 機能 | エージェントができること |
|------------|--------------------|
| **検出** | 設定済みのプロジェクトを一覧表示し、プロジェクトが 1 つだけの場合は自動で選択します |
| **エラーのトリアージ** | 現在のアイテムを一覧表示し、アイテムの詳細と発生回数を読み、上位エラーをランク付けします |
| **リリースのコンテキスト** | 最近のデプロイを確認し、デプロイのリビジョンからバージョンの詳細を取得します |
| **セッションリプレイ** | 記録済みのリプレイがあるアイテムのリプレイコンテキストを取得します。Rollbar でそのプロジェクトのセッションリプレイを設定しておく必要があります |
| **アイテムの更新（毎回確認）** | 1 つのアイテムの状態を変更します。プロジェクト、アイテム、希望する変更を指定する必要があります |

エージェントは、トリアージ、デプロイの確認、リプレイの読み取り中にアイテムを変更することはありません。更新は会話の中で依頼したときにだけ実行され、Approvals を通ります。

<ApprovalDefault />

### 接続を確認する

新しいチャットで CloudThinker に次のように聞きます:

```text
List my Rollbar projects and show the top errors in each
```

設定にあるすべてのプロジェクト名が、それぞれ影響の大きいアイテム、そのレベル、発生回数とともに表示されるはずです。表示されないプロジェクトは、貼り付けた JSON に含まれていません。

### プロンプト例

```text
Which errors in backend first appeared after the latest deployment?
Rank the active items in frontend by impact and show replay context for the top one
Resolve item #1042 in backend
```

複数のプロジェクトを設定している場合は、プロンプトでプロジェクト名を指定してください。指定しないと、エージェントがどれを使うか尋ねます。アイテム番号には、Rollbar がアイテムに表示する `#` 番号を使います。

## トラブルシューティング

<Accordion title="呼び出しが 401 Unauthorized で失敗する、または空で返る">
貼り付けた設定が無効な JSON であるか、指定したプロジェクトが含まれていないか、Rollbar で取り消し、無効化、またはレート制限されたトークンが入っています。エージェントに設定済みのプロジェクトを一覧表示させてから、接続を編集して JSON またはトークンを修正してください。
</Accordion>

<Accordion title="エージェントがどのプロジェクトを使うか尋ねてくる">
複数のプロジェクトが設定されていて、プロンプトでプロジェクトを指定していません。設定にあるプロジェクト名を追加してください（例: "in backend"）。
</Accordion>

<Accordion title="アイテムにリプレイがない">
リプレイのコンテキストは、セッションリプレイが記録されたアイテムにだけ存在します。リプレイのないアイテムはリプレイデータを返しません。これは想定どおりの動作で、エラーではありません。
</Accordion>

<Accordion title="アイテムの更新がブロックされる、または失敗する">
そのプロジェクトのトークンに write スコープがないか、承認を拒否しました。Rollbar でトークンに write スコープを追加し、接続を更新して、もう一度依頼してください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **一時的な設定ファイル**: トークンは暗号化して保存されます。エージェントが Rollbar を使うとき、その Rollbar プロセスは、そのプロセスだけが読める一時ファイルからトークンを読み込み、プロセスが停止するとファイルは削除されます。
- **ローテーションと新しいプロジェクト**: 接続を編集するとき、保存済みの JSON は表示されません。トークンをローテーションするときやプロジェクトを追加するときは、すべてのプロジェクトを含む JSON 全体をもう一度貼り付けてください。
