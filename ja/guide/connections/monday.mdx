monday.com を接続すると、[CloudThinker](/ja/guide/agents/overview) はボードの確認、動きの止まったアイテムの発見、アイテムのアップデートとドキュメントの閲覧、依頼に応じたアイテムの作成や変更ができます。monday.com はホスト型の MCP サーバーを通じて OAuth を使うため、作成したり貼り付けたりするトークンはありません。

## 前提条件

- CloudThinker に読ませたいボードを開ける monday.com アカウント。
- monday.com アカウントでサードパーティアプリを認可する権限。
- ボードの編集権限。エージェントにそのボードでアイテムの作成、列の値の変更、アップデートの投稿をさせたい場合のみ必要です。
- CloudThinker ワークスペースで接続を管理する権限。monday.com は CloudThinker のすべてのプランで使えます。

## セットアップ

<Steps>
  <Step title="CloudThinker で monday.com を開く">
    **Settings → Workspace → Connections** を開きます。**Discover** タブで **monday.com** を検索し、**Connect** をクリックします。
  </Step>
  <Step title="monday.com で認可する">
    新しいウィンドウで monday.com が開きます。ブラウザがブロックした場合は代わりにダイアログが表示されるので、**Open monday.com** をクリックします。CloudThinker に見せたいボードを持つアカウントでサインインし、アクセスを承認します。ウィンドウは自動で閉じます。

    ブラウザが別の monday.com アカウントにすでにサインインしている場合は、先にサインアウトしてください。
  </Step>
  <Step title="CloudThinker に戻る">
    CloudThinker に戻ったら、クリックするものはありません。CloudThinker が OAuth トークンを保存し、接続をテストします。

    **成功状態:** monday.com に **Connected** ステータスが表示されます。
  </Step>
</Steps>

## 接続の詳細

入力するフィールドはありません。

| 項目 | 説明 |
|---|---|
| **OAuth tokens** | アクセスを承認したときに monday.com が発行し、CloudThinker が保存します。置き換えるには再接続します。 |

1 つのワークスペースが持てる monday.com 接続は 1 つなので、到達できる monday.com アカウントも 1 つです。アカウントを切り替えるには、接続を解除してから再度接続してください。

## 必要な権限

CloudThinker は、接続を認可したアカウントとして動作します。そのアカウントが開けないボードは、エージェントからも見えません。

| アクセス | 対象 |
|---|---|
| **Read** | ワークスペース、ボード、アイテム、アイテムのアップデート、ボードのアクティビティ、ドキュメント、ユーザーとチーム、オートメーション、monday dev のスプリント（monday dev はソフトウェアチーム向けの monday.com の製品で、スプリントボードがあります） |
| **Write** | 次の 3 つの操作のみ: アイテムの作成、アイテムの列の値の変更、アイテムへのアップデートの投稿 |

<ApprovalDefault />

CloudThinker はボード、ワークスペース、ドキュメント、ダッシュボードを作成・削除できず、アイテムを削除・アーカイブすることもできません。

<Tip>
CloudThinker に必要なボードだけが見えるアカウントで認可してください。エージェントが作成したものは、monday.com 側で削除する必要があります。
</Tip>

## エージェントの機能

| 機能 | CloudThinker が行うこと | Approvals による確認 |
|---|---|---|
| **Account discovery** | ワークスペースとそのボード、ユーザー、チームを一覧表示し、他のリクエストに必要なボード ID を返します | なし |
| **Board review** | ボードのグループと列、そしてアイテムがステータスと担当者でどう分かれているかを要約します | なし |
| **Stalled work** | 指定した期間（デフォルトは 14 日）動いていないアイテムを古い順に見つけます。`Done` のアイテムは除きます | なし |
| **Item context** | アイテムのアップデート、ボードのアクティビティ、monday のドキュメントを読みます | なし |
| **Sprint reporting** | monday dev のスプリントボード、スプリントの詳細、スプリントのサマリーを読みます | なし |
| **Item changes** | アイテムの作成、列の値の変更、アップデートの投稿を行います | あり |

### 接続を確認する

```text
List my monday.com workspaces and the boards in each one, with their board IDs
```

ワークスペース名と見覚えのあるボードが表示されるはずです。あるはずのボードがない場合は、トラブルシューティングを参照してください。

### プロンプト例

```text
Review the Sprint Tasks board and show how open items split by status and owner
Which items on the Sprint Tasks board haven't moved in 21 days? Treat Done and Shipped as finished
Post an update on the "Checkout timeout" item saying the fix is in review
```

ボードで `Done` 以外の完了ラベルを使っている場合は、2 つ目のプロンプトのようにその名前を指定してください。3 つ目のプロンプトは書き込みなので、実行前に Approvals を通ります。

## トラブルシューティング

<Accordion title="OAuth のウィンドウが完了しない">
ブラウザが別の monday.com アカウントにサインインしている可能性があります。サインアウトし、目的のアカウントでサインインしてから、もう一度 **Connect** をクリックしてください。
</Accordion>

<Accordion title="エージェントがボードを空だと報告する">
monday.com は、不明、削除済み、または非表示のボード ID に対して、エラーではなく空のレコードを返します。まず CloudThinker にワークスペースとボードを一覧表示させ、その一覧にある名前か ID でボードを指定してください。
</Accordion>

<Accordion title="monday.com では見えるボードがない">
接続を認可したアカウントに、そのボードへのアクセスがありません。そのボードを開けるアカウントで再接続してください。ボードはワークスペースごとに一覧表示されるため、そのボードがあるワークスペースについて質問してください。
</Accordion>

<Accordion title="スプリントのサマリーが利用できないと返る">
スプリントのサマリーは、スプリントサマリーの列がある monday dev のスプリントボードにしかありません。他のボードでは、代わりにボードの確認かスプリントの詳細を依頼してください。
</Accordion>

<Accordion title="リクエストが 401 または 403 で失敗する">
401 は OAuth トークンが期限切れか取り消されたことを意味するので、monday.com を再接続してください。403 は認可したアカウントがそのボードやワークスペースを見られないことを意味するので、見られるアカウントで再接続してください。
</Accordion>

<Accordion title="リクエストがレート制限または複雑度のエラーで失敗する">
monday.com は 1 回のリクエストで取得できるボードデータの量を制限しています。1 分待ってから、リクエストを 1 つのボード、1 つのグループ、またはより少ないアイテムに絞ってください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **書き込みの範囲が小さい。** エージェントができるのは、アイテムの作成、列の値の変更、アップデートの投稿だけです。monday.com のその他の変更はすべてチームの手に残ります。
- **削除の手段がない。** CloudThinker は自分が作成したものを削除・アーカイブできないため、**Manual** を選んですべての変更を人が承認するようにし、確定する前に各承認リクエストを確認してください。**Ask first** の [Rule](/guide/approvals/rules) を使えば、この接続だけに同じことができます。
- **monday.com 側でも取り消す。** 接続を削除したら、monday.com アカウントが認可したアプリからも CloudThinker を削除してください。
