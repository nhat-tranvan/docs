Flespi アカウントを接続すると、[CloudThinker](/ja/guide/agents/overview) がテレマティクスのフリートに関する質問に答えられるようになります。どのデバイスが報告を止めたか、あるデバイスが過去 1 日に何を送信したか、チャネルがデータを受信しているか、ストリームがそれを配信しているか、といった質問です。Flespi は、GPS トラッカーやその他の IoT デバイスからデータを受信するテレマティクスのバックエンドです。CloudThinker は、あなたが作成した 1 つの **Flespi トークン** でサインインし、Flespi 自身がホストする MCP サーバーと通信します。

## 対応プラットフォーム

| プラットフォーム | 対応 | 備考 |
|----------|-----------|-------|
| **Flespi cloud**（flespi.io） | はい | CloudThinker は `https://flespi.io/ai/mcp/develop` にある Flespi のホスト型 MCP サーバーを呼び出します。アドレスは固定のため、データは Flespi の MCP サーバーから CloudThinker に流れ、他の Flespi エンドポイントは設定できません |

## 前提条件

- [flespi.io](https://flespi.io/#/) の Flespi パネルにアクセスできる Flespi アカウント。
- そのアカウントでトークンを作成する権限。

## トークンの種類を選ぶ

| トークンの種類 | アクセス | 用途 |
|------------|--------|------------|
| **ACL** | モジュールとメソッドごとに付与するまで何もできません | 本番環境。推奨 |
| **Standard** | テレマティクスのエンティティへの完全な読み書き | 短期間のテストのみ |
| **Master** | アカウントの完全な管理 | CloudThinker では決して使わない |

読み取り専用の ACL トークンでは、エージェントに見せる各モジュールに **GET** を付与します。

| ACL モジュール | メソッド | 利用可能になるもの |
|------------|--------|---------|
| `gw/devices` | GET | Devices と Telemetry: デバイス一覧、最終報告時刻、デバイスのメッセージ |
| `gw/channels` | GET | Channels: 設定、プロトコル、受信データ |
| `gw/streams` | GET | Streams: ステータスと配信 |
| `gw/geofences` | GET | ジオフェンス |
| `gw/calcs` | GET | 走行検出などの計算機（calculator） |

エージェントが必要としないモジュールは含めないでください。書き込みメソッド（POST、PUT、DELETE）は、エージェントに変更させたい場合にのみ付与してください。[書き込みアクセス](#書き込みアクセス)を参照してください。

<Info>
ACL トークンはデフォルトで拒否し、権限は互いを含みません。デバイスへの書き込みアクセスには、読み取りも付与しない限り、デバイスの読み取りは含まれません。
</Info>

## セットアップ

<Steps>
  <Step title="Flespi でトークンを作成する">
    Flespi パネルの左メニューで **Tokens** を開き、**+** をクリックします。次を設定します。

    - **Name**: `CloudThinker`
    - **Type**: **ACL**。ACL エディターで、[ACL の表](#トークンの種類を選ぶ)のモジュールごとにエントリを 1 つ追加し、それぞれで **GET** メソッドを許可します
    - **Expiration**: Flespi では、すべてのトークンに TTL または有効期限が必要です。90 日の非アクティブ TTL を使ってください。呼び出しのたびにリセットされるため、使用中のトークンは有効なままで、使われていないトークンは削除されます

    トークンを保存し、その値をコピーします。
  </Step>
  <Step title="CloudThinker で接続を追加する">
    **Settings → Workspace → Connections** を開き、**Discover** タブを開いて **Flespi** を選びます。トークンを **FLESPI_TOKEN** に貼り付けます。`FlespiToken` のプレフィックスは付けず、トークンの値だけを貼り付けてください。CloudThinker がそのヘッダーを自分で付加します。

    **Connect** をクリックします。

    **成功時の状態:** 接続に **Connecting** と **Verifying** が表示され、その後 **Connected** になります。検証が失敗すると **Failed** と表示され、エラーメッセージが表示されます。メッセージを[トラブルシューティング](#トラブルシューティング)と照合してください。
  </Step>
</Steps>

## 接続の詳細

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| **FLESPI_TOKEN** | はい | Flespi の ACL または Standard トークン。CloudThinker はこれを `Authorization: FlespiToken <token>` として Flespi の MCP サーバーに送信します |

## エージェントの機能

エージェントができることは、トークンが許可する内容によって決まります。

| 機能 | エージェントができること | 必要な ACL |
|------------|--------------------|-----------|
| **Devices** | デバイスを一覧表示し、それぞれの最終報告時刻を確認し、デバイスの最近のメッセージを読みます | `gw/devices` GET |
| **Telemetry** | 期間を指定して、デバイスのメッセージから位置、速度、センサーの値を取得します | `gw/devices` GET |
| **Channels** | チャネルの設定とプロトコル、チャネルがデータを受信しているかを調べます | `gw/channels` GET |
| **Streams** | ストリームのステータスと、下流のシステムへの配信を確認します | `gw/streams` GET |
| **Geofences and calculators** | ジオフェンスのゾーンと、走行検出などの計算機の設定を読みます | `gw/geofences` GET、`gw/calcs` GET |

Flespi のドキュメント検索など、Flespi の AI 支援ツールの一部は、Flespi アカウントの AI 使用枠を消費します。これらに頼る場合は、Flespi パネルの **AI** タイルを確認してください。通常のデバイス、チャネル、ストリームの読み取りは枠を消費しません。

### 接続を確認する

```text
List my Flespi devices and when each one last reported
```

デバイス名または ID と、それぞれの最終メッセージ時刻の一覧が返されることを確認します。トークンが読めないデバイスは表示されません。

### プロンプトの例

```text
Which Flespi devices haven't sent a message in the last 6 hours?
Show the messages from device 12345 over the last 24 hours and flag any gaps
Are all my Flespi streams delivering, and which ones have errors?
```

## 書き込みアクセス

推奨される構成は読み取り専用の ACL トークンで、Flespi は許可されていない書き込みをすべて拒否します。書き込みメソッドを付与した場合、エージェントが試みる各書き込みは [Approvals](/guide/approvals/overview) を経由します。Rules と Approval mode によって、実行されるか、人の判断を待つか、拒否されるかが決まります。読み取りには承認は不要です。

## トラブルシューティング

<Accordion title="Invalid or expired token">
Flespi はトークンが期限切れになると削除します。Flespi パネルでトークンの TTL を確認し、なくなっている場合は新しいトークンを作成して、接続の **FLESPI_TOKEN** を更新してください。
</Accordion>

<Accordion title="Action is not permitted by ACL">
ACL トークンに、そのリクエストのモジュールとメソッドがありません。Flespi パネルでトークンに権限を追加してください。読み取りと書き込みは別々に付与されることに注意してください。
</Accordion>

<Accordion title="Using token from unauthorized location">
トークンに、CloudThinker を含まない IP 許可リストが設定されています。Flespi パネルでトークンの IP ホワイトリストに CloudThinker の送信元 IP を追加するか、制限を削除してください。このドキュメントでは CloudThinker の送信元 IP の一覧を公開していません。CloudThinker の担当者に問い合わせるか、[お問い合わせ](https://cloudthinker.io/contact)ください。
</Accordion>

<Accordion title="HTTP 429 のレート制限">
Flespi は、アカウントの API、MQTT、トラフィックをまとめて 1 分あたりの使用量を制限しています。範囲を絞るか、一度に扱うデバイスを減らして依頼するか、1 分待ってから再試行してください。
</Accordion>

<Accordion title="AI 支援の検索が拒否される">
その月の Flespi の AI 使用枠を使い切りました。デバイス、チャネル、ストリームの読み取りは引き続き機能します。使用量は Flespi パネルの **AI** タイルで確認してください。
</Accordion>

## セキュリティ

<ConnectionSecurity />

- **CloudThinker 専用のトークンを 1 つ**: 他の連携と共有しないでください。そうすれば単独で取り消せます。
- **Master トークンは決して使わない**: エージェントが必要とするモジュールとメソッドだけを持つ ACL を使ってください。
- **90 日の非アクティブ TTL を維持する**: 使用中のトークンは有効なままです。接続がそれだけの期間使われないと、Flespi がトークンを削除し、新しいトークンが必要になります。通常の認証情報のスケジュールでもローテーションしてください。
