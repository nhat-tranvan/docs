Microsoft Teams を一度接続すれば、マッピングされたチームのメンバーなら誰でも、チャンネルで `@CloudThinker` をメンションしてクラウドについて質問し、そのままスレッドで会話を続けられます。同じ接続で、アラートやコードレビューの要約などの[通知](/ja/guide/notifications)を、選択したチャンネルに Adaptive Cards として配信します。

## 前提条件

- CloudThinker 組織の **Owner** または **Admin** であること。ほかのロールは Teams のページを閲覧できますが、接続や変更はできません。
- Team、Scale、または Enterprise プラン。Free プランでは、Microsoft Teams の行に **Requires Team plan** と表示され、**Configure** ボタンは表示されません。[料金](/ja/guide/billing/pricing)を参照してください。
- Microsoft Entra ID で管理者の同意を付与できる Microsoft 365 管理者。CloudThinker はボットを組織の Teams アプリカタログに公開するため、管理者の同意が必要です。1人が両方のロールを兼ねてもかまいません。Microsoft 365 の管理者でない場合は、CloudThinker の Owner または Admin として Teams のページを開き、ステップ2で **Connect with Microsoft** をクリックして、一緒に作業しながら Microsoft の画面で Microsoft の管理者にサインインしてもらいます。管理者が同意する権限は、[セキュリティと権限](#セキュリティと権限)に記載しています。
- app.cloudthinker.io でホストされている CloudThinker。セルフホストのインストールでは、行に **Not available on self-host** と表示されます。

各 Microsoft テナントは、1つの CloudThinker 組織に接続できます。

## Microsoft Teams を接続する

<Steps>
  <Step title="Teams 連携を開く">
    **Settings → Organization → Chat integrations** に移動し、**Microsoft Teams** の行を見つけて **Configure** をクリックします。Settings を開くには、サイドバー上部のワークスペースメニューをクリックし、**Settings** をクリックします。
  </Step>
  <Step title="Connect with Microsoft をクリックする">
    Microsoft の管理者アカウントでサインインします。権限の画面で **Consent on behalf of your organization** にチェックを入れ、**Accept** をクリックします。

    **成功状態：** **Teams connected successfully** というメッセージとともに Teams のページに戻り、**Authenticate with Microsoft** にテナント名と ID が表示されます。
  </Step>
  <Step title="チームを追加する">
    **Install bot and configure workspaces** で **Add team** をクリックし、チームを検索して選択します。検索結果には、自分が所有するチームだけでなく、入力した文字で名前が始まるテナント内のすべてのチームが表示されます。チームのメンバー全員がボットを表示・メンションできるようになるため、事前にチームの所有者と調整してください。CloudThinker はそのチームにボットをインストールし、ボットはそこでチャンネルのメッセージを読み取り（`ChannelMessage.Read.Group` 権限）、返信やカードを投稿できるようになります。

    **成功状態：** **CloudThinker bot installed to team** というメッセージが表示され、チームが行として表示されます。さらにチームを追加するには、**Add another team** をクリックして繰り返します。
  </Step>
  <Step title="各チームのワークスペースを選ぶ">
    チームの行で **Select workspace** を開き、そのチームが使う接続を持つ CloudThinker のワークスペースを選びます。チーム内のすべてのチャンネルがこのワークスペースを使います。

    **成功状態：** **Workspace mapping updated** というメッセージが表示されます。
  </Step>
  <Step title="テストメッセージを送る">
    そのチームの任意の標準チャンネルで、ボットをメンションします。

    ```text
    @CloudThinker What drove our cloud spend up last week?
    ```

    **成功状態：** CloudThinker がスレッドで返信します。続けて質問するには、そのスレッドで返信してください。ボットを再度メンションする必要はありません。
  </Step>
</Steps>

<Warning>
マッピングされたチームに投稿できる人は誰でも、そのワークスペースの接続を使った作業を CloudThinker に依頼できます。CloudThinker アカウントをリンクした人のリクエストは、そのユーザーとして実行されます。それ以外の人のリクエストは、1つのアカウントとして実行されます。ワークスペースを作成した人、または組織が所有するワークスペースの場合は組織の **Owner** です。メンバーにそのアクセスを与えてよいチームだけをマッピングしてください。
</Warning>

### CloudThinker アカウントをリンクする

アカウントをリンクすると、リクエストはその1つのアカウントではなく、あなた自身としてあなたのワークスペースロールで実行されます。リンクは任意のタイミングでは開始できません。CloudThinker が **Link Your CloudThinker Account** カードを投稿するのは、ワークスペースを所有するアカウントが見つからない場合だけです。カードの **Link Account** をクリックしてサインインします。完了すると、ページに **Account linked successfully!** と表示されます。ステップ2でサインインした Microsoft アカウントは、**Connect with Microsoft** をクリックした CloudThinker アカウントに自動的にリンクされます。そのため、2人で一緒にセットアップした場合、その Microsoft 管理者のリクエストは CloudThinker の管理者として実行されます。ユーザーごとのリンク解除はありません。**Disconnect from Teams** を実行すると、リンクされたすべてのアカウントが削除されます。

## Teams で CloudThinker に質問する

新しいリクエストは、チームのチャンネルで `@CloudThinker` から始めます。それ以降は、Web アプリで入力するのと同じリクエストを書きます。

<PromptSyntaxBasics />

```text
@CloudThinker Which EC2 instances ran under 10% CPU for the last 14 days?
@CloudThinker Summarize open critical security findings for production
@CloudThinker Why did checkout latency spike at 14:00 UTC today?
```

| 表示されるもの | 意味 |
| --- | --- |
| 入力中のインジケーター | CloudThinker がリクエストを処理しています |
| スレッドでの返信 | 回答です。会話全体は CloudThinker の Web アプリにも表示されます |
| **View in CloudThinker** 付きの **Permission Required** カード | リクエストに、[Approvals](/guide/approvals/overview) の設定で人の判断を待つアクションが必要です。リンクを開き、Web アプリで承認または却下してください。Resolve のインシデントのチャンネルでは、代わりにカードに **Approve** と **Reject** のボタンが表示されます |
| **Link Your CloudThinker Account** カード | アカウントをリンクしておらず、CloudThinker がワークスペースを所有するアカウントを見つけられなかったため、リクエストは実行されませんでした。**Link Account** をクリックし、CloudThinker にサインインしてください |

CloudThinker はチームのチャンネルでのみ動作します。個人チャットやグループチャットではリクエストを実行せず、チームが見つからない場合は **I can only respond in team channels** と返信します。CloudThinker はメッセージのテキストを読み取るため、ファイルを添付する代わりに、読ませたい内容を貼り付けてください。

## Teams に通知を送る

<Steps>
  <Step title="通知の設定を開く">
    Teams のページの **Configure notifications** で、**Go to notification settings** をクリックします。**Settings → Workspace → Notifications** に移動することもできます。
  </Step>
  <Step title="ワークスペースのデフォルトのチャンネルを選ぶ">
    **Delivery channels** で Teams のカードを見つけます（設定されるまでは **Pick a channel** と表示されます）。設定アイコン（**Change Teams channel**）をクリックし、**Teams channel** でチャンネルを検索して選択します。表示されるのは標準チャンネルだけです。プライベートチャンネルと共有チャンネルは、ボットの通知を受け取れません。
  </Step>
  <Step title="通知の種類ごとに上書きする（任意）">
    **What to send** で、イベントの Teams のセルをオンにし、その横の **→** チャンネルチップをクリックして、そのイベントを別のチャンネルに送ります。**Alerts** と **Keepers** の行には重大度の選択もあります。種類の一覧は[通知](/ja/guide/notifications)を参照してください。

    **成功状態：** 次に該当するイベントが、選択したチャンネルにカードとして投稿されます。
  </Step>
</Steps>

## コードレビューの通知

接続されたリポジトリで [Review](/ja/guide/code-review/overview) がプルリクエストまたはマージリクエストのレビューを終えると、CloudThinker は Teams に Adaptive Card を投稿できます。

- 重大度別の検出結果の表
- 未解決の検出結果を最大5件。それぞれにタイトル、重大度、ファイルパス、行番号が付きます
- 以前の検出結果のうち、解決済みになった件数
- CloudThinker でレビューを開く **View Review** ボタン
- レビューで問題がなかった場合は **No issues found**

レビューのチャンネルと重大度のしきい値は、[通知](/ja/guide/notifications)で選びます。

## セキュリティと権限

| 質問 | 回答 |
| --- | --- |
| Microsoft Graph の権限 | 委任された権限で、サインイン時に付与されます。下の表を参照してください |
| CloudThinker が保持するのは誰のトークンか | Teams を接続した Microsoft 管理者のものです。CloudThinker はその管理者のアクセストークンとリフレッシュトークンを暗号化して保存し、チームとチャンネルの一覧表示やボットのインストールに使います。管理者が退職したなどの理由でトークンが機能しなくなると、チームの追加は **Teams connection token expired. An admin must reconnect Teams.** というエラーで失敗します。CloudThinker のアクセスを取り消すには、Microsoft Entra ID の **Enterprise applications** で管理者の同意を削除します |
| 各チームでのボットの権限（アプリケーション、リソース固有） | `ChannelMessage.Read.Group`。ボットがそのチームのチャンネルのメッセージを読み取れるようにします |
| CloudThinker が保存するもの | リクエストとその返信（マッピングされたワークスペースに会話として保存）、チームとワークスペースのマッピング、リンクされたアカウント |

| Graph の権限 | 理由 |
| --- | --- |
| `User.Read`、`openid`、`profile` | Microsoft 管理者をサインインさせる |
| `Organization.Read.All` | Teams のページ用にテナント名を読み取る |
| `Team.ReadBasic.All` | **Add team** の検索でチームを一覧表示する |
| `Channel.ReadBasic.All` | 通知の選択でチャンネルを一覧表示する |
| `AppCatalog.ReadWrite.All` | CloudThinker のボットを組織の Teams アプリカタログに公開する |
| `TeamsAppInstallation.ReadWriteForTeam`、`TeamsAppInstallation.ReadWriteSelfForTeam` | 追加したチームにボットをインストールし、チームを削除したときにボットを削除する |
| `TeamsAppInstallation.ReadWriteAndConsentForTeam` | ボットが参加する各チームで、ボットに `ChannelMessage.Read.Group` 権限を付与する |
| `offline_access` | リフレッシュトークンを取得し、CloudThinker が再度サインインせずに Graph を呼び出し続けられるようにする |

## 接続を管理する

| 作業 | 方法 |
| --- | --- |
| チームを別のワークスペースに移す | その行の **Select workspace** を変更します |
| チームで CloudThinker の利用をやめる | Teams のページでそのチームの行を削除します。CloudThinker はそのチームからボットをアンインストールし、そのチャンネルを指していた通知の設定を消去します |
| 接続を解除する | Teams のページの下部にある **Disconnect from Teams** をクリックします。CloudThinker はマッピングされたすべてのチームからボットをアンインストールし、チームのマッピング、リンクされたアカウント、Teams の通知設定を削除します |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Teams authorization denied">
    Microsoft のサインインが拒否されたか、キャンセルされました。もう一度 **Connect with Microsoft** をクリックし、権限を承諾してください。
  </Accordion>
  <Accordion title="チームの追加時に Missing required permissions と表示される">
    Microsoft アカウントが管理者の同意を付与していません。Microsoft 365 の管理者として再度サインインして **Consent on behalf of your organization** にチェックを入れるか、Microsoft Entra ID で CloudThinker に管理者の同意を付与してください。
  </Accordion>
  <Accordion title="ボットがチームにインストールされない">
    Teams の管理者設定でカスタムアプリがブロックされている可能性があります。Teams 管理センターで **Teams apps → Manage apps** に移動し、開発者 CloudThinker によって組織に公開されたカスタムアプリ **CloudThinker** を検索します。状態がブロックされている場合は許可に変更し、アプリのアクセス許可ポリシーでブロックされていないことを確認します。その後、もう一度 **Add team** をクリックしてください。
  </Accordion>
  <Accordion title="This tenant is already connected">
    Microsoft テナントがすでに別の CloudThinker 組織に接続されています。まずそちらで接続を解除してください。
  </Accordion>
  <Accordion title="This team isn't linked to any workspace">
    チームにワークスペースのマッピングがありません。Teams のページでチームの行の **Select workspace** を設定するか、チームが一覧にない場合は **Add team** をクリックしてください。
  </Accordion>
  <Accordion title="ボットが返信しない">
    追加したチームの標準チャンネルに投稿したこと、そして新しいメッセージで `@CloudThinker` をメンションしたことを確認してください。メンションのないメッセージに返信があるのは、CloudThinker がすでに開始したスレッドの中だけです。
  </Accordion>
  <Accordion title="通知の選択にチャンネルが表示されない">
    表示されるのは標準チャンネルだけです。同じチームの標準チャンネルを選ぶか、チームが Teams のページに表示されていることを確認してください。
  </Accordion>
</AccordionGroup>
