**チームのやり方に合わせて動きます。**

Customize は、エージェント（組み込みのアシスタントである CloudThinker と、作成したカスタムエージェント。[エージェント](/ja/guide/agents/overview)を参照）をチームに合わせて調整する仕組みです。どのエージェントを置くか、どの手順に従うか、どのシークレットを使えるか、アラートをどこに送るか、どの変更に人の確認が必要かを決めます。ここでの設定はすべてワークスペース単位で、**Settings → Workspace** にあります。

これらを何も設定しなくても、CloudThinker は動作します。

## 仕組み

各要素は、エージェントの振る舞いに関する 1 つの問いに答えます。どの順番で設定してもかまいません。

1. **誰が答えるか。** カスタムエージェントは、独自の名前、`@mention`、指示、返答言語、接続を持ちます。
2. **どう動くか。** Skills には、手順やルールを保存します。
3. **何にアクセスできるか。** Connections は、あなたのシステムへのアクセスを提供します。Credentials は、CLI 用のベンダー API キーなど、その他のシークレットを保存します。そのツール用の接続がない場合に使います。
4. **何を変更してよいか。** Approvals は、各書き込みを実行するか、人の判断を待つか、拒否するかを決めます。モードは 2 つあります。**Manual** はすべての書き込みの前に人に確認し、**Auto** は Rules、次に AI の判断に任せます。
5. **誰に知らせるか。** Notifications は、アラートをメール、Slack、Teams、Google Chat に送ります。

これらに加えて、任意の機能が 1 つあります。**Memory** は、エージェントが会話をまたいで覚えておく内容を保存します。

<Warning>
新しいワークスペースは **Auto · Rules + AI · Ask me** で始まり、AI の判断で安全な書き込みを確認なしで実行できます。本番環境を接続する前に、すべての書き込みの前に人に確認する **Manual** に切り替えてください。**Ask first** の [Rule](/guide/approvals/rules) は、より範囲を絞った制御で、特定の種類の書き込みだけを人の判断待ちにします。[Approvals](/guide/approvals/overview#what-you-get-out-of-the-box) を参照してください。
</Warning>

## エージェントごとの設定とワークスペース全体の設定

| カスタムエージェントごとに設定 | ワークスペース内のすべてのエージェントで共有 |
|---|---|
| 名前と `@mention`、指示、返答言語、モデルティア、Learning Mode、接続 | スキル、認証情報、メモリ、通知、Approval Rules とワークスペースの Approval mode |

スキルは、**Available in** でチェックした各サーフェス（Chat や Review など）のすべてのエージェントに届きます。カスタムエージェントを特定のスキルに限定することはできません。代わりに、指示と接続で範囲を絞ってください。指示はエージェントの方向付けであり、何かをブロックするものではありません。接続が厳密な制限です。エージェントは、自分に追加された接続にしかアクセスできません。

## 各設定の場所

サイドバー上部のワークスペースメニューから **Settings** を開くか（**Workspace** が開きます）、⌘,（Windows/Linux では Ctrl+,）を押します。**Workspace** タブでは、ページが次のようにグループ化されています。

| グループ | ページ | 設定する内容 | 編集できるロール | ガイド |
|-------|------|--------------------|--------------|-------|
| Overview | **Connections** | エージェントがアクセスできるクラウドアカウント、クラスター、データベース、ツール | Admin | [Connections](/ja/guide/connections/overview) |
| Overview | **Notifications** | どのイベントをメール、Slack、Teams、Google Chat に送るか | Admin | [Notifications](/ja/guide/notifications) |
| Agents & context | **Agents** | カスタムエージェント：アイデンティティ、指示、モデルティア、接続 | Admin と Developer | [カスタムエージェントのクイックスタート](/guide/agents/quickstart) |
| Agents & context | **Skills** | 再利用できる手順と、それぞれの適用先 | Admin | [Skills](/ja/guide/skills/overview) |
| Agents & context | **Memory** | エージェントが会話をまたいで覚えておく内容 | Admin | [Memory](/guide/memory) |
| Access & keys | **Credentials** | エージェントがコマンドを実行するときに受け取るシークレット | Admin | [Credentials](/guide/credentials) |
| Autonomy | **Rules**、**Approvers**、**Runbooks** | Rules、Approval mode、書き込みの承認者 | Admin | [Approvals](/guide/approvals/overview) |

同じグループには、**General**、**Members**、**Capabilities**、**Environments**、**BYOK** など、その他のワークスペースページもあります。

ロールごとのすべての権限は、[ロール](/guide/security/roles)を参照してください。

## できること

| 目的 | 設定する内容 | 詳細 |
|------|-------------|------------|
| ベトナム語で答えるコストレビュー担当など、チーム専用のスペシャリストを用意する | カスタムエージェントを作成し、**Language** を設定し、必要な接続だけを追加する | [カスタムエージェントのクイックスタート](/guide/agents/quickstart) |
| エージェントに毎回ランブックどおりに作業させる | ランブックをスキルとして書き、**Chat** または **Incident** に追加する | [カスタムスキル](/ja/guide/skills/custom-skills) |
| すべてのプルリクエストにレビュー基準を適用する | スキルを書き、**Review** に追加する | [カスタムスキル](/ja/guide/skills/custom-skills#スキルを適用する場所を選ぶ) |
| エージェントを特定のアカウントやツールに限定する | それらの接続だけをエージェントに追加する | [カスタムエージェントのクイックスタート](/guide/agents/quickstart#give-it-a-connection) |
| チャットに貼り付けずにエージェントへ API トークンを渡す | **Credentials** に追加する | [Credentials](/guide/credentials) |
| 本番環境への書き込みの前に必ず人の確認を求める | Approval mode を **Manual** に設定するか、**Ask first** の Rule を追加して特定の種類の書き込みを人の判断待ちにする | [Approvals](/guide/approvals/overview) |

スキル、メモリ、Learnings、ランブックソースのどれを使うかは、[CloudThinker に教える](/guide/teach-cloudthinker)を参照してください。

## カスタムエージェントの概要

| 項目 | 詳細 |
|------|--------|
| 作成 | **Settings → Workspace → Agents** で **Create agent** をクリックします。**Create with AI** または **Build with form**（Identity、Configuration、Connect の 3 ステップのダイアログ）を選びます。 |
| Create with AI | 名前、`@mention`、役割、目標、指示、モデルティア、言語、Learning Mode、アバター、接続を尋ねるチャットが開きます。`@mention` を確認したあと、確認用のフォームなしでチャットからエージェントを作成します。通常のチャットなので、クレジットを消費します。 |
| `@mention` | 英小文字、数字、ドット、アンダースコア、ハイフンを使用でき、英字で始まる 63 文字以内です。一度だけ設定でき、後から変更できません。 |
| 指示 | 最大 4,000 文字の平易な文章によるガイダンスです。エージェントにスキルを指し示すのに使います。例：`Use the ec2-high-cpu-runbook skill for performance questions.` |
| Model Tier | **Light**（Pro の 0.3 倍のクレジット、簡単な質問向け）、**Pro**（デフォルト、日常の作業向け）、**Ultra**（Pro の 1.7 倍のクレジット、難しい問題向け）。Free プランは Light のみ実行できるため、その場合は **Light** を選んでください。[実行コストが増える要因](/ja/guide/billing/usage#実行コストが増える要因)を参照してください。 |
| Language | デフォルトは **Match the user** で、エージェントは最新のメッセージと同じ言語で返答します。言語を選ぶと、すべての返答がその言語に固定されます。 |
| Learning Mode | 繰り返すワークフローをエージェントがスキルとして保存するかどうか。[Learning Mode](#learning-mode) を参照してください。 |
| Connections | 1 エージェントあたり最大 64 個。**Builtin** タブと **MCP** タブから選びます |
| 作成・編集できるロール | ワークスペースの Admin と Developer。Viewer はエージェントを表示できますが、チャットや編集はできません。 |

各ワークスペースで持てるカスタムエージェントの数は、プランによって異なります。

| プラン | カスタムエージェント数 |
|------|---------------|
| Free | 1 |
| Team | 5 |
| Scale | 10 |
| Enterprise | 無制限 |

**Create Custom Agent** ダイアログには、使用済みの枠数が **3 of 5 custom agents used** のように表示されます。組織の Owner は、プラン自体を **Settings → Organization → Billing** で確認できます。

上限に達すると **Create agent** が無効になり、ホバーすると **Custom agent limit reached.** と **Upgrade plan** リンクが表示されます。エージェントを削除すると、その枠はすぐに空きます。上限はエージェントの作成時にのみチェックされるため、ダウングレード後も既存のエージェントは動作し続けますが、新しい上限を下回るまで追加はできません。その他のプラン別の上限は、[料金](/ja/guide/billing/pricing#プラン別の-ai-機能)を参照してください。

## Learning Mode

Learning Mode を使うと、カスタムエージェントは繰り返し行うワークフローをスキルにできます。ツール呼び出しが 10 回以上行われた会話で、エージェントが同じ接続に対して同じツール呼び出しを 3 回行うと動作します。これらのしきい値はワークスペース設定では変更できません。

| モード | 動作 |
|---|---|
| **Auto**（フォームのデフォルト） | エージェントが自分でワークフローをスキルとして保存します。「調査のみ、何も変更しない」など、依頼が読み取りに限定されている場合は保存しません。 |
| **Offer** | エージェントがまずチャットで確認し、そのチャットにいる人なら誰でも承認できます。 |
| **Off** | エージェントはスキルを保存しません。 |

<Note>
**Settings → Workspace → Skills** でスキルを作成できるのは Admin だけですが、Developer もエージェントを作成できます。**Auto** または **Offer** のカスタムエージェントは Admin なしでワークスペースのスキルを追加し、そのスキルはすべてのエージェントの **Chat** で有効になります。[Audit Logs](/guide/security/audit-logs) には記録されません。本番ワークスペースのエージェントには **Off** を使ってください。Off を強制するワークスペース設定はありません。Admin がエージェントの設定でエージェントごとに設定し、学習されたスキルは **Settings → Workspace → Skills** で編集、適用範囲の変更、削除ができます。
</Note>
