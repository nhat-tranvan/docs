組み込みのアシスタントである [CloudThinker](/ja/guide/agents/overview) は、すぐに使えます。カスタムエージェントを使うと、独自の指示、返答言語、接続を持つ専門家をその横に追加できます。

## 変更できること

**Settings → Agents** に移動します。サイドバーにはワークスペースの **Custom** エージェントが一覧表示されます。組み込みのアシスタントには設定項目がありません。エージェントをクリックすると、**Identity** と **Connections** の 2 つのタブが開きます。

<Note>
  エージェントのカスタマイズには、ワークスペースの **Admin** ロールが必要です。[Developer と Viewer](/ja/guide/workspace-users) はエージェントとチャットできますが、編集はできません。
</Note>

| フィールド | 変更できるか |
|-------|--------------------|
| @メンション | 作成時に一度だけ設定 |
| 名前、役割、目標、Instructions | はい |
| Model Tier、Language、Skill Learning | はい |
| Connections | はい — 追加と削除 |
| アクティブ状態 | はい — 接続がないとエージェントは自動的にオフになります |

## プランティア

カスタムエージェントの数はプランによって異なります。

| プラン | カスタムエージェント数 |
|------|---------------|
| Free | 1 |
| Team | 5 |
| Scale | 10 |
| Scale+ | 10 |
| Enterprise | 無制限 |

上限に達した場合は、未使用のエージェントを削除するか[プランをアップグレード](/ja/guide/billing/pricing)してください。

## カスタムエージェントを作成する

チームのルールを組み込んだエージェント — 請求アナリスト、オンコールサマライザー、ドキュメント専門家など — が必要ですか？独自のエージェントを構築しましょう。

**Settings → Agents** に移動し、**Create agent** をクリックして、**Create with AI** または **Build with form** を選択します。

<Tabs>
  <Tab title="Create with AI">
    **エージェントに何をさせたいかはわかっているが**、すべてのフィールドを自分で入力したくない場合に最適です。

    何が必要かを 1 文で説明すると、CloudThinker が引き継ぎます。通常、以下を確認します：

    - **名前と @メンション** — 説明に基づいて候補を提案します。
    - **役割と目標** — 両方の下書きを作成し、承認または微調整できます。
    - **Model Tier** — タスクの複雑さに基づいて Light / Pro / Ultra を推奨します。
    - **Instructions** — 最初の下書きを生成し、後から洗練できます。
    - **Connections** — どれを接続するかを尋ねます（クラウド、データベース、Kubernetes、または [MCP](/ja/guide/connections/mcp) — 外部ツールを接続するためのオープン標準）。
    - **Skill Learning** — エージェントが新しい [Skills](/ja/guide/skills/overview)（作業から身につけた再利用可能なノウハウ）を自動で保存するか（**Auto**）、先に確認するか（**Offer**）、保存しないか（**Off**）。

    プロンプト例：*「AWS の支出を監視し、日次コストが 20% 以上跳ね上がったときに通知するエージェントが必要です。」*

    その後、エージェントの設定ダイアログから任意のフィールドを編集できます。
  </Tab>
  <Tab title="Build with form">
    最初からすべてのフィールドを完全に制御したい場合に最適です。ダイアログは 3 つのステップを案内します。ヘッダーには現在のプランのカスタムエージェントクォータが表示されます（例：Scale では「1 of 10 custom agents used」）。

    <Steps>
      <Step title="Identity">
        - **Avatar** — タイルをクリックして変更します（デフォルトはグラデーション上のイニシャル）。
        - **Name** — 例：「Cost Guardian」。
        - **@mention** — チャットハンドル（例：`@cost-guardian`）。英小文字、数字、ドット、アンダースコア、ハイフンを使用でき、英字で始まる 63 文字以内です。一意である必要があり、CloudThinker が予約している名前は使用できません。**一度設定すると後から変更できません。**
        - **Role** — 短いタイトル（例：「FinOps Specialist」）。
        - **Goal** — このエージェントが何をするかを 1 文で。

        **Next** をクリックします。

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-1.png" alt="カスタムエージェント作成ウィザード、ステップ 1 Identity — アバタータイル、名前、@メンション、役割、目標フィールド" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Configuration">
        - **Model Tier** — **Light**（高速、最低クレジットコスト）、**Pro**（バランス型）、**Ultra**（最大性能、最高クレジットコスト）から選択します。現在のクレジット乗数については[モデルティアとクレジットコスト](/guide/billing/usage#model-tiers-and-credit-cost)をご覧ください。
        - **Instructions** — エージェントの振る舞いを記述するテキストエリア：何に集中するか、どのように応答するか、何を避けるか。平易な文章で記述します — ガイドライン、制約、トーン、応答フォーマットはすべてここに記載します。最大 4,000 文字です。
        - **Language** — 返答言語。
        - **Skill Learning** — **Auto** は新しいスキルを自動保存、**Offer** は保存前に確認、**Off** は保存しません。

        **Next** をクリックします。

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-2.png" alt="カスタムエージェント作成ウィザード、ステップ 2 Configuration — Model Tier、Instructions、Language、Learning mode" style={{ maxWidth: '400px' }} />
        </Frame>
      </Step>
      <Step title="Connect">
        省略可能。**Builtin** と **MCP** タブを使って、このエージェントがアクセスできる接続を選択します。後からエージェント設定で追加することもできます。

        **Skip and Create** をクリックして完了します。

        <Frame>
          <img src="/images/agents/create-custom-agent-dialog-3.png" alt="カスタムエージェント作成ウィザード、ステップ 3 Connect — Builtin と MCP タブおよび接続追加リスト" style={{ maxWidth: '500px' }} />
        </Frame>
      </Step>
    </Steps>

    エージェントは **Custom** の下に表示され、チャットで @メンションハンドルから呼び出せます。
  </Tab>
</Tabs>

## 接続を追加する

接続は、カスタムエージェントがクラウド、データベース、Kubernetes、MCP サーバーにアクセスするための手段です。各エージェントが何にアクセスできるかはあなたが決めます。すべてのエージェントは同じ組み込みツールを持ち、エージェントごとのツール切り替えはないため、エージェントの範囲は接続の選択で絞り込みます。1 つのエージェントには最大 64 個の接続を追加できます。

<Steps>
  <Step title="Connections タブを開く">
    エージェントダイアログから **Connections** をクリックします。ヘッダーに接続数が表示されます（例：「3 connections」）。
  </Step>
  <Step title="Builtin または MCP を選択する">
    サブタブを使って **Builtin**（クラウド、データベース、Kubernetes）と **MCP** を切り替えます。
  </Step>
  <Step title="追加または削除する">
    **Add** をクリックして追加、**Remove** をクリックして削除します。Save で適用します。
  </Step>
</Steps>

エージェントの役割に必要な接続だけを追加してください — データベースレビュー担当に本番環境の IAM アクセスは必要ありません。**接続のないカスタムエージェントは自動的にオフになります**。有効に戻すには少なくとも 1 つの接続を追加してください。

## 使用例

| やりたいこと | 実施方法 |
|---------------|------------|
| ベトナム語で返答するエージェント | エージェントの **Identity** タブで **Language** をベトナム語に設定します。 |
| 推奨のみ行い、変更は加えないエージェント | Instructions に *「推奨のみ — 書き込みアクセスが必要な変更は提案しないこと。」* と記載したカスタムエージェントを作成します。 |
| コストを EUR で報告し、週次ダイジェストを送る | Instructions に *「コストを EUR で報告すること。週次で支出をまとめること。」* と記載したカスタムエージェントを作成し、クラウド接続を追加します。 |

良い Instructions は 3 つの領域をカバーします：役割のコンテキスト（あなたの環境に合わせた専門性）、範囲の制限（エージェントが触れてよいもの、触れてはいけないもの）、運用ガイドライン（手順とエスカレーション経路）。例：

```text
You are the Cloud Engineer for Acme Corp.

Environment:
- Primary cloud: AWS (us-east-1, us-west-2)
- Secondary cloud: GCP (for ML workloads)
- Cost target: Reduce by 20% this quarter

Guidelines:
- Flag every security group change for review before recommending it
- Prioritize production stability over cost savings
- Flag any resource costing >$1000/month for review
```

## 注意事項

- 編集は**次の**メッセージから適用されます — 進行中のチャットは古い設定のまま完了します。
- カスタムエージェントの @メンションは慎重に選んでください — 一度設定したら変更できません。
- カスタムエージェントは、ワークスペースの自律モード（Manual または Auto）のもとで動作します。[Auto Mode](/ja/guide/auto-mode) をご覧ください。
