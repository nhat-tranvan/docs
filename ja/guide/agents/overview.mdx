エージェントとは、リクエストを読み、[接続](/ja/guide/connections/overview)を使って情報を調べ、回答または操作を行う AI です。すべてのワークスペースには組み込みのエージェント **CloudThinker** が 1 つあり、大きなタスクを一時的なサブエージェントに分割できます。さらに、チームが作成したカスタムエージェントも利用できます。どのエージェントの書き込みも、ワークスペースの [Approvals](/guide/approvals/overview) に従います。

## エージェントと会話する

<PromptSyntaxBasics />

誰が応答するかはメンションで決まります。

| 送信内容 | 応答するのは |
|---|---|
| メンションなしのメッセージ | CloudThinker |
| `@CloudThinker` をメンションしたメッセージ | CloudThinker |
| `@db-reviewer` などのカスタムエージェントをメンションしたメッセージ | そのカスタムエージェント |

チャットボックスで `@` を入力すると **Mention an agent** ピッカーが開きます。CloudThinker とワークスペースの有効なカスタムエージェントが一覧表示されます。

最初のリクエストにはメンションは不要です。

```text
Which pods in the production namespace restarted more than 3 times in the last 24 hours, and why?
```

CloudThinker は Kubernetes 接続を選んでチェックを実行し、該当する Pod、再起動回数、見つかった再起動の理由をそれぞれ返します。

## CloudThinker アシスタント

CloudThinker は常に有効です。オフにすることはできず、ワークスペース内のすべての接続を使用できます。質問、調査、レポート、変更（Approvals の設定に応じて承認待ちになります）など、何にでも使えます。

## サブエージェント

サブエージェントは、CloudThinker が大きなタスクの一部を担当させるために起動する短命のヘルパーです。たとえばインシデント対応中に、3 つのサービスを 1 つずつではなく同時にチェックできます。各サブエージェントが結果を報告し、CloudThinker がそれらを 1 つの回答にまとめます。

サブエージェントはチャット内と、サイドパネルの **Agents** タブに表示されます。

| 表示 | 意味 |
|---|---|
| **Spawn Subagents** | CloudThinker がこのタスクのためにサブエージェントを起動した |
| **N agents still working** | サブエージェントがまだ実行中 |
| **1 agent needs you** | サブエージェントがあなたの対応を待っている。行をクリックすると **Agents** タブが開く |
| **Finish Subagent** | サブエージェントが結果を報告した |

**Agents** タブの各サブエージェントにはステータスが表示されます。

| ステータス | 対応 |
|---|---|
| **Waiting to start**、**Working**、**Waiting for background work** | 対応不要です。実行中です |
| **Needs approval** | 書き込み操作を実行しようとしています。**Approve** または **Reject** をクリックします。このパネルには **Approve and draft rule** はありません。**Reject** はサブエージェントを停止しますが、チャットカードの **Decline** はその操作なしでエージェントに作業を続けさせます |
| **Needs review** | サブエージェントが結果を受け取る前に呼び出しが中断されたため、変更が行われたかどうか分かりません。対象システムを確認し、**Agents** タブのサブエージェントで **I verified it completed** または **I verified it did not complete** をクリックするか、**Stop this agent** をクリックします。その呼び出しを自動で再実行することはありません |
| **Done**、**Failed**、**Stopped**、**Replaced** | 完了しています。**Replaced** は新しい実行が引き継いだことを意味し、エラーではありません |

サブエージェントは、それを起動したタスクの間だけ存在します。エージェント一覧には表示されず、メンションすることもできません。

## カスタムエージェント

カスタムエージェントは、ワークスペースが定義するエージェントで、独自の名前、`@mention`、指示、接続を持ちます。命名規則を常に適用するデータベースレビュアーや、ステージングクラスターだけを扱うオンコール用ヘルパーなど、チームが毎回同じ振る舞いを必要とする場合に作成します。

ワークスペースの Admin と Developer は **Settings → Workspace → Agents** で作成できます。**Create agent** をクリックし、**Create with AI**（平易な言葉で説明する）または **Build with form** を選びます。カスタムエージェントには独自の承認モードはありません。その書き込みは、他のエージェントと同様にワークスペースの Approvals に従います。

| 設定 | 制御する内容 |
|---|---|
| **Identity** | アバター、名前、`@mention`、役割、目標 |
| **Instructions** と **Language** | エージェントの作業方法と返信する言語 |
| **Model Tier** | **Light**（高速で経済的、0.3x）、**Pro**（バランス型、1.0x）、**Ultra**（最大性能、1.7x）。倍率は各実行で使うクレジットに掛かります。チャットは Pro で開始します。[What makes a run cost more](/ja/guide/billing/usage#実行コストが増える要因) を参照してください |
| **Skill Learning** | **Auto** は新しいスキルを保存し、**Offer** は保存前に確認し、**Off** は保存しません |
| **Connections** | このエージェントが使用できる唯一の接続 |

<Note>
接続のないカスタムエージェントは有効なままですが、操作に使えるツールがありません。メンションする前に少なくとも 1 つ接続を追加してください。Team ではカスタムエージェントを最大 5 個、Scale では最大 10 個まで作成でき、Enterprise には上限がありません。[AI features by plan](/ja/guide/billing/pricing#プラン別の-ai-機能) を参照してください。
</Note>

テストプロンプトと期待される返信を含む実例は、[Build your first custom agent](/guide/agents/quickstart) を参照してください。すべての設定は[エージェントのカスタマイズ](/ja/guide/agents/customize)にあります。

## 各プロダクトのエージェント

| プロダクト | 作業を行うのは |
|---|---|
| [Resolve](/ja/guide/incident/overview) | CloudThinker が各インシデントを調査し、修正を提案します |
| [Review](/ja/guide/code-review/overview) | レビューボットがプルリクエストにレビューを投稿します。`@cloudthinker-ai` の[コマンド](/ja/guide/code-review/mention-commands)で返信します |
| [Optimize](/ja/guide/cost-optimization/overview) | 検出結果は請求データから得られます。チャットで CloudThinker に依頼すれば、どれでも掘り下げられます |
| [Cyber](/guide/security/cyber-overview) | CloudThinker が、テストを許可された稼働中のアプリに対して動的なセキュリティテストを実行します |

## よくある質問

<AccordionGroup>
  <Accordion title="CloudThinker をオフにできますか？">
    いいえ。CloudThinker はすべてのワークスペースで常に有効です。カスタムエージェントはオン・オフを切り替えられます。
  </Accordion>
  <Accordion title="カスタムエージェントとサブエージェントも承認に従いますか？">
    はい。CloudThinker、サブエージェント、カスタムエージェントの書き込み操作はすべて、同じワークスペースの Approvals 設定に従います。
  </Accordion>
  <Accordion title="CloudThinker が見えるシステムを、カスタムエージェントが見られないのはなぜですか？">
    カスタムエージェントは自分に追加された接続だけを使います。**Settings → Workspace → Agents** で開き、接続を追加してください。
  </Accordion>
  <Accordion title="古いブログ記事やスクリーンショットに名前付きのエージェントが載っています。どこにありますか？">
    以前のバージョンには 5 つの名前付き専門エージェントがありました。現在は CloudThinker が 1 つのアシスタントとしてそれらの作業をすべて行い、並列作業が必要なときはサブエージェントを起動します。CloudThinker に直接依頼してください。
  </Accordion>
</AccordionGroup>
