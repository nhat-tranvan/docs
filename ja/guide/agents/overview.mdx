すべてのリクエストは、各ワークスペースに組み込まれたアシスタントである **CloudThinker** に届きます。CloudThinker は直接回答し、大きなタスクは一時的なサブエージェントに分割し、チームが作成したカスタムエージェントに作業を引き継ぎます。

## 1 つのアシスタントにする理由

- **質問する場所は 1 つ。** 最初に専門家を選ぶ必要はありません。リクエストを入力すれば、CloudThinker が必要な接続と Skills を判断します。
- **必要に応じて並列作業。** CloudThinker は短時間だけ動くサブエージェントを起動して複数の項目を同時に確認し、その結果をまとめます。
- **チーム独自の専門家。** カスタムエージェントは、チームの指示と、追加した接続だけを持ちます。
- **どこでも同じガードレール。** すべてのエージェントの書き込みアクションは、ワークスペースの [Manual または Auto](/ja/guide/auto-mode) 設定と [Tool Permissions](/ja/guide/approval) に従います。

## CloudThinker アシスタント

CloudThinker は常にオンです。オフにすることはできず、ワークスペースのすべての[接続](/ja/guide/connections/overview)を使用できます。

`@CloudThinker` をメンションするか、そのまま入力してください。次の表は、どのエージェントがメッセージに回答するかを示しています:

| 送信内容 | 回答するエージェント |
|---|---|
| メンションのないメッセージ | CloudThinker、または直前に回答したエージェント（まだアクティブな場合） |
| カスタムエージェントをメンションしたメッセージ | そのカスタムエージェント |
| `@CloudThinker` をメンションしたメッセージ | CloudThinker |

**Mention an agent** というタイトルの `@` ピッカーには、CloudThinker とワークスペースのアクティブなカスタムエージェントが一覧表示されます。

## サブエージェント

独立した部分が複数あるタスク — たとえば、インシデント中に 3 つのサービスを確認する場合 — では、CloudThinker が並列に動作する一時的なサブエージェントを起動します。各サブエージェントが結果を報告し、CloudThinker がそれらを 1 つの回答にまとめます。

| 表示 | 意味 |
|---|---|
| チャット内の **Spawn Subagents** | CloudThinker がこのタスクのために並列のサブエージェントを起動しました |
| **N agents still working** | サブエージェントがまだ実行中です |
| **1 agent needs you** | サブエージェントがあなたの対応を待っています。この行をクリックすると、サイドパネルの **Agents** タブが開きます |
| サブエージェントの **Needs approval** | あなたの承認が必要な書き込みアクションを実行しようとしています |
| **Finish Subagent** | サブエージェントが結果を報告しました |

サブエージェントは、それを起動したタスクの間だけ存在します。エージェント一覧には表示されません。

## カスタムエージェント

カスタムエージェントは、ワークスペースで定義するエージェントです。独自の名前、`@mention`、役割、指示、接続を持ちます。チームとして一貫した振る舞いが必要なとき — たとえば、常にチームの命名規則に従うデータベースレビュー担当 — に使います。

**Settings → Agents**（**Agent Configuration** グループ内）で作成します。**Create agent** をクリックし、**Create with AI** または **Build with form** を選択します。各カスタムエージェントには次の設定があります:

| 設定 | 制御する内容 |
|---|---|
| **Identity** | アバター、名前、`@mention`、役割、目標 |
| **Instructions** と **Language** | エージェントの作業方法と返答方法 |
| **Model Tier** | エージェントが使用するモデルクラス |
| **Skill Learning** | **Auto** は新しいスキルを保存、**Offer** は先に確認、**Off** は保存しない |
| **Connections** | このエージェントが使用できる接続 |

カスタムエージェントは、接続がないと自動的にオフになります。カスタムエージェントの数はプランによって異なります — 完全なセットアップについては[エージェントのカスタマイズ](/ja/guide/agents/customize)をご覧ください。

## 各モジュールのエージェント

| モジュール | 作業を行うエージェント |
|---|---|
| [Resolve](/ja/guide/incident/overview) | CloudThinker が各インシデントを調査し、修復案を提示します |
| [Review](/ja/guide/code-review/overview) | プルリクエストのレビューはレビューボットが投稿します。`@cloudthinker-ai` [コマンド](/ja/guide/code-review/mention-commands)で返信してください |
| [Optimize](/ja/guide/cost-optimization/overview) | 発見事項は請求データから生成されます。いずれかを掘り下げたい場合は、チャットで CloudThinker に質問してください |
| [Cyber](/guide/security/cyber-overview) | 専任のセキュリティエージェントが、アプリに対する各ペネトレーションテストを実行します |

各モジュールを開始する前に必要なものについては、[モジュール](/ja/guide/modules)をご覧ください。

## よくある質問

<AccordionGroup>
  <Accordion title="Anna、Alex、Oliver、Tony、Kai はどうなりましたか？">
    以前のバージョンでは、5 つの名前付きエージェントが表示されていました。現在は CloudThinker が 1 つのアシスタントとしてそれらの作業を担い、タスクに並列の専門性が必要なときはサブエージェントを起動します。専門家を選ぶ代わりに、CloudThinker に直接質問してください。
  </Accordion>
  <Accordion title="CloudThinker をオフにできますか？">
    いいえ。CloudThinker はすべてのワークスペースで常にアクティブです。カスタムエージェントはオン・オフを切り替えられます。
  </Accordion>
  <Accordion title="カスタムエージェントも承認に従いますか？">
    はい。CloudThinker、サブエージェント、カスタムエージェントのいずれであっても、書き込みアクションは同じワークスペースの承認設定に従います。
  </Accordion>
</AccordionGroup>
