CloudThinker の構成要素はわずかです。組織がワークスペースを持ち、各ワークスペースが、モジュールの動作に必要な接続、エージェント、ガードレール、コンテキストを持ちます。このページでは、それらがどのように組み合わさるかを示し、それぞれのページへのリンクを紹介します。

## 組織とワークスペース

[組織](/ja/guide/organization)はアカウントそのものであり、請求、プラン、メンバー一覧を管理します。[ワークスペース](/ja/guide/workspaces)は組織内の分離された環境です — 本番とステージング、あるいはチームごとに 1 つ、といった形で使います。

| 組織に属するもの | 各ワークスペースに属するもの |
|---|---|
| 請求、プラン、クレジット | 接続と認証情報 |
| メンバーと組織ロール: Owner、Admin、Developer、Viewer | カスタムエージェント |
| シングルサインオンと監査ログ | メモリ、ナレッジベース、Skills |
| | 自動化、コマンド、承認設定 |

組織の Owner と Admin は、すべてのワークスペースで Admin になります。それ以外のメンバーには、ワークスペースごとにワークスペースロール — Admin、Developer、Viewer — が付与されます。[ワークスペースユーザー](/ja/guide/workspace-users)をご覧ください。

## 接続

[接続](/ja/guide/connections/overview)は、1 つのサービス — AWS アカウント、Kubernetes クラスター、GitHub 組織、Datadog アカウントなど — に対する認証情報です。エージェントが参照・操作できるのはワークスペースの接続が許可する範囲だけなので、接続の権限がすべてのエージェントにとっての上限になります。

## エージェント

組み込みのアシスタントである **CloudThinker** が、すべてのリクエストを受け付けます。並列作業のために一時的なサブエージェントを起動し、チームが定義したカスタムエージェントに作業を引き継ぎます。[エージェント](/ja/guide/agents/overview)をご覧ください。

## ガードレール

エージェントの書き込みアクションがそのまま実行されるか、人の判断を待つかは、2 つの設定で決まります。

| 設定 | 動作 | 場所 |
|---|---|---|
| **Auto**（新しいワークスペースのデフォルト） | 書き込みアクションは実行前に AI の安全性クラシファイアでチェックされます | チャットボックスの **Approval** コントロール |
| **Manual** | 各書き込みアクションを実行前にあなたが承認します | チャットボックスの **Approval** コントロール |
| **Tool Permissions** | Manual のとき、各接続ツールを **Always allow**、**Needs approval**、**Never allow** のいずれかに設定します | **Settings → Approval → Tool Permissions** |

このモードは、自動化やサブエージェントを含め、ワークスペース全体に適用されます。[Auto Mode](/ja/guide/auto-mode) と [承認](/ja/guide/approval) をご覧ください。

## コンテキスト

コンテキストとは、あなたが何も言わなくてもエージェントがあらかじめ知っている情報です。種類ごとに情報源が異なります。

| コンテキスト | 内容 | 追加する人 |
|---|---|---|
| [メモリ](/guide/memory) | 環境、好み、最近の出来事に関するメモ | エージェントが作業中に追加します。あなたが修正することもできます |
| [ナレッジ](/ja/guide/knowledge) | ランブック、ポリシー、ドキュメント | あなたが、ファイルのアップロードやサイトのクロールで追加します |
| [Skills](/ja/guide/skills/overview) | 特定の種類のタスクに対する手順 | あなたが追加するか、スキル学習がオンのときはエージェントが追加します |

## モジュール

4 つの[モジュール](/ja/guide/modules) — Resolve、Review、Optimize、Cyber — は、同じエージェント、ガードレール、コンテキストをそれぞれ 1 種類のシグナルに適用します: インシデント、プルリクエスト、クラウドの請求、アプリのセキュリティです。

## 結果が表示される場所

| 場所 | 確認できる内容 |
|---|---|
| [Home](/guide/activity) | **Needs you** — あなたの承認や判断を待っている項目 — に加え、モジュールの状態と今日の自動化 |
| **Investigation**（Resolve 内） | すべてのインシデントと、その根本原因、証拠、修復案 |
| [Artifacts](/ja/guide/artifacts/overview) | エージェントが作成したダッシュボード、レポート、ファイル |
| チャットのサイドパネル | 現在の会話の実行、コンソール出力、サブエージェント、発見事項 |
