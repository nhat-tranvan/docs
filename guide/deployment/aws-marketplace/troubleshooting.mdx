Most launch problems show up in the first minute, in the launch check, before the stack builds anything that costs money. Open the stack's **Events** tab and read the first `CREATE_FAILED` reason.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Set a sign-in sender email different from the admin email in CloudThinker setup.">
    **Cause:** the sender address and the administrator email on the setup page are the same address.

    **Fix:** delete the failed stack, change the sender on the setup page to a separate address, such as `cloudthinker-notify@example.com`, and send a new install token (see the next item). Then launch again.
  </Accordion>
  <Accordion title="Relaunch after a failed launch">
    A failed launch does not use up the install token. The token is used only when an install finishes registering. To retry with the same settings, delete the failed stack and launch again with the same token.

    The settings saved with a token are locked once a launch checks them. To change them after a failed launch, choose **Get a fresh token** on the setup page (from the next release), or send a new token under **Enterprise → Install token**, then launch again.
  </Accordion>
  <Accordion title="This install token was already used by another install.">
    **Cause:** an install already registered with this token. Each token registers one install.

    **Fix:** to add another install, send a new token on the setup page under **Enterprise → Install token**, then choose **Launch template** again.
  </Accordion>
  <Accordion title="The install token expired; a token works for 7 days.">
    **Cause:** the token was sent more than 7 days before the launch.

    **Fix:** send a new token on the setup page under **Enterprise → Install token**, then launch the stack again.
  </Accordion>
  <Accordion title="The stack rolled back">
    **Cause:** usually a service quota, a missing deployment permission, or an unsupported Region. The first `CREATE_FAILED` event names it.

    **Fix:** fix the cause, delete the rolled-back stack, then launch again. A launch that failed after the launch check can keep data resources, such as the KMS key, the VPC, or the Aurora cluster. Remove them as in [Uninstall](/guide/deployment/aws-marketplace/uninstall), because they keep costing money.
  </Accordion>
  <Accordion title="The stack is complete but the address does not open">
    **Cause:** the name for `<your-install-address>` can take a few minutes to resolve after the stack completes, and the app takes a few more minutes to start.

    **Fix:** wait 5 to 10 minutes and try again. With private network access, open the address from a network that routes to the VPC. With internet access, check that your current public IP is inside the ranges you allowed.
  </Accordion>
  <Accordion title="Invitations or sign-in codes do not arrive">
    **Cause:** Amazon SES is in sandbox mode and delivers only to verified addresses, or the sender is not verified yet.

    **Fix:** check the `EmailSetup` output and the SES console **Identities** page. Add the DKIM records, verify the administrator's address in SES while you are in sandbox mode, then [request production access](https://docs.aws.amazon.com/ses/latest/dg/request-production-access.html). See [Email](/guide/deployment/aws-marketplace/email).
  </Accordion>
  <Accordion title="Not enough vCPUs, Elastic IPs, or NAT gateways">
    **Cause:** a service quota in the Region is lower than the stack needs.

    **Fix:** request the increase in Service Quotas, wait for approval, then launch again. See [Before you start](/guide/deployment/aws-marketplace/before-you-start#account-quotas).
  </Accordion>
  <Accordion title="The stack delete stops with DependencyViolation">
    **Cause:** the installer's network interfaces linger for some minutes after the function is gone.

    **Fix:** wait about 15 minutes and delete the stack again.
  </Accordion>
</AccordionGroup>

If none of these match, [contact CloudThinker](https://cloudthinker.io/contact) with the stack's Region and the first `CREATE_FAILED` reason.
