CloudThinker Enterprise from AWS Marketplace runs single-tenant in your own AWS account, built by one CloudFormation stack. This page is for the AWS administrator who reviews and launches it.

<Note>
**Early access.** The Marketplace offer is new. Defaults, sizing, and supported Regions can change between releases.
</Note>

## What gets created in your account

The stack builds everything in one Region of your account. CloudThinker gets no IAM user, no access key, and no role it can assume in your account.

| AWS service | What the stack creates |
|---|---|
| Amazon VPC | One VPC across two Availability Zones, with public, private, data, and sandbox subnets, an internet gateway, and one NAT gateway with an Elastic IP |
| Amazon EKS | One cluster with a private API endpoint, an app node group (three `m7i.xlarge` by default), and a separate sandbox node group (one `m7i.xlarge`) for agent-run code |
| Amazon Aurora PostgreSQL | One Aurora Serverless v2 cluster with one writer (1 to 8 ACUs by default), encrypted, deletion protection on, 7-day automated backups |
| Amazon ElastiCache | One Valkey node (`cache.t4g.medium` by default), encrypted in transit and at rest |
| Amazon S3 | One private, versioned, encrypted bucket for files, attachments, and images |
| AWS KMS | One customer managed key, rotation on, that encrypts the database, cache, bucket, secrets, and logs |
| AWS Secrets Manager | Generated passwords and the app's keys. No password is ever a stack parameter |
| Elastic Load Balancing | One Network Load Balancer in front of the app, internal or internet-facing |
| AWS Lambda | A launch check and an installer function, which run only on stack create, update, and delete |
| AWS Certificate Manager | One public certificate for the managed address |
| AWS IAM | Roles for the cluster, nodes, app, upgrades, load balancer, and installer, each limited to this stack's resources |

## How it fits together

Users reach the app at `<your-install-address>` through the Network Load Balancer, either from your private network or from the internet ranges you allow. The app runs on the app node group in private subnets. The database and cache sit in data subnets that have no route to the internet and accept connections only from the app nodes.

Agent-generated code runs in sandboxes on the sandbox node group. Sandboxes can never reach the database, the cache, the cluster API, or instance metadata. They reach your private ranges only if you list them. Every outbound call from the install leaves through the one NAT gateway, so you allow a single address on your firewalls.

The app calls AI models through Amazon Bedrock in your account with its own IAM role. Your data, secrets, and logs stay in your account.

## Supported Regions

| Region | Name |
|---|---|
| `us-east-1` | US East (N. Virginia) |
| `us-east-2` | US East (Ohio) |
| `us-west-2` | US West (Oregon) |
| `eu-west-1` | Europe (Ireland) |
| `eu-central-1` | Europe (Frankfurt) |
| `ap-southeast-1` | Asia Pacific (Singapore) |
| `ap-southeast-2` | Asia Pacific (Sydney) |
| `ap-northeast-1` | Asia Pacific (Tokyo) |

The stack refuses to start in any other Region, even when the Marketplace page lists more.

## Monthly AWS cost estimate

<Warning>
**Estimate only.** These figures use AWS public on-demand list prices for US East (N. Virginia) and the default sizes. Other Regions usually cost more. Check your own numbers in the [AWS Pricing Calculator](https://calculator.aws/) before you launch.
</Warning>

AWS bills these resources to your account, separately from the CloudThinker subscription.

| Cost driver | Default size | Rough monthly cost (USD) |
|---|---|---|
| EKS control plane | 1 cluster | about 73 |
| EC2 nodes | 4 × `m7i.xlarge`, running all the time | about 590 |
| Node disks | 4 × 100 GB gp3 | about 32 |
| NAT gateway | 1 gateway plus data processed | 37 to 80 |
| Public IPv4 addresses | NAT address, plus 2 for an internet-facing load balancer | 4 to 11 |
| Aurora PostgreSQL Serverless v2 | 1 ACU minimum, more under load, plus storage | 90 to 285 |
| ElastiCache for Valkey | 1 × `cache.t4g.medium` | about 38 |
| Network Load Balancer | 1 load balancer plus light traffic | 21 to 25 |
| S3, KMS, Secrets Manager, CloudWatch Logs | Light use | 5 to 20 |
| **Total** | | **about 900 to 1,150** |

The nodes are the largest line, and they run around the clock. Larger node types or more nodes raise it in proportion. Amazon Bedrock model use and data transfer out to the internet are not included: they depend on how much your team uses CloudThinker.
