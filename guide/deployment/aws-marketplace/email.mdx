CloudThinker sends sign-in codes, invitations, and alerts by email. Email is optional at launch: the administrator can set it up later.

## Choose a method

| Method | How it works | Good for |
|---|---|---|
| **Amazon SES** (default) | The app sends through Amazon SES in your account with its own IAM role. No password is stored. | Most installs |
| **Your SMTP server** | The app sends through a mail server you run or buy, such as Microsoft 365. | Teams whose mail must leave through an existing relay |

## Amazon SES

The app may send only from the sender address you chose on the setup page. SES must trust that sender in one of two ways:

- **Email address.** SES emails the address a verification link. Mail starts once someone opens it.
- **Domain.** The stack's `EmailSetup` output lists the DKIM records to add to your DNS. SES verifies the domain once the records resolve, usually within an hour.

### Leave the SES sandbox

A new SES account is in sandbox mode: it delivers only to verified addresses and has a low daily limit. The administrator's address is verified for you, so they can sign in. Before you invite your team, [request production access](https://docs.aws.amazon.com/ses/latest/dg/request-production-access.html) in the SES console for the Region you launched in.

## SMTP

Enter on the setup page:

| Field | Example |
|---|---|
| Host | `smtp.example.com` |
| Port | `587` for STARTTLS, or `465` for TLS |
| User name | The account the app signs in as. Leave empty for a server with no sign-in. |
| Password | The ARN of an AWS Secrets Manager secret in your account that holds the password. Never the password itself. |
| Sender | An address your server allows the app to send from |

Keep TLS on whenever the server needs a password, so the password never crosses the network in clear text.

## Set up email later

<Note>
**Subject to change.** Setting up or changing email from inside the app after launch is being finished. Until then, update the email settings in the stack's parameters.
</Note>
