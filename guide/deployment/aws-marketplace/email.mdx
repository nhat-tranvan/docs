CloudThinker sends invitations, alerts, and sign-in messages by email. Email is optional at launch: the first administrator signs in with a one-time setup link, and an administrator can set up email later.

## Choose a method

| Method | How it works | Good for |
|---|---|---|
| **None for now** (default) | The app sends no email. The administrator signs in with the [setup link](/guide/deployment/aws-marketplace/first-sign-in) and sets up SMTP later. | Installs with no mail server yet |
| **Amazon SES** | The app sends through Amazon SES in your account with its own IAM role. No password is stored. | Most installs |
| **Your SMTP server** | The app sends through a mail server you run or buy, such as Microsoft 365. | Teams whose mail must leave through an existing relay |

## Amazon SES

The app may send only from the sender address you chose on the setup page. Use an address on a domain you control, different from the administrator's email.

1. After the stack completes, open the `EmailSetup` output. It lists the DKIM records SES needs for the sender's domain.
2. Add those records to your DNS. SES verifies the domain once they resolve, usually within an hour.
3. Open any verification link SES emails to you.

### Leave the SES sandbox

A new SES account is in sandbox mode: it delivers only to verified addresses and has a low daily limit. Before you invite your team, [request production access](https://docs.aws.amazon.com/ses/latest/dg/request-production-access.html) in the SES console for the Region you launched in.

## SMTP

Enter on the setup page:

| Field | Example |
|---|---|
| Host | `smtp.example.com` |
| Port | `587` for STARTTLS, or `465` for TLS |
| User name | The account the app signs in as. Leave empty for a server with no sign-in. |
| Password | The ARN of an AWS Secrets Manager secret in your account that holds the password, encrypted with the AWS managed key (`aws/secretsmanager`). Never the password itself. |
| Sender | An address your server allows the app to send from |

Keep TLS on whenever the server needs a password, so the password never crosses the network in clear text.

## Set up email later

If you chose none on the setup page, an administrator sets up SMTP later in the app: **Admin → Enterprise → Email delivery**. Enter the same fields as in [SMTP](#smtp) and send a test email. To switch a running install to Amazon SES, [contact CloudThinker](https://cloudthinker.io/contact).
