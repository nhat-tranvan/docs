Deleting the stack removes the cluster, nodes, load balancer, and network gateways. It keeps your data on purpose, so a mistaken delete never loses it.

<Warning>
**Kept resources keep costing money.** The Aurora cluster, S3 bucket, KMS key, and secrets stay billed until you delete them yourself.
</Warning>

## Delete the stack

<Steps>
  <Step title="Note the kept resources">
    Open the stack's **Outputs** tab and copy `KeptResources`. It lists what stays after the delete.
  </Step>
  <Step title="Delete the stack">
    In the CloudFormation console, select the stack and choose **Delete**. The managed address is released.
  </Step>
  <Step title="Retry if it stops on a dependency">
    If the delete stops with `DependencyViolation` on a subnet or security group, wait about 15 minutes and delete again. AWS removes the installer's network interfaces a few minutes after the function is gone.
  </Step>
</Steps>

## Remove the kept resources

Only do this when you are sure you no longer need the data. Retained resources carry the tag `aws:cloudformation:stack-name` with your stack's name, which helps you find them.

| Order | Resource | How to remove it |
|---|---|---|
| 1 | Aurora cluster and instance | RDS console: modify the cluster to turn off deletion protection, delete the instance, then delete the cluster. A final snapshot is optional, and it keeps costing money too. |
| 2 | S3 bucket | Empty the bucket, including old versions, then delete it. |
| 3 | Secrets Manager secrets | Delete the database, app database, and app keys secrets. |
| 4 | DB subnet group and cluster parameter group | RDS console, **Subnet groups** and **Parameter groups** |
| 5 | Security groups | The database security group, and any group the stack left behind |
| 6 | VPC and data subnets | Delete the data subnets, then the VPC. |
| 7 | SES identities | SES console, **Identities**: the sender and administrator identities, if nothing else uses them |
| 8 | CloudWatch log groups | The installer's log groups, if you do not need the logs |
| 9 | KMS key | Last. Schedule the key's deletion (7 to 30 days). After that, any backup encrypted with it can never be read. |

## Cancel the subscription

Deleting the stack does not end the contract. Manage the subscription in the AWS Marketplace console, under **Manage subscriptions**. See [Contract and billing](/guide/deployment/aws-marketplace/contract-and-billing).
