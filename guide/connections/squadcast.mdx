Connect Squadcast to let CloudThinker operate incidents, responders, notes, and maintenance. The connection uses **a Squadcast API refresh token**.

## Prerequisites

- An account with access to the Squadcast resources you intend to investigate.
- The **Admin** role in your CloudThinker workspace to add and manage the connection. See [Roles](/guide/security/roles).
- The credentials described below and a network route from CloudThinker to the service. For a private endpoint, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare access in Squadcast">
    Generate an API token in your Squadcast account. Use the long-lived refresh token in CloudThinker, not an access token returned by the authentication API. Choose US or EU to match the account. The connection exchanges the refresh token for short-lived access automatically.

    Follow the [vendor’s credential and authentication guidance](https://developers.incidents.cloud.solarwinds.com/api-reference) for your account.
  </Step>
  <Step title="Connect in CloudThinker">
    Open **Settings → Workspace → Connections**, find **Squadcast**, and click **Connect**. Fill in the fields in [Connection details](#connection-details), check the account and region, and click **Connect**.

    **Success state:** the connection shows **Connected**. Run the verification prompt below to check what the account can actually read.
  </Step>
  <Step title="Verify the scope">
    Run the [verification prompt](#verify-the-connection). Compare the returned organization, projects, or resource names with the account you intended to connect. Keep a denied request visible as an access problem; do not interpret it as an empty result.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Region** | Yes | Select the region where your account is hosted. Choose **US**, **EU**. Default: **US**. |
| **API refresh token** | Yes | The API refresh token for the account described in Setup. |

Squadcast is now SolarWinds Incident Response in vendor documentation. Authentication and API requests must use matching regional hosts.

## Required permissions

The token user’s role and team permissions control access to services, incidents, responders, notes, and maintenance. Incident or service mutations require the corresponding provider permissions and the workspace’s approval policy.

<Tip>
Start with read access to the smallest useful scope. Adding a connection does not grant permissions that the provider account lacks. For supported changes, [Approvals](/guide/approvals/overview) decides whether CloudThinker may proceed; provider permissions still apply.
</Tip>

## Agent capabilities

| Workflow | What agents can do |
|---|---|
| Discovery | Inspect incidents, services, and responders |
| Investigation | Read incident notes and maintenance |
| Investigation | Acknowledge, resolve, reassign, or reprioritize incidents when authorized |
| Changes | Manage service metadata or maintenance when authorized |

### Verify the connection

```text
Review open Squadcast incidents, their responders, and current maintenance without changing anything. Report any denied or unavailable checks separately.
```

Expect current resource names or a clear access error. No matching records is a valid outcome only when the request succeeded and its account, filters, and time window match your question.

### Example prompts

```text
Review open Squadcast incidents, their responders, and current maintenance without changing anything
Use this connection to inspect one resource from the results and explain its current state with supporting evidence
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential is active, belongs to the intended account, and matches the selected region or endpoint. Replace an expired or revoked credential in CloudThinker. Do not paste it into chat or include it in a support screenshot.
  </Accordion>
  <Accordion title="Connected, but some resources are missing">
    Compare the provider account’s access, selected organization, and investigation filters. A successful sign-in does not prove access to every resource. Squadcast is now SolarWinds Incident Response in vendor documentation. Authentication and API requests must use matching regional hosts.
  </Accordion>
  <Accordion title="Requests are denied or cannot reach the service">
    A permission denial needs a provider access change for the specific read, not a broader account by default. For a timeout or certificate error, confirm the HTTPS endpoint, network route, and trusted CA with the service administrator. For throttling, narrow the investigation and retry after the provider’s indicated wait.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep the connection restricted to the account and resources intended for this workspace.
- Rotate credentials through the provider and replace the saved value in CloudThinker; never send secrets in a conversation.
