Connect Smartsheet so CloudThinker can read sheets, rows, and reports to track project work. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Smartsheet account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Generate a Smartsheet API access token for the account whose sheets and reports you want CloudThinker to read. See the [vendor's authentication documentation](https://developers.smartsheet.com/api/smartsheet/guides/basics/authentication) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Smartsheet**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Select your account's region. Smartsheet regional services use separate tokens.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **API access token** | Yes | It acts as that user. |
| **Region** | Yes | The data center of your account: smartsheet.com is US, .eu is EU, .au is Australia, smartsheetgov.com is Gov. Options: **US (api.smartsheet.com)**, **EU (api.smartsheet.eu)**, **Australia (api.smartsheet.au)**, **Gov (api.smartsheetgov.com)**. Default: `us`. |

## Required permissions

Read access to the intended sheets and reports through the token's account.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Sheet inventory | Find accessible sheets. |
| Row review | Read sheet rows. |
| Report context | Inspect reports available to the authorized user. |

The connection is read-only. It cannot add, edit, move, or delete sheets, rows, columns, or shares.

This connection is read-only. Make changes in Smartsheet.

### Verify the connection

```text
Inspect my Smartsheet connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Smartsheet to read sheets, rows, and reports to track project work.
Summarize the highest-priority items visible through my Smartsheet connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Smartsheet. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Smartsheet when access is no longer needed, and update the connection after rotation.
