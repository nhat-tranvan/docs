Connect Sprinto so CloudThinker can review framework readiness and vendor due diligence. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Sprinto account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Ask a Sprinto administrator for a Developer API key for your organization's region. See the [vendor's authentication documentation](https://developer.sprinto.com/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Sprinto**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Enter the Sprinto URL you sign in to, including the correct regional host.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Sprinto URL** | Yes | The address you sign in at, for example https://app.sprinto.com (use your region's address for Europe, India, or Australia). |
| **Developer API key** | Yes | The API allows 10 requests per minute per key. |

## Required permissions

Read framework readiness, controls, and vendor due-diligence data.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Framework readiness | Review compliance framework state. |
| Vendor due diligence | Inspect vendor context. |
| Scope review | Read the controls and evidence visible to the credential. |

The connection is read-only. It cannot change controls, vendor scope, staff scope, or evidence.

This connection is read-only. Make changes in Sprinto.

### Verify the connection

```text
Inspect my Sprinto connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Sprinto to review framework readiness and vendor due diligence.
Summarize the highest-priority items visible through my Sprinto connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Sprinto. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Sprinto when access is no longer needed, and update the connection after rotation.
