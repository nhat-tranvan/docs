Connect Chroma so CloudThinker can inspect Chroma Cloud collections and retrieve or query selected documents. The connection uses a Chroma Cloud API key scoped to a tenant and database.

## Prerequisites

- Access to the Chroma account or installation containing the data you want to investigate.
- A workspace role that can add connections. See [Roles](/guide/security/roles).
- Permission to authorize the account or obtain the credentials described below.

## Setup

<Steps>
  <Step title="Prepare access">
    Open your Chroma Cloud dashboard and identify the tenant and database containing the collections to share. Obtain an API key authorized for that database. Use the tenant identifier and database name from the same account; this connection is for Chroma Cloud rather than a local Chroma server.

    See the [provider documentation](https://docs.trychroma.com/reference/python) for its current access requirements.
  </Step>
  <Step title="Add the connection">
    Open **Connections**, find **Chroma**, and choose **Connect**. Enter the fields in [Connection details](#connection-details), then click **Connect**. Enter credentials only in the connection form; do not include them in a chat message.

    **Success state:** the connection shows **Connected**. This confirms the connection was established; run the verification prompt below to check the data access needed for an investigation.
  </Step>
  <Step title="Check the intended scope">
    Run the verification prompt below. Confirm the returned account, project, or resource names belong to the intended scope before asking for a deeper investigation. If a section fails, check its permissions rather than interpreting the failure as an empty result.
  </Step>
</Steps>

## Connection details

| Field | Description | Example |
|-------|-------------|---------|
| **CHROMA_TENANT** | Cloud tenant identifier. | Your tenant ID |
| **CHROMA_DATABASE** | Database containing the intended collections. | Your database name |
| **CHROMA_API_KEY** | Cloud API key authorized for this tenant and database. | Copy from Chroma Cloud |

## Required permissions

Limit the API key to the intended tenant and database. Collection metadata, document retrieval, and queries need read access. Give it collection or document mutation rights only when those changes are intended. Access to a different database does not make its collections visible here.

## Agent capabilities

| Capability | What CloudThinker can do |
|------------|-------------------------|
| **Collections** | List a bounded selection and read collection metadata and counts. |
| **Documents** | Peek at or retrieve a small number of documents. |
| **Similarity queries** | Query a selected collection using the inputs it supports. |

Requests stay within the configured tenant and database. Query results are samples, not proof that every relevant document was found. A failed collection lookup must not be treated as an empty collection.

Creating, renaming, forking, or deleting collections and adding, updating, or deleting documents require approval through [Approvals](/guide/approvals/overview). Review the collection and document identifiers carefully before approving a destructive change.

### Verify the connection

```text
List a small sample of Chroma collections in this database and show their document counts
```

Expect named resources or a clear empty result for each successful read. Keep any permission errors separate from the resources that were successfully inspected.

### Example prompts

```text
Show metadata and a small document sample for the selected Chroma collection
Query the selected collection for the supplied embedding and explain the returned matches
```

Use a resource returned by the verification step and a short time range where relevant. Narrow requests are easier to verify than account-wide conclusions.

## Troubleshooting

<Accordion title="Credentials are rejected">
Check the credential fields belong to the same account and have not expired or been revoked. Replace credentials in the connection form, then rerun the verification prompt.
</Accordion>

<Accordion title="The collection is not found">
Check CHROMA_TENANT and CHROMA_DATABASE belong together, then list the collections visible to that key. Use a returned collection name rather than guessing another database.
</Accordion>

<Accordion title="Requests fail or results are incomplete">
Check the provider’s availability, the selected resource scope, and any returned permission or rate-limit message. Narrow the request before retrying. For a private API, confirm the network route from CloudThinker itself, not only from your workstation.
</Accordion>

## Security

<ConnectionSecurity />

- Keep access limited to the intended account and resources. Replace or revoke credentials when the connection is no longer needed.
- Review the exact resource and proposed change before approving a write. An uncertain result needs a fresh read before retrying.
