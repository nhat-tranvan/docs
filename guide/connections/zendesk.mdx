Connect Zendesk to let CloudThinker review support tickets, queues, and assignees. The connection uses **a Zendesk agent email and API token**.

## Prerequisites

- An account with access to the Zendesk resources you intend to investigate.
- The **Admin** role in your CloudThinker workspace to add and manage the connection. See [Roles](/guide/security/roles).
- The credentials described below and a network route from CloudThinker to the service. For a private endpoint, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare access in Zendesk">
    Have a Zendesk administrator enable and create an API token under **Admin Center → Apps and integrations → APIs → API tokens**. Enter the subdomain, the email of the authorized agent, and the token value. The account permissions of that email determine the access used by this connection.

    Follow the [vendor’s credential and authentication guidance](https://support.zendesk.com/hc/en-us/articles/4408889192858-Managing-API-token-access-to-the-Zendesk-API) for your account.
  </Step>
  <Step title="Connect in CloudThinker">
    Open **Settings → Workspace → Connections**, find **Zendesk**, and click **Connect**. Fill in the fields in [Connection details](#connection-details), check the account and region, and click **Connect**.

    **Success state:** the connection shows **Connected**. Run the verification prompt below to check what the account can actually read.
  </Step>
  <Step title="Verify the scope">
    Run the [verification prompt](#verify-the-connection). Compare the returned organization, projects, or resource names with the account you intended to connect. Keep a denied request visible as an access problem; do not interpret it as an empty result.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Subdomain** | Yes | The acme in https://acme.zendesk.com. |
| **Agent email** | Yes | The Agent email for the account described in Setup. |
| **API token** | Yes | The API token for the account described in Setup. |

Zendesk is retiring API-token authentication: unused tokens can be deleted after 30 days, and the vendor states all API tokens stop working April 30, 2027. This connector currently takes an API token; it does not accept an OAuth access token in that field.

## Required permissions

An agent account that can view the intended ticket queues and groups. Ticket assignment, priority, and status changes also require the relevant ticket-update permissions and the workspace’s approval policy.

<Tip>
Start with read access to the smallest useful scope. Adding a connection does not grant permissions that the provider account lacks. For supported changes, [Approvals](/guide/approvals/overview) decides whether CloudThinker may proceed; provider permissions still apply.
</Tip>

## Agent capabilities

| Workflow | What agents can do |
|---|---|
| Discovery | Review support queues and unsolved tickets |
| Investigation | Inspect ticket details and recent comments |
| Changes | Assign, reprioritize, or update a ticket when authorized |

### Verify the connection

```text
Review unsolved high and urgent Zendesk tickets and highlight unassigned tickets without changing them. Report any denied or unavailable checks separately.
```

Expect current resource names or a clear access error. No matching records is a valid outcome only when the request succeeded and its account, filters, and time window match your question.

### Example prompts

```text
Review unsolved high and urgent Zendesk tickets and highlight unassigned tickets without changing them
Use this connection to inspect one resource from the results and explain its current state with supporting evidence
```

Solving a ticket can trigger Zendesk automations that later close it. A closed ticket cannot be reopened; review the intended ticket and status before approving the change.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential is active, belongs to the intended account, and matches the selected region or endpoint. Replace an expired or revoked credential in CloudThinker. Do not paste it into chat or include it in a support screenshot.
  </Accordion>
  <Accordion title="Connected, but some resources are missing">
    Compare the provider account’s access, selected organization, and investigation filters. A successful sign-in does not prove access to every resource. Zendesk is retiring API-token authentication: unused tokens can be deleted after 30 days, and the vendor states all API tokens stop working April 30, 2027. This connector currently takes an API token; it does not accept an OAuth access token in that field.
  </Accordion>
  <Accordion title="Requests are denied or cannot reach the service">
    A permission denial needs a provider access change for the specific read, not a broader account by default. For a timeout or certificate error, confirm the HTTPS endpoint, network route, and trusted CA with the service administrator. For throttling, narrow the investigation and retry after the provider’s indicated wait.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep the connection restricted to the account and resources intended for this workspace.
- Rotate credentials through the provider and replace the saved value in CloudThinker; never send secrets in a conversation.
