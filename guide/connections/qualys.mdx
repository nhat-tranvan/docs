Connect Qualys VMDR so CloudThinker can review host vulnerabilities, severities, and assets. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Qualys VMDR account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Obtain the username and password of a Qualys user with VM API access. See the [vendor's authentication documentation](https://docs.qualys.com/en/vm/qweb-all-api/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Qualys VMDR**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Select the platform-specific API address associated with your account.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Platform** | Yes | Options: **US1**, **US2**, **US3**, **US4**, **EU1**, **EU2**, **EU3**, **IN1**, **CA1**, **AE1**, **UK1**, **AU1**, **KSA1**. Default: `https://qualysapi.qualys.com`. |
| **Username** | Yes | A Qualys user with API access, such as a Reader with the VM API enabled. |
| **Password** | Yes | That user's password. |

## Required permissions

Read host vulnerability detections and assets visible to that user.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Vulnerability review | Inspect host detections and severities. |
| Asset context | Read visible asset information. |
| Risk triage | Associate findings with affected hosts. |

The connection is read-only. It cannot launch scans, open remediation tickets, or edit exceptions and asset tags.

This connection is read-only. Make changes in Qualys VMDR.

### Verify the connection

```text
Inspect my Qualys VMDR connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Qualys VMDR to review host vulnerabilities, severities, and assets.
Summarize the highest-priority items visible through my Qualys VMDR connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Qualys VMDR. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Qualys VMDR when access is no longer needed, and update the connection after rotation.
