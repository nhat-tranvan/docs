Connect Zoho Desk so CloudThinker can review support tickets, departments, and overdue work. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Zoho Desk account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Self Client in the Zoho API Console. Generate a grant code for the read scopes, exchange it for a refresh token, and retain the client ID and secret. See the [vendor's authentication documentation](https://desk.zoho.com/DeskAPIDocument#Authentication) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Zoho Desk**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Choose the data center matching your Desk organization. The refresh token and OAuth client must come from that data center.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Data center** | Yes | Options: **United States (zoho.com)**, **Europe (zoho.eu)**, **India (zoho.in)**, **Australia (zoho.com.au)**, **Japan (zoho.jp)**, **Canada (zohocloud.ca)**, **Saudi Arabia (zoho.sa)**. Default: `com`. |
| **Organization ID** | Yes | Enter organization id. |
| **Client ID** | Yes | A Self Client in the Zoho API Console (api-console.zoho.com). |
| **Client secret** | Yes | The Self Client's secret. |
| **Refresh token** | Yes | Generate a code with the scopes Desk.tickets.READ,Desk.search.READ,Desk.basic.READ and exchange it for a refresh token. |

## Required permissions

Use `Desk.tickets.READ`, `Desk.search.READ`, and `Desk.basic.READ` for the selected organization.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Ticket review | Read support tickets. |
| Department context | Inspect accessible departments. |
| Overdue work | Review ticket workload and overdue items. |

The connection is read-only. It cannot reply, assign, merge, delete, or change the status of tickets.

This connection is read-only. Make changes in Zoho Desk.

### Verify the connection

```text
Inspect my Zoho Desk connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Zoho Desk to review support tickets, departments, and overdue work.
Summarize the highest-priority items visible through my Zoho Desk connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Zoho Desk. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Zoho Desk when access is no longer needed, and update the connection after rotation.
