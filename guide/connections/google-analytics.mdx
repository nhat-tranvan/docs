Connect Google Analytics 4 so [CloudThinker](/guide/agents/overview) can answer questions about traffic, key events, and active users. The connection uses a Google Cloud service account JSON key and reads only the properties that account can access.

## Prerequisites

- A Google Analytics 4 property that collects data, and Administrator access to grant a user access to it.
- A Google Cloud project where you can create a service account, create a JSON key, and enable APIs. Your organization may restrict key creation; ask your Google Cloud administrator if it does.
- The Admin role in your CloudThinker workspace. See [Workspace roles](/guide/workspace-users#workspace-roles).

## Setup

<Steps>
  <Step title="Enable the Google Analytics APIs">
    In your Google Cloud project, enable both the [Google Analytics Admin API](https://console.cloud.google.com/apis/library/analyticsadmin.googleapis.com) and the [Google Analytics Data API](https://console.cloud.google.com/apis/library/analyticsdata.googleapis.com). Use the same project that will hold the service account.
  </Step>
  <Step title="Create a service account and key">
    In the [Google Cloud console](https://console.cloud.google.com/), create a service account. Open it, select **Keys → Add key → Create new key**, choose **JSON**, and click **Create**. Keep the downloaded file private. See Google's guides to [creating a service account](https://docs.cloud.google.com/iam/docs/service-accounts-create) and [creating a key](https://docs.cloud.google.com/iam/docs/keys-create-delete).
  </Step>
  <Step title="Grant access to your property">
    In Google Analytics, open **Admin → Property access management** for the property. Add the service account email with the **Viewer** role. Repeat for each property CloudThinker should read. See [Google's access guide](https://support.google.com/analytics/answer/9305788).
  </Step>
  <Step title="Connect in CloudThinker">
    Open **More → Workspace settings → Connections**, select **Builtin Connections**, and search for **Google Analytics**. Click **Connect**, upload the JSON key under **GOOGLE_SERVICE_ACCOUNT_KEY**, and click **Connect**.

    **Success state:** the connection shows **Connected**. CloudThinker checks the service account’s access to Analytics accounts and properties.
  </Step>
</Steps>

## Connection details

| Field | What to enter |
|---|---|
| **GOOGLE_SERVICE_ACCOUNT_KEY** | The JSON key file for the service account with access to your Analytics properties |

The connection checks account and property access when you connect. Ask a traffic question after setup to check that the Data API also works.

## Required permissions

Grant the service account **Viewer** access on each property you want to query. Google Analytics account-level access can include all properties in that account, so choose the narrowest access you need.

<Tip>
Use a dedicated service account for CloudThinker. You can revoke its access without affecting other integrations.
</Tip>

## Agent capabilities

  <img src="/images/connections/google-analytics/01-read-flow-dark.svg" alt="A question goes from you to CloudThinker, which reads a Google Analytics property and returns an answer." className="hidden dark:block" style={{width: '100%'}} />

1. You ask CloudThinker a question about a property.
2. CloudThinker reads the data available to the service account.
3. CloudThinker returns an answer using the data Google Analytics reports.

| Capability | What CloudThinker can do |
|---|---|
| Properties | List accessible accounts and properties, and inspect property details |
| Traffic | Compare users, sessions, engagement, and key events across periods; break results down by source, channel, page, country, device, or event |
| Realtime activity | Read active users and recent events, with page, country, device, platform, or event breakdowns |
| Configuration | Read custom definitions, Google Ads links, and annotations |

The connection cannot create or change Google Analytics settings, audiences, key events, or annotations. Make those changes in Google Analytics.

### Verify the connection

```text
List my Google Analytics properties and show users and sessions for the last 7 days for my main property.
```

A successful answer identifies the property and reports its data. If several properties are available, name the one you want. A new property with no events can return empty results.

### Example prompts

```text
Which channels brought the most sessions to my website over the last 28 days?
Compare key events this week with the previous week for my main property.
How many active users are on my site right now, broken down by page?
```

## Troubleshooting

<Accordion title="The service account sees no property">
In Google Analytics, open the property's **Property access management** and add the service account email as a **Viewer**. Then test the connection again.
</Accordion>

<Accordion title="Google Analytics reports an API or permission error">
Enable the Google Analytics Admin API and Data API in the service account's Google Cloud project. Check the service account's property access, then retry.
</Accordion>

<Accordion title="The key is rejected">
Upload the complete JSON key file for a Google Cloud service account. If the key was deleted or disabled, create a new one and replace the saved credential.
</Accordion>

<Accordion title="A report reaches a quota limit">
Wait and retry with a narrower date range or breakdown. Google Analytics applies quotas to report requests.
</Accordion>

## Security

<ConnectionSecurity />

- Keep the JSON key out of chat and source control. Upload it only in the connection form.
- Grant the service account access only to the properties you want CloudThinker to read.
