Connect BMC Helix ITSM so CloudThinker can investigate incidents, work logs, changes, and problems. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing BMC Helix ITSM account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Ask your Helix administrator for an AR System REST account with access to the Incident, Change, and Problem records you want to inspect. See the [vendor's authentication documentation](https://docs.bmc.com/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **BMC Helix ITSM**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Use the AR System REST address, not a browser-only service portal address.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **REST URL** | Yes | The AR System REST address, for example https://acme-restapi.onbmc.com |
| **Username** | Yes | A Helix account with read access to Incident, Change, and Problem. |
| **Password** | Yes | The account password. Each script signs out when it ends. |

## Required permissions

Read Incident, Change, Problem, and related work-log records.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Incident review | Read incidents and work logs. |
| Change context | Inspect related change records. |
| Problem context | Read problem records without modifying them. |

The connection is read-only. It does not assign or resolve incidents or add work notes.

This connection is read-only. Make changes in BMC Helix ITSM.

### Verify the connection

```text
Inspect my BMC Helix ITSM connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use BMC Helix ITSM to investigate incidents, work logs, changes, and problems.
Summarize the highest-priority items visible through my BMC Helix ITSM connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in BMC Helix ITSM. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in BMC Helix ITSM when access is no longer needed, and update the connection after rotation.
