Connect Shortcut so CloudThinker can search stories, epics, and iterations, then read one. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Shortcut account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Shortcut API token at Settings → Your Account → API Tokens. See the [vendor's authentication documentation](https://developer.shortcut.com/api/rest/v3/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Shortcut**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Choose an account with access only to the workspaces and projects you want investigated.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **API token** | Yes | It acts as that user. |

## Required permissions

The token can read the stories, epics, and iterations visible to its owner.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Story search | Search stories. |
| Planning context | Read epics and iterations. |
| Work-item detail | Inspect a selected item without changing it. |

The connection is read-only. It cannot move, assign, comment on, create, or edit work items.

This connection is read-only. Make changes in Shortcut.

### Verify the connection

```text
Inspect my Shortcut connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Shortcut to search stories, epics, and iterations, then read one.
Summarize the highest-priority items visible through my Shortcut connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Shortcut. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Shortcut when access is no longer needed, and update the connection after rotation.
