Connect Huawei Cloud to let CloudThinker review servers, disks, CCE clusters, and security groups. The connection uses **a Huawei Cloud access key and secret key**.

## Prerequisites

- An account with access to the Huawei Cloud resources you intend to investigate.
- The **Admin** role in your CloudThinker workspace to add and manage the connection. See [Roles](/guide/security/roles).
- The credentials described below and a network route from CloudThinker to the service. For a private endpoint, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare access in Huawei Cloud">
    Use a dedicated IAM user with access to the intended regional project. Create an access key in that user’s security settings, or have an authorized IAM administrator create it. Download the credential file and keep its AK and SK together. Record the region and the project ID for that region.

    Follow the [vendor’s credential and authentication guidance](https://support.huaweicloud.com/intl/en-us/usermanual-iam/iam_02_0003.html) for your account.
  </Step>
  <Step title="Connect in CloudThinker">
    Open **Settings → Workspace → Connections**, find **Huawei Cloud**, and click **Connect**. Fill in the fields in [Connection details](#connection-details), check the account and region, and click **Connect**.

    **Success state:** the connection shows **Connected**. Run the verification prompt below to check what the account can actually read.
  </Step>
  <Step title="Verify the scope">
    Run the [verification prompt](#verify-the-connection). Compare the returned organization, projects, or resource names with the account you intended to connect. Keep a denied request visible as an access problem; do not interpret it as an empty result.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Access key (AK)** | Yes | The Access key (AK) for the account described in Setup. |
| **Secret key (SK)** | Yes | The secret key from the downloaded credentials file. Huawei shows it once. |
| **Region** | Yes | The region to read, for example ap-southeast-1 or cn-north-4. |
| **Project ID** | Yes | My Credentials &gt; Projects: the 32-character project ID listed for that region. |

The regional project ID is not the account ID. A key can be valid while access to the selected project is denied.

## Required permissions

Read access to ECS servers, EVS disks, CCE clusters, and VPC security groups in the specified project. Use read-only policies or a custom policy restricted to the required resources.

<Tip>
Start with read access to the smallest useful scope. Adding a connection does not grant permissions that the provider account lacks. For supported changes, [Approvals](/guide/approvals/overview) decides whether CloudThinker may proceed; provider permissions still apply.
</Tip>

## Agent capabilities

| Workflow | What agents can do |
|---|---|
| Discovery | Inspect ECS servers and attached resources |
| Investigation | Review disks and CCE clusters |
| Investigation | Review VPC security group rules |

### Verify the connection

```text
Review Huawei Cloud servers, disks, CCE clusters, and security groups in the connected regional project. Report any denied or unavailable checks separately.
```

Expect current resource names or a clear access error. No matching records is a valid outcome only when the request succeeded and its account, filters, and time window match your question.

### Example prompts

```text
Review Huawei Cloud servers, disks, CCE clusters, and security groups in the connected regional project
Use this connection to inspect one resource from the results and explain its current state with supporting evidence
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential is active, belongs to the intended account, and matches the selected region or endpoint. Replace an expired or revoked credential in CloudThinker. Do not paste it into chat or include it in a support screenshot.
  </Accordion>
  <Accordion title="Connected, but some resources are missing">
    Compare the provider account’s access, selected organization, and investigation filters. A successful sign-in does not prove access to every resource. The regional project ID is not the account ID. A key can be valid while access to the selected project is denied.
  </Accordion>
  <Accordion title="Requests are denied or cannot reach the service">
    A permission denial needs a provider access change for the specific read, not a broader account by default. For a timeout or certificate error, confirm the HTTPS endpoint, network route, and trusted CA with the service administrator. For throttling, narrow the investigation and retry after the provider’s indicated wait.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep the connection restricted to the account and resources intended for this workspace.
- Rotate credentials through the provider and replace the saved value in CloudThinker; never send secrets in a conversation.
