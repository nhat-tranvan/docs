Connect Checkmarx One so CloudThinker can review projects, scans, and SAST, SCA, and IaC results. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Checkmarx One account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Checkmarx One API key for the tenant you want to inspect. Use the vendor's API key procedure. See the [vendor's authentication documentation](https://docs.checkmarx.com/en/34965-188712-creating-api-keys.html) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Checkmarx One**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Choose the region from your Checkmarx One login URL and enter the tenant name.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Region** | Yes | The region in your Checkmarx One URL. Options: **US**, **US2**, **EU**, **EU2**, **Germany**, **Australia and New Zealand**, **India**, **Singapore**, **UAE**. Default: `ast.checkmarx.net`. |
| **Tenant** | Yes | The tenant name you sign in with. |
| **API key** | Yes | A key with a read-only role such as ast-viewer is enough. |

## Required permissions

Read projects, scans, and results for the scanners your organization licenses.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Project inventory | Identify accessible projects. |
| Scan review | Read scan status. |
| Finding review | Inspect SAST, SCA, and IaC results. |

The connection is read-only. It does not start scans or change result severity, triage state, or project settings.

This connection is read-only. Make changes in Checkmarx One.

### Verify the connection

```text
Inspect my Checkmarx One connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Checkmarx One to review projects, scans, and SAST, SCA, and IaC results.
Summarize the highest-priority items visible through my Checkmarx One connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Checkmarx One. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Checkmarx One when access is no longer needed, and update the connection after rotation.
