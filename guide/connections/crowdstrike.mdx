Connect CrowdStrike Falcon so CloudThinker can investigate alerts, hosts, and open vulnerabilities. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing CrowdStrike Falcon account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Falcon API client and copy its client ID and secret. See the [vendor's authentication documentation](https://developer.crowdstrike.com/sdks/python/authentication/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **CrowdStrike Falcon**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Select the Falcon cloud that owns the client. Credentials do not transfer between cloud regions.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Falcon cloud** | Yes | Options: **US-1**, **US-2**, **EU-1**, **US-GOV-1**, **US-GOV-2**. Default: `https://api.crowdstrike.com`. |
| **Client ID** | Yes | Enter client id. |
| **Client secret** | Yes | Shown once when you create the client. Scopes: Alerts read, Hosts read, Vulnerabilities read; Alerts write lets the agent update alerts. |

## Required permissions

Read access to Alerts, Hosts, and Vulnerabilities. Updating an alert also requires Alerts write access.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Alert triage | Read alerts and their host context. |
| Host inventory | Inspect hosts and visibility. |
| Alert updates | Change supported alert status or assignment after approval. |

Only alert updates are supported as changes. Host containment, real-time response, IOC edits, and prevention policy changes are excluded.

Supported changes require the corresponding provider permission and go through [Approvals](/guide/approvals/overview). Ask for a specific target and change.

### Verify the connection

```text
Inspect my CrowdStrike Falcon connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use CrowdStrike Falcon to investigate alerts, hosts, and open vulnerabilities.
Summarize the highest-priority items visible through my CrowdStrike Falcon connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in CrowdStrike Falcon. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in CrowdStrike Falcon when access is no longer needed, and update the connection after rotation.
