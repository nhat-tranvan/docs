Connect JetBrains YouTrack so CloudThinker can review issues by project, state, and history. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing JetBrains YouTrack account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a YouTrack permanent token for the account whose projects you want to inspect. See the [vendor's authentication documentation](https://www.jetbrains.com/help/youtrack/devportal/authentication-with-permanent-token.html) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **JetBrains YouTrack**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Use the complete YouTrack base URL, including a deployment path when your server uses one.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **YouTrack URL** | Yes | Your YouTrack address, for example https://acme.youtrack.cloud, or https://yt.example.com/youtrack for a Server install with a path. |
| **Permanent token** | Yes | The token reads what its user can read. |

## Required permissions

Choose the YouTrack scope; effective record access follows the account's permissions.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Issue search | Find issues by project and state. |
| Issue detail | Read selected issue information. |
| History review | Inspect issue activity without changing it. |

The connection is read-only. It cannot create, edit, assign, comment on, or resolve issues.

This connection is read-only. Make changes in JetBrains YouTrack.

### Verify the connection

```text
Inspect my JetBrains YouTrack connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use JetBrains YouTrack to review issues by project, state, and history.
Summarize the highest-priority items visible through my JetBrains YouTrack connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in JetBrains YouTrack. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in JetBrains YouTrack when access is no longer needed, and update the connection after rotation.
