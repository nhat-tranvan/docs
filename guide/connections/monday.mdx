Connect monday.com so [CloudThinker](/guide/agents/overview) can review boards, find items that stopped moving, read item updates and docs, and create or change items when you ask. monday.com uses OAuth through its hosted MCP server, so there's no token to create or paste.

## Prerequisites

- A monday.com account that can open the boards you want CloudThinker to read.
- Permission in your monday.com account to authorize a third-party app.
- Edit rights on a board, only if you want agents to create items, change column values, or post updates there.
- Permission to manage connections in your CloudThinker workspace. monday.com works on every CloudThinker plan.

## Setup

<Steps>
  <Step title="Open monday.com in CloudThinker">
    In the sidebar, click **More → Workspace settings → Connections**. On the **Builtin Connections** tab, search for **monday.com** and click **Connect**.
  </Step>
  <Step title="Authorize in monday.com">
    monday.com opens in a new window. If your browser blocks it, a dialog appears instead: click **Open monday.com**. Sign in with the account whose boards CloudThinker should see, then approve access. The window closes on its own.

    If your browser is already signed in to a different monday.com account, sign out of it first.
  </Step>
  <Step title="Return to CloudThinker">
    Back in CloudThinker, there's nothing to click. CloudThinker stores the OAuth tokens and tests the connection.

    **Success state:** monday.com shows a **Connected** status.
  </Step>
</Steps>

## Connection details

There are no fields to fill in.

| Item | Description |
|---|---|
| **OAuth tokens** | Issued by monday.com when you approve access and stored by CloudThinker. Reconnect to replace them. |

A workspace holds one monday.com connection, so it reaches one monday.com account. To switch accounts, disconnect it and connect again.

## Required permissions

CloudThinker acts as the account that authorized the connection. A board that account can't open stays invisible to agents.

| Access | What it covers |
|---|---|
| **Read** | Workspaces, boards, items, item updates, board activity, docs, users and teams, automations, and monday dev sprints (monday dev is monday.com's product for software teams, with sprint boards) |
| **Write** | Three actions only: create an item, change an item's column values, post an update on an item |

<ApprovalDefault />

CloudThinker can't create or delete boards, workspaces, docs, or dashboards, and it can't delete or archive items.

<Tip>
Authorize with an account that only sees the boards CloudThinker needs. Anything an agent creates has to be removed in monday.com itself.
</Tip>

## Agent capabilities

| Capability | What CloudThinker does | Checked by Approvals |
|---|---|---|
| **Account discovery** | Lists your workspaces, their boards, users, and teams, and returns the board IDs other requests need | No |
| **Board review** | Summarizes a board's groups and columns and how its items split by status and owner | No |
| **Stalled work** | Finds items that haven't moved in a window you set (14 days by default), oldest first, skipping items marked `Done` | No |
| **Item context** | Reads an item's updates, the board's activity, and monday docs | No |
| **Sprint reporting** | Reads monday dev sprint boards, sprint details, and sprint summaries | No |
| **Item changes** | Creates an item, changes column values, or posts an update | Yes |

### Verify the connection

```text
List my monday.com workspaces and the boards in each one, with their board IDs
```

You should see your workspace names and boards you recognize. If a board you expect is missing, see Troubleshooting.

### Example prompts

```text
Review the Sprint Tasks board and show how open items split by status and owner
Which items on the Sprint Tasks board haven't moved in 21 days? Treat Done and Shipped as finished
Post an update on the "Checkout timeout" item saying the fix is in review
```

If your board uses a finished label other than `Done`, name it as in the second prompt. The third prompt is a write, so it goes through your Approvals before it runs.

## Troubleshooting

<Accordion title="The OAuth window doesn't finish">
Your browser is likely signed in to a different monday.com account. Sign out, sign in to the intended account, and click **Connect** again.
</Accordion>

<Accordion title="An agent reports a board as empty">
monday.com answers an unknown, deleted, or hidden board ID with an empty record instead of an error. Ask CloudThinker to list your workspaces and boards first, then refer to the board by a name or ID from that list.
</Accordion>

<Accordion title="A board you can see in monday.com is missing">
The connection was authorized by an account without access to that board. Reconnect with an account that can open it. Boards are listed per workspace, so ask about the workspace that holds the board.
</Accordion>

<Accordion title="A sprint summary comes back unavailable">
Sprint summaries only exist on monday dev sprint boards that have a sprint summary column. For other boards, ask for a board review or sprint details instead.
</Accordion>

<Accordion title="Requests fail with 401 or 403">
A 401 means the OAuth token expired or was revoked, so reconnect monday.com. A 403 means the authorizing account can't see that board or workspace, so reconnect with one that can.
</Accordion>

<Accordion title="A request fails with a rate limit or complexity error">
monday.com limits how much board data one request can pull. Wait a minute, then narrow the request to one board, one group, or fewer items.
</Accordion>

## Security

<ConnectionSecurity />

- **Small write surface.** Agents can only create an item, change column values, or post an update. Every other monday.com change stays with your team.
- **No delete path.** CloudThinker can't delete or archive what it creates, so choose **Manual** so a person approves every change, and review each approval request before you confirm it. Once CloudThinker turns on [Rule enforcement](/guide/approvals/rules#troubleshooting) for your workspace, an **Ask first** [Rule](/guide/approvals/rules) can do the same for this connection alone.
- **Revoke in monday.com too.** When you remove the connection, also remove CloudThinker from the apps your monday.com account has authorized.
