Connect Wiz so CloudThinker can review issues, vulnerability findings, and cloud resources. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Wiz account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Ask a Wiz administrator for a Custom Integration service account and its client ID and secret. See the [vendor's authentication documentation](https://docs.wiz.io/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Wiz**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Use the tenant's GraphQL API endpoint and matching authentication provider. Wiz for Gov is not supported by this connection.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **API endpoint** | Yes | Wiz for Gov is not supported yet. |
| **Client ID** | Yes | Grant read:issues, read:vulnerabilities, and read:resources. |
| **Client secret** | Yes | The secret shown once when you create the service account. |
| **Sign-in provider** | Yes | Options: **Wiz (auth.app.wiz.io)**, **Legacy (auth.wiz.io)**. Default: `cognito`. |

## Required permissions

Grant `read:issues`, `read:vulnerabilities`, and `read:resources` for the relevant projects.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Issue review | Read cloud security issues. |
| Vulnerability review | Inspect vulnerability findings. |
| Resource context | Associate findings with accessible cloud resources. |

The connection is read-only. It cannot resolve, reject, or assign issues or create tickets.

This connection is read-only. Make changes in Wiz.

### Verify the connection

```text
Inspect my Wiz connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Wiz to review issues, vulnerability findings, and cloud resources.
Summarize the highest-priority items visible through my Wiz connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Wiz. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Wiz when access is no longer needed, and update the connection after rotation.
