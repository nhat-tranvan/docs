Connect Ternary so CloudThinker can track multicloud spend, budgets, savings, and cost alerts. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Ternary account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Ternary API key for a user who can view integrations, budgets, and recommendations. See the [vendor's authentication documentation](https://docs.ternary.app/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Ternary**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Copy the tenant UUID from the Ternary web application and select the region. EU cost queries are limited by API availability.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Region** | Yes | Options: **US**, **EU**. Default: `us`. |
| **API key** | Yes | The key acts with your role, so create it as a user who can view integrations, budgets, and recommendations. |
| **Tenant ID** | Yes | The tenant_id value in the Ternary web app URL, a UUID. CloudThinker only reads costs, budgets, recommendations, and alerts. |

## Required permissions

Read cost, budget, recommendation, and alert data for the selected tenant.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Multicloud spend | Inspect tenant cost data. |
| Budget review | Read budgets and cost alerts. |
| Savings | Review recommendations without changing their state. |

The connection is read-only. It cannot change budgets, recommendation state, alert rules, or cases.

This connection is read-only. Make changes in Ternary.

### Verify the connection

```text
Inspect my Ternary connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Ternary to track multicloud spend, budgets, savings, and cost alerts.
Summarize the highest-priority items visible through my Ternary connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Ternary. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Ternary when access is no longer needed, and update the connection after rotation.
