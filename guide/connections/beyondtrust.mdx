Connect BeyondTrust Password Safe so CloudThinker can review managed accounts, password age, and sessions. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing BeyondTrust Password Safe account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Obtain a Password Safe API registration key and a RunAs username authorized to use that registration. Supply the RunAs password only when the registration requires it. See the [vendor's authentication documentation](https://docs.beyondtrust.com/bips/v25.2/docs/api) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **BeyondTrust Password Safe**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Use your Password Safe instance origin. If the registration restricts source IPs, allow CloudThinker's approved egress addresses.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Instance URL** | Yes | Your Password Safe address without a path, for example https://acme.ps.beyondtrustcloud.com or https://pam.example.com. |
| **API key** | Yes | Add the CloudThinker's approved source address to its allowed sources. |
| **RunAs user** | Yes | The Password Safe user the API key acts as, for example DOMAIN\svc-cloudthinker. Give it Requestor and Session Reviewer roles to read accounts and sessions. |
| **RunAs password** | No | Only when the API registration requires the user password. Leave empty otherwise. |

## Required permissions

The RunAs user must be able to read the managed accounts and sessions being investigated.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Managed accounts | Inspect account metadata and password age. |
| Sessions | Review session records. |
| Access health | Investigate the accounts and sessions visible to the RunAs user. |

The connection is read-only. It cannot retrieve passwords, release credentials, rotate them, or terminate sessions.

This connection is read-only. Make changes in BeyondTrust Password Safe.

### Verify the connection

```text
Inspect my BeyondTrust Password Safe connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use BeyondTrust Password Safe to review managed accounts, password age, and sessions.
Summarize the highest-priority items visible through my BeyondTrust Password Safe connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in BeyondTrust Password Safe. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in BeyondTrust Password Safe when access is no longer needed, and update the connection after rotation.
