Connect Tines so CloudThinker can review stories, failing actions, runs, and cases. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Tines account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).
- An HTTPS route from CloudThinker to your service. For a private service, see [Reaching private services](/guide/connections/overview#reaching-private-services).

## Setup

<Steps>
  <Step title="Prepare the credential">
    Create a Tines API key through a team Credentials connect flow or under Settings → Access & security → API keys. See the [vendor's authentication documentation](https://www.tines.com/stories/docs/api/authentication/) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Tines**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Choose a restricted team or service identity where possible instead of a tenant-owner key.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Tenant URL** | Yes | Your Tines tenant address, for example https://acme.tines.com |
| **API key** | Yes | A personal key sees the teams its owner can view. |

## Required permissions

Read the teams, stories, actions, runs, and cases needed for investigation. A personal key follows its owner's access.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Story health | Inspect stories, actions, and run failures. |
| Failure context | Read action error logs. |
| Case review | Inspect cases without changing them. |

The connection is read-only. It cannot run, edit, enable, or disable stories or modify cases.

This connection is read-only. Make changes in Tines.

### Verify the connection

```text
Inspect my Tines connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Tines to review stories, failing actions, runs, and cases.
Summarize the highest-priority items visible through my Tines connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Tines. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Tines when access is no longer needed, and update the connection after rotation.
