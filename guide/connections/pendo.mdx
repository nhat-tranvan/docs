Connect Pendo so CloudThinker can track feature adoption, page usage, and guide reach. Use a dedicated credential with access only to the resources you want to inspect.

## Prerequisites

- An existing Pendo account or deployment containing the resources you want to inspect.
- Permission to create or obtain the credential described below.
- A CloudThinker workspace role that can add connections; see [Roles](/guide/security/roles).

## Setup

<Steps>
  <Step title="Prepare the credential">
    As a Pendo subscription administrator, create an integration key under Settings → Integrations → Integration Keys. See the [vendor's authentication documentation](https://support.pendo.io/hc/en-us/articles/9491198203547-Pendo-integration-keys) for the procedure that applies to your account.
  </Step>
  <Step title="Add the connection">
    Open **Settings → Connections**, find **Pendo**, and click **Connect**. Enter the values in [Connection details](#connection-details).

    Choose the region matching your Pendo login address. An integration key is different from the install-script application key.
  </Step>
  <Step title="Check the result">
    Click **Connect** and wait for the connection check.

    **Success state:** the connection shows **Connected**. Run the verification prompt below and confirm that the expected resources appear.
  </Step>
</Steps>

## Connection details

| Field | Required | What to enter |
|---|---|---|
| **Region** | Yes | The address you sign in to Pendo at. Options: **US (app.pendo.io)**, **US1 (us1.app.pendo.io)**, **EU (app.eu.pendo.io)**, **Japan (app.jpn.pendo.io)**, **Australia (app.au.pendo.io)**. Default: `us`. |
| **Integration key** | Yes | Leave Allow Write Access off. |

## Required permissions

Use an integration key without write access. Treat the key as subscription-wide access, not an application-specific credential.

<Tip>
Start with the smallest resource scope that answers your investigation. Verify a known resource before expanding access. A successful sign-in does not prove access to every project or account.
</Tip>

## Agent capabilities

| Task | What CloudThinker can do |
|---|---|
| Feature adoption | Inspect feature usage. |
| Page usage | Review page analytics. |
| Guide reach | Inspect guide activity without changing guides. |

The connection is read-only. It cannot edit guides, tags, segments, or metadata.

This connection is read-only. Make changes in Pendo.

### Verify the connection

```text
Inspect my Pendo connection. Identify the accessible account or resource scope and show a small sample without changing anything.
```

Confirm that the returned scope matches the credential you intended to connect. An empty result can mean missing data or restricted access; it is not proof that the service is healthy.

### Example prompts

```text
Use Pendo to track feature adoption, page usage, and guide reach.
Summarize the highest-priority items visible through my Pendo connection and cite their identifiers.
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">
    Check that the credential belongs to the same account, region, or tenant entered in the form. Replace an expired or revoked credential, then reconnect. Do not paste credentials into chat.
  </Accordion>
  <Accordion title="A resource is missing or access is denied">
    Check the credential's access to that specific project, organization, or resource in Pendo. Grant the missing read permission only for the intended scope, then try the same read again.
  </Accordion>
  <Accordion title="The service cannot be reached">
    Verify the service address and a route from CloudThinker. For a private endpoint, check your allowlist and trusted certificate chain. Keep certificate verification enabled when using a trusted certificate.
  </Accordion>
</AccordionGroup>

## Security

<ConnectionSecurity />

- Keep this integration's credential separate from personal daily-use credentials where your provider supports it.
- Revoke or rotate it in Pendo when access is no longer needed, and update the connection after rotation.
