A share link turns one [artifact](/guide/artifacts/overview) (a report, dashboard, or saved file) into a public web page. Anyone with the URL can open it without a CloudThinker account, and you can revoke it whenever you want.

## Prerequisites

- The **Developer** or **Admin** [workspace role](/guide/workspace-users). **Viewers** can't create or revoke share links.
- A finished artifact in the **Artifacts** gallery or in a conversation

## Create a share link

<Steps>
  <Step title="Open the artifact">
    Click **Artifacts** in the left sidebar and find the item, or open the artifact from the conversation that built it.
  </Step>
  <Step title="Click Share">
    Use the **Share** icon on the artifact's card in the gallery, at the top of the artifact page, or in the artifact panel of the conversation (the panel that opens when you click the artifact card in the chat). The share dialog opens and confirms that anyone with the link can view the item without signing in.
  </Step>
  <Step title="Click Create share link">
    **Success state:** a **Share link created successfully** toast appears, and the dialog shows a **Share URL** with **Open link** and **Revoke** buttons. In the gallery, a globe icon appears next to the card's title, and the **Share** icon's tooltip reads **Shared · Manage link**.
  </Step>
  <Step title="Copy the URL and send it">
    Click the copy icon at the right of the **Share URL** field (**Copied to clipboard** confirms it). Paste it into an email, a ticket, or a chat. Click **Open link** first if you want to see the page the way a recipient will.
  </Step>
</Steps>

## What viewers see

| Viewers get | Viewers don't get |
|---|---|
| That one artifact, on its own page | Access to your workspace, conversations, or other artifacts |
| The artifact's current version | Older versions |
| The data as of when that version was published, labeled **Version N as of** with the date and time | Live data. A shared page never runs queries against your connections |
| Your logo and a "Shared from" footer with your company name, if [workspace branding](/guide/workspace-branding) is set up. Without branding, the footer has no logo and no company name | A sign-in prompt |
| For a saved file: a preview and a **Download** button | A **Download PDF** button on a shared report or dashboard |

Because the link always serves the current version, a new version CloudThinker publishes later replaces what viewers see at the same URL. You can't pin a link to a version. To try changes without touching the shared page, ask for a draft as a separate artifact in a new conversation. Once it's approved, ask CloudThinker to apply the same changes to the shared artifact, and it publishes them as a new version at the same URL.

To send a recipient a PDF, click **Download PDF** on the artifact page yourself and attach the file.

<Warning>
A share link is public until you revoke it, and anyone who receives the URL can forward it. Read the artifact once as an outsider would before you share: cost figures, account IDs, resource names, and architecture details are all visible. To redact before you share, ask CloudThinker in the conversation to mask account IDs and resource names, then check the new version.
</Warning>

## Review everything you've shared

In the gallery, open the filter and set **Sharing** to **Shared**. The list then shows only items with an active link, so you can audit them in one pass. Set it to **Private** to see what hasn't been shared.

## Security and controls

- Links don't expire. A link stays live until someone revokes it.
- There's no password or sign-in option on a link. Anyone with the URL can open it.
- Only Admins and Developers can create or revoke links, so roles are how you control sharing. See [Workspace users](/guide/workspace-users).
- The URL holds a random identifier (a UUID), so it can't be guessed from the artifact's name or ID.
- There's no workspace switch to turn sharing off. Limit it with roles instead.
- Creating or revoking a link isn't recorded in [Audit Logs](/guide/security/audit-logs), and there's no view count or access log for a shared page. The gallery and share dialog don't show who created a link or when. To audit, use the **Shared** filter above.

## Revoke a link

<Steps>
  <Step title="Open the share dialog">
    Click the **Share** icon on the artifact's card (its tooltip reads **Shared · Manage link**) or **Share** on the artifact page.
  </Step>
  <Step title="Click Revoke">
    **Success state:** the dialog goes back to **Create share link**. The old URL stops working for everyone right away, and recipients see **This link is no longer active** (a revoked file link shows a not found page). Files they already downloaded stay with them.
  </Step>
</Steps>

Sharing the same artifact again creates a new URL. The revoked one never comes back.

<Warning>
**Remove from artifacts** on a saved file doesn't revoke its link. The page stays public, and the file leaves the gallery, so revoke the link first.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="There's no Share button, or it's disabled">
    **Cause:** your workspace role is **Viewer**, which hides **Share**. In a conversation, the icon stays disabled with **Available after this artifact finishes** until CloudThinker is done writing. **Fix:** wait for the artifact to finish, or ask a workspace Admin to share it or to change your role in [Workspace users](/guide/workspace-users).
  </Accordion>
  <Accordion title="The recipient sees This link is no longer active or a not found page">
    **Cause:** the link was revoked, or the URL was cut off when it was pasted. **Check:** open the share dialog. If it shows **Create share link**, the item isn't shared. **Fix:** create a new link and send the full URL.
  </Accordion>
  <Accordion title="The shared page shows old numbers">
    **Cause:** shared pages show the snapshot from when the current version was published, never live data. **Fix:** ask CloudThinker to update the artifact. The new version appears at the same link.
  </Accordion>
  <Accordion title="The footer doesn't show our company">
    **Cause:** workspace branding isn't set. **Fix:** add your logo and company name in [Workspace branding](/guide/workspace-branding).
  </Accordion>
</AccordionGroup>
