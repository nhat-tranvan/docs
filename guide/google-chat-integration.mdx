Use Google Chat to work with CloudThinker in direct messages or shared spaces and receive configured workspace notifications.

<Note>
**Early access** — Google Chat is available to selected organizations. [Contact us](https://cloudthinker.io/contact) to turn it on for your organization.
</Note>

<Note>
  Google Chat is an integration, not a [connection](/guide/connections/overview), and adding CloudThinker does not give it access to other Google Workspace data.
</Note>

## Prerequisites

- A CloudThinker [messaging-eligible plan](/guide/billing/pricing#ai-features-by-plan) (Team and above).
- A Google Workspace administrator who can install CloudThinker for your organization.
- The Google account that sent the message to CloudThinker.

An organization Owner or Admin must map a shared space. A workspace member with chat access can map their own direct message. Direct messages cannot receive workspace notifications.

## Setup

<Steps>
  <Step title="Review the installation guidance">
    Sign in as a CloudThinker organization Owner or Admin. Go to [**Admin Settings → Integrations → Google Chat**](https://app.cloudthinker.io/admin-settings/integrations/google-chat).

    A Google Workspace administrator installs CloudThinker once for your organization. Google publishes no universal installation link.
  </Step>
  <Step title="Add CloudThinker in Google Chat">
    Open Google Chat, then start a direct message with CloudThinker or add CloudThinker to a shared space.

    If CloudThinker already appears in an existing direct message, remove CloudThinker and add CloudThinker again. Google sends the setup event only after a fresh add.
  </Step>
  <Step title="Open your configuration link">
    CloudThinker replies with a personal configuration link. Open it within 15 minutes.

    An organization Owner or Admin must open the link for an unmapped shared space. A member with chat access can configure their own direct message.
  </Step>
  <Step title="Choose a workspace and verify your identity">
    Select the CloudThinker workspace when prompted. Continue with the same Google account that messaged CloudThinker.

    **Success state:** CloudThinker shows **Google Chat is ready**.
  </Step>
  <Step title="Test the conversation">
    Return to Google Chat and mention CloudThinker again. CloudThinker answers in the mapped workspace and continues the conversation in that thread.
  </Step>
</Steps>

## Ask CloudThinker for work

Mention CloudThinker to start work in a mapped direct message or shared space. Add a tool tag to shape the output.

```text
@CloudThinker #dashboard summarize this month's cloud costs
@CloudThinker #report review our critical security findings
@CloudThinker investigate pod failures in production
```

Replies in the same Google Chat thread continue the same CloudThinker conversation. See [CloudThinker Language](/guide/memory) for supported tool tags.

### Send files to CloudThinker

Upload a file directly to the Google Chat message when CloudThinker needs to inspect it. Google Drive attachments are not downloaded because adding CloudThinker does not grant Drive access.

CloudThinker cannot upload generated files back to Google Chat.

## Configure notifications

Mapped shared spaces can receive workspace notifications, including incident updates. Configure the destination for each event in the [notification matrix](/guide/notifications) — the grid that maps each event type to destinations.

Direct messages never appear as notification destinations. If a space is missing, confirm that it is a shared space mapped to the current workspace.

## Manage mapped spaces

Go to [**Admin Settings → Integrations → Google Chat**](https://app.cloudthinker.io/admin-settings/integrations/google-chat) to review every mapped space and its workspace.

An organization Owner or Admin can move a space to another workspace in the same organization. New messages start fresh conversations there; earlier conversations remain in the original workspace.

Disconnect Google Chat from the same page when the organization should stop using the integration.

## Troubleshooting

<Accordion title="CloudThinker does not send a configuration link">
  Mention CloudThinker again in the same Google Chat conversation. For an existing direct message, remove CloudThinker and add CloudThinker again so Google sends a fresh setup event.
</Accordion>

<Accordion title="The configuration link is invalid or unavailable">
  Each link works for 15 minutes. Mention CloudThinker again to create a new link, then open it with the same Google account that sent the message.
</Accordion>

<Accordion title="CloudThinker asks for an organization Admin">
  An organization Owner or Admin must map an unmapped shared space. Ask one to mention CloudThinker in that space and open the new link.
</Accordion>

<Accordion title="You cannot run CloudThinker in this workspace">
  Ask a workspace administrator to grant you chat access. Then mention CloudThinker again and use the new configuration link.
</Accordion>

<Accordion title="A Google Chat space is missing from notifications">
  Direct messages cannot receive notifications. Confirm that the destination is a shared space mapped to the current workspace, then select it in the notification matrix.
</Accordion>
