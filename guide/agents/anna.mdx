Anna is CloudThinker's Team Lead. Anna answers workspace requests directly and brings in a specialist when that improves the answer.

## What Anna does best

- Handle a request that spans cloud, security, databases, and Kubernetes.
- Hand parts of a task to Alex, Oliver, Tony, or Kai and combine their results.
- Write summaries and plans that you can share.
- Work with your GitHub and GitLab repositories.
- Create and run scheduled Automations.

Changes to your environment follow your workspace's autonomy mode, Manual or Auto. See [Auto Mode](/guide/auto-mode) and [Approval](/guide/approval).

## Example prompts

Mention an agent with `@`, a connection with `#`, and a Skill or command with `/`. Plain language works.

```text
@anna summarize last night's outage across infrastructure, database, and Kubernetes
@anna build a remediation plan with an owner for each finding
have @oliver lead the assessment and @alex review the infrastructure impact
```

## Connections

Anna uses your GitHub and GitLab connections. A specialist that Anna brings in uses its own connections, and its changes need the same approval as when you ask it directly.
