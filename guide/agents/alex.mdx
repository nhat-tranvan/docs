Alex is CloudThinker's Cloud Engineer, specializing in cost optimization, performance tuning, and multi-cloud architecture across AWS, Azure, and GCP.

## How Alex works

1. **Connects to your cloud providers** via read-access credentials — AWS Cost Explorer, CloudWatch, EC2/RDS APIs, Azure Cost Management, GCP Billing.
2. **Analyzes in context** — Alex correlates utilization patterns with cost data and your infrastructure topology, not just raw metrics.
3. **Forms recommendations** with specific dollar savings, effort level, risk rating, and implementation steps.
4. **Acts within your autonomy mode** — Alex can execute right-sizing (matching a resource's size to its real usage), tag resources, or generate infrastructure-as-code (IaC) diffs for review.
5. **Learns your environment** — Alex remembers which resources are exempt, your preferred instance families, and your cost thresholds.

Alex proposes write actions under your workspace's autonomy mode — Manual or Auto. See [Auto Mode](/guide/auto-mode) and [Approval](/guide/approval).

## Tool usage

| Tool | Alex use case |
|------|---------------|
| `#dashboard` | Cost trends, resource utilization, spending by service |
| `#report` | Quarterly cost analysis, migration assessments, architecture reviews |
| `#recommend` | Right-sizing, reserved capacity purchases, optimization actions |
| `#alert` | Budget thresholds, cost spikes, utilization anomalies |
| `#visualize` | Spending trends, usage patterns, cost forecasts |

## Example prompts

Cost analysis:

```text
@alex #dashboard monthly cost trends by service and region
@alex #report last quarter's spending with the largest cost drivers
@alex #recommend EC2 instances for right-sizing based on 30-day utilization
```

Waste and capacity:

```text
@alex #report unattached volumes, unused Elastic IPs, and orphaned snapshots
@alex #recommend reserved instances vs savings plans for our usage pattern
@alex #alert when daily spend exceeds $5,000
```

Multi-cloud:

```text
@alex #visualize spending across AWS, Azure, and GCP for the last 6 months
@alex #report cost comparison of AWS vs Azure for our current workloads
@alex #recommend consolidation opportunities across providers
```

## Connection requirements

Alex requires cloud provider connections with cost and performance data access:

| Provider | Required access |
|----------|----------------|
| **AWS** | Cost Explorer, CloudWatch, EC2, RDS, S3, Lambda |
| **Azure** | Cost Management, Monitor, Compute, Storage |
| **GCP** | Billing, Monitoring, Compute Engine, Cloud SQL |
