Alex is CloudThinker's Cloud Engineer. Alex operates secure, reliable, and cost-efficient cloud infrastructure on AWS, Azure, and GCP.

## What Alex does best

- Find cloud waste and right-size resources, with the savings for each change.
- Explain spend by service, region, and account, and forecast it.
- Review and plan infrastructure, including Terraform and CloudFormation.
- Compare costs and plan migrations across providers.
- Create and run scheduled Automations.

Changes to your environment follow your workspace's autonomy mode, Manual or Auto. See [Auto Mode](/guide/auto-mode) and [Approval](/guide/approval).

## Example prompts

Mention an agent with `@`, a connection with `#`, and a Skill or command with `/`. Plain language works.

```text
@alex show last quarter's biggest cost drivers in AWS
@alex find unattached volumes, unused Elastic IPs, and old snapshots
@alex which EC2 instances can we right-size, based on 30 days of usage?
```

## Connections

Alex uses your AWS, Azure, and GCP connections.
