Oliver is CloudThinker's Security Engineer. Oliver assesses and improves the security of your cloud, applications, and infrastructure.

## What Oliver does best

- Audit IAM policies and find over-privileged access.
- Find misconfigurations such as open security groups and public resources.
- Collect compliance evidence for SOC 2, ISO 27001, and similar frameworks.
- Test an app with [Pentest](/guide/security/pentest).

Changes to your environment follow your workspace's autonomy mode, Manual or Auto. See [Approval mode](/guide/approvals/approval-mode) and [Approvals](/guide/approvals/overview).

## Example prompts

Mention an agent with `@`, a connection with `#`, and a Skill or command with `/`. Plain language works.

```text
@oliver list security groups open to 0.0.0.0/0 in AWS
@oliver find IAM roles with privilege escalation paths
@oliver prepare a SOC 2 gap analysis for our logging and access controls
```

## Connections

Oliver uses your AWS, Azure, GCP, and Vault connections. To work with Oliver, add an App or attach a connection.
