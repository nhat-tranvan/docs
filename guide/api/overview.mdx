The CloudThinker Public API is a REST API that reads and acts on one workspace with an API token. A token carries the scopes you pick and never does more than your workspace role allows.

New here? The [quickstart](/guide/api/quickstart) takes you from a token to your first call in about five minutes.

## What you can call

<ApiAreas />

Each call needs one scope, and your workspace role must allow it. Every endpoint page names its scope; [API Tokens](/guide/api/tokens#scopes) explains how scopes work. See [Approvals for API Runs](/guide/api/approvals#start-a-run-and-get-its-answer) to start an agent run and read its answer.

To call CloudThinker another way, use the [CloudThinker CLI](/guide/cli/api), the [Claude Connector](/guide/mcp/overview), the [A2A API](/guide/api/a2a) for an outside system such as ServiceNow, [Webhooks](/guide/webhooks/overview), or [SCIM provisioning](/guide/security/scim) for Okta and Microsoft Entra ID.

## How it works

- **Base URL:** `https://app.cloudthinker.io/api/public`. Paths look like `/v1/workspaces/<workspace-id>/{module}/{resource}`.
- **Authentication:** send `Authorization: Bearer <token>` with a personal (`ct_pat_…`), service account (`ct_sat_…`) or OAuth (`ct_oat_…`) token, or a CLI login. Each token works in one workspace; `GET /v1/token` returns its workspace ID, scopes and expiry.
- **Format:** JSON in and out, UTF-8. A body field the operation doesn't define returns `422`. The OpenAPI 3.1 contract is at `https://app.cloudthinker.io/api/public/v1/openapi.json`, no token needed.
- **Paging:** list calls take `limit` (1–100, default 20) and `cursor`. A page is `{"items": [...], "next_cursor": "..."}`; pass `next_cursor` back as `cursor` until it is `null`. Keep `limit` and filters the same; a changed query returns `400` `invalid_cursor`.
- **Writes:** every `POST` needs an `Idempotency-Key` header. See [API Errors](/guide/api/errors#retry-safe-writes).
- **Versions:** every path starts with the version, `v1`. A breaking change ships as a new version. Within `v1`, new fields and operations can appear, so ignore response fields you don't recognize.

List incidents in your workspace, with `WORKSPACE_ID` set from `GET /v1/token`:

```bash
curl -sS "https://app.cloudthinker.io/api/public/v1/workspaces/$WORKSPACE_ID/resolve/incidents?limit=20" \
  -H "Authorization: Bearer $CLOUDTHINKER_TOKEN"
```
