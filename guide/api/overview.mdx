**Coming soon** — The CloudThinker REST API is not available yet. This page describes what it will do. [Contact us](https://cloudthinker.io/contact) to hear when it launches.
</Note>

The CloudThinker API exposes the operations you use in the web console as authenticated HTTPS endpoints. Use it to embed cloud operations into your own products, automate workflows, or integrate CloudThinker with internal tooling.

## What you can do

| Capability | Description |
| --- | --- |
| Start conversations | Trigger agent conversations programmatically and read the results back into your own tools |
| Query resources | Read the discovered inventory of cloud resources and costs across your connected providers |
| Work with recommendations | List and update cost, security, and reliability recommendations |
| Manage incidents | Open incidents and read investigation results from [Resolve](/guide/incident/overview) |

## Availability

The API is not available yet. Endpoint paths, authentication details, and versioning guarantees will be published here at launch. [Contact us](https://cloudthinker.io/contact) to hear when it launches.

If you need external systems to trigger agent work today, [webhooks](/guide/webhooks/overview) are generally available.
