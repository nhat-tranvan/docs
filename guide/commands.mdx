You talk to CloudThinker in plain language, and three optional symbols make a request more precise: `@` picks an agent, `#` picks a connection, and `/` runs a skill or a chat action.

## Prompt syntax

```text
@agent #connection your request
```

| Part | Required | What it does | Example |
| --- | --- | --- | --- |
| `@agent` | No | Sends the request to one of your workspace's [custom agents](/guide/agents/customize). Leave it out and CloudThinker, the built-in assistant, answers. Type `@` to pick from your workspace's agents. A name that matches no agent stays plain text, and CloudThinker answers | `@finops-reviewer` |
| `#connection` | No | Points CloudThinker at one connected system, such as an AWS account or a Kubernetes cluster. The `#` picker also lists Slack channels, Microsoft Teams channels, and Google Chat spaces, so you can name where a result should go | `#prod-aws` |
| `/name` | No | Runs a [skill](/guide/skills/overview) or a chat action from the `/` menu | `/security-configuration-audit` |
| Your request | Yes | What you need, in your own words. Add scope, time range, and the output shape you want | `top 5 cost drivers this month as a table` |

A plain sentence with none of the symbols works. Add `#connection` when the workspace has several accounts and the answer depends on which one CloudThinker reads.

```text
What changed in our AWS bill this week?
#prod-aws Which EC2 instances ran under 10% CPU for the last 14 days?
Summarize open critical findings for production as a dashboard
```

Ask for an output shape, such as a dashboard, a report, or a table, in words. The `#` picker selects connections and chat destinations only, not output types.

A channel or space you pick with `#` only tells CloudThinker which one you mean. Picking it sends nothing: say what you want in words, such as "post the summary there".

## What the / menu shows

Type `/` in the CloudThinker chat box to open the menu. It has two groups, and typing after the `/` filters both.

| Group | What it contains |
| --- | --- |
| **Actions** | Controls for the current chat, listed below |
| **Skills** | Your workspace's enabled [skills](/guide/skills/overview) (packaged procedures an agent follows), then the built-in skills you can start by name. Skills you used recently sort first |

| Action | What it does |
| --- | --- |
| **Compact** | Summarizes the chat to free context. The summary is a model call, so it uses [credits](/guide/billing/usage) |
| **Side chat** | Asks a quick side question while this chat keeps running. It's a model call, so it uses credits too |
| **Context** | Shows how full the context window is |
| **Model** | Switches the model for this chat. The model's tier sets its [credit multiplier](/guide/billing/usage#what-makes-a-run-cost-more) |
| **Approval** | Sets the [approval mode](/guide/approvals/approval-mode) for this chat |
| **Attach files** | Adds files or images to the message |
| **Connection** | Opens a list of your connections and inserts the one you pick as a `#connection` token in your message. Same result as typing `#` |
| **Resume chat** | Continues a recent chat |
| **New chat** | Starts a fresh conversation. Shown inside an existing chat |
| **Rename** | Renames this chat |
| **Stop** | Stops the running reply. Shown while CloudThinker is answering |

## Built-in skills

You can start these built-in skills by name from the `/` menu in every workspace. A workspace skill with the same name takes its place.

### Setup helpers

These interview you or check your setup, then create or propose something.

| Skill | What it does |
| --- | --- |
| `/creating-agent` | Helps design a new custom agent |
| `/creating-skill` | Saves a reusable skill, runbook, or procedure |
| `/creating-automation` | Creates an [automation](/guide/automation/automations) that runs a prompt on a schedule or an event |
| `/creating-review-custom-section` | Adds a custom section to [Review](/guide/code-review/overview) summaries |
| `/creating-policy` | Writes, changes, or relaxes an [approval rule](/guide/approvals/rules), or reviews your rules |
| `/import-runbooks` | Turns pasted runbooks into workspace runbooks |
| `/oncall-setup` | Walks an admin through on-call sources, schedule, and team process |
| `/recap` | Sums up the chat since the last recap in 1 to 3 sentences |

### Cloud analysis skills

CloudThinker runs these against the workspace's connected cloud accounts, so connect at least one first, and add `#connection` when you want one account.

| Skill | What it does |
| --- | --- |
| `/resource-rightsizing-analysis` | Finds underused resources to downsize |
| `/automated-backup-strategy` | Reviews backup schedules and retention |
| `/monitoring-alerting-setup` | Plans monitoring and alerts for key metrics |
| `/security-configuration-audit` | Reviews access controls and encryption settings |
| `/cost-allocation-tagging` | Sets up consistent cost allocation tags |

## Run a skill

<Steps>
  <Step title="Type / and pick the skill">
    Type `/` in the chat box, keep typing to filter, and select the skill. The `/name` token stays in your message.
  </Step>
  <Step title="Add context and send">
    Type anything extra after the token, then send:

    ```text
    /security-configuration-audit focus on the production AWS account
    ```

    **Success state:** CloudThinker loads the skill and follows its procedure for the context you added.
  </Step>
</Steps>

To save an instruction your team repeats, make it a [custom skill](/guide/skills/custom-skills). Once it's enabled, it shows in the `/` menu for everyone in the workspace.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The / menu shows Nothing matches">
    No skill matches the text after the `/`, so **Enter** sends your message as typed. Clear the filter, or check the skill's name on **Settings → Workspace → Skills**.
  </Accordion>
  <Accordion title="A skill I created is missing from the / menu">
    The menu lists enabled skills only. Open **Settings → Workspace → Skills** and check that the skill shows **Enabled**.
  </Accordion>
</AccordionGroup>
