Use **Review → Settings → Repositories** to choose what runs on each repository. Search your connected repositories and adjust the features on each one.

## Prerequisites

- [Review is set up](/guide/code-review/setup), and your Git connection can access the repositories you want to manage.
- You're a workspace **Admin** to change repository settings. Developers and Viewers can inspect the list. See [roles and permissions](/guide/security/roles).
- Codebase Atlas and Learnings controls appear when those features are available for your workspace and provider.

## Find a repository

Open **Review → Settings** and find **Repositories**. When the workspace has more than 10 repositories, a search box and filters appear above the table. Search by repository name, then narrow the list:

| Filter | Choices |
|---|---|
| Status (**All statuses**) | **Ready**, **Setting up**, **Needs attention** (failed setup or lost provider access) or **Not set up** |
| Review (**All review states**) | **On** or **Off** |
| Learnings (**All learning schedules**) | **Off**, **Weekly** or **Monthly** |

If nothing matches, click **Show all repositories** to clear the search and filters. Use the page controls to browse a longer list.

## Add a repository

<Steps>
  <Step title="Open the repository picker">
    Click **Add repository** in **Review → Settings → Repositories**.
  </Step>
  <Step title="Choose a repository your connection can access">
    Select one or more repositories, then click **Add**, which shows your selection count. Already configured repositories are marked **Added**.

    If a repository is missing, check the Git connection's access first. See [provider authentication](/guide/code-review/provider-auth).
  </Step>
  <Step title="Wait for setup">
    The repository shows **Setting up**, and its **Enabled** switch stays locked until setup finishes. Wait for setup to finish before changing its features.

    **Success state:** the repository appears in the table with an available **Enabled** switch.
  </Step>
</Steps>

Repositories created later in your Git provider need to be added here too. Adding a repository to the provider alone does not add it to Review.

## Choose what runs

Each ready repository has controls for its available features. Changes save when you use the control; there is no separate page-wide save action.

| Control | Choices and behavior |
|---|---|
| **Enabled** | Turn automatic reviews on or off for the repository |
| **Codebase Atlas branch** | Choose the branch the daily map follows, or **Off** to stop the map |
| **Learnings** | Choose **Off**, **Weekly** or **Monthly** for learning from resolved findings |

The **Codebase Atlas branch** column shows the branch followed by an enabled map. Click it to choose another branch. This branch setting controls the daily map; [review filters](/guide/code-review/setup#filter-which-prs-get-reviewed) separately decide which pull or merge requests get reviewed.

Open **Review → Codebase Atlas**, then select your repository. See [Codebase Atlas](/guide/code-review/codebase-atlas) for navigation and map details.

<Note>
  Codebase Atlas needs Review to be on. Turning Review off also turns off its daily Atlas map. Turning Review back on does not restore the map automatically: enable the daily map again.
</Note>

[Learnings](/guide/code-review/learnings) keeps its selected schedule while Review is off, but runs pause until Review is on again. To change that saved schedule, turn Review on first, then choose **Off**, **Weekly** or **Monthly** in the Learnings column.

## Map every repository on a page

To turn the daily map on or off for every repository on the current page, open the menu next to the **Codebase Atlas branch** column heading and click **Map all** or **Map none**. Each item shows how many repositories it changes. **Map all** skips repositories that are still setting up or have Review off.

## Use repository actions

Open a repository's actions menu (⋯) for these tasks:

| Action | What to do |
|---|---|
| **Configure filters** | Include or exclude pull requests by author, target branch or label. Follow [review filters](/guide/code-review/setup#filter-which-prs-get-reviewed) |
| **Learning sources** | Inspect convention files Review reads. See [convention files](/guide/code-review/learnings#add-your-own-convention-files) |
| **Customize for this repository** | Open its summary layout settings. See [Review Personalization](/guide/code-review/customizations) |
| **Run Code Audit** | Open a source security audit for this repository, when available and permitted. See [Code Audit](/guide/security/code-audit) |
| **Open Codebase Atlas** | Open the repository's map. Shown when its daily map is on. See [Codebase Atlas](/guide/code-review/codebase-atlas) |
| **Remove repository** | Remove it from this Review setup; confirm with **Remove**. You can add it again later |

Some actions appear only after repository setup finishes. To pause reviews while keeping the repository configured, use its **Enabled** switch.

## Troubleshooting

<AccordionGroup>
  <Accordion title="A feature says Setting up or Not set up">
    **Cause:** the repository has not finished cloning, or setup failed or was cancelled.

    **Check:** inspect its setup status under the repository name. **Setup failed** or **Setup cancelled** is followed by the clone error when there is one.

    **Fix:** correct provider access if needed, then click **Retry**. For a repository that stays on **Setting up**, click **Cancel**, confirm **Cancel clone**, then retry.
  </Accordion>
  <Accordion title="A repository lost provider access">
    **Cause:** the provider connection no longer has access to it.

    **Check:** filter the list by **Needs attention**, then confirm the repository is still granted to your connected account or app.

    **Fix:** restore provider access. Use **Update token** when offered if the token expired or changed. See [authentication problems](/guide/code-review/troubleshooting).
  </Accordion>
  <Accordion title="The Codebase Atlas branch can't be changed">
    **Cause:** Review is off for this repository. The control reads "Turn on Review for this repository to choose a Codebase Atlas branch."

    **Fix:** turn Review on, then pick a branch in the **Codebase Atlas branch** column. A previous daily map does not resume automatically.
  </Accordion>
</AccordionGroup>
