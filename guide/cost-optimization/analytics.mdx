Cost Explorer explains completed-month spend for one selected Optimize connection. It groups billing evidence by service and keeps each provider's currency visible.

## Read the chart

Choose **6 months** or **12 months** to change the completed-month range. The stacked chart shows each service's spend over time, and **Last full month** shows the total for the latest completed month.

Cost Explorer excludes the current partial month. Use [Optimize Overview](/guide/cost-optimization/overview) for current-month spend and forecast.

## Compare services

The **Breakdown by service** table uses the latest completed month in the selected range.

| Value | Meaning |
|---|---|
| Service | Provider billing service name |
| Spend | Finalized spend for the latest completed month |
| Share | Percentage of that month's total spend |
| Month-over-month | Change from the preceding completed month when both months have data |

The chart and table use the same selected connection and range. They do not combine multiple cloud accounts.

## Export the view

Select **Export** to download the current Cost Explorer data as CSV. The export uses the same connection, range, service grouping, and currency shown on the page.

The button remains unavailable until Cost Explorer has completed-month data to export.

## Currency and freshness

| Provider | Currency rule |
|---|---|
| AWS | Stored and displayed in USD |
| GCP | Normalized to USD during ingestion |
| Azure | Kept in the billing scope's currency |

Provider billing data can arrive after usage occurs. Optimize preserves the last successful evidence and shows refresh health when new evidence is delayed or blocked.

## Missing data

| State | What happens |
|---|---|
| No cloud connection | Optimize asks you to connect AWS, GCP, or Azure |
| Billing source missing | GCP or Azure setup appears before cost pages |
| No completed month | Cost Explorer shows **No cost history yet** |
| Load failure | The page keeps existing data safe and offers **Try again** |
