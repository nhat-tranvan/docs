Optimize turns saved billing data into ranked cost decisions for AWS, GCP, and Azure. Select one cloud connection to see what needs attention now, then open a focused page for deeper work.

## How it works

1. **Connect a cloud account.** Add an [AWS](/guide/connections/aws), [GCP](/guide/connections/gcp), or [Azure](/guide/connections/azure) connection with billing read access.
2. **Choose the billing source.** AWS uses the connected account. GCP and Azure ask you to select a readable billing scope when needed.
3. **Run the first scan.** Optimize reads billing evidence, calculates Cost Health, and asks an agent to verify savings findings with read-only cloud commands.
4. **Review the account snapshot.** Overview ranks the most useful actions, services, and anomalies without hiding missing or stale evidence.
5. **Open the owning page.** Use Cost Explorer, Findings, Anomalies, or Reports for the complete workflow.

The scan is read-only. A missing billing permission or billing source blocks Optimize for that connection, but it does not disconnect the cloud account.

## What Overview shows

| Area | What it answers | Next step |
|---|---|---|
| Cost Health | How efficiently the account uses commitments, resources, and allocation data | Run or wait for the first scan if the score is preparing |
| Spend and forecast | What the current month has cost so far and where it may finish | Open [Cost Explorer](/guide/cost-optimization/analytics) for completed-month history |
| Potential monthly savings | The overlapping upper bound across open actionable findings | Open [Findings](/guide/cost-optimization/recommendations) to prioritize and settle work |
| Top actions | The three highest-value open findings | Open a finding to review its evidence and status |
| Top cost drivers | The three largest services from the last completed month | Open Cost Explorer for service shares and trends |
| Recent anomalies | The three largest unreviewed cost changes from the last 30 days | Open [Anomalies](/guide/cost-optimization/anomalies) to review evidence or investigate |

Overview totals cover the selected account even when it shows only the top three rows. A missing Cost Health score appears as **Preparing**, not zero. Azure can show spend and actions while Cost Health is unavailable.

## Optimize destinations

| Destination | Use it to |
|---|---|
| Overview | Decide what needs attention now |
| Cost Explorer | Compare service spend across 6 or 12 completed months and export CSV |
| Findings | Move verified savings findings through their workflow and record dispositions |
| Anomalies | Review finalized daily cost changes and investigate them with Anna |
| Reports | Generate or schedule evidence-grounded cost reports |

The selected account stays in scope as you move between these destinations. Reports can instead use all connected Optimize accounts, with each account and currency kept separate.

## Provider behavior

| Provider | Billing evidence | Currency |
|---|---|---|
| AWS | Cost Explorer | USD |
| GCP | Cloud Billing Standard export in BigQuery | Normalized to USD during ingestion |
| Azure | Cost Management subscription or billing scope | Billing scope currency |

Provider billing evidence can arrive late. Optimize shows the last successful evidence and its freshness instead of treating a delayed refresh as zero spend.
