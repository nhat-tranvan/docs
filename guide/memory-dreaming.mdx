Dreaming is a nightly run that keeps [workspace memory](/guide/memory) short, current, and consistent. It reads the day's conversations, adds what is new, merges duplicates, and removes memory and [custom skills](/guide/skills/custom-skills) that no longer hold.

## Why Dreaming

- **Clean memory without upkeep.** Agents save facts as they work. Dreaming merges the overlaps and drops what newer conversations contradict.
- **Nothing slips through.** It reads every conversation in its window, and anything it can't finish is read first the next night.
- **Leaner skills.** It merges and retires redundant custom skills, within limits you set.
- **Bounded by design.** [Connections](/guide/connections/overview) stay read-only, and conversation and connection notes are never changed.

## Prerequisites

- The workspace Admin role to change settings or click **Run now**. Other members see the settings read-only.
- Credits in the workspace. Dreaming bills at the Pro rate and can't use the free daily pool. See [Usage](/guide/billing/usage).

## Turn it on

Dreaming is on by default for every workspace.

<Steps>
  <Step title="Open Memory settings">
    Open workspace **Settings**, then select **Memory** under **Agent Configuration**.
  </Step>
  <Step title="Set the switch">
    Turn **Consolidate memory nightly (Dreaming)** on or off.
  </Step>
</Steps>

**Success state:** the card shows **Next run** with a date and time, followed by "Runs start within 45 minutes of that time."

## How a run works

Runs start at 00:30 UTC, spread over the next 45 minutes across workspaces. Only one run per workspace happens at a time.

1. **Gather.** Dreaming lists every conversation updated in the activity window, plus any the previous run didn't finish.
2. **Read.** Read-only readers digest batches of conversations in parallel and report what is worth keeping.
3. **Consolidate.** Dreaming compares the digests with existing memory and custom skills, then adds, edits, merges, or deletes.
4. **Finalize.** Dreaming writes a summary to **Run history**. Near the time limit it stops reading and finalizes with what it has.
5. **Carry over.** Conversations it didn't read to the end go first on the next run.

### What Dreaming reads and changes

| Area | What Dreaming does |
|---|---|
| Chats, rooms, Memory chats, headless chats, and deep dives | Reads every one updated in the activity window |
| Scheduled tasks and [autonomous agent](/guide/automation/autonomous-agents) runs | Reads them when **Include automated conversations** is on |
| Memory items | Adds, edits, merges, and deletes |
| Custom skills | Creates, updates, and merges. Deletes up to 10 per run when allowed |
| Conversation notes and connection notes | Never changes them. A run that touches them is rolled back and publishes nothing |
| Connections | Reads only |

## Customize Dreaming

Expand **Customize** on the Dreaming card.

| Option | Default | What it does |
|---|---|---|
| **Activity window** | **Last 24 hours** | How far back Dreaming reads: **Last 24 hours**, **Last 3 days**, or **Last 7 days** |
| **Include automated conversations** | On | Also reads scheduled tasks and CloudKeepers (autonomous agent) runs, not only chats |
| **Allow Dreaming to delete redundant custom skills** | On | Off keeps every skill. Dreaming can still create and update them |
| **Focus instructions** | Empty | Up to 1,000 characters on what to watch for. Click **Save focus** to apply |

<Frame>
  <img src="/images/memory/06-dreaming-customize.jpg" alt="Customize section with the activity window choices, the automated conversations and skill deletion switches, and the Focus instructions box" />
</Frame>

A focus instruction that works well names a topic and an outcome:

```text
Track cost-saving decisions and name the owner.
Keep one item per AWS account with its region and exemptions.
```

Focus instructions never override the safety rules: connections stay read-only and protected notes stay untouched.

## Run Dreaming now

Use this after a big import or a busy day, instead of waiting for the night.

<Steps>
  <Step title="Start the run">
    On the Dreaming card, click **Run now**.
  </Step>
  <Step title="Confirm the cost">
    Click **Run at Pro rate**. The run uses workspace credits at the Pro rate, the same as the nightly run.
  </Step>
</Steps>

**Success state:** the button shows **Running…**, and the run appears in **Run history** as **Manual by** your name when it finishes.

If the run doesn't start, the dialog shows **Dreaming did not start** with one of these reasons:

| Message | Fix |
|---|---|
| Dreaming is already running for this workspace. | Wait for the current run to finish |
| There are no conversations in the activity window… | Widen **Activity window** under **Customize**, or chat first |
| This workspace has no credits left to run Dreaming. | Add credits. The free daily pool doesn't count |
| Nightly consolidation is off for this workspace… | Turn the switch on first |

## Read the run history

**Run history** lists the latest 20 runs with status, start time, trigger (**Scheduled** or **Manual**), and duration. Click a run to expand it.

<Frame>
  <img src="/images/memory/07-run-history.jpg" alt="Run history with succeeded, skipped, and failed runs, one expanded to show conversations read and the run summary" />
</Frame>

| Status | Meaning |
|---|---|
| **Succeeded** | Finished. Shows conversations read, skills deleted, and the summary |
| **Skipped** | Didn't start work. The reason is shown, for example **No conversations in the activity window** or **Another run was already going** |
| **Failed** | Stopped early. Edits already made are kept; skill deletes are not applied. The row shows a run ID an instance admin can look up in the server logs |
| **Queued** or **Running** | Waiting or in progress |

## Limits

| Item | Value |
|---|---|
| Time limit | One hour per run |
| Billing | Pro rate, from workspace credits |
| Carry-over | Up to 200 unread conversations, kept for up to 7 days |
| Failed runs | Not retried. The next night picks up from the carry-over |

## Troubleshooting

<AccordionGroup>
  <Accordion title="A run says Succeeded but memory didn't change">
    Dreaming only edits memory when conversations add something new. A quiet day can end with no edits, and the run summary says so.
  </Accordion>
  <Accordion title="An item I edited by hand was merged or deleted">
    Dreaming can merge or delete any item, including one you edited, when a newer conversation shows it's outdated. To pin a fact, restate it in chat or add a focus instruction. Deleted items keep a copy in the revision history.
  </Accordion>
  <Accordion title="The card says an instance admin turned off Dreaming">
    Dreaming or workspace memory is switched off for the whole instance. The switch and **Run now** stay locked until an instance admin turns it back on.
  </Accordion>
  <Accordion title="Run now is greyed out">
    Either you aren't a workspace Admin, the nightly switch is off, or a run is already in progress.
  </Accordion>
</AccordionGroup>
