`cloudthinker` puts your workspace in the terminal: it runs the CloudThinker coding agent on your own machine, and sends prompts to Anna from any script. It is one binary with no runtime to install.

## What you can do

| Capability | Description |
| --- | --- |
| Run the coding agent | `cloudthinker` starts an agent session in the current directory. It edits files and runs commands locally, and reaches your cloud only through the CloudThinker Sandbox with your workspace [connections](/guide/connections/overview) |
| Send headless prompts | `cloudthinker chat -p "..."` submits one prompt to Anna and prints her answer on stdout, ready to pipe |
| Follow long runs | Submit without waiting, list recent runs, and collect an answer later from any machine |
| Check a review | Read the status, verdict, and findings of a [Review](/guide/code-review/overview) on a merge request or pull request |
| Authenticate scripts | Print a short-lived bearer token for a tool that needs its own credential |

## Install

```bash
curl -fsSL https://cloudthinker.ai/install.sh | sh
```

The installer detects your platform, drops the `cloudthinker` binary in `~/.local/bin`, and adds that directory to your `PATH`. Open a new shell, then check the install:

```bash
cloudthinker --version
```

macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64) are supported. Update in place at any time with `cloudthinker update`.

## First session

<Steps>
  <Step title="Log in through your browser">
    ```bash
    cloudthinker login
    ```

    The CLI prints a consent URL and opens it. Approve the request, pick a workspace if your account has more than one, and the terminal confirms which workspace it stored.

    <Frame>
      <img src="/images/cli/login-consent-url.png" alt="cloudthinker login printing the consent URL" />
    </Frame>
  </Step>

  <Step title="Confirm who you are">
    ```bash
    cloudthinker whoami
    ```

    **Success state:** one line with the host, your email, and the active workspace.
  </Step>

  <Step title="Run the agent, or ask Anna">
    ```bash
    cloudthinker                                   # agent session in this directory
    cloudthinker chat -p "Check production health" # one headless prompt
    ```

    The bare command runs the [Agent CLI](/guide/cli/agent). The first run downloads the agent build that matches your CLI version.
  </Step>
</Steps>

## Command surface

| Command | Purpose |
| --- | --- |
| `cloudthinker` | Run the local coding agent in the current directory |
| `cloudthinker login` | Log in through the browser, or with a device code |
| `cloudthinker logout` | Clear stored credentials for a workspace, or for every workspace |
| `cloudthinker whoami` | Show the live account and workspace behind the stored credential |
| `cloudthinker auth token` | Print the current access token for a tool that needs a bearer |
| `cloudthinker chat` | Send a headless prompt, check a run, or list recent runs |
| `cloudthinker review` | Read a tracked review by its merge-request URL |
| `cloudthinker agent` | Run the local coding agent, with arguments passed through. See [Agent CLI](/guide/cli/agent) |
| `cloudthinker update` | Install the latest release |
