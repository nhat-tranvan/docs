**Preview** — The CloudThinker MCP server is in early access. The tool surface and transport options may change before general availability. [Contact us](https://cloudthinker.io/contact) to join the preview.
</Note>

CloudThinker can act as a [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server — MCP is an open standard that lets AI apps use external tools — so an MCP-compatible AI client can call CloudThinker tools and read CloudThinker data using your workspace's authenticated context. This is the inverse of the existing [MCP connection](/guide/connections/mcp), which lets CloudThinker agents call _your_ external MCP servers.

## What it enables

| Capability | Description |
| --- | --- |
| Cloud operations in your IDE | Query your cloud inventory and costs from Cursor, Claude Desktop, or any MCP-compatible client |
| Use your connections | Reach the databases, Kubernetes clusters, and observability tools you already connected to CloudThinker |
| Run skills remotely | Invoke your workspace [skills](/guide/skills/overview) from an MCP-compatible host |
| Shared context | Read the same recommendations, dashboards, and incident history the web console shows |

## Get access

The MCP server is not yet generally available, so the exact tool list, transport options, and authentication setup are shared with preview participants rather than published here. [Contact us](https://cloudthinker.io/contact) to join the preview and receive the current client configuration for your workspace.

To use external MCP servers as agent tools today, set up an [MCP connection](/guide/connections/mcp) — that direction is generally available.
