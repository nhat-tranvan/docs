Tool tags tell an agent what kind of output to produce. Add the tag directly after the agent mention — see [CloudThinker Language](/guide/language) for the full `@agent #tool instruction` syntax and the `#` picker that inserts these tags.

## #visualize

`#visualize` produces a standalone chart from data in the conversation, rendered directly in the chat. For a chart inside a broader view, ask for a `#dashboard` or `#report` instead — charts are components of both [artifact types](/guide/artifacts/overview).

| Ask for | Prompt |
|---------|--------|
| Spend breakdown | `@alex #visualize spending by service over the last 6 months` |
| Latency trend | `@tony #visualize p95 query latency for the orders database this week` |

## #dashboard

`#dashboard` produces an interactive dashboard with live metrics from your [connections](/guide/connections/overview). It opens in the conversation's dashboard panel, and you can filter views, go fullscreen, and export to PDF. Dashboards are saved as [artifacts](/guide/artifacts/overview) for sharing and later reference.

  <img src="/images/capabilities-dashboard.png" alt="Interactive cost dashboard artifact with filters and export controls" />
</Frame>

| Ask for | Prompt |
|---------|--------|
| Cost trends | `@alex #dashboard monthly cost trends by service with forecast` |
| Database performance | `@tony #dashboard performance metrics for all production RDS instances` |
| Cluster health | `@kai #dashboard cluster resource utilization by namespace` |

## #report

`#report` produces an analysis document with an executive summary, detailed findings, and prioritized recommendations. Reports open in the conversation's report panel and download as PDFs.

| Ask for | Prompt |
|---------|--------|
| Compliance assessment | `@oliver #report SOC 2 control gaps with evidence` |
| Waste detection | `@alex #report unused EBS volumes across all regions` |
| Slow queries | `@tony #report top slow queries in production RDS over the past 7 days` |

## #tabular_engine

`#tabular_engine` runs SQL analysis over a tabular file you attach to the conversation — a CSV export or a spreadsheet. Attach the file, then ask your question; the agent queries the imported table and answers from the results.

| Ask for | Prompt |
|---------|--------|
| Cost export analysis | `@alex #tabular_engine total spend by team in the attached cost export` |
| Inventory filter | `@tony #tabular_engine instances in the attached list with CPU below 20%` |

## #slide

`#slide` builds a slide deck from the conversation's findings. Run the analysis first, then ask for the deck that summarizes it.

| Ask for | Prompt |
|---------|--------|
| Executive summary | `@anna #slide executive summary of this quarter's cost review` |
| Audit readout | `@oliver #slide key findings from the security audit above` |

## #alert

`#alert` produces a monitoring notification triggered on the condition you define. An alert appears as a card with a title, summary, and severity — Critical, High, Medium, or Low — and can be routed to your configured destinations in [Notifications](/guide/notifications).

| Ask for | Prompt |
|---------|--------|
| Spend threshold | `@alex #alert daily spend exceeds $5,000` |
| Pod failures | `@kai #alert on pod OOMKilled events in production` |
| Security changes | `@oliver #alert on security group changes` |

## #schedule

`#schedule` creates a scheduled or recurring run of the instruction instead of executing it once now. For stored instructions with schedule, webhook, or repository triggers, see [Automations](/guide/automation/automations).

| Ask for | Prompt |
|---------|--------|
| Weekly report | `@alex #schedule a weekly cost summary every Monday morning` |
| Nightly check | `@kai #schedule a nightly check for pods stuck in CrashLoopBackOff` |

## #search

`#search` researches the web and combines what it finds with your infrastructure data. Use it for information that lives outside your connections — vendor announcements, security advisories, pricing changes.

| Ask for | Prompt |
|---------|--------|
| Security advisories | `@oliver #search recent CVEs affecting nginx 1.25` |
| Pricing check | `@alex #search current Graviton instance pricing in us-east-1` |

## #search-knowledge-base

`#search-knowledge-base` searches every [knowledge base](/guide/knowledge) in the workspace and answers from the matching documents. Use it to pull internal runbooks — step-by-step operational procedures — policies, and standards into a conversation. To search one collection only, tag its name instead — see [mention a knowledge base](/guide/language#mention-a-knowledge-base).

| Ask for | Prompt |
|---------|--------|
| Policy lookup | `@alex #search-knowledge-base cloud governance policies` |
| Runbook lookup | `@kai #search-knowledge-base incident runbook for node failures` |

## #recommend

`#recommend` produces actionable recommendations prioritized by impact, with effort estimates and implementation steps. It has no picker entry — type it by hand right after the mention. Use it when you want the agent to tell you what to change, not just what it found.

| Ask for | Prompt |
|---------|--------|
| Right-sizing | `@alex #recommend right-size EC2 instances in us-east-1 over the past 30 days` |
| Least privilege | `@oliver #recommend least-privilege IAM policy changes` |
| Scaling policy | `@kai #recommend HPA policies for variable workloads` |

## Image generation

Agents can also create images — no tool tag needed. Ask in plain language for a diagram concept, a launch graphic, or a mockup, and your first request produces three concept images in a grid. The **Images** tab of the [side panel](/guide/agents-canvas) opens automatically to show them.

To refine a concept:

1. Click an image to open it, then choose **Select area**.
2. Draw up to eight rectangles over the parts to change, adding a short note to each.
3. Click **Send** — the agent returns exactly one edited image.

**Set as workspace reference** saves an approved image as your team's visual direction: later image requests follow it automatically, and your current instructions win on any conflict. Generated images also appear with the conversation's files and can be saved to [Artifacts](/guide/artifacts/overview).

<Note>
Image generation spends your workspace credit balance — the free daily allowance never covers it — and larger, print-quality sizes cost more. A failed or incomplete request is not charged. See [Usage](/guide/billing/usage).
</Note>

## Combining tags and shaping output

Combine tags when you want more than one output from a single request, and add detailed instructions to shape the result:

```text
@alex #dashboard #recommend AWS costs for the last 30 days
  - Filter by production accounts only
  - Show daily cost breakdown
  - Include cost optimization recommendations
```

For multi-agent coordination, mention several agents or ask Anna to lead:

```text
@anna coordinate security review:
  @oliver audit security groups and IAM
  @alex check for public resources
  @kai review Kubernetes RBAC
```
