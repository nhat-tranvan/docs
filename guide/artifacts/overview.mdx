An artifact is a saved, versioned output that CloudThinker builds in a conversation: a report, a dashboard, or a generated file. You ask in plain language, CloudThinker queries your [connections](/guide/connections/overview), and the result lands in the **Artifacts** gallery where your workspace can open, download, and share it.

## Prerequisites

- At least one [connection](/guide/connections/overview) with the data you want in the artifact (for example AWS for cost, a database for query performance)
- The **Developer** or **Admin** [workspace role](/guide/workspace-users) to create share links. **Viewers** can open and download artifacts.

## Artifact types

| Type | What it is | Where it shows |
|---|---|---|
| **Report** | A written analysis with tables, charts, findings, and recommendations | **Visuals** tab |
| **Dashboard** | A view of related metrics and charts on one page | **Visuals** tab |
| **File** | A file CloudThinker generated in a conversation (for example a CSV or script) that you chose to keep | **Files** tab |

Every report and dashboard is stored as versions. When CloudThinker updates one, it publishes a new version and the old ones stay unchanged.

## Create an artifact

<Steps>
  <Step title="Ask for the output shape in words">
    Start a conversation and say what you want and in which form. You don't need any special syntax.

    ```text
    Build a dashboard of AWS spend by service for the last 30 days, with the top 10 cost drivers and month-over-month change.
    Write a report on Aurora cluster prod-aurora: p50, p95 and p99 query latency over the past 7 days, split by reads and writes, with queries over 200 ms called out.
    ```

    **Success state:** CloudThinker replies with an artifact card in the conversation. Click it to open the artifact.
  </Step>
  <Step title="Refine it in the same conversation">
    Ask for changes as follow-ups, such as "add a breakdown by the `team` tag" or "compare against the previous 30 days".

    **Success state:** CloudThinker publishes a new version. If you already have the artifact open, a **Version N is available** notice appears. The view never switches versions on its own.
  </Step>
  <Step title="Keep a generated file (optional)">
    When CloudThinker produces a file in the conversation, click **Save to artifacts** on its file card. Click it again (**Remove from artifacts**) to take it back out.

    **Success state:** the file appears under the **Files** tab in the gallery.
  </Step>
</Steps>

<Tip>
Add structure when you need specific breakdowns: name the time range, the grouping (service, account, tag), and the comparison period. Vague requests get sensible defaults, specific ones get the exact cut you need.
</Tip>

## Find artifacts in the gallery

Open **Workspace Settings → Artifacts** (or go to `/artifacts`). The gallery has three tabs, each with a count.

| Control | Options |
|---|---|
| Tabs | **All**, **Visuals** (reports and dashboards), **Files** |
| Search | **Search artifacts** filters the list as you type |
| Filter | **Sharing** (**Shared** or **Private**) and **Category** |
| Sort | **Newest**, **Recently updated**, **Name A–Z** |
| View | Grid view or table view |

Open any card to see the artifact on its own page. The **More actions** (⋯) menu there has **Download PDF** and **Open conversation**, which takes you back to the chat that built it.

## Snapshot and live data

A report or dashboard is published with a snapshot: the data as of the moment that version was published. The pill at the top of the artifact page tells you which data you're seeing.

| Pill | Meaning | What you can do |
|---|---|---|
| **Snapshot** | You see the published data, with its "Data from" time | Click **Go live**, or change a filter, to run the artifact's queries against current data |
| **Live** | The queries ran against your connections just now | Click **Refresh** to run them again |
| **Paused** | Live data stopped while you were away | Click **Resume** |
| **Refresh failed** | The last run failed, so you see the last good data | Click **Retry** |

Live data runs only on the artifact's current version, only on the connections it was published with, and needs a paid [plan](/guide/billing/pricing). If your role can't run live queries, the pill says so and you keep the snapshot.

## Share an artifact

Click **Share** on the artifact's card or page, then **Create share link**. Anyone with the link can view it without signing in. [Sharing](/guide/sharing) covers what viewers see and how to revoke a link.

## Rerun on a schedule

An [automation](/guide/automation/automations) can run the same request on a schedule. Each run is a new conversation, so it creates a new artifact rather than updating an existing one.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The artifact is missing data or shows an empty chart">
    **Cause:** CloudThinker couldn't read that source. **Check:** the connection exists and is **Connected** in [Connections](/guide/connections/overview), and the time range has data. **Fix:** reconnect or widen the range, then ask CloudThinker to update the artifact.
  </Accordion>
  <Accordion title="Go live doesn't appear or the pill stays on Snapshot">
    **Cause:** the workspace is on the Free plan, your role can't run live queries, or the artifact only has a published snapshot. **Check:** the message under the pill names the reason. **Fix:** upgrade the [plan](/guide/billing/pricing) or ask an Admin about your role.
  </Accordion>
  <Accordion title="A generated file isn't in the gallery">
    **Cause:** generated files stay in the conversation until you keep them. **Fix:** open the conversation and click **Save to artifacts** on the file card.
  </Accordion>
  <Accordion title="Download PDF fails">
    **Cause:** a print error or too many PDF requests in a short time. **Fix:** wait a minute, then click **Print failed. Retry** in the **More actions** menu.
  </Accordion>
</AccordionGroup>
