Find your symptom below, then open the linked page. Each linked section explains the cause, how to check it, and the fix.

## Sign-in, SSO and members

| Symptom | Where to fix it |
|---|---|
| A user can't sign in after you required SSO | [SSO](/guide/security/sso#troubleshooting) |
| Your IdP reports an invalid ACS or reply URL, or an audience mismatch | [SAML SSO](/guide/security/sso-saml#troubleshooting) |
| "Redirect URI mismatch", Issuer Match or Discovery Reachable fails | [OIDC SSO](/guide/security/sso-oidc#troubleshooting) |
| A user wasn't provisioned, or someone who left can still sign in | [SCIM](/guide/security/scim#troubleshooting) |
| The invite button says Seats full, or you can't remove a member | [Organization](/guide/organization#troubleshooting) |
| A teammate can't see a workspace, or the person isn't in the Add Member list | [Workspaces](/guide/workspaces#troubleshooting) and [Workspace members](/guide/workspace-users#troubleshooting) |
| A Viewer can't type in the chat | [Workspace members](/guide/workspace-users#troubleshooting) |

## Connections, chat and commands

| Symptom | Where to fix it |
|---|---|
| An agent can't find a connection you added | [Workspaces](/guide/workspaces#troubleshooting) |
| A connection won't verify or loses access | The page for that connection under [Connections](/guide/connections/overview) |
| A command doesn't expand, or the `/` menu shows Nothing matches | [Commands](/guide/commands#troubleshooting) |
| A credential name is rejected, or you can't see the `$` picker | [Credentials](/guide/credentials#troubleshooting) |
| The Slack bot doesn't reply, or answers with the wrong account | [Slack](/guide/slack-integration#troubleshooting) |
| The Teams bot doesn't reply, or a team isn't linked to a workspace | [Microsoft Teams](/guide/teams-integration#troubleshooting) |

## Approvals and automations

| Symptom | Where to fix it |
|---|---|
| A write still asks you even though a Rule allows it | [Approvals](/guide/approvals/overview#troubleshooting) |
| You don't see the Approve button | [Approvers](/guide/approvals/approvers#troubleshooting) |
| A scheduled automation refused a write instead of asking | [Approval mode](/guide/approvals/approval-mode#faq) |
| A run sits on Required Approval, or an automation turned itself off | [Autonomous operations](/guide/automation/autonomous-agents#troubleshooting) |
| The run succeeded but nothing posted in Slack | [Automation quickstart](/guide/automation/quickstart#troubleshooting) |

## Products

| Symptom | Where to fix it |
|---|---|
| Pulse shows No signals yet, or every alert opens its own cluster | [Resolve troubleshooting](/guide/incident/troubleshooting) |
| Incidents wait in Not started, or analysis failed | [Resolve troubleshooting](/guide/incident/troubleshooting) |
| A runbook command waits for approval or was blocked | [Resolve troubleshooting](/guide/incident/troubleshooting) |
| Review didn't post on a pull request, or provider auth fails | [Review troubleshooting](/guide/code-review/troubleshooting) |
| Optimize shows no cost data after a scan | [Optimize quickstart](/guide/cost-optimization/quickstart#troubleshooting) |
| A spike you can see in your cloud console isn't listed | [Anomalies](/guide/cost-optimization/anomalies#troubleshooting) |
| The findings total is $0 or doesn't match Overview | [Savings](/guide/cost-optimization/savings#troubleshooting) |
| Target ownership stays at Needs proof, or protected pages aren't tested | [Cyber quickstart](/guide/security/cyber-quickstart#troubleshooting) |
| A fixed Cyber finding came back, or Awaiting retest never clears | [Cyber findings](/guide/security/cyber-findings#troubleshooting) |
| Memory shows Not ready yet, or an edit says the item changed | [Memory](/guide/memory#troubleshooting) |

## Workers and the CLI

| Symptom | Where to fix it |
|---|---|
| The Worker shows Offline, or verification failed | [Workers](/guide/workers#troubleshooting) |

| `cloudthinker: command not found` | [CLI overview](/guide/cli/overview#troubleshooting) |
| A command says you are not logged in (exit code 3) | [CLI authentication](/guide/cli/authentication#troubleshooting) |
| A headless run exits with code 5, or the prompt is too long | [Headless chat](/guide/cli/headless-chat#troubleshooting) |
